# WCSNDM 线性 FLAG（0.25 · 更新 011）

更新 172 补充核验：HN1 八类谐波参数在普通 UTAU 线性 FLAG 及带标注的二／三／四段分区中通过 145 次真实模型合成、660 项检查；曲线／分区继承、优先级、零长度段和短音已验证。普通 UTAU 的经典二区不暴露独立分区 FLAG。详见 [HN 模式说明](wcsndm-hn.md)。

HN1（更新 172）支持 g、Mt、Rd、Mo、ME/QX、Mr、Mq、NA 的逐帧谐波控制，固定开关仍填 HN1；完整范围见 [HN 模式说明](wcsndm-hn.md)。

普通 UTAU、界•UTAU、谋•UTAU 均支持同一音符的多条线性 FLAG 曲线。本次内部更新 002 解除了普通 UTAU 原有的界面和渲染限制，对外版本维持 0.25。

## 使用

1. 选择普通 UTAU 模式和传统 UTAU 音源，使用配套 WCSNDM 0.0803 引擎。
2. 选中音符，点击“线性flag”，再点击“flag 包络”。
3. 在曲线通道右上角选择参数，单击加点、拖动调值；右键可输入数值或选择曲线形状。
4. 切换参数绘制另一条曲线，各参数独立保存并同时生效。播放、导出会使用这些曲线。

可编辑：g、Mt、Rd、Mo、ME、Mr、MH、Mq、Mf、Mb、Ab、Md、Mn、NA、RG、b、bh、MY。参数的声音作用仍取决于 WCSNDM 所选内核及其原有支持范围；b、bh 的编辑范围为声母区。

每条曲线只覆盖同名固定 FLAG，其他固定 FLAG 继续生效。关闭“线性flag”会停用曲线并恢复固定 FLAG，已画标点保留。支持撤销/重做、保存/读取和 UTAU 模式间切换。

普通 UTAU 不会因此开启四分区或分区 FLAG：第 14、15 个扩展参数仅使用空占位，第 16 个扩展参数传入曲线。曲线时间包含前置发声补偿。其他不支持 WCSNDM 曲线扩展的重采样器不保证生效。

加载 DiffSinger 音源后，界面自动切换为“DF线性FLAG / DF参数曲线”，继续使用 DF 专属参数；WCSNDM 曲线与 DF 曲线不会混发。

## 跨音符连续编辑（更新 011）

选中需要编辑的音符并开启“线性flag”，打开“flag 包络”。右键这两个 FLAG 按钮中的任一个，选择 **跨音符（连续绘制）**，再在曲线通道选择参数并按住左键绘制。右键菜单中的 **逐音符（控制点）** 可恢复原来的加点、拖点方式；软件会记住上次选择的模式。

连续模式作用于**当前轨道所有已开启 FLAG、且被笔划经过的音符**，不只作用于当前选中的音符。未开启 FLAG 的音符跳过；空隙可以起笔，左右均可绘制。重叠辅音区按同一绝对时间写入相同数值；b / bh 仍只编辑声母区。

松开鼠标提交整笔，Ctrl+Z 一次撤销；Esc 取消未提交的笔划。只替换当前参数划过的时间范围，保留其他时间和参数。范围边缘的旧曲线可能增加少量控制点以保持原形。保存、播放、导出继续使用原来的逐音符曲线格式。

## 验证

- `--smoke-flag-curve-mode [WCSNDM.exe]`：三个 UTAU 模式的启用、曲线编辑、重置、模式切换；传入引擎时检查普通 UTAU 和界模式的真实导出变化。
- `--smoke-classic-flag-ui [预览.png]`：普通 UTAU 的开关、曲线面板和双参数编辑。
- `juce/tests/flag_curve_smoke.py 编辑器.exe 音源目录 WCSNDM.exe 音节 utau`：真实波形的渐变、开关、曲线形状和多参数叠加。
- DiffSinger 参数命名隔离和原有回归检查。

- `--smoke-continuous-flag 输出目录`：DS / WCSNDM 连续绘制、菜单偏好、边界衔接、撤销保存、渲染参数和局部曲线保护。

## HN1 内核 FLAG（更新 171）

`HN1` 选择 HN-SEP 谐波＋LLSM 非谐波 Mel 实验内核，与 HF2/V1/V2 并列且互斥。裸 `HN`、`HN0`、`HN2` 不启用也不占用内核位置。它不是可绘制的线性参数。使用方式、内核优先级与谐波侧 FLAG 限制见 [HN 模式说明](wcsndm-hn.md)。
