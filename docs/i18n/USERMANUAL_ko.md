# HiFiShifter 사용자 매뉴얼

[简体中文](USERMANUAL.md) | [繁體中文](USERMANUAL_zh-TW.md) | [English](USERMANUAL_en.md) | [日本語](USERMANUAL_ja.md) | [한국어](USERMANUAL_ko.md)

HiFiShifter는 그래픽 보컬 편집 및 합성 도구입니다. 멀티트랙 오디오 클립 처리를 지원하며, 트랙 그룹 단위로 여러 보코더를 사용하여 보컬의 피치 보정 및 파라미터 조정을 수행하여 인간 VOCALOID 제작의 편집과 튜닝을 통합합니다.

## 1. 설치

사용자의 운영 체제 및 아키텍처에 맞는 HiFiShifter 설치 패키지를 다운로드하세요. OS별로 `Windows`, `macOS`, `Linux` 세 가지, 아키텍처별로 `x86_64`와 `arm64` 두 가지가 있습니다.

- Windows 버전은 NSIS 설치 프로그램(`installer`)과 포터블 압축 파일(`portable`) 두 가지를 제공합니다. 일반 사용자는 설치 프로그램 버전을 선택하여 설치하면 됩니다.  
  Windows 사용자로서 `x86_64`와 `arm64`의 차이를 모르신다면 `x86_64` 버전을 선택하세요. `arm64`가 무엇인지 잘 알고 있고 실제로 Windows ARM 장치를 보유하고 있는 경우에만 `arm64` 버전을 다운로드하여 사용하세요.

- macOS 버전은 서명되지 않은 dmg 설치 패키지를 제공합니다. 아직 서명되지 않았기 때문에 설치 시 약간 복잡한 절차를 거쳐 설치를 허용해야 합니다.  
  M 칩 macOS 사용자는 `arm64` 버전을 설치하세요. 오래된 Intel 사용자만 `x86_64` 버전이 필요합니다.  
  dmg를 더블 클릭한 후 "파일이 손상되었습니다"라는 메시지가 표시되면 다음 단계를 따르세요:
    1. 터미널에서 `xattr -cr /Applications/HiFiShifter.app` 입력；
    2. `시스템 설정` -> `개인정보 보호 및 보안` -> `그래도 열기`를 클릭하여 앱 실행을 허용합니다.

- Linux 버전은 AppImage 패키지를 제공합니다. AppImage 패키지는 파일의 `속성 -> 권한`에서 `파일을 프로그램으로 실행 허용`을 체크한 후 직접 실행할 수 있습니다.

**GPU 가속 정보**: HiFiShifter는 각 플랫폼별로 다양한 GPU 가속 옵션을 제공합니다:

- **Windows (x86_64 / ARM64)**: DirectML (DirectX 12) — 검증된 안정적 경로, NVIDIA / AMD / Intel Arc GPU 지원
- **macOS (Apple Silicon)**: CoreML + WebGPU (Dawn/Metal) — CoreML은 Apple Neural Engine을 활용, WebGPU는 보조 백엔드로 사용 가능
- **macOS (Intel)**: CPU 추론만 가능 (ort-tract 대체 백엔드 사용, GPU 가속 없음)
- **Linux (x86_64)**: WebGPU (Dawn/Vulkan) — Dawn이 Vulkan API를 통해 GPU에 접근, GPU가 없으면 CPU로 폴백
- **Linux (ARM64)**: CPU 추론만 가능 (이 타겟용 WebGPU ONNX Runtime 사전 빌드 바이너리 없음)

메뉴 `옵션 → 추론 장치`에서 `Auto`(자동), `CPU`, `GPU`를 선택할 수 있습니다. 벤치마크를 실행하여 각 장치의 추론 지연 시간을 비교하고 가장 빠른 장치를 선택할 수 있습니다.

**WebView 정보**: HiFiShifter 는 Rust + Tauri 프레임워크로 구축되었으며, 인터페이스를 표시하려면 WebView 구성 요소가 필요합니다.

- **Windows**: Edge WebView2 가 필요합니다. Windows 10 (버전 1803 이상) 및 Windows 11 에는 사전 설치되어 있으므로 추가 작업이 필요하지 않습니다. 이전 버전의 Windows를 사용하거나 구성 요소가 없는 경우 설치 프로그램이 자동으로 다운로드하라는 메시지를 표시합니다. 자세한 내용은 [Tauri 공식 문서](https://tauri.app/ko/start/prerequisites/#webview2)를 참조하세요. 일반 사용자는 설치 프로그램을 실행하기만 하면 됩니다.
- **macOS**: 시스템에 WebKit이 포함되어 있으므로 추가 설치가 필요하지 않습니다.
- **Linux**: WebKitGTK 가 필요합니다. 대부분의 주요 배포판(Ubuntu, Fedora, Arch Linux 등)에는 기본적으로 포함되어 있습니다. 누락된 경우 패키지 관리자를 사용하여 `webkit2gtk` 를 설치하세요(예: `sudo apt install webkit2gtk`). 자세한 내용은 해당 배포판의 문서를 참조하세요.

Windows에서는 HiFiShifter가 WebView2 자체의 브라우저 단축키(`Ctrl + F`, `Ctrl + P`, `F5`, 그리고 `Ctrl`과 `+` / `-`를 이용한 페이지 확대/축소)를 비활성화했으므로, 이 키들은 HiFiShifter로 정상 전달되어 편집 작업을 방해하지 않습니다.

**VST3 / ARA 플러그인 정보**: 독립 실행형 앱 외에도 HiFiShifter는 VST3(ARA) 플러그인 형태를 제공하며, 동일한 편집 인터페이스를 REAPER 프로젝트 안에서 바로 열 수 있습니다. 현재 플러그인은 Windows x64 버전이며 REAPER에서만 검증되었습니다. 설치와 사용 방법은 [VST3 / ARA 플러그인](#8-vst3--ara-플러그인-reaper) 장을 참고하세요.

## 2. 메뉴

메뉴 표시줄은 왼쪽부터 `파일`, `편집`, `트랙`, `보기`, `옵션`, `도움말` 여섯 개 메뉴로 이루어져 있으며, 메뉴 표시줄 맨 오른쪽에는 `언어` 버튼이 있어 English / 简体中文 / 繁體中文 / 日本語 / 한국어 사이에서 인터페이스 언어를 전환할 수 있습니다.

`파일` 메뉴에서는 HiFiShifter 프로젝트 파일을 새로 만들고, 열고, 저장할 수 있으며(`새 프로젝트`, `프로젝트 열기...`, `최근 프로젝트`, `저장`, `다른 이름으로 저장...`), 미디어 파일(오디오 또는 동영상 파일) 가져오기, MIDI 파일 가져오기, 외부 프로젝트 가져오기, 오디오 내보내기, 자동 백업, 녹음 등의 작업도 할 수 있습니다. 오디오 내보내기는 `wav`, `mp3`, `flac` 세 가지 형식을 지원하며, 자세한 내용은 [오디오 내보내기](#6-오디오-내보내기) 섹션을 참고하세요.

HiFiShifter 프로젝트 파일의 확장자는 `.hshp` 또는 `.hsp`입니다. 그 외에도 `다른 이름으로 저장` 기능은 프로젝트 파일을 일반 텍스트 `json` 파일로 저장하거나, 현재 프로젝트와 사용된 모든 미디어 파일을 함께 아카이브 압축 파일 `.zip`으로 패키징할 수 있습니다.

`파일 → 미디어 파일 가져오기`에서는 일반적인 오디오 형식(`wav`, `mp3`, `flac`, `ogg`, `m4a`, `aac` 등)과 일반적인 비디오 컨테이너(`mp4`, `mov`, `mkv`, `webm`, `avi`, `wmv`, `ts`, `mpg` 등)를 가져올 수 있습니다. 한 번에 여러 미디어 파일을 선택하면 가져오기 방식 선택 창이 나타나며, `시간을 가로질러 추가`(타임라인을 따라 차례로 배치), `트랙 간 추가`(여러 트랙에 세로로 걸쳐 배치) 또는 `테이크로 추가`(하나의 오디오 클립에 여러 테이크로 병합) 중에서 선택할 수 있습니다. 미디어 파일에 여러 오디오 트랙이 포함된 경우(예: 다국어 음성 트랙이 있는 동영상) 가져올 때 가져올 오디오 트랙을 선택할 수도 있습니다.

`파일 → 누락 미디어 다시 가져오기...`는 프로젝트 내 미디어 파일이 이동되거나 손실된 후 해당 파일들을 다시 찾아 연결하는 데 사용합니다.

자동 백업 기능을 통해 프로젝트 파일의 자동 백업을 설정할 수 있습니다. `저장 시 백업`과 `정기 백업`의 두 가지 모드가 있습니다.

- `저장 시 백업`: 프로젝트 파일을 덮어쓰기 저장할 때마다 이전 프로젝트 파일이 자동으로 원래 파일명에 `-bak`가 추가된 백업 파일(예: `.hshp-bak`, `.hsp-bak`)로 이름이 변경됩니다. 기본값으로 활성화되어 있습니다.
- `정기 백업`: 편집 중에 설정한 간격과 경로에 따라 자동으로 백업 프로젝트 파일을 생성합니다. 기본값으로 비활성화되어 있습니다.

### HiFiShifter 프로젝트 가져오기

`파일 → 외부 프로젝트 가져오기 → HiFiShifter 프로젝트 가져오기...`를 사용하면 현재 프로젝트를 닫지 않고 다른 `.hshp` / `.hsp` / `.json` 프로젝트의 모든 내용을 현재 프로젝트에 병합할 수 있습니다. 같은 하위 메뉴에는 `Reaper 프로젝트 가져오기...`(`.rpp`)와 `VocalShifter 프로젝트 가져오기...`(`.vshp` 또는 `.vsp`)도 있습니다.

- `원래 타임라인 위치 유지`: 가져온 클립이 원본 프로젝트의 시간 위치를 유지합니다.
- `재생 헤드 위치에 배치`: 가져온 내용 전체를 이동하여 가장 먼저 시작하는 클립을 현재 재생 헤드에 맞춥니다.
- `템포 맵 가져오기`: 현재 프로젝트에 템포 맵이 없을 때만 사용할 수 있습니다. 가져온 후에는 원본 프로젝트 시작점의 BPM, 박자표, 스케일이 현재 프로젝트의 기준이 됩니다.
- 모든 트랙, 하위 트랙, 클립, 파라미터 곡선, 그룹 관계는 가져올 때 새 ID를 할당받아 현재 프로젝트와 충돌하지 않습니다. 오디오 소스 파일은 먼저 가져온 프로젝트 파일이 있는 폴더를 기준으로 찾으며, 누락된 파일은 기존처럼 수동으로 다시 연결할 수 있습니다.
- 가져온 프로젝트의 노트는 현재 프로젝트 노트를 덮어쓰지 않고 끝에 추가됩니다.

### 프로세스 간 복사 / 잘라내기 / 붙여넣기

HiFiShifter의 구조화된 복사/붙여넣기는 시스템 클립보드에 저장되므로 프로세스 간 복사/붙여넣기를 지원합니다.

복사, 잘라내기, 붙여넣기는 현재 작업 위치에 따라 대상을 자동으로 판단하므로 모드를 수동으로 전환할 필요가 없습니다:

- 포커스가 트랙 인터페이스에 있고 클립이 선택되어 있으면 `Ctrl + C` / `Ctrl + X` / `Ctrl + V`는 클립에 적용됩니다.
- 포커스가 파라미터 에디터에 있고 파라미터 라인 구간이 선택되어 있으면 같은 세 단축키가 파라미터 라인에 적용됩니다. 이때 `Ctrl + X`는 `파라미터 프레임 잘라내기`로, 선택한 파라미터 라인을 클립보드에 복사한 뒤 지워서 다른 곳으로 옮기기 쉽게 합니다. 반면 `BackSpace`(초기화)는 선택 영역을 기본값으로 되돌릴 뿐 클립보드에 기록하지 않습니다.
- 붙여넣을 때는 클립보드의 실제 내용을 참고하여 무엇을 붙여넣을지 결정하므로, 도중에 트랙을 전환했더라도 파라미터 라인을 새 트랙에 올바르게 붙여넣을 수 있습니다.

- 타임라인에서 클립을 선택하고 `Ctrl + C`(또는 오른쪽 클릭 `복사`)를 누른 뒤, 다른 프로세스의 프로젝트에서 `Ctrl + V`(또는 트랙 빈 곳 오른쪽 클릭 `붙여넣기`)를 누르면 클립과 파라미터 곡선이 함께 붙여넣어집니다.
- HiFiShifter에서 클립을 복사하면 데이터가 REAPER 클립보드로도 직렬화되어 REAPER에서 `Ctrl + V`를 누르면 바로 붙여넣을 수 있습니다. 사용 가능한 소스 파일이 없는 클립은 건너뜁니다.
- `편집 → 새 트랙으로 붙여넣기`(`Ctrl + Alt + V`)는 원본 계층 구조대로 새 루트 트랙 그룹을 만듭니다.

- **REAPER 클립보드 데이터 붙여넣기**: REAPER에서 아이템/트랙/MIDI 노트를 복사한 후 HiFiShifter에서 일반 붙여넣기를 하면 REAPER 클립보드 데이터를 자동으로 인식하여 가져옵니다.
    - 아이템 데이터: HiFiShifter의 클립으로 가져오며, Reaper의 튜닝 데이터(전체 튜닝 및 피치 엔벨로프 모두)를 유지합니다.
    - 트랙 데이터: 트랙과 그 안의 아이템을 HiFiShifter의 트랙 및 오디오 클립으로 가져옵니다. 트랙 그룹을 유지할 수 있습니다.
    - MIDI 노트 데이터: 다른 DAW(Reaper, FL Studio 등)에서 노트 데이터를 시스템 클립보드 MIDI 데이터로 내보낸 뒤, HiFiShifter의 파라미터 에디터에서 `선택` 도구로 피치 곡선 구간을 선택하면 해당 구간에 클립보드 MIDI 노트 데이터를 가져올 수 있습니다. MIDI 가져오기 기능에 대한 자세한 설명은 [음높이 참조 클립](#8-음높이-참조-클립) 섹션을 참고하세요.

- **Reaper 엔벨로프**: Reaper 프로젝트(`.rpp`)를 가져오거나, Reaper 클립보드 데이터를 붙여넣거나, HiFiShifter의 내용을 다시 Reaper로 복사할 때 모두 Reaper의 Take 엔벨로프와 트랙 엔벨로프(볼륨, 팬, 뮤트)가 함께 처리되며 HiFiShifter의 파라미터 곡선과 상호 변환됩니다. 단, 피치 엔벨로프는 해당 트랙 그룹의 루트 트랙에서 합성(`C`)이 켜져 있을 때만 내보내기되어, 실제로 들리는 소리와 일치하도록 합니다.

- **VocalShifter 클립보드 데이터 붙여넣기**: VocalShifter 또는 VocalShifter LE에서 파라미터 라인 복사, 오디오 클립 복사, 트랙 복사 작업을 수행한 후, 이 기능을 통해 VocalShifter 클립보드 데이터를 빠르게 HiFiShifter로 가져올 수 있습니다.
    - 파라미터 라인 데이터: HiFiShifter의 파라미터 에디터에서 `선택` 도구로 파라미터 라인 구간을 선택한 후, VocalShifter 클립보드의 파라미터 라인 데이터를 해당 구간으로 가져올 수 있습니다.
    - 오디오 클립 데이터: HiFiShifter의 클립으로 가져오며, 다양한 파라미터 라인 데이터를 유지합니다.
    - 트랙 데이터: 트랙과 그 안의 오디오 클립을 HiFiShifter의 트랙으로 가져옵니다. HiFiShifter는 현재 마지막으로 복사한 내용이 오디오 클립인지 트랙인지 구분할 수 없습니다. 트랙을 가져오려는 경우, VocalShifter에서 트랙 복사 작업을 수행하기 전에 VocalShifter 프로젝트에서 선택된 오디오 클립이 없는지 확인하세요. 그렇지 않으면 선택된 오디오 클립만 가져와집니다.

`편집` 메뉴에는 클립보드와 선택 관련 자주 쓰는 작업이 모여 있습니다: `실행 취소` / `다시 실행`, `잘라내기` / `복사` / `붙여넣기`, `새 트랙으로 붙여넣기`, 그리고 `VocalShifter 클립보드 붙여넣기`(Windows 버전에서만 제공)입니다. 선택 관련 작업으로는 `모두 선택`, `선택 해제`, 그리고 `클립 범위를 파라미터 선택에 추가` / `클립 범위를 파라미터 선택에서 제거`가 있습니다(자세한 내용은 [트랙 인터페이스](#3-트랙-인터페이스) 장을 참고하세요).

`트랙` 메뉴는 `트랙 추가`(현재 선택한 트랙 아래에 삽입), `선택 트랙 복제`와 `선택한 트랙 삭제`를 제공합니다.

`보기` 메뉴에는 인터페이스 표시 관련 옵션이 있습니다:

- `창` / `레이아웃`: 각 도킹 패널의 표시 여부와 레이아웃 프리셋, 레이아웃 가져오기/내보내기, 레이아웃 초기화 등을 관리합니다.
- `템포 맵`: 템포 맵 행의 표시/숨기기를 전환합니다(기본 켜짐. 프로젝트에 템포 맵 데이터가 없으면 행이 표시되지 않습니다).
- `모든 테이크 표시(공간이 충분할 때)`: 여러 테이크가 있는 클립의 펼침 표시를 전환합니다.
- `클립보드 미리보기`: 파라미터 에디터의 클립보드 미리보기를 전환합니다.
- `파라미터 값 팝업`: 파라미터 값 팝업 표시를 전환합니다.
- `시간 표시`: 타임라인의 기본/보조 시간 단위를 선택하고 `타임라인 표시 설정...`을 열 수 있습니다.
- `테마: 자동 / 다크 / 라이트`: 현재 테마를 전환합니다. `자동`을 선택하면 HiFiShifter가 운영 체제의 밝은/어두운 외관을 따라 자동으로 전환됩니다(기본값).
- `외관 설정...`: 외관 설정 패널을 엽니다.
- `ARA 호스트 연결...`: 실행 중인 ARA 호스트(REAPER) 인스턴스에 연결하여 독립 실행형 앱에서 호스트의 오디오를 편집합니다. 독립 실행형 앱에서만 표시되며, 열면 떠 있는 세션 패널이 되어 전송·새로 고침·연결 해제를 할 수 있습니다. 자세한 내용은 [VST3 / ARA 플러그인](#8-vst3--ara-플러그인-reaper) 장을 참고하세요.
- `새로고침`: 런타임 정보를 다시 불러옵니다.
- `파형 캐시 지우기`: 캐시된 파형 데이터를 지웁니다. 다음에 표시할 때 다시 생성됩니다.

`옵션` 메뉴에서 HiFiShifter의 다양한 옵션을 수정할 수 있습니다:

- `프로젝트 스트레치 재정의`: 현재 프로젝트의 스트레치 알고리즘과 `HiFiGAN Mel Stretch` 스위치를 수정할 수 있습니다.
- `전역 스트레치 기본값`: 전역 기본 스트레치 알고리즘과 `HiFiGAN Mel Stretch` 스위치를 수정할 수 있습니다.
- `추론 장치`: 렌더링에 사용할 추론 장치를 설정할 수 있습니다. 현재 `자동`, `CPU`, `GPU` 세 가지가 있으며, `GPU` 선택 시 `GPU 장치` 목록에서 그래픽카드를 지정할 수 있습니다. 이 메뉴에서 벤치마크를 실행하여 각 추론 장치의 성능을 테스트할 수 있습니다(벤치마크에서는 GPU (DirectML), GPU (WebGPU) 등 구체적인 백엔드가 표시됩니다). `GPU` 옵션은 해당 GPU 버전의 HiFiShifter에서만 유효합니다.
- `백그라운드 사전 렌더링`：활성화하면 프로젝트를 열거나 파라미터를 편집한 후, 편집된 파라미터가 자동으로 백그라운드에서 사전 렌더링되며, 렌더링 중에도 이미 렌더링된 부분을 재생할 수 있습니다. 비활성화하면 재생 시작 시에만 렌더링이 진행되며, 타임라인을 정상적으로 재생하려면 렌더링이 완료될 때까지 기다려야 합니다. 기본값은 활성화입니다. 비활성화하면 렌더링 빈도를 낮춰 성능을 절약할 수 있습니다.
- `모든 테이크에 편집 동기화`：활성화하면 어떤 테이크의 편집(게인, 잘라내기, 속도, 역재생, 루프 등)이 해당 클립의 다른 모든 테이크에도 동일하게 적용됩니다(기본 켜짐).
- `수정된 미디어 파일 자동 다시 로드`：활성화하면 프로젝트의 미디어 파일이 외부에서 수정되었을 때 자동으로 다시 로드됩니다(기본 켜짐).
- `새 클립에 루프 사용`：활성화하면 새로 가져오거나 만든 클립에 루프(Loop 소스)가 기본으로 활성화됩니다(기본 켜짐).
- `스냅/그리드 설정...`：[스냅 / 그리드 설정](#스냅--그리드-설정) 창을 엽니다(타임라인 도구 모음의 `스냅` 버튼 오른쪽 클릭 메뉴로도 열 수 있습니다).
- `검색 및 일치...`: 파일 브라우저와 빠른 검색이 공용으로 사용하는 검색 일치 규칙(대소문자 구분, 정규식 등)을 설정합니다.
- `렌더 캐시 관리...`: 렌더 캐시를 확인하고 정리합니다.
- `비브라토 프리셋 관리...`: [비브라토 프리셋](#6-비브라토-프리셋) 관리자를 엽니다.
- `가져오기 채널 처리...`: 미디어 파일을 가져올 때 채널 수를 처리하는 정책(예: 가짜 스테레오를 모노로 변환)을 설정합니다.
- `포인터 및 펜 입력...`: 트랙패드, 타블렛, 스타일러스 펜, 터치스크린 등 포인터 장치의 입력 환경 설정을 지정합니다.
- `키보드 단축키...`：HiFiShifter의 키 바인딩을 설정할 수 있습니다. 여러 프리셋을 선택할 수 있습니다.

`도움말` 메뉴에는 진단과 지원을 위한 항목이 있습니다:

- `로그 폴더 열기`: 실행 로그가 있는 폴더를 시스템 파일 관리자에서 엽니다. 자세한 내용은 [로그 및 문제 해결](#9-로그-및-문제-해결) 장을 참고하세요.
- `진단 정보 내보내기...`: 저장 위치를 선택하면 진단 패키지(시스템 정보 + 전체 로그 + 추론 장치 벤치마크 결과)를 생성합니다. 이슈 등록 시 첨부해 주세요.
- `HiFiShifter 정보`: 정보 대화상자를 열어 프로젝트 소개, 현재 버전, 프로젝트 홈페이지(GitHub 저장소) 링크를 확인할 수 있습니다.

## 3. 트랙 인터페이스

소프트웨어의 대략적인 작동 로직과 단축키는 Reaper, VocalShifter, VEGAS Pro 등의 DAW 소프트웨어를 참고할 수 있습니다. `옵션 -> 키보드 단축키`에서 자신의 단축키 선호도를 조정할 수 있습니다. 아래 설명은 모두 기본 단축키를 기준으로 합니다.

트랙 인터페이스는 HiFiShifter의 핵심 기능 중 하나로, 오디오 클립을 자르고 붙이는 등의 작업을 할 수 있습니다. 작동 로직은 기본적으로 Reaper를 참고할 수 있습니다.

인터페이스 조작은 마우스 가운데 버튼(마우스 휠 누름)을 드래그하여 화면을 이동할 수 있습니다. 수평/수직 확대/축소 또는 스크롤은 `Ctrl`, `Alt`, `Shift` 등의 수정 키를 누른 상태에서 마우스 휠을 굴려 조정할 수 있습니다. 이러한 수정 키는 단축키 설정에서 조정할 수 있습니다.

화면 가장자리의 스크롤바에 포인터를 올린 뒤 휠을 굴리면, 해당 스크롤바 방향으로만 스크롤됩니다(세로 스크롤바는 위아래, 가로 스크롤바는 좌우). 확대/축소로 처리되지 않습니다. 이때 확대/축소 수정 키(기본 `Alt`)를 함께 누르면 휠이 해당 방향의 확대/축소로 바뀝니다. 세로 스크롤바에서는 트랙 높이가, 가로 스크롤바에서는 타임라인이 포인터 위치를 중심으로 확대/축소됩니다.

자주 사용하는 단축키:

> **macOS 사용자**: 아래의 `Ctrl`은 `Command (⌘)`, `Alt`는 `Option (⌥)`에 해당합니다.

- `스페이스바`: 재생 / 일시 정지 (재생 시작점으로 돌아가지 않음)
- `Enter`: 재생 / 정지 (재생 시작점으로 돌아감)
- `K`: 메트로놈 켜기/끄기
- `S`: 분할
- `G`: 그룹
- `U`: 그룹 해제
- `T`: 다음 테이크로 순환 전환(`Shift + T`: 이전 테이크)
- `Ctrl + C`: 복사(REAPERMedia 데이터도 함께 기록되어 REAPER에서 바로 붙여넣을 수 있음)
- `Ctrl + X`: 잘라내기
- `Ctrl + V`: 붙여넣기
- `Ctrl + Alt + V`: 새 트랙으로 붙여넣기
- `Ctrl + Z`: 실행 취소
- `Ctrl + Shift + Z` / `Ctrl + Y`: 다시 실행(macOS: `⌘ + ⇧ + Z` / `⌘ + Y`)
- `Ctrl + A`: 모두 선택

- `Delete`: 오디오 클립 삭제
- `-` / `=`: 선택한 오디오 클립의 파라미터 라인을 아래로/위로 이동(`Shift`를 누르면 크게, `Ctrl`을 누르면 미세 조정)
- 수정 키 `Alt`: 누른 상태에서 클립 시작/끝을 드래그하면 클립을 스트레치하고, 클립 중간을 드래그하면 내부 오프셋(슬립 편집)을 조정합니다.
- 수정 키 `Shift`: 누른 상태에서 스냅을 일시적으로 전환합니다.
- 수정 키 `Ctrl`: 누른 상태에서 클립을 드래그하면 복사합니다.
- 수정 키 `Alt + Shift`: 누른 상태에서 클립 위에서 세로로 드래그하면 해당 클립 전체의 피치를 조정하며, 파라미터 에디터의 피치 선이 실시간으로 따라가므로 드래그하면서 결과를 볼 수 있습니다.

타임라인에서 클립을 더블 클릭하면 해당 클립 범위의 모든 파라미터 프레임이 선택되고 복사/잘라내기 포커스가 파라미터 에디터로 이동합니다.

`Alt`( `옵션 -> 키보드 단축키` 에서 변경 가능)를 누른 채 클립을 더블 클릭하면 그 클립의 범위가 파라미터 에디터 선택 범위에 **추가**됩니다(기존 선택 범위와 겹치거나 맞닿으면 하나로 합쳐집니다). 같은 클립에 같은 조작을 한 번 더 하면 그 범위가 **해제**됩니다. 이렇게 여러 클립의 시간 범위를 빠르게 하나의 다중 선택 범위로 모아 한 번에 처리할 수 있습니다. 클립이 많을 때는 클립 오른쪽 클릭 메뉴의 `범위를 파라미터 선택 범위에 추가` / `범위를 파라미터 선택 범위에서 제거` 로 일괄 처리하거나, `Ctrl + Shift + A` (macOS에서는 `Alt` 가 `Option`, 단축키는 `⌘ + ⇧ + A`) 로 현재 선택한 클립 범위를 모두 추가할 수 있습니다. 이러한 작업은 **파라미터 에디터가 표시 중인 루트 트랙 그룹 내**의 클립에만 적용됩니다(에디터는 한 번에 하나의 루트 트랙 파라미터만 표시하므로 다른 트랙의 클립은 무시됩니다).

클립 왼쪽 상단의 작은 원은 볼륨 조절 노브이고, `M` 버튼은 해당 클립을 개별적으로 음소거하며, `F` 버튼은 해당 클립의 포먼트 편집 메뉴를 엽니다. 포먼트 편집 메뉴는 모음 차트(F1/F2 평면) 방식으로 목표 포먼트를 설정합니다. 차트에는 소재에서 감지된 현재 소스 포먼트 위치(빈 점과 궤적 산점)가 표시되며, 소스 점과 목표 점 사이의 화살표가 포먼트의 이동 방향을 직관적으로 보여줍니다. 모음 글자를 클릭하면 해당 모음이 한 번에 목표로 설정되고, `바이패스 청취` 버튼을 누르고 있는 동안에는 처리 전후의 소리를 임시로 비교할 수 있습니다. 소재에서 안정적인 모음이 감지되지 않으면 창에 안내가 표시됩니다. 클립의 왼쪽/오른쪽 끝은 페이드 인/페이드 아웃 길이를 조정할 수 있습니다. 클립의 이름 영역을 더블 클릭하면 이름을 바꿀 수 있습니다(현재 활성 테이크에 적용됩니다).

클립을 마우스 오른쪽 버튼으로 클릭하면 컨텍스트 메뉴가 열리며, `삭제`, `음소거` / `음소거 해제`, `테이크`(하위 메뉴, `교체` 포함), `채널 모드`(하위 메뉴에서 좌우 채널 교체, 모노 변환 등을 할 수 있고 `가짜 스테레오 검사 후 변환` 항목도 있습니다), `역재생`, `루프`, `복사` / `잘라내기`, `재생 위치에서 분할`, `노멀라이즈`, `범위를 파라미터 선택 범위에 추가`, `재생 속도 편집...`, `무음 감지...`, `음높이 참조 클립으로 변환`(음높이 참조 클립에는 `음높이 업데이트`로 표시됩니다), `빠른 내보내기`, `MIDI로 내보내기`, `그룹`(하위 메뉴, `그룹` / `그룹 해제` / `붙이기` 포함) 및 메뉴 하단의 `페이드 인` / `페이드 아웃` 형태 버튼 행 등의 기능이 있습니다. 같은 트랙의 여러 클립을 선택한 상태에서 컨텍스트 메뉴의 `붙이기`를 선택하면 하나의 단일 오디오 클립으로 합칠 수 있습니다.

여러 오디오 클립을 선택한 뒤 컨텍스트 메뉴에서 `그룹`(또는 `G`)을 선택하면 그룹화됩니다. Reaper 또는 VEGAS Pro와 유사하게 같은 그룹의 클립은 편집 시 연동됩니다. 클립 왼쪽 상단의 체인 버튼을 클릭하면 그룹 연동 편집을 일시적으로 비활성화/활성화할 수 있습니다. 그룹화된 클립을 선택하고 `그룹 해제`(또는 `U`)를 선택하면 그룹에서 제거됩니다.

### 테이크(Take)

하나의 클립에는 여러 테이크(REAPER의 Take와 유사)를 포함할 수 있으며, 같은 위치의 서로 다른 녹음/소재를 비교하거나 전환하는 데 사용합니다.

- 테이크 추가 / 관리: 클립을 마우스 오른쪽 버튼으로 클릭하면 `테이크` 하위 메뉴에서 `미디어에서 테이크 추가...`, `현재 테이크 복제`, `테이크 이름 바꾸기`, `테이크 삭제` 등을 수행할 수 있습니다. 클립에 여러 테이크가 있으면 하위 메뉴에서 클릭만으로 활성 테이크를 전환하거나, `다음 테이크로 전환` / `이전 테이크로 전환`(단축키 `T` / `Shift + T`, 순환 전환)을 사용할 수 있습니다. `테이크를 개별 클립으로 분리`는 해당 클립의 각 테이크를 타임라인의 독립 클립으로 분해합니다. `교체`도 이 하위 메뉴에 있으며, 새 미디어 파일로 현재 테이크의 오디오 소스를 교체할 수 있습니다. 각 테이크 행의 오른쪽에는 독립적인 `역재생`과 `채널 모드` 작은 버튼이 있어 개별 테이크에 각각 적용할 수 있습니다.
- 트랙 간 테이크로 묶기: 서로 다른 트랙의 여러 클립을 동시에 선택한 뒤 우클릭 메뉴의 `클립을 테이크로 통합`을 선택하면, 하나의 클립 아래 여러 테이크로 합쳐집니다.
- `보기 -> 모든 테이크 표시(공간이 충분할 때)`: 활성화하면 여러 테이크가 있는 클립은 트랙 높이가 충분하면 모든 테이크를 펼쳐 표시합니다. 끄면 현재 활성 테이크만 표시합니다.
- `옵션 -> 모든 테이크에 편집 동기화`: 활성화하면 어떤 테이크의 편집(게인, 잘라내기, 속도, 역재생, 루프 등)이 해당 클립의 다른 모든 테이크에도 동일하게 적용됩니다.

트랙 인터페이스 왼쪽은 트랙 헤더 영역으로, 트랙을 추가/삭제하고 트랙 파라미터를 조정할 수 있습니다. 트랙을 마우스 오른쪽 버튼으로 클릭하면 복제할 수 있습니다. 트랙의 빈 영역을 마우스 오른쪽 버튼으로 클릭하면 클립보드의 클립을 붙여넣을 수 있습니다.

Reaper와 유사하게 HiFiShifter의 트랙에도 트랙 그룹 개념이 있습니다. 트랙 헤더 영역에서 한 트랙 헤더를 다른 트랙 헤더로 드래그하면 트랙 그룹을 생성할 수 있습니다. 트랙 그룹은 하나의 파라미터 패널을 공유합니다. 실제 사용 시 "한 파트당 하나의 트랙 그룹"으로 정리하는 것이 좋습니다.

트랙 인터페이스의 기능 버튼(왼쪽에서 오른쪽으로):

- `메트로놈`: 재생 시 클릭 기준을 제공합니다. 왼쪽 클릭으로 켜고 끄며, 오른쪽 클릭으로 음량·세분화·음색 등의 설정을 엽니다. 자세한 내용은 [메트로놈](#메트로놈) 섹션을 참고하세요.
- `BPM`: 프로젝트 전체의 템포 BPM을 조정합니다(템포 맵이 있을 때는 재생 헤드에서 가장 가까운 변경점의 BPM을 조정합니다. 아래 "템포 맵" 참조).
- `박자표`: 프로젝트의 박자를 설정합니다.
- `그리드`: 프로젝트의 그리드 간격을 설정합니다.
- `기준 스케일`: 프로젝트 전체의 기준 스케일 설정을 조정합니다. 사용자 정의 스케일을 허용합니다. 스케일 기능은 주로 후술할 `피치 스냅` 및 기타 피치 조정 관련 기능과 관련됩니다.
- `정지` 버튼 및 `재생 / 일시 정지` 버튼: 재생을 제어합니다.
- `녹음`: 선택한 트랙에서 녹음할 수 있습니다. 마우스 오른쪽 버튼으로 녹음 소스와 녹음 장치를 설정하거나 자세한 녹음 설정을 열 수 있습니다.
- `실행 취소` / `다시 실행`: 편집 메뉴의 같은 이름 기능과 동일합니다. 버튼을 오른쪽 클릭하면 `작업 기록` 패널이 열려 최근 작업 이력을 확인하고 임의의 시점으로 이동할 수 있습니다.
- `파일 브라우저`: HiFiShifter의 파일 브라우저 창을 엽니다.
- `노트`: HiFiShifter 노트 창을 열어 Markdown 형식의 텍스트를 기록하고 표시합니다.
- `자동 크로스페이드`: Reaper/VEGAS Pro의 유사 기능과 동일하게, 활성화하면 클립 이동 시 겹치는 부분의 크로스페이드 엔벨로프를 자동 조정합니다.
- `분할 트랜지션`: Reaper/VEGAS Pro의 분할 페이드 방식을 참고한 기능으로, 기본적으로 활성화되어 있습니다. 분할 후 분할 지점에 앞 클립의 페이드아웃과 뒤 클립의 페이드인을 자동으로 추가하거나 클립을 확장하여 겹치게 만들어 클립 간 전환이 더 부드러워집니다. 왼쪽 클릭으로 켜고 끄며, 오른쪽 클릭으로 자세한 설정을 엽니다.
- `스냅`: 활성화하면 클립 조정이 그리드, 다른 오브젝트 가장자리, 재생 헤드 등 설정된 대상에 스냅됩니다. `Shift`를 누르면 임시로 스냅을 전환할 수 있습니다.
- `리플 편집 (자동 추적)`: 활성화하면 트랙의 클립에 대한 일부 편집 작업이 자동으로 후속에 적용됩니다. 왼쪽 클릭으로 `끄기`, `트랙 단위`, `전체 트랙` 세 단계 사이를 순환 전환하고, 오른쪽 클릭으로 모드를 직접 선택할 수 있습니다.
- `재생 헤드 기준 줌`: 마우스 휠로 수평 확대/축소할 때의 중심을 설정합니다. 비활성화 시 마우스 커서 위치가 중심이고, 활성화 시 항상 재생 헤드 위치가 중심입니다(Reaper/VEGAS Pro 로직과 유사).
- `자동 스크롤`: 활성화하면 재생 중 재생 헤드를 따라 인터페이스가 수평으로 자동 스크롤됩니다.
- `파라미터 에디터에서 재생 헤드 이동 허용`: 비활성화하면 파라미터 에디터의 편집 패널 클릭으로는 재생 헤드가 이동하지 않습니다. 트랙 인터페이스나 파라미터 에디터의 시간 코드 영역을 클릭해야만 재생 헤드가 이동합니다.
- `타임라인 클릭으로 트랙 전환`: 기본적으로 활성화되어 있습니다. 활성화하면 타임라인의 클립이나 빈 영역을 클릭할 때 현재 트랙이 전환되고 파라미터 에디터도 해당 트랙을 편집합니다. 비활성화하면 왼쪽 트랙 헤더를 클릭할 때만 현재 트랙이 전환됩니다.
- `그룹화 무시`: 활성화하면 그룹화된 모든 오디오 클립 편집 시 그룹 연동 편집을 전역적으로 무시합니다.

### 스냅 / 그리드 설정

타임라인 도구 모음의 `스냅` 버튼은 스냅을 빠르게 켜고 끄는 스위치입니다. 왼쪽 클릭으로 스냅 마스터 스위치를 전환하고, 오른쪽 클릭하면 `스냅 / 그리드 설정` 창이 바로 열립니다. 같은 창은 메뉴 `옵션 -> 스냅 / 그리드 설정` 에서도 열 수 있습니다. 모든 설정은 자동 저장되며 다음 실행 시 복원됩니다.

설정 항목:

- `그리드`: 그리드 선 표시 여부, 그리드 간격(일반 / 점음표 / 셋잇단음표, `1/1`~`1/64`), 최소 픽셀 간격을 설정할 수 있습니다. `Swing` 을 켜면 홀수 번째 그리드 선이 백분율(0–100%)만큼 이동하며, `스윙 변경 시 모든 클립 재정렬` 을 켜면 기존 클립이 새 스윙 그리드로 자동 이동합니다.
- `스냅 마스터`: `스냅 사용` 이 마스터 스위치입니다. `드래그 중에 스냅 강조 선 표시`(기본 켜짐)는 드래그 중 스냅 대상에 도달했을 때 보조 세로선을 표시합니다. `스냅 거리` 는 대상까지 몇 픽셀 이내일 때 스냅할지를 지정하며(기본 4px), `그리드 상대 스냅` 은 절대 위치 대신 원래 그리드와의 오프셋을 유지한 채 스냅합니다.
- `스냅 대상 및 목표`: `클립`, `선택 영역`, `커서` 각각에 대해 `선택 / 마커 / 커서` 와 `그리드` 로의 스냅을 따로 설정할 수 있습니다. 예를 들어 클립은 그리드에만 스냅하고, 재생 커서는 그리드와 클립 가장자리에 모두 스냅하도록 할 수 있습니다.
- `스냅 동작`: `스냅 설정을 그리드 표시에 따르기` 는 그리드를 숨기면 그리드로의 스냅을 멈춥니다. `임의 거리에서 그리드로 스냅` 은 거리와 관계없이 그리드에 강제 배치하는 모드입니다. `독립 스냅 간격 사용` 을 켜면 표시 그리드와 별도의 스냅 간격과 최소 픽셀 값을 지정할 수 있습니다.
- `클립 및 특수 요소 상호작용`: 클립 시작/끝만 스냅할지, 또는 `클립 스냅 오프셋`(클립 콘텐츠 시작 위치)도 함께 스냅할지 선택할 수 있습니다. `다른 트랙의 클립으로 스냅` 을 켜면 몇 트랙까지 건너 대상 트랙을 찾을지 설정할 수 있습니다. `레이저 편집 스냅` 은 `S` 분할 작업의 분할 위치도 스냅에 참여시킵니다.
- `고급`: `프로젝트 샘플레이트로 스냅` 으로 샘플 단위 정밀 스냅을, `클립 가장자리를 소스 시작/끝으로 스냅` 으로 잘라낸 클립 가장자리를 원본 소재의 시작/끝으로 되돌릴 수 있습니다. `선택 영역을 배수로 강제` 는 선택 영역을 지정한 그리드로 반올림하며, `선택 영역 배수` 로 몇 배 그리드 기준으로 반올림할지 지정할 수 있습니다. `편곡 뷰와 MIDI 편집기에 같은 그리드 분할 사용` 은 타임라인과 파라미터 에디터의 그리드 정밀도를 동기화합니다.

### 분할 트랜지션

`분할 트랜지션` 은 분할 지점의 클릭 노이즈를 줄이기 위한 기능으로, 기본적으로 활성화되어 있습니다. 타임 스트레치 알고리즘 등의 영향으로 분할 후 클립 경계에서 클릭 노이즈가 발생할 수 있습니다. 이 기능은 Reaper/VEGAS Pro의 방식을 참고하여 분할할 때마다 경계를 자동으로 처리합니다.

도구 모음의 `분할 트랜지션` 버튼은 `자동 크로스페이드` 오른쪽에 있습니다. 왼쪽 클릭으로 기능을 켜고 끄며, 오른쪽 클릭으로 상세 설정을 엽니다.

- `페이드만`: 분할 후 앞 클립에 길이 X의 페이드아웃, 뒤 클립에 길이 X의 페이드인을 자동으로 추가합니다. 두 클립은 겹치지 않습니다.
- `확장 및 겹치기`(기본): 분할 후 앞 클립의 끝을 뒤로 X만큼, 뒤 클립의 시작을 앞으로 X만큼 자동으로 늘려 2X초의 겹치는 구간을 만듭니다. 연장 시 클립 안의 소재가 타임라인에서 같은 위치를 유지하도록 하며 재생 속도도 올바르게 처리합니다. 연장 범위는 클립 원본 소재의 실제 길이 범위 안으로 제한됩니다. `자동 크로스페이드` 가 켜져 있으면 이 겹치는 구간에도 크로스페이드가 자동으로 적용됩니다.
- `트랜지션 길이 X`: 두 모드에서 사용하는 페이드/오버랩 길이로, 기본값은 0.01초입니다.
- `트랜지션 길이 단위`: `초`(기본값) 또는 `퍼센트`를 선택할 수 있습니다. 퍼센트는 기본 1%이며, 분할로 생성된 앞뒤 두 클립의 전체 길이 합계를 기준으로 계산됩니다. 예를 들어 두 클립의 전체 길이가 10초일 때 1%는 0.1초입니다.
- `페이드 커브`: 분할 트랜지션이 경계 페이드로 작성하는 페이드 커브 유형을 선택합니다. 기본값은 `페이드 커브 변경 안 함`입니다.
- `오버랩 크로스페이드`: `자동 크로스페이드 따르기` 를 선택하면 `자동 크로스페이드` 가 켜져 있을 때만 겹치는 구간에 크로스페이드를 적용합니다. `항상 적용` 을 선택하면 겹치는 구간에 항상 크로스페이드가 적용됩니다.

### 클립 페이드 및 크로스페이드

모든 클립에는 독립적인 페이드인 / 페이드아웃 엔벨로프가 있으며, 상호작용 모델은 REAPER와 거의 동일합니다. 편집 대상은 '페이드 영역 전체'가 아니라 화면에 실제로 표시되는 두 선 — 페이드 엔벨로프 선과 페이드 영역의 가장자리 세로 선입니다.

**페이드 길이 조절**

- 클립 왼쪽 / 오른쪽 끝의 페이드 엔벨로프 선 또는 페이드 영역의 가장자리 세로 선을 드래그하면 페이드인 / 페이드아웃 길이를 조절할 수 있습니다. 길이 0부터 페이드를 만들려면 이름 표시줄 **아래**(파형 영역의 위 모서리)에 있는 작은 삼각형을 드래그하십시오 —— 이 삼각형은 해당 쪽에 아직 페이드가 없을 때만 표시되며, 페이드를 만든 뒤에는 엔벨로프 선 자체가 핸들이 됩니다. 이름 표시줄의 노브와 배지는 클립 컨트롤이며 페이드 제스처를 받지 않습니다.
- 페이드 컨트롤을 (드래그하지 않고) 클릭하면 재생 커서가 해당 위치로 이동합니다: 엔벨로프 선은 페이드 영역의 안쪽 가장자리(페이드인 → 영역의 오른쪽 끝, 페이드아웃 → 영역의 왼쪽 끝), 교차점 그립은 클릭한 위치, 클립 가장자리는 그 가장자리의 정확한 위치로 이동합니다.
- 엔벨로프 선, 가장자리 세로 선, 교차점 그립 등 페이드 컨트롤 위에 마우스를 올리면 페이드인 / 페이드아웃 유형(곡선 아이콘), 길이(시간 표시 설정의 주 / 보조 시간 단위), 곡률로 구성된 툴팁이 표시됩니다.

**페이드 형태와 곡률**

HiFiShifter는 REAPER와 동일한 7가지 페이드 형태를 제공합니다: `직선`, `패스트 스타트`, `패스트 엔드`, `샤프 패스트 스타트`, `샤프 패스트 엔드`, `슬로우 스타트/엔드(S 커브)`, `샤프 슬로우 스타트/엔드`.

- 페이드 엔벨로프 선이나 가장자리 세로 선을 오른쪽 클릭하면 페이드 전용 컨텍스트 메뉴가 열립니다: 위쪽에 7개의 형태 버튼(현재 형태는 강조 표시), 아래쪽에 곡률 슬라이더와 미니 곡선 미리보기가 있습니다. 곡률 범위는 `-1.00 ~ +1.00` 이며 변경 즉시 적용됩니다. 슬라이더는 휠 스텝 조절을 지원하고(`파라미터 미세 조정` 수정 키를 누르면 더 세밀하게 조절), 미니 곡선은 직접 드래그할 수도 있습니다.
- `페이드 곡률` 수정 키(기본값 `Alt`)를 누른 채 엔벨로프 선을 드래그하면 곡선을 포인터 위치로 '끌어오듯' 곡률을 조절할 수 있습니다.
- 엔벨로프 선을 더블클릭하면 해당 측의 곡률을 현재 형태의 기본값으로 초기화할 수 있습니다. 형태를 바꾸면 곡률도 새 형태의 기본값으로 초기화됩니다.
- `페이드 형태 순환` 수정 키(기본값 `Ctrl`)를 누른 채 엔벨로프 선을 클릭하면 페이드 형태를 순환적으로 전환할 수 있습니다.
- 클립의 컨텍스트 메뉴에도 `페이드 인` / `페이드 아웃` 형태 선택 행이 있어 페이드 형태를 바로 전환할 수 있습니다.

**자동 크로스페이드**

도구 모음의 `자동 크로스페이드` 버튼(기본값 활성화)은 REAPER / VEGAS Pro의 유사 기능과 마찬가지로, 클립을 이동하여 같은 트랙 위에서 겹침이 생기면 겹침 길이에 맞춰 두 클립에 크로스페이드를 자동으로 설정합니다.

- 자동 크로스페이드 길이는 수동 페이드 길이와 별도로 저장됩니다: 겹침이 사라지면 자동 페이드는 해제되고 이전의 수동 페이드가 다시 표시됩니다. 반대로 페이드 길이를 수동으로 조절하면 해당 측은 수동 페이드로 전환됩니다.
- 한 클립이 다른 클립을 완전히 포함하는 경우에는 유효한 크로스페이드 관계로 간주되지 않아 자동 크로스페이드가 발생하지 않습니다.
- 타임라인과 파라미터 에디터에 표시되는 페이드 길이는 항상 '실효 페이드'입니다: 자동 크로스페이드가 수동 페이드보다 우선합니다.

**겹치는 구간 편집**

두 클립이 겹치면 겹치는 구간에 양쪽 클립을 위한 완전한 편집 컨트롤이 표시되며, 조작 방식은 일반 클립과 동일합니다: 겹침 구간의 왼쪽은 뒤 클립(왼쪽 가장자리 잘라내기 / 연장 및 페이드인 컨트롤), 오른쪽은 앞 클립(오른쪽 가장자리 잘라내기 / 연장 및 페이드아웃 컨트롤)에 해당합니다. 우선순위는 클립 가장자리가 가장 높고, 다음이 페이드 영역의 가장자리 세로 선, 마지막이 엔벨로프 선입니다.

두 페이드 곡선의 교차점에는 그립(교차점 핸들)이 있습니다:

- 그립을 그대로 드래그: 교차점이 앞뒤로 이동하며 겹침 길이는 변하지 않습니다;
- `크로스페이드 반전 모드` 수정 키(기본값 `Ctrl`)를 누른 채 드래그: 앞뒤 두 클립의 가장자리가 반대 방향으로 이동하여 겹침 길이가 변하고 페이드 길이가 비례하여 조절됩니다;
- `페이드 곡률` 수정 키(기본값 `Alt`)를 누른 채 드래그: 두 페이드 곡선의 곡률을 동시에 조절합니다;
- 그립을 오른쪽 클릭: 앞 클립의 페이드아웃과 뒤 클립의 페이드인 두 열로 이루어진 페이드 메뉴가 동시에 열려 각각의 형태와 곡률을 설정할 수 있습니다. 더블클릭하면 양쪽 곡률을 동시에 초기화할 수 있습니다.

이러한 수정 키는 `옵션 -> 키보드 단축키...` 의 `수정 키 · 페이드 및 크로스페이드` 그룹에서 변경할 수 있습니다.

### 타임라인 시간 표시

타임라인 상단의 눈금자는 가로 확대/축소에 따라 눈금을 자동으로 세분화합니다. 축소 상태에서는 마디만 표시되고(`1.1`, `2.1`), 점점 확대하면 2분음표(`1.1`, `1.3`), 4분음표(`1.1`, `1.2`), 8분음표(`1.1`, `1.1.500`), 더 나아가 16분/32분음표까지 세분화됩니다. 가장 정밀한 단계는 `그리드` 설정에 따라 제한됩니다.

네 가지 시간 단위를 지원합니다.

- `마디.박.소단위`(기본 주 단위): `1.2.500`은 1번째 마디의 2번째 박에서 0.5박 더 간 위치를 뜻합니다(1000소단위 = 1박).
- `마디.분할`: `1.17/32`는 `1/32` 그리드 기준 1번째 마디의 17번째 분할을 뜻합니다. 분할은 `그리드` 설정을 따릅니다. 셋잇단 그리드는 정수 분할 수(예: `1.2/12`)를, 점음표 그리드는 소수 분할 수(예: `1.2/2.6667`)를 가질 수 있습니다.
- `초`: 절대 초로, 예를 들어 `1234.5678`.
- `시:분:초.밀리초`(기본 보조 단위): 시가 0이면 시를 생략하고, 밀리초는 항상 3자리입니다(예: `4:43.750`, `1:4:43.750`).

눈금자를 마우스 오른쪽 버튼으로 클릭하면 기본 시간 단위와 보조 시간 단위를 각각 선택할 수 있으며, 보조 단위는 `미사용`으로도 설정할 수 있습니다. `보기 -> 시간 표시` 메뉴나 `타임라인 표시 설정...` 대화상자에서도 조정할 수 있습니다. 두 단위를 모두 표시할 때는 위아래 두 줄로 나뉘고 그 사이에 연한 가로선이 표시됩니다. 보조 단위가 `미사용`이거나 기본 단위와 같으면 기본 단위만 세로 중앙에 표시됩니다.

트랙 뷰 왼쪽의 `트랙` 제목 줄 오른쪽에는 재생 헤드 시간이 `주 단위 / 보조 단위`(보조 단위가 없으면 주 단위만) 형식으로 실시간 표시되며, 재생 중이나 시간 형식 전환 시에도 자동으로 갱신됩니다. 재생 헤드 시간 텍스트는 자릿수를 고정하여 정렬됩니다(예: `1.1.000`, `0.000`).

눈금자 위에서 마우스를 움직이면 포인터 위치의 시간이 표시됩니다. 오른쪽 클릭 메뉴의 `재생 헤드 시간 복사`로 현재 재생 헤드 시간을 텍스트로 클립보드에 복사할 수 있습니다. `타임라인 표시 설정...`에서는 눈금자 라벨 간격을 조정하고 트랙 헤더의 재생 헤드 시간 표시를 켜거나 끌 수 있습니다.

### 템포 맵(템포 / 박자표 / 스케일)

HiFiShifter는 프로젝트 단위 템포 맵을 지원하여 타임라인의 서로 다른 위치에 서로 다른 BPM, 박자표, 스케일을 정의할 수 있습니다. 빈 프로젝트에는 기본적으로 템포 맵 데이터가 없습니다. 프로젝트에 템포 맵 데이터를 추가하면 눈금자가 시간 단위 아래에 템포 맵 행을 자동으로 추가 표시하며(시간 단위와 연한 가로선으로 구분됨), 각 구간의 템포·박자표·스케일은 각 변경점의 라벨에 표시됩니다. 어느 구간의 시작 라벨이 화면 왼쪽 밖으로 스크롤되면 행의 맨 왼쪽에 라벨과 같은 스타일의 플로팅 라벨이 나타나 해당 구간의 매개변수를 표시합니다. 라벨은 가로 스크롤에 따라 부드럽게 전환되며 라벨과 겹치지 않고, 고정 라벨과 완전히 동일한 조작(더블 클릭으로 입력 편집, 오른쪽 클릭으로 편집 창 열기)을 지원합니다. 파라미터 편집기의 눈금자에도 동일한 템포 맵 행이 표시됩니다.

- 변경점 추가: 시간 눈금자를 마우스 오른쪽 버튼으로 클릭하고 메뉴의 `여기에 템포/박자표/스케일 변경 추가...`를 선택하면 클릭한 위치에 변경점을 만들고 편집 대화상자를 엽니다. 템포 맵 행의 빈 곳을 더블 클릭하면 해당 위치에 변경점이 바로 생성됩니다.
- 변경점 편집: 템포 맵 행의 변경점 라벨(0 위치의 초기 포인트 포함)을 더블 클릭하면 BPM, 박자표와 스케일을 수정할 수 있습니다. 라벨은 더블 클릭 후 그 자리에서 텍스트 입력 상자로 바뀌어 `120 4/4 - C / Am` 같은 텍스트를 직접 입력할 수 있습니다. 라벨을 오른쪽 클릭하면 `템포 맵 변경점` 편집 창이 바로 열립니다. 변경점 라벨은 드래그하여 위치를 조정할 수도 있습니다. 눈금자 오른쪽 클릭 메뉴의 `이 변경점 편집...` / `이 변경점 삭제`는 커서가 있는 변경점에 적용되며, `템포 맵 지우기`로 템포 맵 전체를 비우거나(데이터를 유지한 채 숨기기만 할 수도 있습니다) 할 수 있습니다.
- 이전 박자표 / 스케일 따르기: 각 변경점의 박자표는 `이전 박자표 따르기`, 스케일은 `이전 스케일 따르기`를 선택할 수 있습니다.
- 초기 포인트는 프로젝트 기준: 프로젝트 전체의 BPM, 박자표(분자와 분모)와 스케일은 0 위치의 초기 포인트에 기록되며, 템포 맵 행에 `120 4/4 - C / Am` 같은 텍스트로 표시됩니다.
- 그리드와 눈금자: 템포 맵이 있으면 시간 눈금자 눈금, 마디/박 라벨과 배경 그리드가 각 변경점에서 다시 정렬되고 각 구간의 템포와 박자표에 따라 구간별로 계산됩니다. 또한 각 템포 맵 변경점마다 해당 지점의 시간 값이 표시되어 변화가 어디서 일어나는지 바로 읽을 수 있습니다.
- 스케일 연동: 템포 맵의 스케일 변화는 피치 스냅(스케일 모드), 스케일 하이라이트, 도수 이조/퀀타이즈/평균 퀀타이즈 등의 `프로젝트 스케일` 옵션과 하위 트랙의 `도수 차` 렌더링에 반영됩니다.
- 가져오기: MIDI를 음높이 참조 클립으로 가져올 때 가져오기 대화상자에서 `템포 맵으로 가져오기`를 켜고 템포, 박자표와 스케일을 각각 가져올지 선택할 수 있습니다. REAPER 프로젝트(.rpp)를 가져올 때는 가져오기 대화상자의 `템포 맵 가져오기 (현재 프로젝트에 없을 때만)` 옵션이 기본으로 체크되어 있으며, 프로젝트 수준의 템포·박자표 변화가 함께 가져와집니다.

### 클립 속도 및 게인 배지

각 클립의 제목 표시줄 오른쪽에는 `속도`(`x1.5` 형식)와 `게인`(`+3.0dB` 형식) 두 가지 배지가 직접 표시됩니다. 가장 자주 쓰는 두 가지 조정은 별도 창을 열 필요가 없습니다.

- 배지를 더블 클릭하면 그 자리에서 값을 입력할 수 있습니다. `Enter`로 확인, `Esc`로 취소하며, 클립 바깥을 클릭해도 값이 저장됩니다.
- 클립 왼쪽 위의 볼륨 노브는 이전과 같이 위아래로 드래그할 수 있으며, 더블 클릭하면 0 dB로 돌아갑니다.
- 클립이 너무 좁으면 배지가 자동으로 숨겨집니다. 트랙 높이를 늘리거나 가로로 확대하면 다시 나타납니다.

속도 배지를 오른쪽 클릭(또는 클립 컨텍스트 메뉴의 `재생 속도 편집...`)하면 BPM 변환이나 일괄 편집이 필요할 때 쓰는 가벼운 팝오버가 열립니다:

- `스트레치 배수`, `원본 BPM`, `새 BPM`은 연결되어 항상 "배수 = 새 BPM ÷ 원본 BPM"을 만족합니다. 예를 들어 소재가 120 BPM이고 140 BPM으로 만들고 싶다면 `새 BPM`을 140으로 설정하면 배수가 약 1.167로 자동 계산됩니다. 배수나 원본 BPM을 수정해도 나머지가 같은 방식으로 다시 계산됩니다. 필드에서 마우스 휠을 굴리면 고정 스텝으로 미세 조정할 수 있고(배율 0.1, BPM 1), `미세 조정` 수정 키(기본 `Ctrl`, macOS는 `Command`)를 누르면 더 세밀하게(배율 0.01, BPM 0.1) 조정됩니다.
- `길이` 필드에 목표 길이를 직접 입력하면 배수가 그로부터 역산됩니다. 입력 형식은 매우 유연하여 표시 형식을 엄격히 지키지 않아도 됩니다. 예를 들어 `1.2`(초), `0:01.5`(시:분:초), `1.2.500`(마디.박.소단위), `1.2/16`(그리드 포함) 모두 인식되며, 소수점 구분자로 쉼표도 사용할 수 있습니다.
- `새 배율에 맞춰 클립 길이 자동 조정`(기본 켜짐): 클립 길이가 배율과 함께 변합니다. 흔히 말하는 "속도와 피치를 함께 바꾸기" 동작입니다. 끄면 현재 길이를 유지하고 재생 속도와 피치만 바뀝니다.
- 여러 클립을 선택하면 팝오버 하단에 몇 개의 클립에 적용되는지 표시되어 한 번에 일괄 적용됩니다.

### 무음 감지

`무음 감지`는 클립의 무음 구간을 자동으로 찾아 일괄 제거하여 하나씩 잘라 삭제하는 수고를 덜어줍니다. 하나 이상의 클립을 선택하고 마우스 오른쪽 버튼을 클릭한 뒤 `무음 감지...`를 선택하세요.

대화상자가 열리면 결과를 미리 보여줍니다. 감지된 무음 범위는 클립 위에 빨간색으로 강조 표시되고, 하단에 몇 개의 범위가 발견되었고 총 길이가 얼마인지 표시됩니다. 매개변수를 바꾸면 즉시 다시 분석됩니다. `적용`을 누르기 전에는 실제로 수정되지 않으며, 전체 작업은 실행 취소할 수 있습니다.

- `방식`: `RMS(에너지)`(기본)는 평균 음량으로 판단하여 대부분 소재에 적합합니다. `피크`는 순간 최대 레벨만 보아 간혹 클릭이 섞인 틈에 도움이 됩니다.
- `임계값(dBFS)`: 이보다 낮은 내용을 무음으로 간주합니다. 기본값은 `-50`입니다. 값을 높일수록 더 많은 소재가 무음으로 표시됩니다.
- `적응형 임계값(노이즈 플로어 + 6 dB)`: 켜면 HiFiShifter가 노이즈 플로어를 추정하여 임계값을 정하므로 수동 튜닝이 필요 없습니다.
- `최소 무음(ms)`: 이보다 짧은 조용한 구간은 그대로 둡니다. 기본값은 `120`입니다. 더 잘게 자르려면 낮추세요.
- `최소 발성(ms, 0 = 끄기)`: 무음에 둘러싸인 이보다 짧은 소리는 무음과 함께 제거됩니다. 기본값은 끄기입니다.
- `여유(ms)`: 각 컷 안쪽에 약간의 여유를 두어 단어의 머리/끝이 잘리지 않도록 합니다. 기본값은 `10`입니다.
- `컷 페이드(ms)`: 각 컷 양쪽에 작은 페이드를 더해 클릭을 방지합니다. 기본값은 `5`입니다.
- `처리 방식`:
    - `무음 제거 후 간격 메우기`(기본): 무음을 제거하고 그 뒤 내용을 앞으로 당겨 타임라인이 더 촘촘해집니다.
    - `제거만(간격 유지)`: 무음을 제거하되 원래 시간 간격은 남겨 둡니다. 이후 수동으로 배치할 때 유용합니다.
    - `분할만`: 무음 경계에서만 분할하고 아무것도 삭제하지 않습니다. 각 조각을 직접 처리하고 싶을 때 씁니다.
- `완전 무음 클립 삭제`: 처음부터 끝까지 무음인 클립을 제거합니다(기본 켜짐).
- `모든 테이크 감지(합집합)`: 같은 클립의 모든 테이크 무음 범위를 합친 뒤 처리하여 테이크 전환 후 무음이 다시 나타나지 않도록 합니다.

대화상자에서 매개변수 행을 더블 클릭하면 해당 매개변수가 기본값으로 초기화됩니다.

### 간격 닫기

트랙의 빈 영역을 마우스 오른쪽 버튼으로 클릭하고 `간격 닫기`를 선택하면 클릭한 위치 이후의 같은 트랙에 있는 모든 클립을 앞으로 이동시켜 사이 빈 공간을 없애고 끝과 끝이 맞닿게 합니다. 클릭한 위치 이전의 내용은 제자리에 유지됩니다. 클릭한 위치 이후 해당 트랙에 클립이 없으면 메뉴 항목이 비활성화됩니다.

### 메트로놈

메트로놈은 재생 중 안정적인 클릭 기준을 제공하여 리듬 확인, 따라 부르기, 템포 변화 검증에 도움이 됩니다.

- 켜기/끄기: 메인 도구 모음에서 BPM 왼쪽에 있는 메트로놈 버튼을 클릭합니다. 기본 단축키는 `K`입니다.
- 메트로놈 버튼을 마우스 오른쪽 버튼으로 클릭하면 설정이 열립니다:
    - `음량`: 메트로놈 음량. 드래그 외에 마우스 휠 조절도 지원하며, `미세 조정` 수정 키(기본 `Ctrl`, macOS는 `Command`)를 누르면 더 세밀하게 조정됩니다.
    - `세분화`: 클릭 밀도를 제어합니다. `그리드 따르기`(기본)는 현재 그리드 세분에 맞춰 클릭합니다(예: `1/8` 그리드면 반박자마다 한 번, 점음표와 셋잇단음표 그리드도 따릅니다). `박만`은 BPM에 따라 박자마다 한 번, `마디 머리만`은 각 마디의 첫 박자만 클릭하여 가장 성깁니다.
    - `음색`: `클릭 소리`(기본) / `우드블록` / `비프` 중 선택합니다.
    - `강세 강조`: 켜면 각 마디 첫 박자의 소리가 더 무거워져 강약을 들기 쉽습니다.
- 프로젝트에 템포 맵이 있으면 메트로놈이 각 BPM 변경점을 자동으로 따르므로 클릭이 음악과 어긋나지 않습니다.

## 4. 파일 브라우저

파일 브라우저를 사용하면 특정 폴더를 열고, 그 안의 오디오 및 동영상 미디어 파일을 조건 검색 및 정렬하고, HiFiShifter의 트랙 인터페이스로 드래그 앤 드롭할 수 있습니다. 동영상 파일은 보라색, 오디오 파일은 파란색 아이콘으로 표시됩니다. 검색은 정규 표현식을 지원합니다. 미디어 파일을 클릭하면 자동으로 미리듣기가 재생됩니다(동영상은 오디오 트랙만 미리듣기). `Ctrl` 및 `Shift` 키를 누른 상태에서 파일을 다중 선택할 수 있습니다. 왼쪽 드래그로 하나 이상의 미디어 파일을 시간축에 일괄적으로 추가할 수 있습니다. 오른쪽 드래그로 `시간을 가로질러 추가` / `트랙 간 추가` 메뉴가 나타납니다. `트랙 간 추가`는 여러 미디어 오디오 클립을 세로 방향으로 여러 트랙에 걸쳐 시간축에 추가할 수 있습니다.

트랙 영역에 포커스가 있을 때 단축키 `Ctrl + F`를 누르면 빠른 검색 창이 열립니다. 이것은 파일 브라우저 기능의 간소화된 버전으로, 폴더 내 오디오/동영상 미디어 파일을 빠르게 조건 검색 및 미리듣기(동영상은 오디오 트랙만)하고 시간축에 추가할 수 있습니다.

## 5. 파라미터 에디터

파라미터 에디터는 HiFiShifter의 핵심 기능 중 하나로, 현재 선택된 트랙의 다양한 파라미터를 편집할 수 있습니다.

트랙의 파라미터 편집 기능을 활성화하려면 먼저 해당 트랙의 합성 버튼 `C`를 누르고 오디오 분석이 완료될 때까지 기다려야 합니다. HiFiShifter는 오프라인 렌더링을 사용하며, 파라미터를 편집할 때마다 다시 렌더링이 완료될 때까지 기다린 후에 청취할 수 있습니다.

파라미터 에디터 제목 왼쪽의 `타임라인 뷰 동기화` 버튼(링크 아이콘)으로 파라미터 에디터와 트랙 뷰의 가로 동기화를 켜거나 끌 수 있습니다. 활성화하면(기본값) 두 뷰의 가로 위치와 확대/축소가 완전히 일치하며 양방향으로 연동됩니다: 어느 뷰에서 스크롤하거나 확대/축소해도 다른 뷰가 함께 따라갑니다. 활성화한 순간에는 트랙 뷰를 기준으로 파라미터 에디터가 맞춰집니다. 트랙 뷰 왼쪽에는 트랙 헤더 영역이 있으므로, 파라미터 에디터는 좌우 오프셋을 자동으로 보정하여 두 패널에서 그리드 선과 타임라인 눈금이 같은 화면 위치에 정렬됩니다. 비활성화하면 두 뷰는 독립적으로 확대/축소·스크롤됩니다.

### 1. 알고리즘 및 파라미터

현재 버전의 HiFiShifter는 다음 3가지 음성 튜닝 알고리즘과 파라미터를 지원합니다.

- **PC-NSF-HiFiGAN**(인터페이스 알고리즘 목록에는 `nsf-hifigan`으로 표시됨): OpenVPI의 오픈소스 노래 특화 hifigan 보코더로, HiFiShifter의 기본 알고리즘입니다.
    - `피치`: 음성의 피치를 조정합니다.
    - `포먼트 시프트`: 음성의 포먼트 시프트를 조정합니다.
    - `브레스 게인`: 음성의 브레스(숨소리) 볼륨을 조정합니다(VR-hnsep 모델 기반).
    - `텐션`: 음성의 텐션을 조정합니다.
    - `볼륨`: 음성의 볼륨을 조정합니다.
    - `다이내믹`: 음성의 라우드니스를 조정합니다.
    - `팬`: 음성의 팬을 조정합니다.
    참고: `브레스 게인`과 `텐션`은 모두 툴바의 `하모닉 분리` 스위치를 먼저 켜야 합니다. 켜면 렌더링 비용이 추가됩니다(처음에는 각 오디오 클립을 한 번씩 분리해야 하므로 시간이 걸릴 수 있습니다). 끄면 분리를 전혀 수행하지 않으며, 이 두 파라미터는 회색으로 표시되고 커브는 보이지만 편집할 수 없으며 합성에도 관여하지 않습니다. 또한 `포먼트 시프트`, `브레스 게인`, `텐션` 세 파라미터는 해당 트랙 그룹의 합성 스위치(`C`)가 켜져 있어야 하며, 그렇지 않으면 마찬가지로 회색으로 표시됩니다.
- **World**: 오픈소스 고품질 음성 분석 및 합성 알고리즘.
    - `피치`: 음성의 피치를 조정합니다.
    - `볼륨`: 음성의 볼륨을 조정합니다.
    - `다이내믹`: 음성의 라우드니스를 조정합니다.
    - `팬`: 음성의 팬을 조정합니다.
- **VsLib**(인터페이스 알고리즘 목록에는 `vslib`로 표시됨): VocalShifter 공식 음성 분석 및 합성 라이브러리. VsLib 알고리즘은 Windows x86_64 버전에서만 사용 가능합니다.
    - `피치`: 음성의 피치를 조정합니다.
    - `포먼트 시프트`: 음성의 포먼트 시프트를 조정합니다.
    - `브레스`: 음성의 브레스(숨소리) 강도를 조정합니다.
    - `볼륨`: 음성의 볼륨을 조정합니다.
    - `다이내믹`: 음성의 라우드니스를 조정합니다.
    - `팬`: 음성의 팬을 조정합니다.
    - `합성 모드`: 음성의 합성 모드를 조정합니다. 특정 모드에서는 일부 파라미터가 무효화될 수 있습니다.
        - `모노`: VocalShifter의 M 알고리즘, 단음 악기용.
        - `모노 (포먼트)`: VocalShifter의 V 알고리즘, 단음 보컬용.
        - `코러스`: VocalShifter의 P 알고리즘, 하모니용.

하나의 트랙은 하나의 알고리즘만 사용할 수 있습니다. 여러 알고리즘을 동시에 사용하려면 별도의 트랙으로 분리하세요.

트랙 그룹은 파라미터를 공유하며, 하위 트랙은 루트 트랙으로부터 파라미터를 상속받습니다. 특히 하위 트랙에는 `센트 차`, `도수 차`, `포먼트 차`라는 세 가지 추가 파라미터가 있어 루트 트랙에 대한 상대적인 피치와 음색 변화를 편리하게 조정할 수 있습니다. `도수 차`는 프로젝트의 스케일 설정을 기준으로 합니다. 파라미터 편집기 도구 모음에서 하위 트랙의 `센트 차` / `도수 차`는 `피치` 버튼 드롭다운에, `포먼트 차`는 `포먼트 시프트` 버튼 드롭다운에, `다이내믹`은 `볼륨` 버튼 드롭다운에 통합되어 있습니다.

`선택` 도구로 `피치` 구간을 복사한 후, `센트 차`나 `도수 차`에 붙여넣으면 적절한 오프셋 값이 자동 계산되어 적용됩니다.

### 2. 선택 도구

선택 도구를 사용하면 파라미터 라인 구간을 선택하고, 드래그하거나 마우스 오른쪽 버튼 컨텍스트 메뉴를 통해 파라미터를 조정할 수 있습니다.

자주 사용하는 단축키:

- `Ctrl + C`: 복사
- `Ctrl + X`: 파라미터 프레임 잘라내기(선택한 파라미터 선을 클립보드에 복사하고 지워서 다른 곳에 붙여넣을 수 있음)
- `Ctrl + V`: 붙여넣기
- `Ctrl + Z`: 실행 취소
- `Ctrl + Shift + Z` / `Ctrl + Y`: 다시 실행(macOS: `⌘ + ⇧ + Z` / `⌘ + Y`)
- `Ctrl + A`: 모두 선택

- `BackSpace`: 초기화(선택 영역을 기본값으로 되돌리며 클립보드에는 기록하지 않음)
- `-` / `=`: 현재 클립 범위의 파라미터 선 전체를 아래로/위로 이동
- `[` / `]`: 선택 범위 내 파라미터 라인을 아래로/위로 이동

위 두 이동 단축키 중 `-` / `=`는 클립 범위 전체의 파라미터 선을 이동하고, `[` / `]`는 현재 선택한 구간만 이동합니다. 둘 다 세 가지 단계를 지원해 "크게"에서 "미세"까지 한 번에 조정할 수 있습니다.

| 단계               | 클립 범위                 | 선택 범위                 | 피치 단계           |
| ------------------ | ------------------------- | ------------------------- | ------------------- |
| 기본               | `-` / `=`                 | `[` / `]`                 | ±1 반음             |
| 크게(`Shift` 누름) | `Shift + -` / `Shift + =` | `Shift + [` / `Shift + ]` | ±12 반음(한 옥타브) |
| 미세(`Ctrl` 누름)  | `Ctrl + -` / `Ctrl + =`   | `Ctrl + [` / `Ctrl + ]`   | ±1 센트             |

길게 누르고 있으면 한 번 실행된 뒤 잠시 후 자동으로 반복되므로 연속 미세 조정에 편리합니다. 피치 외의 파라미터도 이에 대응하는 세 단계(기본 약 2.5%, 크게 약 12.5%, 미세 약 0.25%)로 움직입니다. 이 단축키들은 `옵션 -> 키보드 단축키`의 `파라미터 에디터` 그룹에서 변경할 수 있습니다(macOS에서 `Ctrl`은 `Command`에 해당).

선택한 파라미터 라인을 왼쪽 드래그하면 `드래그 방향` 설정에 따라 수직, 수평 또는 자유롭게 이동할 수 있습니다. 왼쪽 드래그 중에 오른쪽 버튼(또는 `D` 키)을 누르면 드래그 방향을 빠르게 전환할 수 있습니다.

뷰의 좌우 가장자리 근처까지 드래그하면 파라미터 에디터가 자동으로 가로 스크롤됩니다(선택 도구는 포인터가 움직일 때만 조금씩 진행하며, 포인터가 가장자리에 멈춰 있으면 계속 스크롤되지 않습니다). 자세한 내용은 [그리기 도구](#3-그리기-도구) 장을 참고하세요.

선택한 파라미터 곡선을 오른쪽 드래그하면 진폭을 조정할 수 있습니다. 위로 드래그할수록 진폭이 커지고 아래로 드래그할수록 작아지며, 끝까지 내리면 완전히 평탄해집니다. 피치 파라미터는 비브라토 등 세부만 강화하거나 약화되고 전체 윤곽과 음정은 유지되어 피치 전체가 올라가는 일은 없습니다. 드래그 중 실시간 미리보기가 지원됩니다.

파라미터 에디터 화면 안에서 마우스 오른쪽 버튼을 클릭하면 컨텍스트 메뉴가 열리고, 선택한 파라미터 라인에 대해 `초기화`, `센트 단위로 조바꿈...`, `도 단위로 조바꿈...`(피치 파라미터에만 표시됩니다), `다음 값으로 설정...`, `평균화...`, `스무딩...`, `비브라토 추가...`, `퀀타이즈...`, `평균 퀀타이즈...` 등 다양한 처리 작업을 수행할 수 있습니다. 파라미터가 볼륨 또는 다이내믹일 때는 `다이내믹으로 변환` / `볼륨으로 변환`도 나타나며(두 작업은 단순 복사가 아니라 음량 등가 환산입니다), 파라미터가 피치일 때는 `음높이 참조 클립으로 저장`과 `MIDI로 내보내기`도 있습니다.

이 처리 작업들에는 기본 단축키가 있습니다: `센트 단위로 조바꿈`은 `Ctrl + F`, `도 단위로 조바꿈`은 `Ctrl + I`, `다음 값으로 설정`은 `Ctrl + 0`, `평균화`는 `Ctrl + E`, `스무딩`은 `Ctrl + M`, `비브라토 추가`는 `Ctrl + B`, `퀀타이즈`는 `Ctrl + P`, `평균 퀀타이즈`는 `Ctrl + Q`이며, 모두 `옵션 → 키보드 단축키...`에서 변경할 수 있습니다.

`비브라토 추가...`를 선택하면 **적용 팝업**이 열립니다: 왼쪽 열에서 프리셋을 선택하면(각 행에 해당 프리셋의 파형 썸네일이 표시됩니다) 오른쪽에서 **선택 범위의 실제 곡선**에 그 프리셋을 얹어 그려 보여줍니다 — 점선이 원래 곡선, 실선이 적용 결과이므로 비브라토가 어떤 피치 움직임 위에 얹히는지 한눈에 보입니다. 미리보기 오른쪽 위에서 `배치 방식`을 선택할 수 있습니다(비브라토가 무엇을 기준으로 흔들릴지를 결정하며 기본값은 `시작 → 끝`입니다. `기존 곡선 유지`를 선택하면 원래의 피치 움직임을 그대로 둔 채 기존 곡선 위에 비브라토를 겹칠 수 있습니다). 팝업에는 깊이/속도 두 개의 빠른 조절 항목도 있으며, 이는 이번 적용의 로컬 복사본만 바꿉니다 — `적용`은 이 값을 편집 파이프라인에 넘길 뿐 **라이브러리에 기록하지 않습니다**(남겨 두려면 `저장`을 누르세요). 선택 영역이 없을 때는 먼저 파라미터 라인 전체가 암묵적으로 선택됩니다. 팝업 왼쪽 아래의 `선택 범위에서 비브라토 프리셋 만들기`는 현재 선택 영역에 작용하여, 그 안에 이미 있는 비브라토를 역산해 하나의 프리셋으로 만들어 줍니다.

`Alt` 키를 누르면 선택 범위에 대해 4점 편집 모드가 됩니다. VocalShifter의 동일 유형 기능과 유사하게 4개 점을 드래그하여 현재 파라미터 라인을 휘게 할 수 있습니다.

`Alt` 키를 누른 상태에서 선택 영역 가장자리를 드래그하면 선택 영역 내의 파라미터 라인을 스트레치할 수 있습니다.

다중 선택 범위 모디파이어(기본값 `Ctrl`, macOS에서는 `Command`. `옵션 -> 키보드 단축키` 의 `파라미터 에디터 수정키` 그룹에서 변경할 수 있습니다)를 누른 채 선택 도구를 사용하면 **여러 개의 선택 범위**를 만들 수 있습니다. 누른 채 드래그하면 범위를 **추가**하고(기존 범위와 겹치거나 맞닿으면 하나로 합쳐집니다), 누른 채 기존 범위를 클릭하면 그 범위를 **해제**합니다. 여러 범위는 시간축에서 서로 독립적이며, 복사, 잘라내기, 붙여넣기, 전조, 다음 값으로 설정, 평균화, 스무딩, 양자화, 평균 양자화, 진폭 조정, 형태 변형, 드래그, 가장자리 스트레치 등 모든 작업이 **범위별로 독립적으로** 실행됩니다. 범위 사이의 선택되지 않은 구간은 항상 그대로 남고, 채워지거나 압축·병합되지 않습니다. 예를 들어 `0~1s` 와 `2~3s` 를 복사한 뒤 `0~3s` 를 선택해 붙여넣으면 `0~1s` 와 `2~3s` 에만 기록되고 `1~2s` 는 원래 값을 유지합니다. 반대로 `0~3s` 를 복사한 뒤 `0~1s` 와 `2~3s` 를 선택해 붙여넣으면 첫 번째 범위에는 클립보드의 앞 1초, 두 번째 범위에는 클립보드의 마지막 1초가 들어가며, `1~2s` 에는 아무것도 기록되지 않고 클립보드 미리보기도 표시되지 않습니다.

### 3. 그리기 도구

그리기 도구를 사용하면 파라미터 라인을 자유롭게 그릴 수 있습니다. 기본 단축키는 `F8`입니다.

왼쪽 드래그로 `드래그 방향` 설정에 따라 자유롭게 또는 수평으로 파라미터 라인을 그릴 수 있습니다. 왼쪽 드래그 중에 오른쪽 버튼(또는 `D` 키)을 누르면 드래그 방향을 빠르게 전환할 수 있습니다.

뷰의 좌우 가장자리 근처까지 드래그하면 뷰가 자동으로 가로 스크롤되며, 가장자리에 가까울수록 더 빠르게 스크롤되어 보이지 않는 곳까지 한 번에 그릴 수 있습니다. 그리기, 직선과 비브라토 도구는 누르고 드래그하는 동안 계속 스크롤되고, 선택 도구는 포인터가 움직일 때만 조금씩 진행하며 포인터가 가장자리에 멈춰 있으면 계속 스크롤되지 않습니다. 세로 방향은 자동으로 스크롤되지 않습니다. 이 동작은 설정이 필요 없으며 끌 수도 없습니다.

오른쪽 드래그로 현재 파라미터 라인을 재설정할 수 있습니다.

파라미터 에디터 도구 모음의 그리기 유형 도구 버튼을 **오른쪽 클릭**하면 세 가지 그리기 도구 — 그리기 도구, 직선 도구, 비브라토 도구 — 사이에서 전환할 수 있습니다(메뉴에는 각 도구의 단축키도 함께 표시됩니다). 도구 모음 버튼에 표시되는 것은 현재 선택된 도구이며, 왼쪽 클릭으로 바로 활성화할 수 있습니다.

파라미터 에디터에는 네 가지 도구가 있습니다: 선택 도구(`F7`), 그리기 도구(`F8`), 직선 도구(`F9`), 비브라토 도구(`F10`). `Tab`을 누르면 선택 도구와 마지막에 사용한 그리기 계열 도구 사이를 전환할 수 있습니다. **현재 사용 중인 도구는 기억되며**, 프로그램을 다시 시작해도 유지됩니다.

### 4. 직선 도구

직선 도구는 시작점에서 끝점까지의 직선을 그립니다. 기본 단축키는 `F9`입니다.

직선 도구는 「비브라토 도구 + 직선 프리셋」입니다 — 따라서 다음 절에서 설명하는 모든 제스처(휠로 깊이·속도 조절, `,` `.`과 마우스 사이드 버튼으로 프리셋 전환, 두 키 동시 입력 초기화, 읽기 버블)는 직선 도구에서도 **그대로 사용할 수 있습니다**. 유일한 차이는 시작할 때 쓰는 프리셋입니다: 직선 도구는 항상 「직선」 프리셋으로 시작하고, 비브라토 도구는 선택해 둔 프리셋으로 시작합니다.

왼쪽 드래그로 `드래그 방향` 설정에 따라 자유롭게 또는 수평으로 직선을 그릴 수 있습니다. 왼쪽 드래그 중에 오른쪽 버튼(또는 `D` 키)을 누르면 드래그 방향을 빠르게 전환할 수 있습니다.

드래그 중에 깊이를 올리면 그려지는 것은 더 이상 직선이 아닙니다 — 이것은 의도된 동작입니다: 직선 도구는 "비브라토 0에서 시작"하는 도구이며, 이 한 획에 얼마나의 비브라토를 넣을지는 사용자가 결정합니다. 반대로 비브라토 도구에서 두 키 초기화 제스처를 하거나 프리셋을 돌려 「직선」에 도달하면 직선 도구로 바로 전환됩니다.

오른쪽 드래그로 현재 파라미터 라인을 재설정할 수 있습니다.

### 5. 비브라토 도구

비브라토 도구는 시작점과 끝점 사이에 한 겹의 비브라토를 얹습니다. 기본 단축키는 `F10`입니다.

왼쪽 드래그로 `드래그 방향` 설정에 따라 자유롭게 또는 수평으로 비브라토를 그릴 수 있습니다. 왼쪽 드래그 중에 오른쪽 버튼(또는 `D` 키)을 누르면 드래그 방향을 빠르게 전환할 수 있습니다.

왼쪽 드래그 중에 마우스 휠을 굴리면 비브라토의 **깊이**를, 수정 키 `Alt`를 누른 채 휠을 굴리면 **속도**를 조정할 수 있습니다. 수정 키 `미세 조정`(기본 `Ctrl`)을 누른 채 휠을 굴리면 더 미세하게 조정됩니다. 드래그하는 동안 포인터 옆에 읽기 버블이 떠서 **첫 줄은 파라미터 값**(이 획이 떨어진 값)을, **그 아래는 비브라토 상태**(현재 프리셋, 깊이와 속도)를 보여줍니다. 두 정보는 따로 뜨지 않고 하나의 버블로 합쳐져 표시됩니다 — 그렇지 않으면 나중에 뜬 것이 먼저 뜬 것을 가립니다. 버블 전체는 `옵션 → 파라미터 값 팝업` 스위치로 표시 여부가 결정되며, 끄면 표시되지 않습니다. 깊이는 **음수**까지 조절할 수 있습니다: 음수 깊이는 파형 전체를 반전하는 것과 같고(시작할 때 아래로 흔들림), 0에서 막히지 않고 계속 음쪽으로 조절할 수 있습니다.

**깊이의 단위, 한 칸의 크기, 최대값은 모두 현재 파라미터 유형이 결정합니다.** 같은 깊이 값이라도 파라미터에 따라 전혀 다른 양이기 때문입니다:

- **피치류**(`피치`, 하위 트랙의 `센트 차` / `도수 차`, `포먼트 시프트`): 깊이는 **센트** 단위이며 한 칸에 24센트입니다. 상한은 도구의 깊이 상한(±1200센트)이고, 파라미터 자체의 범위가 더 좁으면 그 범위를 따릅니다 — 그보다 크게 조절하면 쓰기 클램프에 의해 파형 꼭대기가 평평한 직선이 될 뿐 "더 세게 흔들리지"는 않습니다.
- **게인류**(`다이내믹`, `볼륨`, `브레스 게인`): 깊이는 **백분율** 단위이며 한 칸에 2%입니다. 100%는 게인을 풀폭으로 흔드는 것입니다.
- **그 외 값역류**(`팬`, `텐션`, `브레스`): 깊이는 마찬가지로 **백분율** 단위입니다 — "해당 파라미터 풀스윙의 몇 퍼센트"를 뜻하며 한 칸에 2%, 100%는 값역 전체를 채웁니다. 따라서 팬의 `30%`와 브레스의 `30%`는 같은 규모의 깊이이며, 각 파라미터의 원래 숫자로 다시 환산할 필요가 없습니다.

한 칸의 스텝은 모두 해당 파라미터 **풀스윙의 1/50**이므로, "0에서 풀까지"는 어떤 파라미터에서도 약 50칸입니다. 기술자가 커버하지 않는 파라미터는 내장 범위로 폴백하므로 "휠이 안 돌아가거나" "한 칸에 끝까지 튀는" 일은 없습니다.

드래그 중에도 언제든 비브라토 프리셋을 전환할 수 있습니다:

- **마우스 사이드 버튼**: 앞쪽 버튼으로 다음 프리셋, 뒤쪽 버튼으로 이전 프리셋으로 전환합니다.
- **키보드**: `,`로 이전 프리셋, `.`로 다음 프리셋으로 전환합니다(`옵션 → 키보드 단축키...`에서 변경할 수 있습니다).

프리셋은 파형(사인 / 삼각 / 상승 톱니 / 하강 톱니 / 사각 / 사다리꼴 / 트릴 계단 / 직접 그리기)과 엔벨로프(페이드 인, 부풀림, 페이드 아웃), 속도 변화를 결정하며, 깊이와 속도는 이번 드래그에서 사용자가 조정하는 값입니다. 드래그 중의 깊이/속도 미세 조정은 프리셋을 **덮어쓰지 않으며** 다음 시작에도 남지 않습니다 — 프리셋은 프리셋 관리자에서만 수정할 수 있습니다. 하지만 **프리셋 전환은 영구적입니다**: 드래그 중 사이드 버튼이나 `,` `.`로 프리셋을 바꾸면 현재 사용하는 프리셋 자체가 바뀐 것입니다(설정에 기록되므로 프로그램을 다시 시작해도 유지됩니다).

프리셋을 돌리다가 `직선` 프리셋에 닿으면 곧바로 **직선 도구로 전환**됩니다(직선 도구는 곧 "비브라토 도구 + 직선 프리셋"입니다). 직선 도구에서 돌리기 시작하면 비브라토 도구로 돌아오면서 인접한 프리셋으로 전환됩니다. 도구 전환은 기억된 비브라토 프리셋을 **바꾸지 않습니다** — 직선을 그리고 돌아와도 원래 고른 프리셋이 그대로입니다.

전환할 때 깊이와 속도의 계승 여부는 **따로** 판단합니다: 진폭을 조절한 적이 있으면 진폭을 유지하고, 속도를 조절한 적이 있으면 속도를 유지하며, 조절하지 않은 항목은 새 프리셋이 가진 값을 따릅니다 — 바뀌는 것은 음색이고, 사용자가 손대지 않은 항목은 당연히 새 프리셋의 것을 따라야 합니다.

드래그 중에는 한 번에 알려진 상태로 돌아가는 「두 키」 제스처도 몇 가지 있습니다:

- **프리셋 전환 두 키를 동시에 누르기**(기본 `,` `.`), 또는 **마우스의 두 사이드 버튼을 동시에 누르기**: 직선 도구로 전환하여(그 즉시 직선을 그릴 수 있음) 이번 제스처가 기록한 진폭과 주파수 조절 기록을 지웁니다.
- **진폭 증가/감소 두 키를 동시에 누르기**(기본 `↑` `↓`), 또는 휠이 진폭 조절 상태일 때(주파수 수정 키 `Alt`를 누르지 않은 상태에서) **마우스 가운데 버튼 누르기**: 진폭을 프리셋이 가진 값으로 되돌리고 진폭 조절 기록을 지웁니다.
- **주파수 증가/감소 두 키를 동시에 누르기**(기본 `←` `→`), 또는 휠이 주파수 조절 상태일 때(`Alt`를 누른 상태에서) **마우스 가운데 버튼 누르기**: 주파수를 프리셋이 가진 값으로 되돌리고 주파수 조절 기록을 지웁니다.

「기록 지우기」의 효과는: 이후 프리셋을 전환할 때 지워진 항목은 더 이상 사용자의 조절을 따르지 않고 새 프리셋이 가진 값을 따릅니다.

확대/축소에 따라 값이 크게 변하는 파라미터에서도 드래그의 속도는 항상 Hz 단위이므로, 같은 프리셋을 아무리 길게 드래그해도 들리는 빠르기는 같습니다.

오른쪽 드래그로 현재 파라미터 라인을 재설정할 수 있습니다.

### 6. 비브라토 프리셋

비브라토 프리셋은 재사용할 수 있는 비브라토 파라미터 묶음입니다. `옵션 → 비브라토 프리셋 관리...`, 파라미터 에디터 도구 모음의 그리기 유형 도구 버튼 **오른쪽 클릭 → 비브라토 프리셋**(하위 메뉴에 사용 가능한 프리셋 전체가 나열되고 맨 아래에 `프리셋 관리...`가 있습니다), 또는 `비브라토 추가...` 적용 팝업 왼쪽 아래의 `선택 범위에서 비브라토 프리셋 만들기`에서 열 수 있습니다. **기본으로 사용되는 프리셋은 `내추럴`입니다** — 비브라토 도구로 전환할 때 원하는 것은 들리는 비브라토이고, "비브라토 0"의 역할은 이제 직선 도구가 담당합니다. 출고 프리셋 목록에서 `직선`은 여전히 목록 맨 위에 있지만, 그것은 **프리셋 시퀀스 안에서 직선 도구가 차지하는 위치**입니다: 목록에서 그것을 선택하는 것은 직선 도구로 전환하는 것과 같습니다.

프리셋 입구(도구 모음 버튼)에 표시되는 것은 **비브라토 도구**가 현재 사용하는 프리셋입니다 — 지금 직선 도구를 쓰고 있더라도 그 값을 그대로 표시합니다. 비브라토 도구로 돌아갈 때 쓰게 될 음색이기 때문입니다. 목록에서 체크된 것도 그 프리셋입니다.

프리셋 관리자 맨 위에는 **파형 미리보기**가 있습니다(행 전체 폭이며 스크롤에 참여하지 않습니다 — 아래 파라미터를 조정할 때 항상 보이고 화면 밖으로 굴러가지 않습니다). 파라미터를 바꾸면 즉시 다시 그립니다. 그 아래 왼쪽이 프리셋 목록, 오른쪽이 파라미터 편집기입니다. 세로 눈금은 **고정된** 스케일입니다: 대화상자를 열거나 프리셋을 전환할 때 그 프리셋의 진폭에 맞춰 한 번 피팅되어(파형이 보통 캔버스의 60% 정도를 차지합니다) 이후 편집 중에는 변하지 않습니다. 덕분에 파형의 높이가 곧 깊이이며, 축의 `+N / −N` 눈금 라벨과 함께 진폭 크기를 바로 읽을 수 있습니다. 깊이를 조절할 때 보이는 것은 파형이 실제로 커졌다 작아지는 모습이지, 전체가 다시 확대/축소되는 것이 아닙니다(그렇게 하면 "한 번 흔들릴" 뿐 크기를 읽을 수 없습니다). 파형을 범위 밖으로 끌어냈다면 미리보기 카드의 `맞춤`을 눌러 다시 피팅하면 됩니다. 미리보기 카드의 재생 버튼으로 현재 프리셋을 **합성 음색으로 청취**할 수 있습니다 — 피아노 롤 건반과 같은 음색을 사용하며 보코더를 돌릴 필요가 없고, 누르면 즉시 소리가 나고 한 번 더 누르면 멈춥니다; 들리는 것은 그린 곡선 그대로입니다(페이드 인, 부풀림, 불규칙도 포함). 시스템 프리셋도 청취할 수 있습니다.

미리보기 캔버스는 보기만 하는 것이 아닙니다: **왼쪽/오른쪽 가장자리의 작은 사각형 핸들**을 드래그하면 페이드 인 / 페이드 아웃 길이가 바뀌고(커서가 좌우 크기 조절로 바뀝니다), 파형 본체를 누른 채 드래그하면 시작 위상(좌우)과 깊이(상하)가 바뀝니다. 두 핸들은 모두 비브라토 선의 반대쪽 끝까지 끌 수 있습니다 — 페이드 인을 최대로 당기면 선 전체가 약에서 강으로 향하고, 양쪽 모두 최대이면 두 구간의 게인이 곱해져 중간이 부드럽게 꺼집니다. 깊이는 **캔버스와 1:1**입니다 — 눈금이 고정되어 있으므로(위 참조) "파형 피크를 중간선까지 끌기"가 곧 "깊이를 0까지 끌기"이며, 깊이가 작을 때는 픽셀당 이동하는 센트도 작아 한 번에 날아가지 않습니다. `미세 조정` 수정 키(기본 `Ctrl`, macOS는 `Command`)를 누르고 있으면 이동량이 1/5로 줄어 한 픽셀씩 조정하기에 알맞습니다. 수정 키는 드래그 도중에도 언제든 누르거나 뗄 수 있으며 현재 드래그는 중단되지 않고(값이 튀지 않습니다) 이후 한 칸의 보폭이 더 촘촘해지거나 거칠어질 뿐입니다. 모든 제스처가 바꾸는 것은 현재 초안이며 `저장`을 눌러야 프리셋에 기록됩니다. 시스템 프리셋의 캔버스는 폼과 마찬가지로 읽기 전용입니다.

`저장`은 **창을 닫지 않습니다** — 한 번 저장한 뒤 계속 조정하거나 다른 프리셋으로 전환할 수 있습니다. 편집하던 중에 다른 프리셋으로 전환하면 현재 변경 사항이 **라이브러리에 자동으로 기록**됩니다(`저장`을 누른 것과 같은 경로이므로 프리셋을 바꿨다는 이유로 사라지지 않습니다). 라이브러리에 사용자 프리셋이 새로 생기는 경로는 두 가지뿐입니다: `내 것으로 복제`를 눌렀거나, 시스템 프리셋에 손을 댔을 때(위 참조)입니다. 창 왼쪽 아래의 `닫기` 버튼(또는 `Esc`)으로 창을 닫습니다.

왼쪽 아래의 `내보내기`는 현재 선택한 프리셋을 JSON 파일로 저장하고, `가져오기`는 파일에서 읽어 들입니다: 중복 프리셋은 자동으로 건너뛰며(같은 파일을 두 번 가져와도 두 배가 되지 않습니다) 가져오기가 끝나면 새 프리셋이 선택되고 피드백이 표시됩니다. 잘못된 파일(예: 외관 테마 JSON)은 이유와 함께 거부됩니다. 가져온 프리셋은 파일에 시스템 프리셋의 이름이 있더라도 항상 새 사용자 프리셋입니다.

조정할 수 있는 파라미터는 네 그룹으로 나뉩니다:

- **파형**: 모양(사인 / 삼각 / 상승 톱니 / 하강 톱니 / 사각 / 사다리꼴 / 트릴 계단)과 치우침. 치우침의 의미는 모양에 따라 달라집니다: 삼각파에서는 상승 구간의 비율이고 사각파류에서는 듀티 비율입니다. 보컬 비브라토가 자연스럽게 들리게 하는 가장 중요한 파라미터입니다 — 실제 사람 비브라토의 상승과 하강은 비대칭입니다. 모양 오른쪽의 `직접 그리기...` 버튼은 **단일 주기 편집 캔버스**를 펼칩니다: 누른 채 드래그로 이 하나의 주기 파형을 칸 단위로 그리면 됩니다(초기값은 현재 모양에서 가져오므로, 0부터 그리는 것보다 모양을 고치는 쪽이 손이 편합니다). `부드럽게`는 한 번 누를 때마다 한 번 다듬어지고 **누르고 있으면 계속 다듬어집니다**(키보드 자동 반복과 같은 감각입니다). 초기화 버튼은 두 개입니다: `이전 모양으로`는 직접 그리기에 들어가기 전 파형으로 돌아가고(추출이나 직접 그리기로 만들어진 표일 수 있습니다), `{모양}(으)로 초기화`는 표를 모양 드롭다운에서 현재 선택한 모양으로 다시 샘플링합니다 — 직접 그리다 잘못 그려 처음부터 다시 하고 싶거나, 추출해 온 파형을 정갈한 사인으로 바꾸고 싶을 때 모두 이 버튼을 씁니다. 직접 그리는 중에 모양을 바꿔도 편집기에서 나가지 않으며 바꾸면 즉시 적용됩니다. 표는 앞끝과 뒷끝이 이어져 있어 이음새에 꺾임이 생기지 않습니다.
- **깊이**: 진폭(현재 파라미터 유형에 따라 표시됩니다: 피치와 센트류 파라미터는 센트, 다이내믹 등 게인 파라미터와 나머지 값역 파라미터는 **풀스윙 기준 백분율**입니다), 부풀림(시작/끝의 깊이 배율), 중심 오프셋, 불규칙도. 불규칙도는 결정론적 노이즈로 위상과 깊이를 흔들어 기계적인 느낌이 아니라 "흔들리는" 느낌을 만듭니다. 옆의 주사위 버튼으로 **흔들림 패턴을 새로 뽑을 수 있습니다**(시드는 프리셋 필드이므로 같은 프리셋은 렌더링/청취/적용 때마다 완전히 동일합니다). 불규칙도가 0이면 바꿀 패턴이 없습니다(노이즈가 통째로 곱해져 없어지므로) — 주사위 버튼은 비활성화되고 이유가 표시됩니다.
- **속도**: 주파수(Hz) 또는 구간 전체의 주기 수로 측정합니다(측정 방식), 끝의 속도(문장 끝으로 갈수록 빠르게 또는 느리게 변합니다), 정수 주기로 마무리(노트가 기준선에 깔끔히 떨어지도록 합니다).
- **엔벨로프**: 페이드 인 / 페이드 아웃의 길이와 곡선 모양(길이는 비브라토 선 전체가 상한이며 최대로 당기면 전 구간 페이드 인 / 페이드 아웃이 됩니다), 시작 위상.

프리셋 파라미터에 `배치 방식`은 포함되지 않습니다: 그것은 **적용할 때**의 설정으로, `비브라토 추가...` 팝업 미리보기의 오른쪽 위에서 선택합니다(앞 참조). 비브라토가 무엇을 기준으로 흔들릴지 결정합니다 — `시작 → 끝`, `시작값 유지`, `끝값 유지`, `전체 평균`, 또는 **기존 곡선 유지**(기존 곡선 위에 겹치며 원래의 피치 움직임을 유지합니다).

시스템 프리셋 자체는 읽기 전용이지만(출고 정의는 언제든 복원할 수 있습니다) 파라미터는 자유롭게 조정할 수 있습니다: **손대는 순간 프로그램은 곧바로 「출고 정의 + 이번 변경」을 하나의 사용자 프리셋으로 새로 저장**하고 편집 포커스를 그쪽으로 옮깁니다(목록에 그 자리에서 새 행이 생기고, 이름은 `내추럴 2` 같은 번호가 미리 채워지며 목록도 자동으로 그곳으로 스크롤됩니다). "시스템 프리셋을 편집하면 사용자 프리셋이 생긴다"는 것을 뒤에서 뒤늦게 발견하는 것이 아니라 바로 눈으로 볼 수 있습니다. 원래의 시스템 프리셋은 언제나 그대로 남습니다. **프리셋을 현재 사용으로 설정**하는 눈에 보이는 입구는 두 개입니다: 목록 행 맨 왼쪽의 원점(실심 = 현재 사용 중, 속심 = 전환 가능, 마우스를 올리면 설명이 표시됨)을 클릭하거나, 편집기 상단의 `현재 사용으로 설정` 버튼을 클릭하는 것입니다 — 후자는 지금 편집 중인 프리셋에 작용하며, 이미 현재 사용 중일 때는 `현재 사용 중`으로 바뀌고 비활성화됩니다. 목록 행을 더블 클릭하는 것도 같은 동작의 단축 방법입니다.

목록 항목을 클릭하는 것은 편집을 위해 선택하는 것일 뿐 **현재 사용으로 설정되지 않습니다** — 아직 정하지 않은 프리셋을 조정하는데 지금 그릴 음색이 함께 바뀌어서는 안 됩니다.

각 행의 오른쪽에는 **사용 / 사용 안 함** 버튼(눈 아이콘)이 있습니다: 사용 안 함으로 만든 프리셋은 파라미터 에디터 도구 모음의 프리셋 목록에 나타나지 않고, 드래그 중 단축키나 마우스 사이드 버튼으로 순환 전환할 때도 **건너뜁니다**. 시스템 프리셋과 사용자 프리셋 모두 사용 안 함으로 만들 수 있습니다 — 예를 들어 두세 개만 쓴다면 나머지를 꺼두면 도구 모음 목록과 순환 전환이 깔끔해집니다. 사용 안 함은 "프리셋을 고르는 방법"에만 영향을 줍니다: 프리셋 자체는 여전히 편집할 수 있고 현재 사용 프리셋이 될 수도 있습니다(지금 사용 중인 프리셋을 사용 안 함으로 만드는 것도 허용됩니다).

목록 행을 **오른쪽 클릭**하면 해당 프리셋의 컨텍스트 메뉴가 열립니다: `사용` / `사용 안 함`, `현재 사용으로 설정`, `이름 바꾸기`, `위로` / `아래로`, `내 것으로 복제`, `삭제`(시스템 프리셋의 삭제와 이름 바꾸기는 사용할 수 없고 복제본만 삭제할 수 있습니다). `이름 바꾸기`는 해당 행 위에 입력 상자가 겹쳐 펼쳐지며, Enter 또는 다른 곳을 클릭하면 제출되고 `Esc`로 취소합니다. 행에 마우스를 올리면 해당 프리셋의 설명과 요약으로 이루어진 사용자 지정 버블이 표시됩니다 — 요약의 첫 항목은 파형 모양입니다(샘플 표는 가장 비슷한 모양 이름을 알려주며, 어느 것도 닮지 않았으면 `직접 그린`이라고 표시합니다).

새로 만들기, `내 것으로 복제`, `선택 범위에서 추출`, `가져오기` 후에는 목록이 자동으로 새로 생긴 항목으로 스크롤됩니다 — 새 프리셋은 목록 끝에 추가되고, 목록이 길어지면 화면 밖에 놓이기 때문입니다.

프리셋 목록은 **드래그로 순서를 정렬**할 수 있습니다: 한 행을 누른 채 위아래로 끌어 인접 행의 중간선을 넘으면 자리가 바뀌고, 놓으면 저장됩니다. 드래그 중에는 끌고 있는 행이 어두워지고 놓을 위치에 하이라이트 표시선이 생깁니다. 목록의 상하 가장자리로 끌면 목록이 **자동으로 스크롤**됩니다(가장자리에 가까울수록 빠릅니다) — 프리셋이 많아도 한 번에 끌어올 수 있습니다. 시스템 프리셋과 사용자 프리셋은 각각 그룹을 이루어 따로따로 정렬됩니다(서로 섞이지 않습니다). 키보드 사용자는 오른쪽 클릭 메뉴의 `위로` / `아래로`로 같은 조정을 할 수 있습니다.

**선택 범위에서 비브라토 프리셋 추출**: 만족스러운 비브라토를 그려 놓았다면 그 구간을 선택하고 `비브라토 추가...` 적용 팝업 왼쪽 아래의 `선택 범위에서 비브라토 프리셋 만들기`를 클릭합니다. 프로그램은 피치 자체의 추세를 제거하고, 자기상관으로 주기를 측정하며, 잔차를 하나의 평균 주기로 접어 파형으로 삼고, 깊이·페이드 인/아웃·불규칙도를 측정해 바로 미세 조정할 수 있는 프리셋을 생성합니다. 접어서 얻은 파형은 한 번의 저역 통과(가장 낮은 몇 개의 하모닉만 유지)를 거치므로 결과는 **매끄러운** 곡선이며, 녹음 속 관측 노이즈까지 함께 저장해 울퉁불퉁해 보이는 일은 없습니다. 이 기능은 모든 파라미터에 사용할 수 있습니다.

### 7. 피치 스냅

다양한 편집 도구로 피치 파라미터를 편집할 때 피치 스냅을 사용하면 반음 또는 스케일에 스냅할 수 있습니다. `Shift` 키를 누르면 임시로 스냅을 전환할 수 있습니다.

피치 스냅 기능은 기본적으로 꺼져 있습니다. 피치 스냅 버튼을 마우스 오른쪽 버튼으로 클릭하면 피치 스냅 설정 메뉴가 열리며, 퀀타이즈 단위와 허용 오차를 조정할 수 있습니다.

- `퀀타이즈 단위`: `반음`과 `스케일` 두 가지 유형이 있습니다(기본값은 `반음`). 스케일을 선택하면 기준 스케일은 프로젝트의 스케일 설정입니다.
- `허용 오차`: 스냅의 허용 범위를 조정합니다(기본값은 0센트). 허용 오차 내의 피치 편집은 스냅되지 않고, 범위를 벗어난 편집은 가장 가까운 허용 오차 경계에 스냅됩니다.

예를 들어, 보컬 하모니 효과를 만들려면:

1. 프로젝트 스케일을 확인하고 설정합니다.
2. 피치 스냅을 활성화하고 퀀타이즈 단위를 `스케일`로 설정합니다.
3. 스케일 하이라이트 기능을 활성화하여 이동 도수를 쉽게 관찰할 수 있도록 합니다.
4. 선택 도구로 수직 드래그합니다.

또는 하위 트랙의 `센트 차` 및 `도수 차` 파라미터를 사용할 수도 있습니다:

1. 프로젝트 스케일을 확인하고 설정합니다.
2. 하모니 트랙의 헤더를 메인 보컬 트랙으로 드래그하여 트랙 그룹을 생성합니다(메인 보컬 = 루트, 하모니 = 하위).
3. 파라미터 에디터를 하모니 트랙의 `도수 차` 파라미터로 전환하고 필요한 도수선을 그립니다. `센트 차` 및 `도수 차` 편집도 피치 스냅을 지원하여 각각 정수 반음 및 정수 도수에 스냅할 수 있습니다.

이렇게 하면 도수 이동에 의한 하모니 효과를 빠르게 만들 수 있습니다. 마찬가지로 하위 트랙의 `포먼트 차`로 전환하여 프레임별 포먼트 시프트 곡선을 그리면 `포먼트 시프트`를 지원하는 알고리즘(NSF-HiFiGAN / vslib)에서 음색 차이가 있는 하모니를 만들 수 있습니다.

### 8. 음높이 참조 클립

트랙의 음높이 참조 클립은 타임라인에 피치 곡선을 저장할 수 있는 특수한 클립입니다.

음높이 참조 클립은 다음 경로를 통해 생성할 수 있습니다:

- `파일` 메뉴, MIDI 파일을 트랙 인터페이스로 드래그 앤 드롭, 또는 파라미터 에디터의 피치 파라미터에서 MIDI 파일을 직접 드래그 앤 드롭하여 가져옵니다. MIDI 가져오기 대화상자가 나타납니다.
    - MIDI 파일: 가져올 MIDI 파일을 선택할 수 있습니다. 다른 DAW에서 시스템 클립보드로 출력한 MIDI 데이터 파싱도 지원합니다. 현재 시스템 클립보드를 통한 MIDI 데이터 전송이 확인된 DAW는 Reaper와 FL Studio입니다.
        - Reaper: Reaper의 MIDI 에디터에서 노트를 선택하고 복사하면 선택한 노트 데이터가 시스템 클립보드로 출력되어 HiFiShifter에서 읽을 수 있습니다. Reaper의 클립보드 노트 데이터에는 BPM 정보가 포함되어 있지 않으므로, 가져올 때 현재 프로젝트 BPM을 사용하거나 수동으로 지정할 수 있습니다.
        - FL Studio: FL Studio의 피아노 롤 화면에서 왼쪽 상단의 작은 삼각형을 클릭하여 메뉴를 펼치고 `파일` -> `MIDI 클립보드로 복사`를 선택하면 현재 채널의 모든 노트가 시스템 클립보드로 출력되어 HiFiShifter에서 읽을 수 있습니다.
    - 트랙 선택: 가져올 MIDI 트랙을 선택할 수 있습니다.
    - 가져오기 대상: `음높이 참조 블록` 또는 `음높이 파라미터`(현재 선택한 트랙의 피치 라인에 직접 기록)로 가져올지 선택할 수 있습니다.
    - 가져오기 위치: `프로젝트 시작`, `재생 헤드` 또는 `선택 범위`를 선택할 수 있습니다.
    - MIDI BPM을 프로젝트 BPM으로 가져오기: 활성화하면 MIDI의 초기 BPM을 프로젝트 BPM으로 가져옵니다.
    - 노트 BPM: 가져올 노트의 BPM 매핑 방식을 설정할 수 있습니다.
        - MIDI 자체 BPM: BPM 매핑을 하지 않고 MIDI 자체 BPM으로 직접 가져옵니다.
        - 현재 프로젝트 BPM: 노트 BPM을 현재 프로젝트 BPM으로 매핑한 후 가져옵니다.
        - 지정 BPM: 노트 BPM을 수동으로 지정한 BPM으로 매핑한 후 가져옵니다.
    - 멀티트랙 병합: 활성화하면 선택한 모든 트랙과 모든 노트를 자동으로 병합하고, 가장 높은 피치의 노트를 피치 곡선 파라미터로 사용하여 최종적으로 1개의 음높이 참조 클립만 가져옵니다. 비활성화하면 모든 노트가 피치 곡선 파라미터로 가져와질 수 있도록 트랙과 노트를 분할하려고 시도하며, 최종적으로 여러 개의 음높이 참조 클립이 세로로 배치될 수 있습니다.
    - 노트 사이 간격 채우기: 활성화하면 인접한 두 노트 사이의 간격을 자동으로 채웁니다. 그 외에 `시작 공백 닫기` 옵션이 있어, 가져온 내용 시작 부분에서 첫 노트 이전의 공백을 제거할 수 있습니다.
    - 템포 맵으로 가져오기: 활성화하면 MIDI의 템포(`템포 가져오기`), 박자표(`박자표 가져오기`), 스케일(`스케일 가져오기`)을 각각 프로젝트의 템포 맵 변경점으로 가져올지 선택할 수 있습니다.
- Reaper 프로젝트 또는 Reaper 클립보드를 통해 트랙의 MIDI 아이템을 가져옵니다.
- VocalShifter 프로젝트 또는 VocalShifter 클립보드를 통해 트랙의 MIDI 클립을 가져옵니다.
- 일반 클립을 마우스 오른쪽 버튼으로 클릭하고 컨텍스트 메뉴에서 `음높이 참조 클립으로 변환`을 선택합니다. 이렇게 하면 해당 일반 클립의 원본 피치 곡선이 새로운 음높이 참조 클립의 피치 곡선으로 변환됩니다.
- 파라미터 에디터에서 피치 파라미터를 편집할 때, 선택 도구로 영역을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 컨텍스트 메뉴에서 `음높이 참조 클립으로 저장`을 선택하면 선택 범위 내의 피치 곡선을 새로운 음높이 참조 클립으로 저장할 수 있습니다.

음높이 참조 클립의 일반적인 용도는 다음과 같습니다:

- 트랙에 배치하여 일반 클립이 있는 다른 트랙이 피치를 참조할 수 있도록 합니다. 다른 트랙에서는 파라미터 에디터의 `참조 트랙 그룹` 기능을 사용하여 이 트랙을 보고 피치 곡선을 표시할 수 있습니다.
- 음높이 참조 클립이 트랙 그룹의 루트 트랙에 배치되면, 현재 트랙 그룹의 피치 처리 로직을 변경하여 해당 구간의 원본 피치 곡선을 음높이 참조 클립의 피치 곡선으로 덮어씁니다. 이는 다음 시나리오에 영향을 줍니다:
    - 트랙 그룹 내에서 편집된 적이 없는 피치 곡선 구간이 있으면, 해당 피치 파라미터가 음높이 참조 클립의 피치 곡선으로 직접 덮어쓰기되고 오디오 피치의 재렌더링이 트리거됩니다.
    - `초기화` 관련 기능을 사용할 때--예를 들어 파라미터 에디터에서 그리기 도구로 오른쪽 드래그 작업을 할 때--초기화된 피치 곡선은 트랙 그룹 하위 트랙 내 클립의 원본 피치가 아닌 음높이 참조 클립의 피치 곡선 데이터를 사용합니다.
    - 음높이 참조 클립이 음소거된 경우, 트랙 그룹은 피치를 처리할 때 해당 음높이 참조 클립을 참조하지 않습니다.

음높이 참조 클립을 선택한 뒤 컨텍스트 메뉴에서 `음높이 업데이트`를 실행하면 해당 범위의 기존 피치 파라미터가 음높이 참조 클립에 업데이트됩니다.

### 9. 기타 기능

파라미터 에디터의 기타 편리한 기능:

- `스케일 하이라이트`: 도구 모음에 있습니다. 현재 프로젝트의 기준 스케일에 따라 피아노 롤 배경에서 스케일에 속한 건반 행을 강조하여 피치와 조성의 관계를 쉽게 관찰할 수 있습니다.
- `드래그 방향`: 도구 모음에 있습니다. 왼쪽 드래그로 파라미터 라인을 이동할 때의 방향을 제어합니다(`자유` / `X 축만` / `Y 축만`). 드래그 중 `D` 키로 전환하는 것과 동일합니다.
- `클립보드 미리보기`: `보기` 메뉴에 있습니다. 선택 도구로 파라미터 커브 데이터를 복사하면 선택 영역에 클립보드 커브 데이터가 실시간 표시되어 붙여넣기 위치를 정하는 데 편리합니다.
- `파라미터 값 팝업`: `보기` 메뉴에 있습니다. 마우스가 커브 근처에 있거나 그리기 편집을 실행 중일 때 파라미터 값을 표시합니다.
- `파라미터 라인 잠금`: 도구 모음에 있습니다. 트랙에서 오디오 클립을 드래그할 때 해당 클립에 대응하는 모든 파라미터 라인도 함께 이동할지 여부를 결정합니다. HiFiShifter의 모든 파라미터 편집 기능은 트랙 기반입니다. 잠기지 않으면 편집된 파라미터 라인이 클립을 따라 이동하지 않습니다.
- `스무딩`: 도구 모음에 있습니다. 파라미터 편집 시 자동으로 스무딩을 적용할지 여부와 그 강도입니다.
- `참조 트랙 그룹`: 도구 모음에 있습니다. 파라미터가 `피치`일 때 다른 트랙을 선택하여, 다른 트랙 그룹의 피치 곡선을 참조로 피치 편집 창에 표시할 수 있습니다.
- `MIDI 가져오기`: 도구 모음에 있습니다. 파라미터가 `피치`일 때 MIDI 파일을 선택하여 단일 또는 다중 트랙의 노트를 피치 라인으로 가져올 수 있으며, MIDI 파일을 파라미터 에디터로 직접 드래그 앤 드롭할 수도 있습니다.
- `보조 파라미터 오버레이`: 각 파라미터 버튼의 오른쪽에는 눈 아이콘이 있습니다. 켜면 현재 파라미터를 편집하면서 그 파라미터와 연관된 다른 파라미터(예: `피치` 편집 시 `센트 차`)를 보조 곡선으로 겹쳐 표시하여 대조하기 쉽습니다.
- `볼륨 / 다이내믹 세로축 단위 전환`: 파라미터가 `볼륨` 또는 `다이내믹`일 때, 세로축 눈금 영역을 클릭하면 dB와 배율 두 표시 단위 사이에서 전환할 수 있습니다.

### 10. 스무딩

선택 도구로 영역을 선택한 뒤 마우스 오른쪽 버튼을 클릭하고 `스무딩...`(기본 단축키 `Ctrl + M`)을 선택하면 덜컹거리는 파라미터 곡선을 부드럽게 만들 수 있습니다.

- `스무딩 강도`: 0–100%의 연속 슬라이더로, 클수록 부드럽습니다. 대화상자의 초기값은 도구 모음 `스무딩` 설정값을 따릅니다(이 설정의 기본값은 0%, 즉 기본적으로 평활화하지 않습니다).
- 스무딩은 선택 영역 양쪽 곡선을 참조하여 이어 붙이므로 선택 영역 경계에 갑작스러운 단차가 나타나지 않습니다. 경계 전환 폭은 시간 기준으로 고정되어 선택이 길어져도 넓어지지 않으며, 반복 편집이 영역 밖에 왜곡을 누적하지 않습니다.
- `퀀타이즈`와 `평균 퀀타이즈` 대화상자에도 같은 `스무딩 강도` 슬라이더가 있어 퀀타이즈하면서 동시에 부드럽게 만들 수 있습니다.

빠르게 평탄화하려면 선택 영역 안에서 오른쪽 버튼을 누른 채 아래로 드래그하면 됩니다. 내릴수록 부드러워지며 실시간 미리보기를 지원합니다.

## 6. 오디오 내보내기

모든 편집을 완료한 후 `파일` 메뉴의 `오디오 내보내기` 기능을 통해 HiFiShifter 프로젝트를 오디오 파일로 내보낼 수 있습니다.

파라미터:

- `출력 형식`: `WAV` / `MP3` / `FLAC`.
    - `WAV`: 비압축 무손실로 호환성이 가장 넓고 파일이 가장 큽니다. 다른 소프트웨어에서 계속 편집할 때 선택하세요.
    - `FLAC`: 무손실 압축으로 음질은 WAV와 같으나 파일이 눈에 띄게 작습니다. 장기 무손실 보관에 선택하세요.
    - `MP3`: 손실 압축으로 가장 작고 거의 모든 장치와 재생기에서 지원됩니다. 공유, 업로드, 임시 믹스에 선택하세요.
    - 형식을 바꾸면 출력 파일 이름과 분리 트랙 이름 템플릿의 확장자가 자동으로 바뀝니다.
- `내보내기 유형`: `프로젝트` / `분리 트랙`.
- `내보내기 범위`: `전체` / `사용자 지정`. 사용자 지정에서는 시작 및 종료 시간(초)을 설정할 수 있습니다.
- `샘플레이트`: 출력 오디오의 샘플레이트를 설정합니다. 세 형식 모두 지원하지만 MP3는 8 kHz~48 kHz 사이의 고정 단계만 허용합니다(예: 44100 또는 48000 Hz). MP3가 지원하지 않는 단계를 선택하면 HiFiShifter가 가장 가까운 지원 단계로 자동 변경하고 알립니다.
- `비트 심도`: 출력 오디오의 비트 심도를 설정합니다. WAV는 16 / 24 / 32-bit float를, FLAC는 16 / 24-bit를 지원합니다. MP3는 비트 심도 옵션이 없으며 내부적으로 항상 16비트에 상응하는 정밀도로 인코딩되므로 비트 심도를 신경 쓸 필요가 없습니다.
- `인코더 설정`: MP3와 FLAC를 선택할 때만 표시되며, 음질과 파일 크기의 균형을 맞추는 데 사용합니다.
    - MP3:
        - `인코딩 모드`: `VBR(품질 우선)`은 내용 복잡도에 따라 비트레이트를 배분해 비슷한 청감에서 파일이 더 작아져 좋은 기본값입니다. `CBR(고정 비트레이트)`은 비트레이트를 고정하여 파일 크기를 예측하기 쉽게 합니다.
        - `비트레이트`: `CBR`에서 사용 가능하며 8–320 kbps입니다. 클수록 음질이 좋고 파일이 큽니다.
        - `VBR 품질`: `VBR`에서 사용 가능하며 q0(약 245 kbps)부터 q9(약 65 kbps)까지입니다. 기본 q2면 이미 충분히 좋습니다.
        - `메타데이터(ID3 태그)`: `제목`, `아티스트`, `앨범`, `설명`을 MP3 파일에 기록합니다. 비워 두면 기록하지 않습니다.
    - FLAC:
        - `압축 레벨`: 0–8입니다. `0`은 가장 빠르고 파일이 약간 크며, `8`은 파일이 가장 작지만 가장 느립니다. 기본값은 `5`입니다. 압축 레벨은 파일 크기와 인코딩 시간에만 영향이 있으며 음질에는 영향이 없으므로 기본값이면 충분합니다.
    - 공통:
        - `디더`: 비트 심도를 낮출 때 미세한 노이즈를 더해 체감 음질을 개선합니다. `끄기` 또는 `TPDF`를 선택합니다. 정수 비트 심도(16 / 24-bit)에만 적용되며 대부분 `끄기`로 두면 됩니다.
        - `채널`: `스테레오`는 기존 좌우 채널을 유지합니다. `모노 다운믹스`는 두 채널을 모노로 합칩니다.
- `출력 폴더`: 파일 출력 폴더를 설정합니다. 사용 가능한 자리 표시자:
    - `<ProjectFolder>`: 현재 프로젝트가 저장된 폴더. 저장되지 않은 경우 `내 문서` 폴더를 가리킵니다.
    - `<ProjectName>`: 현재 프로젝트의 파일 이름(확장자 제외).
    - 프로젝트 내보내기의 경우 출력 폴더 기본값은 `<ProjectFolder>`입니다. 분리 트랙 내보내기의 경우 기본값은 `<ProjectFolder>/<ProjectName>`입니다.
- `출력 파일 이름`: 파일 출력 이름을 설정합니다. 사용 가능한 자리 표시자:
    - `<ProjectName>`: 현재 프로젝트의 파일 이름(확장자 제외).
    - 기본값은 `<ProjectName>.wav`입니다.
- `분리 트랙 이름 패턴`: 분리 트랙 출력 시 이름 형식을 설정합니다. 사용 가능한 자리 표시자:
    - `<ProjectName>`: 현재 프로젝트의 파일 이름(확장자 제외).
    - `<ExportIndex>`: 내보내기 시 트랙의 순서 번호(0부터 시작).
    - `<TrackIndex>`: 프로젝트 내 트랙 번호(0부터 시작).
    - `<TrackName>`: 프로젝트 내 트랙 이름.
    - `<TrackType>`: 트랙 유형(`Root` / `Sub`).
    - `<TrackId>`: 트랙의 내부 ID(일반 사용자는 사용하지 않는 것이 좋음).
    - 기본 패턴은 `<ExportIndex>_<TrackName>.wav`입니다.
- `분리 트랙 출력 대상` 패널: 내보낼 트랙을 선택할 수 있습니다. 기본적으로 음소거되지 않은 일반 트랙과 루트 트랙만 선택됩니다. 패널 상단에는 `전체 선택`, `전체 해제`, `하위 트랙 전체 선택`과 `음소거 제외` 바로가기 버튼이 있습니다.
    - 원래 음소거된 트랙을 체크하면 음소거 상태에 관계없이 정상적으로 내보내집니다.
    - 트랙 그룹의 루트 트랙을 체크하면 해당 루트 트랙이 포함된 트랙 그룹이 단일 오디오 파일로 내보내지며, 음소거된 하위 트랙의 오디오 데이터는 제외됩니다.
    - 하위 트랙을 체크하면 해당 하위 트랙이나 해당 루트 트랙의 음소거 상태에 관계없이 정상적으로 내보내집니다.
    - `음소거 제외` 버튼은 현재 체크된 대상에만 적용됩니다. 그중 음소거된 항목의 체크를 해제하고, 체크하지 않은 항목은 그대로 둡니다. 따라서 먼저 직접 고른 뒤 이 버튼으로 음소거 항목을 한 번에 걸러낼 수 있습니다.

파일 경로를 입력하는 동안 `자리 표시자` 버튼을 클릭하면 해당 텍스트를 빠르게 입력할 수 있습니다.

위의 모든 파일 경로 관련 문자열은 `%Y-%m-%d-%H-%M-%S`와 같은 시간 형식 문자열을 지원합니다. 출력 경로에 리터럴 `%` 문자를 포함하려면 `%%`를 사용하여 이스케이프 처리하세요.

클립을 선택하고 컨텍스트 메뉴에서 `빠른 내보내기`를 선택하면 작은 창에서 해당 클립만 내보낼 수 있습니다. 여기서도 `WAV` / `MP3` / `FLAC`를 선택할 수 있으나 인코더 설정은 하지 않고 `오디오 내보내기` 대화상자에 저장된 설정을 그대로 사용합니다.

## 7. 녹음

HiFiShifter는 타임라인에서 직접 녹음할 수 있습니다. 녹음 중에는 재생 커서 위치에서 타임라인 재생이 함께 시작되며(반주나 배경음을 들으며 녹음 가능), 녹음이 끝나면 재생이 자동으로 멈추고 녹음 파일이 타임라인으로 가져와집니다.

### 녹음 버튼과 단축키

- 재생 제어 영역의 빨간 원형 버튼으로 녹음 시작/중지를 전환합니다.
- 기본 단축키는 `Ctrl + R`이며 `옵션 -> 키보드 단축키...`에서 변경할 수 있습니다.
- 녹음 버튼을 마우스 오른쪽 버튼으로 클릭하면 녹음 설정을 빠르게 열 수 있습니다.

### 녹음 설정

`파일 -> 녹음...`에서 설정할 수 있습니다:

- `녹음 소스`: 녹음 소스를 세 가지 모드 중에서 선택합니다.
- `녹음 장치`: 기본값은 `시스템 기본값`이며, 이 PC의 모든 입력 장치(마이크 등)를 나열하여 선택할 수 있습니다.
- `루프백 장치`: 녹음 소스가 `시스템 사운드(루프백)`일 때 캡처할 출력 장치를 선택합니다. 기본은 `시스템 기본 출력`입니다.
- `애플리케이션`: 녹음 소스가 `애플리케이션 오디오`일 때 특정 프로그램의 소리만 캡처할 수 있습니다. `새로고침`을 누르면 현재 오디오를 출력하는 프로그램을 다시 나열합니다. 프로그램이 다시 시작되면 프로세스 이름으로 자동으로 다시 매칭됩니다. Windows 10 21H2(build 20348) 이상에서는 시스템 프로세스 루프백 API를 우선 사용하고, 이전 빌드에서는 다른 세션을 음소거하는 호환 방식으로 자동 전환합니다. Linux에서는 PipeWire(`pw-dump` / `pw-cat`)로 캡처하며, macOS에서는 아직 이 모드를 지원하지 않습니다.
- `샘플 레이트` / `비트 심도` / `채널`: 출력 WAV의 샘플 레이트, 비트 심도, 채널 수.
- `입력 게인`: 녹음 전 게인 보정.
- `카운트다운`: 초 단위로 시간을 입력합니다. 녹음 버튼을 클릭하면 먼저 카운트다운 후 녹음이 시작됩니다.
- `녹음 중 입력 모니터링`: 녹음 중 입력 신호를 출력 장치로 되돌려 보내며, `모니터 게인`으로 되돌려 보내는 음량을 조절할 수 있습니다.
- `가져온 후 자동 정규화`: 중지 후 가져올 때 새 클립의 피크를 자동으로 0 dB로 정규화합니다.
- `선택 클립 끝에서 자동 정지`: 재생이 선택 클립의 끝에 도달하면 자동으로 중지하고 가져옵니다.
- `출력 경로 템플릿`: `<ProjectFolder>`, `<ProjectName>`, 시간 형식 문자열을 지원합니다. 기본값은 `<ProjectFolder>/HiFiShifter Record/%Y-%m-%d-%H-%M-%S.wav`입니다.

### 녹음 과정과 가져오기 규칙

1. 재생 커서를 녹음 시작 위치로 옮기고 대상 트랙을 선택합니다.
2. 녹음 버튼을 누르면 재생 커서에서 타임라인 재생이 시작되고 동시에 캡처가 시작됩니다.
3. 녹음 버튼을 다시 누르면 중지되고 타임라인 재생도 멈춥니다.
4. 선택 트랙이 녹음 범위 안에서 완전히 비어 있으면 해당 트랙으로 직접 가져옵니다. 그렇지 않으면 선택 트랙 바로 아래에 새 `녹음` 트랙을 만들고 가져온 뒤, 새 트랙과 새 클립을 자동으로 선택합니다.

## 8. VST3 / ARA 플러그인 (REAPER)

독립 실행형 앱 외에도 HiFiShifter는 VST3(ARA) 플러그인 형태를 제공합니다: REAPER에 로드하면 REAPER 프로젝트 안에서 동일한 HiFiShifter 편집 인터페이스를 바로 열 수 있습니다. 플러그인은 독립 실행형 앱과 동일한 편집 및 렌더링 로직을 공유하지만, **독립 실행형 앱을 먼저 실행할 필요가 없으며** 편집 결과는 REAPER 프로젝트와 함께 저장됩니다.

현재 플러그인은 Windows x64 버전이며 REAPER에서만 검증되었습니다. Linux / macOS용 플러그인은 아직 제공되지 않습니다.

### 설치 및 연결

플러그인 설치 방법은 두 가지이며, 둘 중 하나를 선택합니다:

- **설치 프로그램(권장)**: `HiFiShifter_v<버전>_windows-x86_64-vst3-setup.exe`를 실행합니다. 마법사는 시스템 UI 언어를 따르며 VST3 디렉터리를 선택할 수 있습니다. 모델은 머신 전체 공유 라이브러리([모델 파일과 공유](#모델-파일과-공유) 참고)에 설치되고, Windows의 "프로그램 및 기능 / 설치된 앱"에 제거 항목이 등록됩니다. 설치 프로그램은 먼저 REAPER와 그 플러그인 호스트 프로세스가 종료되었는지 확인합니다.
- **수동 복사**: REAPER를 종료하고 **전체** `HiFiShifter.vst3` 폴더를 VST3 디렉터리(예: `C:\Program Files\Common Files\VST3`)에 넣거나, 그 상위 디렉터리를 REAPER의 VST 스캔 경로에 추가합니다. 폴더 안의 개별 파일만 복사하지 마세요 —— 인터페이스, 모델과 실행 종속성이 모두 이 폴더 안에 있습니다. 이 방식은 레지스트리에 쓰지 않으므로, 제거할 때는 이 폴더를 삭제하기만 하면 됩니다.

두 방식 모두 WebView2 런타임과 VC++ x64 런타임이 설치되어 있어야 합니다.

연결 단계(두 방식 모두 동일):

1. REAPER를 다시 시작하여 플러그인을 스캔하게 한 뒤, 보컬 오디오 클립이 있는 트랙에 VST3 플러그인 HiFiShifter를 추가하고 호스트의 ARA 방식으로 연결합니다(오디오를 독립 실행형 앱으로 가져오는 방식이 아닙니다). 먼저 프로젝트 복사본으로 시험해 보는 것이 좋습니다.
2. 여러 트랙을 처리해야 할 때는 각 트랙에 플러그인 인스턴스를 따로 추가합니다. 그중 아무 HiFiShifter 창이나 열면 같은 프로젝트에 연결된 모든 트랙을 편집할 수 있으며, 이 창들은 하나의 작업 공간을 보여 주는 서로 다른 뷰일 뿐 각각 독립된 편집 복사본이 아닙니다. 다른 프로젝트 간에는 편집이 공유되지 않습니다.
3. 단축키를 사용하기 전에 플러그인 창을 한 번 클릭하여 키보드 포커스를 인터페이스로 옮깁니다(플러그인은 `Ctrl + C` / `Ctrl + X` / `Ctrl + V` / `Ctrl + Z` / `Ctrl + Y`를 전달하고, 나머지 단축키는 인터페이스 자체에서 처리합니다).

### 트랙 그룹(폴더)에서 오디오가 보이지 않는 이유

REAPER는 ARA 플러그인을 **트랙 단위**로 관리합니다. 플러그인에는 **그 플러그인이 올라가 있는 트랙**의 오디오만 전달됩니다. 따라서 트랙 그룹(폴더)의 상위 트랙에 HiFiShifter를 추가하면, 그룹 안 하위 트랙의 클립은 보이고 드래그할 수도 있지만 **오디오는 전달되지 않습니다** —— 파형도 나오지 않고 파라미터 분석도 되지 않습니다.

- 올바른 방법은 **처리하려는 오디오 트랙마다 HiFiShifter 인스턴스를 하나씩 추가하는 것**입니다. 그룹 상위 트랙에만 추가해서는 동작하지 않습니다.
- 클립을 먼저 선택할 필요도, 수동으로 "ARA 활성화"를 할 필요도 없습니다. REAPER의 ARA 지원은 기본으로 켜져 있고 분석은 자동으로 시작됩니다. 필요한 조건은 그 트랙에 실제 오디오 클립이 있다는 것뿐입니다.
- 플러그인은 이 상황을 인식하여 타임라인 위에 안내를 표시합니다. 그룹 안의 클립은 "REAPER의 오디오를 기다리는 중"으로 표시되며, 쓸 수 있어 보이는 빈 클립으로 표시되지 않습니다.

> 이는 REAPER가 ARA 플러그인을 트랙 단위로 관리하기 때문이며, 플러그인의 결함이 아닙니다.

### 모델 파일과 공유

플러그인에는 FCPE, HNSEP, HiFiGAN 세 가지 모델이 필요합니다(총 약 150 MB). 설치 프로그램은 모델을 **머신 전체 공유 라이브러리**(`%ProgramData%\HiFiShifter\models\<모델 버전>`)에 설치하며, 독립 실행형 앱도 같은 것을 읽습니다 —— 플러그인과 독립 실행형 앱을 함께 사용해도 이 150 MB가 중복되지 않습니다. 수동 복사 버전은 자체적으로 모델을 포함하며 공유 라이브러리에 의존하지 않습니다.

- 모델 버전은 모델 내용에서 파생됩니다: 업그레이드하면 새 버전이 새 디렉터리에 배치되고, 같은 버전의 재설치는 건너뜁니다.
- 플러그인을 제거해도 공유 모델 라이브러리는 **삭제되지 않습니다**(독립 실행형 앱도 사용하기 때문입니다). 정말 지우고 싶다면 `%ProgramData%\HiFiShifter\models`를 직접 삭제하세요.
- 환경 변수 `HIFISHIFTER_MODELS_DIR`로 모델 디렉터리를 지정할 수 있으며, 공유 라이브러리보다 우선합니다.

### 플러그인 모드에서의 역할 분담

플러그인 모드에서는 **호스트가** 오디오 가져오기, 클립의 위치 / 자르기 / 선형 스트레치, BPM과 페이드 오디오를 담당하고, **HiFiShifter가** 피치, 브레스, 텐션, 포먼트 등 파라미터 곡선 편집을 담당합니다.

- `파일` 메뉴에는 `미디어 파일 가져오기...`와 사용할 수 없는 `저장 · REAPER` 하나만 남으며, 프로젝트 저장, 내보내기와 녹음은 모두 REAPER에서 수행합니다.
- `파일 → MIDI 가져오기...`는 플러그인에서도 사용할 수 있지만 가져오기 대상은 **피치 커브**입니다(대화 상자의 `피치 파라미터로 가져오기`). 노트는 독립 실행형 앱과 같은 구현으로 HiFiShifter 자체 커브에 바로 기록됩니다. `피치 참조 블록 만들기`와 클립 우클릭의 `MIDI 교체`는 플러그인에서 **아예 표시되지 않습니다** — 클립은 REAPER에 속하므로 플러그인이 호스트가 보지 못하는 로컬 클립을 만들 수 없습니다.
- `트랙` 메뉴, `녹음` 버튼, `옵션 → 추론 장치` 등 호스트가 인계받는 진입점은 플러그인에서 **아예 표시되지 않습니다**(회색으로 자리만 차지하지 않고 없앱니다). 호스트가 주는 VST 창은 대개 좁아서 쓸 수 없는 컨트롤은 자리를 내줘야 하기 때문입니다.
- 호스트가 제어 기능을 제공할 때 `정지`와 `재생 / 일시 정지` 버튼은 REAPER의 재생을 제어하는 데 사용됩니다. 재생 헤드는 REAPER 프로젝트의 위치를 기준으로 하며, BPM도 REAPER가 결정합니다. 호스트가 재생 제어를 제공하지 않으면 이 버튼 그룹은 표시되지 않습니다.
- 도구 모음의 `BPM` / 박자표 입력란, 메트로놈 버튼, 녹음 버튼은 플러그인에서 표시되지 않습니다. 이들은 호스트의 권위 있는 판독값이거나 호스트의 명령이며, REAPER 자체 화면이 표시와 조작을 담당합니다.
- 클립의 페이드 오디오는 REAPER가 처리합니다. 인터페이스에 표시되는 엔벨로프는 HiFiShifter 자체의 표시용입니다. 호버 안내는 독립 실행형 앱과 같이 모양 / 길이 / 곡률 세 가지만 보여 주며, 호스트의 `c=` / `S=` 판독값은 더 이상 표시하지 않습니다(사용자가 취할 행동이 없는 정보이기 때문입니다). REAPER의 곡선과 점별로 일치할 필요는 없습니다.
- 템포 맵은 플러그인에서도 **사용할 수 있지만 편집할 수 있는 것은 스케일 축뿐**입니다. 템포 맵은 "시간에 따라 변하는 스케일"의 저장소이고, 스케일은 HiFiShifter 자체의 정보입니다(REAPER에는 프로젝트 조표 개념이 없습니다). 변경점의 `BPM`과 박자표는 호스트의 권위 있는 판독값이며 대화상자에서 읽기 전용으로 표시됩니다. 플러그인이 호스트의 템포 맵을 자동으로 채우지도 않습니다(REAPER는 ARA 플러그인에 템포/박자 내용을 전달하지 않습니다. 실기 실측, `probe/ara/README.md`의 F-2 참조). 스케일 변경점은 플러그인 자체 설정에 저장됩니다.
- 루프 소스(REAPER의 "루프 소스" 스위치)는 그대로 읽고 다시 씁니다. 플러그인은 REAPER의 루프 의미론으로 렌더링하며, 오른쪽 클릭 메뉴의 `루프` / `루프 해제`를 쓸 수 있습니다.
- 역재생은 플러그인이 **처리하지 않습니다**. ARA는 역재생 오디오를 제공하지 않으므로 올바른 내용을 렌더링할 수 없습니다. 이런 클립은 (역재생 표시와 함께) 그대로 보이고, 오른쪽 클릭 메뉴의 역재생 항목은 이유와 함께 비활성화됩니다. REAPER에서 조작하세요.
- 오디오가 없는 클립은 이제 **이유**를 알려줍니다. `REAPER의 오디오 할당 완료를 기다리는 중`(분할 / 자르기 / 붙여넣기 직후의 정상적인 진행 상태), `REAPER의 오디오를 기다리는 중`(이 클립에는 오디오가 오지 않음. 예: FX가 폴더 상위 트랙에 있음), `REAPER가 역재생합니다. HiFiShifter는 처리하지 않습니다`. 분할된 클립은 부모의 오디오를 즉시 물려받으므로 오래 자리 표시자에 머물지 않습니다.
- 클립 툴팁은 이름만 표시하고 파일 경로는 표시하지 않습니다.
- 클립 오른쪽 클릭 메뉴는 독립 앱과 **같은 것**입니다. Take 하위 메뉴, 채널 모드, 루프, 페이드 모양 행이 모두 나타납니다. 플러그인이 할 수 없는 항목은 (글루, 무음 감지 등) 이유와 함께 비활성으로 표시되며 항목 자체가 사라지지 않습니다.

### 편집 및 자동 적용

파라미터 편집 방식은 독립 실행형 앱과 완전히 동일합니다([파라미터 에디터](#5-파라미터-에디터) 장을 참고하세요). 편집할 때마다 플러그인은 백그라운드에서 자동으로 렌더링하여 호스트에 다시 적용하며, 상태 표시줄 오른쪽에 현재 진행 상황이 표시됩니다:

- `호스트 오디오 대기 중`: 호스트가 아직 오디오를 플러그인에 넘기지 않았습니다.
- `자동 적용 중...`: 편집이 렌더링 중입니다. 무거운 모델은 첫 처리에 시간이 걸릴 수 있습니다.
- `적용됨`: 처리할 편집이 없습니다. 마우스를 올리면 리비전 수를 볼 수 있습니다(`편집 {edits} / 오디오 {audio}`).
- 렌더링이 끝난 오디오만 현재 출력을 대체하며, 끝나지 않은 렌더링은 성공으로 취급되지 않습니다.
- 실패하면 `적용되지 않음: {error}`가 표시됩니다. 이때는 먼저 안내에 따라 확인하고, 강제 다시 로드를 반복하지 마세요.
- 준비되면 `호스트에서 다시 로드` 버튼이 나타납니다: 모델 / 권한 충돌 시 호스트 상태를 다시 읽는 데 사용합니다. **아직 적용되지 않은 편집이 있으면 먼저 확인을 요구합니다** — 다시 로드하면 로컬 곡선이 호스트 상태로 교체되기 때문입니다. 일반적으로 이것을 일상적인 '전송' 버튼으로 여길 필요는 없습니다.

### 저장 및 제한

- REAPER에서 프로젝트를 저장하면 되며, 플러그인 파라미터는 프로젝트와 함께 저장됩니다. 플러그인 창을 닫아도 편집이 사라지지 않으며, 독립 실행형 앱을 상주시킬 필요도 없습니다.
- **인터페이스 설정은 영구 저장됩니다**: 인터페이스 언어, 단축키, 외관과 사용자 테마, 타임라인과 파라미터 에디터의 확대/축소, 파일 브라우저의 마지막 디렉터리는 REAPER를 종료해도 그대로 유지됩니다.
- 이 설정은 독립 실행형 앱과 **동일한 설정을 공유**합니다: 독립 실행형 앱에서 조정한 외관과 단축키는 플러그인에서도 바로 적용되며, 그 반대도 마찬가지입니다.
- 프로젝트를 다시 열면 플러그인이 호스트에서 오디오를 다시 가져와 백그라운드 준비를 다시 마쳐야 하며, 상태 표시줄은 먼저 `호스트 오디오 대기 중`으로 돌아갑니다.
- 플러그인을 업그레이드하기 전에 프로젝트를 저장하고 REAPER를 완전히 종료하세요. 호스트가 실행 중일 때 로드된 플러그인 폴더를 덮어쓰지 마세요.
- 정방향, **선형** 스트레치만 지원합니다: 역재생과 비선형 스트레치는 지원 범위가 아니며, 인터페이스에 `역재생은 지원되지 않음`이라고 명확히 표시됩니다.
- 하모닉 분리(HNSEP)는 전체 구간 단위로 처리하므로, 아주 긴 소재에서 `하모닉 분리`를 켜면 메모리를 많이 차지할 수 있습니다. HiFiGAN 추론은 블록 단위로 수행됩니다.

### 자주 묻는 질문

- REAPER에서 플러그인을 찾을 수 없음: **전체** `HiFiShifter.vst3` 폴더를 복사했는지(내부의 단일 파일이 아니라), 그 상위 디렉터리가 REAPER의 VST 스캔 경로에 있는지, WebView2 런타임과 VC++ x64 런타임이 설치되어 있는지 확인하세요.
- 계속 `호스트 오디오 대기 중`으로 표시되거나 분석할 수 없음: 해당 트랙에 유효한 오디오가 있는지, 플러그인이 ARA 방식으로 연결되었는지, 상태 표시줄 오른쪽의 자동 적용 상태를 확인하세요.
- 트랙 그룹(폴더) 상위 트랙에 플러그인을 추가했더니 클립은 보이는데 파형이 전혀 나오지 않음: REAPER는 ARA 플러그인을 트랙 단위로 관리하며 플러그인이 올라간 트랙의 오디오만 전달합니다. 처리하려는 오디오 트랙마다 HiFiShifter 인스턴스를 추가하세요([트랙 그룹(폴더)에서 오디오가 보이지 않는 이유](#트랙-그룹폴더에서-오디오가-보이지-않는-이유) 참조).
- 파라미터가 적용되지 않거나 프로젝트를 다시 열었을 때 일치하지 않음: 프로젝트 사본과 상태 표시줄의 오류 내용을 보관하고, 프로젝트를 덮어쓰거나 강제 다시 로드를 반복하지 마세요.
- 메모리 부족 알림이 표시됨: 이번에는 하모닉 분리가 실행되지 않았다는 뜻이며, `하모닉 분리` 관련 효과가 조용히 무시되지는 않습니다. 더 짧은 소재를 사용하거나 먼저 `하모닉 분리`를 끄세요.
- 로그 제출이나 문제 해결: 플러그인 로그와 독립 실행형 앱의 로그는 **같은 폴더**에 저장됩니다(플러그인은 `plugin.log`, 앱은 `hifishifter.log`. 파일 이름이 달라 서로 덮어쓰지 않고 로테이션도 각자 수행합니다). 메뉴 `도움말 → 로그 폴더 열기`가 이 폴더를 열어 줍니다. 호스트 환경이 허용하지 않으면 경로를 표시하므로 바로 복사할 수 있습니다. `도움말 → 진단 정보 내보내기...`와 `옵션 → 추론 장치 벤치마크`는 독립 실행형 앱의 기능이며 플러그인에서는 사용할 수 없습니다.
- 제거: 설치 프로그램 버전을 설치했다면 Windows의 "프로그램 및 기능 / 설치된 앱"에서 HiFiShifter VST3를 제거합니다. 폴더를 직접 복사했다면 `HiFiShifter.vst3` 폴더를 삭제하면 됩니다. 두 경우 모두 설정과 공유 모델 라이브러리는 유지됩니다([모델 파일과 공유](#모델-파일과-공유) 참고).

### 독립 실행형 앱에서 호스트 연결

독립 실행형 앱에서 편집하는 것이 익숙하다면, 실행 중인 REAPER에 연결할 수도 있습니다. 먼저 위 방식대로 REAPER에 플러그인을 연결한 뒤 독립 실행형 앱을 열고 `보기 → ARA 호스트 연결...`을 선택한 다음, 떠 있는 세션 패널(제목은 `ARA / REAPER`)에서 `인스턴스 새로 고침` → 인스턴스 선택 → `연결`을 하고, 이후 `REAPER로 전송`, `호스트 새로 고침` 또는 `연결 해제`를 할 수 있습니다. 상태는 `연결되지 않음` / `연결됨` / `새로 고침됨` / `전송됨` / `연결 해제됨`으로 표시되며, 마우스를 올리면 리비전 번호를 볼 수 있습니다. 현재 프로젝트에 저장되지 않은 변경 사항이 있으면 연결 또는 새로 고침 전에 호스트 스냅샷으로 교체할지 먼저 묻습니다.

## 9. 로그 및 문제 해결

HiFiShifter는 실행 로그를 OS 표준 로그 디렉터리에 자동으로 기록합니다. 명령줄 인수가 필요하지 않습니다. 문제가 발생하면 로그 파일을 첨부해 보고하면 원인 파악에 큰 도움이 됩니다:

| OS      | 로그 디렉터리                                  |
| ------- | ---------------------------------------------- |
| Windows | `%LOCALAPPDATA%\com.arounder.hifishifter\logs` |
| macOS   | `~/Library/Logs/com.arounder.hifishifter`      |
| Linux   | `~/.local/share/com.arounder.hifishifter/logs` |

- `도움말 → 로그 폴더 열기` 메뉴로 로그 파일 위치를 바로 열 수 있습니다.
- 플러그인(ARA) 로그는 앱과 **같은 폴더·같은 형식·같은 로테이션**을 쓰며 파일 이름은 `plugin.log`입니다. 두 로그 모두 버전·날짜·시각을 담고 있어 함께 첨부하기 좋습니다.
- `도움말 → 진단 정보 내보내기...` 메뉴로 진단 패키지 zip(시스템 정보 + 전체 로그 + 추론 장치 벤치마크 결과)을 한 번에 생성할 수 있습니다. 이슈 등록 시 첨부해 주세요.
- 로그는 크기 기준으로 자동 순환됩니다: 파일당 최대 8 MiB, 최대 3개의 이전 파일 보관 (`hifishifter.1.log` ~ `hifishifter.3.log`).
    - 반복되는 오류 / 경고는 자동으로 스로틀링됩니다: 동일한 위치의 로그는 10초 창당 최대 1건만 출력되며, 억제된 건수는 다음 출력 전에 `[throttled]` 행으로 보완 기록됩니다.
- 프런트엔드와 백엔드 오류가 모두 동일한 로그 파일에 기록되어 하나의 파일로 시간순 추적이 가능합니다.

고급 옵션(일반적인 사용에는 불필요):

- 실행 인수 `--log-file=<path>`: 로그를 지정한 경로에 기록합니다. `--log-file=-` 은 파일 로그를 명시적으로 비활성화합니다.
- 환경 변수 `HIFISHIFTER_LOG=debug` (또는 `trace` / `info` / `warn` / `error`): 로그 상세 수준을 조정합니다. release 빌드의 기본값은 `info`입니다.
- 환경 변수 `HIFISHIFTER_LOG_DIR`: 기본 로그 디렉터리를 대체합니다.
- 터미널에서 `HiFiShifter --benchmark` 실행: 추론 장치 벤치마크를 실행하고 결과를 JSON으로 출력합니다.
