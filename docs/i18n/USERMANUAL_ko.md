# HiFiShifter 사용자 매뉴얼

[简体中文](USERMANUAL.md) | [繁體中文](USERMANUAL_zh-TW.md) | [English](USERMANUAL_en.md) | [日本語](USERMANUAL_ja.md) | [한국어](USERMANUAL_ko.md)

HiFiShifter는 그래픽 보컬 편집 및 합성 도구입니다. 멀티트랙 오디오 클립 처리를 지원하며, 트랙 그룹 단위로 여러 보코더를 사용하여 보컬의 피치 보정 및 파라미터 조정을 수행하여 인간 VOCALOID 제작의 편집과 튜닝을 통합합니다.

## 1. 설치

사용자의 운영 체제 및 아키텍처에 맞는 HiFiShifter 설치 패키지를 다운로드하세요. OS별로 `Windows`, `macOS`, `Linux` 세 가지, 아키텍처별로 `x86_64`와 `arm64` 두 가지가 있습니다.

- Windows 버전은 NSIS 설치 프로그램(`installer`)과 포터블 압축 파일(`portable`) 두 가지를 제공합니다. 일반 사용자는 설치 프로그램 버전을 선택하여 설치하면 됩니다.  
  Windows 사용자로서 `x86_64`와 `arm64`의 차이를 모르신다면 `x86_64` 버전을 선택하세요. `arm64`가 무엇인지 잘 알고 있고 실제로 Windows ARM 장치를 보유하고 있는 경우에만 `arm64` 버전을 다운로드하여 사용하세요.

- macOS 버전은 서명되지 않은 dmg 설치 패키지를 제공합니다. 아직 서명되지 않았기 때문에 설치 시 약간 복잡한 절차를 거쳐 설치를 허용해야 합니다.  
  M 칩 macOS 사용자는 `arm64` 버전을 설치하세요. 오래된 Intel 사용자만 `x86_64` 버전이 필요합니다.  
  dmg를 더블 클릭한 후 "파일이 손상되었습니다"라는 메시지가 표시되면 다음 단계를 따르세요:
    1. 터미널에서 `xattr -cr /Applications/HiFiShifter.app` 입력；
    2. `시스템 설정` -> `개인정보 보호 및 보안` -> `그래도 열기`를 클릭하여 앱 실행을 허용합니다.

- Linux 버전은 AppImage 패키지를 제공합니다. AppImage 패키지는 파일의 `속성 -> 권한`에서 `파일을 프로그램으로 실행 허용`을 체크한 후 직접 실행할 수 있습니다.

**GPU 가속 정보**: HiFiShifter는 각 플랫폼별로 다양한 GPU 가속 옵션을 제공합니다:

- **Windows (x86_64 / ARM64)**: DirectML (DirectX 12) — 검증된 안정적 경로, NVIDIA / AMD / Intel Arc GPU 지원
- **macOS (Apple Silicon)**: CoreML + WebGPU (Dawn/Metal) — CoreML은 Apple Neural Engine을 활용, WebGPU는 보조 백엔드로 사용 가능
- **macOS (Intel)**: CPU 추론만 가능 (ort-tract 대체 백엔드 사용, GPU 가속 없음)
- **Linux (x86_64)**: WebGPU (Dawn/Vulkan) — Dawn이 Vulkan API를 통해 GPU에 접근, GPU가 없으면 CPU로 폴백
- **Linux (ARM64)**: CPU 추론만 가능 (이 타겟용 WebGPU ONNX Runtime 사전 빌드 바이너리 없음)

메뉴 `옵션 → 추론 장치`에서 `Auto`(자동), `CPU`, `GPU`를 선택할 수 있습니다. 벤치마크를 실행하여 각 장치의 추론 지연 시간을 비교하고 가장 빠른 장치를 선택할 수 있습니다.

**WebView 정보**: HiFiShifter 는 Rust + Tauri 프레임워크로 구축되었으며, 인터페이스를 표시하려면 WebView 구성 요소가 필요합니다.

- **Windows**: Edge WebView2 가 필요합니다. Windows 10 (버전 1803 이상) 및 Windows 11 에는 사전 설치되어 있으므로 추가 작업이 필요하지 않습니다. 이전 버전의 Windows를 사용하거나 구성 요소가 없는 경우 설치 프로그램이 자동으로 다운로드하라는 메시지를 표시합니다. 자세한 내용은 [Tauri 공식 문서](https://tauri.app/ko/start/prerequisites/#webview2)를 참조하세요. 일반 사용자는 설치 프로그램을 실행하기만 하면 됩니다.
- **macOS**: 시스템에 WebKit이 포함되어 있으므로 추가 설치가 필요하지 않습니다.
- **Linux**: WebKitGTK 가 필요합니다. 대부분의 주요 배포판(Ubuntu, Fedora, Arch Linux 등)에는 기본적으로 포함되어 있습니다. 누락된 경우 패키지 관리자를 사용하여 `webkit2gtk` 를 설치하세요(예: `sudo apt install webkit2gtk`). 자세한 내용은 해당 배포판의 문서를 참조하세요.

## 2. 메뉴

`파일` 메뉴에서는 HiFiShifter 프로젝트 파일을 열고 저장할 수 있으며, 미디어 파일(오디오 또는 동영상) 가져오기, Reaper 프로젝트(`.rpp`) 가져오기, VocalShifter 프로젝트(`.vshp` 또는 `.vsp`) 가져오기, MIDI 파일 가져오기, 오디오 내보내기 등의 작업을 할 수 있습니다.

HiFiShifter 프로젝트 파일의 확장자는 `.hshp` 또는 `.hsp`입니다. 그 외에도 `다른 이름으로 저장` 기능은 프로젝트 파일을 일반 텍스트 `json` 파일로 저장하거나, 현재 프로젝트와 사용된 모든 미디어 파일을 함께 아카이브 압축 파일 `.zip`으로 패키징할 수 있습니다.

`파일 → 미디어 파일 가져오기`에서는 일반적인 오디오 형식(`wav`, `mp3`, `flac`, `ogg`, `m4a`, `aac` 등)과 일반적인 비디오 컨테이너(`mp4`, `mov`, `mkv`, `webm`, `avi`, `wmv`, `ts`, `mpg` 등)를 가져올 수 있습니다.

자동 백업 기능을 통해 프로젝트 파일의 자동 백업을 설정할 수 있습니다. `저장 시 백업`과 `정기 백업`의 두 가지 모드가 있습니다.

- `저장 시 백업`: 프로젝트 파일을 덮어쓰기 저장할 때마다 이전 프로젝트 파일이 자동으로 원래 파일명에 `-bak`가 추가된 백업 파일(예: `.hshp-bak`, `.hsp-bak`)로 이름이 변경됩니다. 기본값으로 활성화되어 있습니다.
- `정기 백업`: 편집 중에 설정한 간격과 경로에 따라 자동으로 백업 프로젝트 파일을 생성합니다. 기본값으로 비활성화되어 있습니다.

### HiFiShifter 프로젝트 가져오기

`파일 → HiFiShifter 프로젝트 가져오기...`를 사용하면 현재 프로젝트를 닫지 않고 다른 `.hshp` / `.hsp` / `.json` 프로젝트의 모든 내용을 현재 프로젝트에 병합할 수 있습니다.

- `원래 타임라인 위치 유지`: 가져온 클립이 원본 프로젝트의 시간 위치를 유지합니다.
- `재생 헤드 위치에 배치`: 가져온 내용 전체를 이동하여 가장 먼저 시작하는 클립을 현재 재생 헤드에 맞춥니다.
- `템포 맵 가져오기`: 현재 프로젝트에 템포 맵이 없을 때만 사용할 수 있습니다. 가져온 후에는 원본 프로젝트 시작점의 BPM, 박자, 음계가 현재 프로젝트의 기준이 됩니다.
- 모든 트랙, 하위 트랙, 클립, 파라미터 곡선, 그룹 관계는 가져올 때 새 ID를 할당받아 현재 프로젝트와 충돌하지 않습니다. 오디오 소스 파일은 먼저 가져온 프로젝트 파일이 있는 폴더를 기준으로 찾으며, 누락된 파일은 기존처럼 수동으로 다시 연결할 수 있습니다.
- 가져온 프로젝트의 노트는 현재 프로젝트 노트를 덮어쓰지 않고 끝에 추가됩니다.

### 프로세스 간 복사 / 잘라내기 / 붙여넣기

HiFiShifter의 구조화된 복사/붙여넣기는 시스템 클립보드에 저장되므로 프로세스 간 복사/붙여넣기를 지원합니다.

- 타임라인에서 클립을 선택하고 `Ctrl + C`(또는 오른쪽 클릭 `복사`)를 누른 뒤, 다른 프로세스의 프로젝트에서 `Ctrl + V`(또는 트랙 빈 곳 오른쪽 클릭 `붙여넣기`)를 누르면 클립과 파라미터 곡선이 함께 붙여넣어집니다.
- HiFiShifter에서 클립을 복사하면 데이터가 REAPER 클립보드로도 직렬화되어 REAPER에서 `Ctrl + V`를 누르면 바로 붙여넣을 수 있습니다. 사용 가능한 소스 파일이 없는 클립은 건너뜁니다.
- `편집 → 새 트랙으로 붙여넣기`(`Ctrl + Alt + V`)는 원본 계층 구조대로 새 루트 트랙 그룹을 만듭니다.

- **REAPER 클립보드 데이터 붙여넣기**: REAPER에서 아이템/트랙/MIDI 노트를 복사한 후 HiFiShifter에서 일반 붙여넣기를 하면 REAPER 클립보드 데이터를 자동으로 인식하여 가져옵니다.
    - 아이템 데이터: HiFiShifter의 클립으로 가져오며, Reaper의 튜닝 데이터(전체 튜닝 및 피치 엔벨로프 모두)를 유지합니다.
    - 트랙 데이터: 트랙과 그 안의 아이템을 HiFiShifter의 트랙 및 오디오 클립으로 가져옵니다. 트랙 그룹을 유지할 수 있습니다.
    - MIDI 노트 데이터: 다른 DAW(Reaper, FL Studio 등)에서 노트 데이터를 시스템 클립보드 MIDI 데이터로 내보낸 뒤, HiFiShifter의 파라미터 에디터에서 `선택` 도구로 피치 곡선 구간을 선택하면 해당 구간에 클립보드 MIDI 노트 데이터를 가져올 수 있습니다. MIDI 가져오기 기능에 대한 자세한 설명은 [음높이 참조 클립](#6-음높이-참조-클립) 섹션을 참고하세요.

- **VocalShifter 클립보드 데이터 붙여넣기**: VocalShifter 또는 VocalShifter LE에서 파라미터 라인 복사, 오디오 클립 복사, 트랙 복사 작업을 수행한 후, 이 기능을 통해 VocalShifter 클립보드 데이터를 빠르게 HiFiShifter로 가져올 수 있습니다.
    - 파라미터 라인 데이터: HiFiShifter의 파라미터 에디터에서 `선택` 도구로 파라미터 라인 구간을 선택한 후, VocalShifter 클립보드의 파라미터 라인 데이터를 해당 구간으로 가져올 수 있습니다.
    - 오디오 클립 데이터: HiFiShifter의 클립으로 가져오며, 다양한 파라미터 라인 데이터를 유지합니다.
    - 트랙 데이터: 트랙과 그 안의 오디오 클립을 HiFiShifter의 트랙으로 가져옵니다. HiFiShifter는 현재 마지막으로 복사한 내용이 오디오 클립인지 트랙인지 구분할 수 없습니다. 트랙을 가져오려는 경우, VocalShifter에서 트랙 복사 작업을 수행하기 전에 VocalShifter 프로젝트에서 선택된 오디오 클립이 없는지 확인하세요. 그렇지 않으면 선택된 오디오 클립만 가져와집니다.

`보기` 메뉴에는 인터페이스 표시 관련 옵션이 있습니다:

- `새로고침`：런타임 정보를 다시 불러옵니다.
- `파형 캐시 지우기`：캐시된 파형 데이터를 지웁니다. 다음에 표시할 때 다시 생성됩니다.
- `클립보드 미리보기`：파라미터 에디터의 클립보드 미리보기를 전환합니다.
- `파라미터 값 팝업`：파라미터 값 팝업 표시를 전환합니다.
- `템포 맵`：템포 맵 행의 표시/숨기기를 전환합니다(기본 켜짐. 프로젝트에 템포 맵 데이터가 없으면 행이 표시되지 않습니다).
- `모든 테이크 표시(공간이 충분할 때)`：여러 테이크가 있는 클립의 펼침 표시를 전환합니다.
- `시간 표시`：타임라인 눈금자의 기본/보조 시간 단위를 선택하고 `타임라인 표시 설정...`을 엽니다.
- `테마: 다크 / 라이트`：현재 테마를 전환합니다.
- `외관 설정...`：외관 설정 창을 엽니다.

`옵션` 메뉴에서 HiFiShifter의 다양한 옵션을 수정할 수 있습니다:

- `프로젝트 스트레치 재정의`：현재 프로젝트의 스트레치 알고리즘을 수정할 수 있습니다.
- `전역 스트레치 기본값`：전역 기본 스트레치 알고리즘을 수정할 수 있습니다.
- `추론 장치`：렌더링에 사용할 추론 장치를 설정할 수 있습니다. 현재 `Auto`、`CPU`、`GPU` 세 가지가 있습니다. 이 메뉴에서 벤치마크를 실행하여 각 장치의 성능을 테스트할 수 있습니다(벤치마크에서는 GPU (DirectML), GPU (WebGPU) 등 구체적인 백엔드가 표시됩니다). `GPU`는 해당 GPU 버전의 HiFiShifter에서만 유효합니다.
- `백그라운드 사전 렌더링`：활성화하면 프로젝트를 열거나 파라미터를 편집한 후, 편집된 파라미터가 자동으로 백그라운드에서 사전 렌더링되며, 렌더링 중에도 이미 렌더링된 부분을 재생할 수 있습니다. 비활성화하면 재생 시작 시에만 렌더링이 진행되며, 타임라인을 정상적으로 재생하려면 렌더링이 완료될 때까지 기다려야 합니다. 기본값은 활성화입니다. 비활성화하면 렌더링 빈도를 낮춰 성능을 절약할 수 있습니다.
- `모든 테이크에 편집 동기화`：활성화하면 어떤 테이크의 편집(게인, 잘라내기, 속도, 역재생, 루프 등)이 해당 클립의 다른 모든 테이크에도 동일하게 적용됩니다(기본 켜짐).
- `수정된 미디어 파일 자동 다시 로드`：활성화하면 프로젝트의 미디어 파일이 외부에서 수정되었을 때 자동으로 다시 로드됩니다(기본 켜짐).
- `새 클립에 루프 사용`：활성화하면 새로 가져오거나 만든 클립에 루프(Loop 소스)가 기본으로 활성화됩니다(기본 켜짐).
- `스냅/그리드 설정...`：[스냅 / 그리드 설정](#스냅--그리드-설정) 창을 엽니다(타임라인 도구 모음의 `스냅` 버튼 오른쪽 클릭 메뉴로도 열 수 있습니다).
- `키보드 단축키...`：HiFiShifter의 키 바인딩을 설정할 수 있습니다. 여러 프리셋을 선택할 수 있습니다.

`도움말` 메뉴에는 진단과 지원을 위한 항목이 있습니다:

- `로그 폴더 열기`: 실행 로그가 있는 폴더를 시스템 파일 관리자에서 엽니다. 자세한 내용은 [로그 및 문제 해결](#8-로그-및-문제-해결) 장을 참고하세요.
- `진단 정보 내보내기…`: 저장 위치를 선택하면 진단 패키지(시스템 정보 + 전체 로그 + 추론 장치 벤치마크 결과)를 생성합니다. 이슈 등록 시 첨부해 주세요.
- `HiFiShifter 정보`: 프로젝트 홈페이지를 엽니다.

## 3. 트랙 인터페이스

소프트웨어의 대략적인 작동 로직과 단축키는 Reaper, VocalShifter, VEGAS Pro 등의 DAW 소프트웨어를 참고할 수 있습니다. `옵션 -> 키보드 단축키`에서 자신의 단축키 선호도를 조정할 수 있습니다. 아래 설명은 모두 기본 단축키를 기준으로 합니다.

트랙 인터페이스는 HiFiShifter의 핵심 기능 중 하나로, 오디오 클립을 자르고 붙이는 등의 작업을 할 수 있습니다. 작동 로직은 기본적으로 Reaper를 참고할 수 있습니다.

인터페이스 조작은 마우스 가운데 버튼(마우스 휠 누름)을 드래그하여 화면을 이동할 수 있습니다. 수평/수직 확대/축소 또는 스크롤은 `Ctrl`, `Alt`, `Shift` 등의 수정 키를 누른 상태에서 마우스 휠을 굴려 조정할 수 있습니다. 이러한 수정 키는 단축키 설정에서 조정할 수 있습니다.

자주 사용하는 단축키:

> **macOS 사용자**: 아래의 `Ctrl`은 `Command (⌘)`, `Alt`는 `Option (⌥)`에 해당합니다.

- `스페이스바`: 재생 / 일시 정지 (재생 시작점으로 돌아가지 않음)
- `Enter`: 재생 / 정지 (재생 시작점으로 돌아감)
- `S`: 분할
- `G`: 그룹
- `U`: 그룹 해제
- `T`: 다음 테이크로 순환 전환(`Shift + T`: 이전 테이크)
- `Ctrl + C`: 복사(REAPERMedia 데이터도 함께 기록되어 REAPER에서 바로 붙여넣을 수 있음)
- `Ctrl + V`: 붙여넣기
- `Ctrl + Alt + V`: 새 트랙으로 붙여넣기
- `Ctrl + Z`: 실행 취소
- `Ctrl + Y`: 다시 실행(macOS: `⌘ + ⇧ + Z`)
- `Ctrl + A`: 모두 선택

- `Delete`: 오디오 클립 삭제
- `-` / `=`: 선택한 오디오 클립의 파라미터 라인을 아래로/위로 이동
- 수정 키 `Alt`: 누른 상태에서 클립 시작/끝을 드래그하면 클립을 스트레치하고, 클립 중간을 드래그하면 내부 오프셋(슬립 편집)을 조정합니다.
- 수정 키 `Shift`: 누른 상태에서 스냅을 일시적으로 전환합니다.
- 수정 키 `Ctrl`: 누른 상태에서 클립을 드래그하면 복사합니다.

클립 왼쪽 상단의 작은 원은 볼륨 조절 노브이고, `M` 버튼은 해당 클립을 개별적으로 음소거하며, `F` 버튼은 해당 클립의 포먼트 편집 메뉴를 엽니다. 클립의 왼쪽/오른쪽 끝은 페이드 인/페이드 아웃 길이를 조정할 수 있습니다.

클립을 마우스 오른쪽 버튼으로 클릭하면 컨텍스트 메뉴가 열리며, `테이크`, `역재생`, `루프`, `이름 변경`, `복사` / `잘라내기`, `교체`, `빠른 내보내기`, `재생 위치에서 분할`, `노멀라이즈`, `음높이 참조 클립으로 변환`, `MIDI로 내보내기`, `페이드 커브 유형` 등의 기능이 있습니다(`빠른 내보내기`는 선택한 클립을 개별적으로 wav 파일로 내보냅니다). 동일 트랙의 여러 클립을 선택하면 컨텍스트 메뉴에서 `글루`를 선택하여 단일 오디오 클립으로 병합할 수 있습니다.

여러 오디오 클립을 선택한 뒤 컨텍스트 메뉴에서 `그룹`(또는 `G`)을 선택하면 그룹화됩니다. Reaper 또는 VEGAS Pro와 유사하게 같은 그룹의 클립은 편집 시 연동됩니다. 클립 왼쪽 상단의 체인 버튼을 클릭하면 그룹 연동 편집을 일시적으로 비활성화/활성화할 수 있습니다. 그룹화된 클립을 선택하고 `그룹 해제`(또는 `U`)를 선택하면 그룹에서 제거됩니다.

### 테이크(Take)

하나의 클립에는 여러 테이크(REAPER의 Take와 유사)를 포함할 수 있으며, 같은 위치의 서로 다른 녹음/소재를 비교하거나 전환하는 데 사용합니다.

- 테이크 추가 / 관리: 클립을 마우스 오른쪽 버튼으로 클릭하면 `테이크` 하위 메뉴에서 `미디어에서 테이크 추가...`, `현재 테이크 복제`, `이름 바꾸기`, `테이크 삭제` 등을 수행할 수 있습니다. 클립에 여러 테이크가 있으면 하위 메뉴에서 클릭만으로 활성 테이크를 전환하거나, `다음 테이크로 전환` / `이전 테이크로 전환`(단축키 `T` / `Shift + T`)을 사용할 수 있습니다. `테이크를 개별 클립으로 분리`는 해당 클립의 각 테이크를 타임라인의 독립 클립으로 분해합니다.
- 트랙 간 테이크로 묶기: 서로 다른 트랙의 여러 클립을 동시에 선택한 뒤 우클릭 메뉴의 `클립을 테이크로 통합`을 선택하면, 하나의 클립 아래 여러 테이크로 합쳐집니다.
- `보기 -> 모든 테이크 표시(공간이 충분할 때)`: 활성화하면 여러 테이크가 있는 클립은 트랙 높이가 충분하면 모든 테이크를 펼쳐 표시합니다. 끄면 현재 활성 테이크만 표시합니다.
- `옵션 -> 모든 테이크에 편집 동기화`: 활성화하면 어떤 테이크의 편집(게인, 잘라내기, 속도, 역재생, 루프 등)이 해당 클립의 다른 모든 테이크에도 동일하게 적용됩니다.

트랙 인터페이스 왼쪽은 트랙 헤더 영역으로, 트랙을 추가/삭제하고 트랙 파라미터를 조정할 수 있습니다. 트랙을 마우스 오른쪽 버튼으로 클릭하면 복제할 수 있습니다. 트랙의 빈 영역을 마우스 오른쪽 버튼으로 클릭하면 클립보드의 클립을 붙여넣을 수 있습니다.

Reaper와 유사하게 HiFiShifter의 트랙에도 트랙 그룹 개념이 있습니다. 트랙 헤더 영역에서 한 트랙 헤더를 다른 트랙 헤더로 드래그하면 트랙 그룹을 생성할 수 있습니다. 트랙 그룹은 하나의 파라미터 패널을 공유합니다. 실제 사용 시 "한 파트당 하나의 트랙 그룹"으로 정리하는 것이 좋습니다.

트랙 인터페이스의 기능 버튼:

- `BPM`: 프로젝트 전체의 템포 BPM을 조정합니다(템포 맵 활성화 시 재생 헤드 위치의 가장 가까운 변경점을 조정합니다. 아래 "템포 맵" 참조).
- `박자표`: 프로젝트의 박자를 설정합니다.
- `그리드`: 프로젝트의 그리드 간격을 설정합니다.
- `기준 음계`: 프로젝트 전체의 기준 음계 설정을 조정합니다. 사용자 정의 음계를 허용합니다. 음계 기능은 주로 후술할 `피치 스냅` 및 기타 피치 조정 관련 기능과 관련됩니다.
- `정지` 버튼 및 `재생 / 일시 정지` 버튼: 재생을 제어합니다.
- `녹음`: 선택한 트랙에서 녹음할 수 있습니다. 마우스 오른쪽 버튼으로 녹음 소스와 녹음 장치를 설정하거나 자세한 녹음 설정을 열 수 있습니다.
- `파일 브라우저`: HiFiShifter의 파일 브라우저 창을 엽니다.
- `메모장`: HiFiShifter 메모장 창을 열어 Markdown 형식의 텍스트를 기록하고 표시합니다.
- `자동 크로스페이드`: Reaper/VEGAS Pro의 유사 기능과 동일하게, 활성화하면 클립 이동 시 겹치는 부분의 크로스페이드 엔벨로프를 자동 조정합니다.
- `분할 트랜지션`: Reaper/VEGAS Pro의 분할 페이드 방식을 참고한 기능으로, 기본적으로 활성화되어 있습니다. 분할 후 분할 지점에 앞 클립의 페이드아웃과 뒤 클립의 페이드인을 자동으로 추가하거나 클립을 확장하여 겹치게 만들어 클립 간 전환이 더 부드러워집니다. 왼쪽 클릭으로 켜고 끄며, 오른쪽 클릭으로 자세한 설정을 엽니다.
- `스냅`: 활성화하면 클립 조정이 그리드, 다른 오브젝트 가장자리, 재생 헤드 등 설정된 대상에 스냅됩니다. `Shift`를 누르면 임시로 스냅을 전환할 수 있습니다.
- `리플 편집`: 활성화하면 트랙의 클립에 대한 일부 편집 작업이 자동으로 후속에 적용됩니다.
- `재생 헤드 기준 확대/축소`: 마우스 휠로 수평 확대/축소할 때의 중심을 설정합니다. 비활성화 시 마우스 커서 위치가 중심이고, 활성화 시 항상 재생 헤드 위치가 중심입니다(Reaper/VEGAS Pro 로직과 유사).
- `자동 스크롤`: 활성화하면 재생 중 재생 헤드를 따라 인터페이스가 수평으로 자동 스크롤됩니다.
- `파라미터 에디터에서 재생 헤드 이동 허용`: 비활성화하면 파라미터 에디터의 편집 패널 클릭으로는 재생 헤드가 이동하지 않습니다. 트랙 인터페이스나 파라미터 에디터의 시간 코드 영역을 클릭해야만 재생 헤드가 이동합니다.
- `타임라인 클릭으로 트랙 전환`: 기본적으로 활성화되어 있습니다. 활성화하면 타임라인의 클립이나 빈 영역을 클릭할 때 현재 트랙이 전환되고 파라미터 에디터도 해당 트랙을 편집합니다. 비활성화하면 왼쪽 트랙 헤더를 클릭할 때만 현재 트랙이 전환됩니다.
- `그룹 무시`: 활성화하면 그룹화된 모든 오디오 클립 편집 시 그룹 연동 편집을 전역적으로 무시합니다.

### 스냅 / 그리드 설정

타임라인 도구 모음의 `스냅` 버튼은 스냅을 빠르게 켜고 끄는 스위치입니다. 왼쪽 클릭으로 스냅 마스터 스위치를 전환하고, 오른쪽 클릭하면 `스냅 / 그리드 설정` 창이 바로 열립니다. 같은 창은 메뉴 `옵션 -> 스냅 / 그리드 설정` 에서도 열 수 있습니다. 모든 설정은 자동 저장되며 다음 실행 시 복원됩니다.

설정 항목:

- `그리드`: 그리드 선 표시 여부, 그리드 간격(일반 / 점음표 / 셋잇단음표, `1/1`~`1/64`), 최소 픽셀 간격을 설정할 수 있습니다. `Swing` 을 켜면 홀수 번째 그리드 선이 백분율(0–100%)만큼 이동하며, `스윙 변경 시 모든 클립 재정렬` 을 켜면 기존 클립이 새 스윙 그리드로 자동 이동합니다.
- `스냅 마스터`: `스냅 사용` 이 마스터 스위치입니다. `스냅 거리` 는 대상까지 몇 픽셀 이내일 때 스냅할지를 지정하며(기본 4px), `그리드 상대 스냅` 은 절대 위치 대신 원래 그리드와의 오프셋을 유지한 채 스냅합니다.
- `스냅 대상 및 목표`: `클립`, `선택 영역`, `커서` 각각에 대해 `선택 / 마커 / 커서` 와 `그리드` 로의 스냅을 따로 설정할 수 있습니다. 예를 들어 클립은 그리드에만 스냅하고, 재생 커서는 그리드와 클립 가장자리에 모두 스냅하도록 할 수 있습니다.
- `스냅 동작`: `스냅 설정을 그리드 표시에 따르기` 는 그리드를 숨기면 그리드로의 스냅을 멈춥니다. `임의 거리에서 그리드로 스냅` 은 거리와 관계없이 그리드에 강제 배치하는 모드입니다. `독립 스냅 간격 사용` 을 켜면 표시 그리드와 별도의 스냅 간격과 최소 픽셀 값을 지정할 수 있습니다.
- `클립 및 특수 요소 상호작용`: 클립 시작/끝만 스냅할지, 또는 `클립 스냅 오프셋`(클립 콘텐츠 시작 위치)도 함께 스냅할지 선택할 수 있습니다. `다른 트랙의 클립으로 스냅` 을 켜면 몇 트랙까지 건너 대상 트랙을 찾을지 설정할 수 있습니다. `레이저 편집 스냅` 은 `S` 분할 작업의 분할 위치도 스냅에 참여시킵니다.
- `고급`: `프로젝트 샘플레이트로 스냅` 으로 샘플 단위 정밀 스냅을, `클립 가장자리를 소스 시작/끝으로 스냅` 으로 잘라낸 클립 가장자리를 원본 소재의 시작/끝으로 되돌릴 수 있습니다. `선택 영역을 배수로 강제` 는 선택 영역을 지정한 그리드로 반올림하고, `편곡 뷰와 MIDI 편집기에 같은 그리드 분할 사용` 은 타임라인과 파라미터 에디터의 그리드 정밀도를 동기화합니다.

### 분할 트랜지션

`분할 트랜지션` 은 분할 지점의 클릭 노이즈를 줄이기 위한 기능으로, 기본적으로 활성화되어 있습니다. 타임 스트레치 알고리즘 등의 영향으로 분할 후 클립 경계에서 클릭 노이즈가 발생할 수 있습니다. 이 기능은 Reaper/VEGAS Pro의 방식을 참고하여 분할할 때마다 경계를 자동으로 처리합니다.

도구 모음의 `분할 트랜지션` 버튼은 `자동 크로스페이드` 오른쪽에 있습니다. 왼쪽 클릭으로 기능을 켜고 끄며, 오른쪽 클릭으로 상세 설정을 엽니다.

- `페이드만`: 분할 후 앞 클립에 길이 X의 페이드아웃, 뒤 클립에 길이 X의 페이드인을 자동으로 추가합니다. 두 클립은 겹치지 않습니다.
- `확장 및 겹치기`(기본): 분할 후 앞 클립의 끝을 뒤로 X만큼, 뒤 클립의 시작을 앞으로 X만큼 자동으로 늘려 2X초의 겹치는 구간을 만듭니다. 연장 시 클립 안의 소재가 타임라인에서 같은 위치를 유지하도록 하며 재생 속도도 올바르게 처리합니다. 연장 범위는 클립 원본 소재의 실제 길이 범위 안으로 제한됩니다. `자동 크로스페이드` 가 켜져 있으면 이 겹치는 구간에도 크로스페이드가 자동으로 적용됩니다.
- `트랜지션 길이 X`: 두 모드에서 사용하는 페이드/오버랩 길이로, 기본값은 0.01초입니다.
- `트랜지션 길이 단위`: `초` 또는 `퍼센트`를 선택할 수 있습니다. 퍼센트는 기본 1%이며, 분할로 생성된 앞뒤 두 클립의 전체 길이 합계를 기준으로 계산됩니다. 예를 들어 두 클립의 전체 길이가 10초일 때 1%는 0.1초입니다.
- `페이드 커브`: 분할 트랜지션이 경계 페이드로 작성하는 페이드 커브 유형을 선택합니다. 기본값은 `페이드 커브 변경 안 함`입니다.
- `오버랩 크로스페이드`: `자동 크로스페이드 따르기` 를 선택하면 `자동 크로스페이드` 가 켜져 있을 때만 겹치는 구간에 크로스페이드를 적용합니다. `항상 적용` 을 선택하면 겹치는 구간에 항상 크로스페이드가 적용됩니다.

### 클립 페이드 및 크로스페이드

모든 클립에는 독립적인 페이드인 / 페이드아웃 엔벨로프가 있으며, 상호작용 모델은 REAPER와 거의 동일합니다. 편집 대상은 '페이드 영역 전체'가 아니라 화면에 실제로 표시되는 두 선 — 페이드 엔벨로프 선과 페이드 영역의 가장자리 세로 선입니다.

**페이드 길이 조절**

- 클립 왼쪽 / 오른쪽 끝의 페이드 엔벨로프 선 또는 페이드 영역의 가장자리 세로 선을 드래그하면 페이드인 / 페이드아웃 길이를 조절할 수 있습니다. 클립 왼쪽 위 / 오른쪽 위 모서리에서 안쪽으로 드래그하면 길이 0부터 페이드를 만들 수 있습니다.
- 페이드 컨트롤을 (드래그하지 않고) 클릭하면 재생 커서가 해당 위치로 이동합니다: 엔벨로프 선은 페이드 영역의 안쪽 가장자리(페이드인 → 영역의 오른쪽 끝, 페이드아웃 → 영역의 왼쪽 끝), 교차점 그립은 클릭한 위치, 클립 가장자리는 그 가장자리의 정확한 위치로 이동합니다.
- 엔벨로프 선, 가장자리 세로 선, 교차점 그립 등 페이드 컨트롤 위에 마우스를 올리면 페이드인 / 페이드아웃 유형(곡선 아이콘), 길이(시간 표시 설정의 주 / 보조 시간 단위), 곡률로 구성된 툴팁이 표시됩니다.

**페이드 형태와 곡률**

HiFiShifter는 REAPER와 동일한 7가지 페이드 형태를 제공합니다: `직선`, `패스트 스타트`, `패스트 엔드`, `샤프 패스트 스타트`, `샤프 패스트 엔드`, `슬로우 스타트/엔드(S 커브)`, `샤프 슬로우 스타트/엔드`.

- 페이드 엔벨로프 선이나 가장자리 세로 선을 오른쪽 클릭하면 페이드 전용 컨텍스트 메뉴가 열립니다: 위쪽에 7개의 형태 버튼(현재 형태는 강조 표시), 아래쪽에 곡률 슬라이더와 미니 곡선 미리보기가 있습니다. 곡률 범위는 `-1.00 ~ +1.00` 이며 변경 즉시 적용됩니다. 슬라이더는 휠 스텝 조절을 지원하고(`파라미터 미세 조정` 수정 키를 누르면 더 세밀하게 조절), 미니 곡선은 직접 드래그할 수도 있습니다.
- `페이드 곡률` 수정 키(기본값 `Alt`)를 누른 채 엔벨로프 선을 드래그하면 곡선을 포인터 위치로 '끌어오듯' 곡률을 조절할 수 있습니다.
- 엔벨로프 선을 더블클릭하면 해당 측의 곡률을 현재 형태의 기본값으로 초기화할 수 있습니다. 형태를 바꾸면 곡률도 새 형태의 기본값으로 초기화됩니다.
- `페이드 형태 순환` 수정 키(기본값 `Ctrl`)를 누른 채 엔벨로프 선을 클릭하면 페이드 형태를 순환적으로 전환할 수 있습니다.
- 클립의 컨텍스트 메뉴에도 `페이드 인` / `페이드 아웃` 형태 선택 행이 있어 페이드 형태를 바로 전환할 수 있습니다.

**자동 크로스페이드**

도구 모음의 `자동 크로스페이드` 버튼(기본값 활성화)은 REAPER / VEGAS Pro의 유사 기능과 마찬가지로, 클립을 이동하여 같은 트랙 위에서 겹침이 생기면 겹침 길이에 맞춰 두 클립에 크로스페이드를 자동으로 설정합니다.

- 자동 크로스페이드 길이는 수동 페이드 길이와 별도로 저장됩니다: 겹침이 사라지면 자동 페이드는 해제되고 이전의 수동 페이드가 다시 표시됩니다. 반대로 페이드 길이를 수동으로 조절하면 해당 측은 수동 페이드로 전환됩니다.
- 한 클립이 다른 클립을 완전히 포함하는 경우에는 유효한 크로스페이드 관계로 간주되지 않아 자동 크로스페이드가 발생하지 않습니다.
- 타임라인과 파라미터 에디터에 표시되는 페이드 길이는 항상 '실효 페이드'입니다: 자동 크로스페이드가 수동 페이드보다 우선합니다.

**겹치는 구간 편집**

두 클립이 겹치면 겹치는 구간에 양쪽 클립을 위한 완전한 편집 컨트롤이 표시되며, 조작 방식은 일반 클립과 동일합니다: 겹침 구간의 왼쪽은 뒤 클립(왼쪽 가장자리 잘라내기 / 연장 및 페이드인 컨트롤), 오른쪽은 앞 클립(오른쪽 가장자리 잘라내기 / 연장 및 페이드아웃 컨트롤)에 해당합니다. 우선순위는 클립 가장자리가 가장 높고, 다음이 페이드 영역의 가장자리 세로 선, 마지막이 엔벨로프 선입니다.

두 페이드 곡선의 교차점에는 그립(교차점 핸들)이 있습니다:

- 그립을 그대로 드래그: 교차점이 앞뒤로 이동하며 겹침 길이는 변하지 않습니다;
- `크로스페이드 반전 모드` 수정 키(기본값 `Ctrl`)를 누른 채 드래그: 앞뒤 두 클립의 가장자리가 반대 방향으로 이동하여 겹침 길이가 변하고 페이드 길이가 비례하여 조절됩니다;
- `페이드 곡률` 수정 키(기본값 `Alt`)를 누른 채 드래그: 두 페이드 곡선의 곡률을 동시에 조절합니다;
- 그립을 오른쪽 클릭: 앞 클립의 페이드아웃과 뒤 클립의 페이드인 두 열로 이루어진 페이드 메뉴가 동시에 열려 각각의 형태와 곡률을 설정할 수 있습니다. 더블클릭하면 양쪽 곡률을 동시에 초기화할 수 있습니다.

이러한 수정 키는 `옵션 -> 키보드 단축키...` 의 `수정 키 · 페이드 및 크로스페이드` 그룹에서 변경할 수 있습니다.

### 타임라인 시간 표시

타임라인 상단의 눈금자는 가로 확대/축소에 따라 눈금을 자동으로 세분화합니다. 축소 상태에서는 마디만 표시되고(`1.1`, `2.1`), 점점 확대하면 2분음표(`1.1`, `1.3`), 4분음표(`1.1`, `1.2`), 8분음표(`1.1`, `1.1.500`), 더 나아가 16분/32분음표까지 세분화됩니다. 가장 정밀한 단계는 `그리드` 설정에 따라 제한됩니다.

네 가지 시간 단위를 지원합니다.

- `마디.박.소단위`(기본 주 단위): `1.2.500`은 1번째 마디의 2번째 박에서 0.5박 더 간 위치를 뜻합니다(1000소단위 = 1박).
- `마디.분할`: `1.17/32`는 `1/32` 그리드 기준 1번째 마디의 17번째 분할을 뜻합니다. 분할은 `그리드` 설정을 따릅니다. 셋잇단 그리드는 정수 분할 수(예: `1.2/12`)를, 점음표 그리드는 소수 분할 수(예: `1.2/2.6667`)를 가질 수 있습니다.
- `초`: 절대 초로, 예를 들어 `1234.5678`.
- `시:분:초.밀리초`(기본 보조 단위): 시가 0이면 시를 생략하고, 밀리초는 항상 3자리입니다(예: `4:43.750`, `1:4:43.750`).

눈금자를 마우스 오른쪽 버튼으로 클릭하면 기본 시간 단위와 보조 시간 단위를 각각 선택할 수 있으며, 보조 단위는 `미사용`으로도 설정할 수 있습니다. `보기 -> 시간 표시` 메뉴나 `타임라인 표시 설정...` 대화상자에서도 조정할 수 있습니다. 두 단위를 모두 표시할 때는 위아래 두 줄로 나뉘고 그 사이에 연한 가로선이 표시됩니다. 보조 단위가 `미사용`이거나 기본 단위와 같으면 기본 단위만 세로 중앙에 표시됩니다.

트랙 뷰 왼쪽의 `트랙` 제목 줄 오른쪽에는 재생 헤드 시간이 `주 단위 / 보조 단위`(보조 단위가 없으면 주 단위만) 형식으로 실시간 표시되며, 재생 중이나 시간 형식 전환 시에도 자동으로 갱신됩니다. 재생 헤드 시간 텍스트는 자릿수를 고정하여 정렬됩니다(예: `1.1.000`, `0.000`).

눈금자 위에서 마우스를 움직이면 포인터 위치의 시간이 표시됩니다. 오른쪽 클릭 메뉴의 `재생 헤드 시간 복사`로 현재 재생 헤드 시간을 텍스트로 클립보드에 복사할 수 있습니다. `타임라인 표시 설정...`에서는 눈금자 라벨 간격을 조정하고 트랙 헤더의 재생 헤드 시간 표시를 켜거나 끌 수 있습니다.

### 템포 맵(템포 / 박자표 / 스케일)

HiFiShifter는 프로젝트 단위 템포 맵을 지원하여 타임라인의 서로 다른 위치에 서로 다른 BPM, 박자표, 스케일을 정의할 수 있습니다. 빈 프로젝트에는 기본적으로 템포 맵 데이터가 없습니다. 프로젝트에 템포 맵 데이터를 추가하면 눈금자가 시간 단위 아래에 템포 맵 행을 자동으로 추가 표시하며(시간 단위와 연한 가로선으로 구분됨), 각 구간의 템포·박자표·스케일은 각 변경점의 라벨에 표시됩니다. 어느 구간의 시작 라벨이 화면 왼쪽 밖으로 스크롤되면 행의 맨 왼쪽에 라벨과 같은 스타일의 플로팅 라벨이 나타나 해당 구간의 매개변수를 표시합니다. 라벨은 가로 스크롤에 따라 부드럽게 전환되며 라벨과 겹치지 않고, 고정 라벨과 완전히 동일한 조작(더블 클릭으로 입력 편집, 오른쪽 클릭으로 편집 창 열기)을 지원합니다. 파라미터 편집기의 눈금자에도 동일한 템포 맵 행이 표시됩니다.

- 변경점 추가: 시간 눈금자를 마우스 오른쪽 버튼으로 클릭하고 메뉴의 `여기에 템포/박자표/스케일 변경 추가…`를 선택하면 클릭한 위치에 변경점을 만들고 편집 대화상자를 엽니다. 템포 맵 행의 빈 곳을 더블 클릭하면 해당 위치에 변경점이 바로 생성됩니다.
- 변경점 편집: 템포 맵 행의 변경점 라벨(0 위치의 초기 포인트 포함)을 더블 클릭하면 BPM, 박자표와 음계를 수정할 수 있습니다. 라벨은 더블 클릭 후 그 자리에서 텍스트 입력 상자로 바뀌어 `120 4/4 - C / Am` 같은 텍스트를 직접 입력할 수 있습니다. 라벨을 오른쪽 클릭하면 `템포 맵 변경점` 편집 창이 바로 열립니다.
- 이전 박자표 / 음계 따르기: 각 변경점의 박자표는 `이전 박자표 따르기`, 음계는 `이전 음계 따르기`를 선택할 수 있습니다.
- 초기 포인트는 프로젝트 기준: 프로젝트 전체의 BPM, 박자표(분자와 분모)와 음계는 0 위치의 초기 포인트에 기록되며, 템포 맵 행에 `120 4/4 - C / Am` 같은 텍스트로 표시됩니다.
- 그리드와 눈금자: 템포 맵이 있으면 시간 눈금자 눈금, 마디/박 라벨과 배경 그리드가 각 변경점에서 다시 정렬되고 각 구간의 템포와 박자표에 따라 구간별로 계산됩니다.
- 음계 연동: 템포 맵의 음계 변화는 피치 스냅(음계 모드), 음계 하이라이트, 도수 이조/퀀타이즈/평균 퀀타이즈 등의 `프로젝트 음계` 옵션과 하위 트랙의 `도수 차` 렌더링에 반영됩니다.
- 가져오기: MIDI를 음높이 참조 클립으로 가져올 때 가져오기 대화상자에서 `템포 맵으로 가져오기`를 켜고 템포, 박자표와 음계를 각각 선택할 수 있습니다. REAPER 프로젝트(.rpp)를 가져오면 프로젝트 수준의 템포·박자표 변화가 자동으로 가져와집니다.

## 4. 파일 브라우저

파일 브라우저를 사용하면 특정 폴더를 열고, 그 안의 오디오 및 동영상 미디어 파일을 조건 검색 및 정렬하고, HiFiShifter의 트랙 인터페이스로 드래그 앤 드롭할 수 있습니다. 동영상 파일은 보라색, 오디오 파일은 파란색 아이콘으로 표시됩니다. 검색은 정규 표현식을 지원합니다. 미디어 파일을 클릭하면 자동으로 미리듣기가 재생됩니다(동영상은 오디오 트랙만 미리듣기). `Ctrl` 및 `Shift` 키를 누른 상태에서 파일을 다중 선택할 수 있습니다. 왼쪽 드래그로 하나 이상의 미디어 파일을 시간축에 일괄적으로 추가할 수 있습니다. 오른쪽 드래그로 `시간을 가로질러 추가` / `트랙 간 추가` 메뉴가 나타납니다. `트랙 간 추가`는 여러 미디어 오디오 클립을 세로 방향으로 여러 트랙에 걸쳐 시간축에 추가할 수 있습니다.

트랙 영역에 포커스가 있을 때 단축키 `Ctrl + F`를 누르면 빠른 검색 창이 열립니다. 이것은 파일 브라우저 기능의 간소화된 버전으로, 폴더 내 오디오/동영상 미디어 파일을 빠르게 조건 검색 및 미리듣기(동영상은 오디오 트랙만)하고 시간축에 추가할 수 있습니다.

## 5. 파라미터 에디터

파라미터 에디터는 HiFiShifter의 핵심 기능 중 하나로, 현재 선택된 트랙의 다양한 파라미터를 편집할 수 있습니다.

트랙의 파라미터 편집 기능을 활성화하려면 먼저 해당 트랙의 합성 버튼 `C`를 누르고 오디오 분석이 완료될 때까지 기다려야 합니다. HiFiShifter는 오프라인 렌더링을 사용하며, 파라미터를 편집할 때마다 다시 렌더링이 완료될 때까지 기다린 후에 청취할 수 있습니다.

파라미터 에디터 제목 왼쪽의 `타임라인 뷰 동기화` 버튼(링크 아이콘)으로 파라미터 에디터와 트랙 뷰의 가로 동기화를 켜거나 끌 수 있습니다. 활성화하면 두 뷰의 가로 위치와 확대/축소가 완전히 일치하며 양방향으로 연동됩니다: 어느 뷰에서 스크롤하거나 확대/축소해도 다른 뷰가 함께 따라갑니다. 활성화한 순간에는 트랙 뷰를 기준으로 파라미터 에디터가 맞춰집니다. 트랙 뷰 왼쪽에는 트랙 헤더 영역이 있으므로, 파라미터 에디터는 좌우 오프셋을 자동으로 보정하여 두 패널에서 그리드 선과 타임라인 눈금이 같은 화면 위치에 정렬됩니다. 비활성화(기본값)하면 두 뷰는 독립적으로 확대/축소·스크롤됩니다.

### 1. 알고리즘 및 파라미터

현재 버전의 HiFiShifter는 다음 3가지 음성 튜닝 알고리즘과 파라미터를 지원합니다.

- **PC-NSF-HiFiGAN**: OpenVPI의 오픈소스 노래 특화 hifigan 보코더로, HiFiShifter의 기본 알고리즘입니다.
    - `피치`: 음성의 피치를 조정합니다.
    - `포먼트 시프트`: 음성의 포먼트 시프트를 조정합니다.
    - `기성(氣聲) 볼륨`: 기성을 활성화하면 기성 볼륨을 조정할 수 있습니다(VR-hnsep 모델 기반).
    - `텐션`: 음성의 텐션을 조정합니다.
    - `볼륨`: 음성의 볼륨을 조정합니다.
    - `팬`: 음성의 팬을 조정합니다.
- **World**: 오픈소스 고품질 음성 분석 및 합성 알고리즘.
    - `피치`: 음성의 피치를 조정합니다.
    - `볼륨`: 음성의 볼륨을 조정합니다.
    - `팬`: 음성의 팬을 조정합니다.
- **VsLib**: VocalShifter 공식 음성 분석 및 합성 라이브러리. VsLib 알고리즘은 Windows x86_64 버전에서만 사용 가능합니다.
    - `피치`: 음성의 피치를 조정합니다.
    - `포먼트 시프트`: 음성의 포먼트 시프트를 조정합니다.
    - `기성 강도`(氣聲強度): 음성의 기성 강도를 조정합니다.
    - `볼륨`: 음성의 볼륨을 조정합니다.
    - `팬`: 음성의 팬을 조정합니다.
    - `합성 모드`: 음성의 합성 모드를 조정합니다. 특정 모드에서는 일부 파라미터가 무효화될 수 있습니다.
        - `모노`: VocalShifter의 M 알고리즘, 단음 악기용.
        - `모노 (포먼트)`: VocalShifter의 V 알고리즘, 단음 보컬용.
        - `코러스`: VocalShifter의 P 알고리즘, 하모니용.

하나의 트랙은 하나의 알고리즘만 사용할 수 있습니다. 여러 알고리즘을 동시에 사용하려면 별도의 트랙으로 분리하세요.

트랙 그룹은 파라미터를 공유하며, 하위 트랙은 루트 트랙으로부터 파라미터를 상속받습니다. 특히 하위 트랙에는 `센트 차`, `도수 차`, `포먼트 차`라는 세 가지 추가 파라미터가 있어 루트 트랙에 대한 상대적인 피치와 음색 변화를 편리하게 조정할 수 있습니다. `도수 차`는 프로젝트의 음계 설정을 기준으로 합니다. 파라미터 편집기 도구 모음에서 하위 트랙의 `센트 차` / `도수 차`는 `피치` 버튼 드롭다운에, `포먼트 차`는 `포먼트 시프트` 버튼 드롭다운에 통합되어 있습니다.

`선택` 도구로 `피치` 구간을 복사한 후, `센트 차`나 `도수 차`에 붙여넣으면 적절한 오프셋 값이 자동 계산되어 적용됩니다.

### 2. 선택 도구

선택 도구를 사용하면 파라미터 라인 구간을 선택하고, 드래그하거나 마우스 오른쪽 버튼 컨텍스트 메뉴를 통해 파라미터를 조정할 수 있습니다.

자주 사용하는 단축키:

- `Ctrl + C`: 복사
- `Ctrl + V`: 붙여넣기
- `Ctrl + Z`: 실행 취소
- `Ctrl + Y`: 다시 실행(macOS: `⌘ + ⇧ + Z`)
- `Ctrl + A`: 모두 선택

- `BackSpace`: 초기화
- `[` / `]`: 선택 범위 내 파라미터 라인을 아래로/위로 이동

선택한 파라미터 라인을 왼쪽 드래그하면 `드래그 방향` 설정에 따라 수직, 수평 또는 자유롭게 이동할 수 있습니다. 왼쪽 드래그 중에 오른쪽 버튼을 누르면 드래그 방향을 빠르게 전환할 수 있습니다.

선택한 파라미터 라인을 오른쪽 드래그하면 진폭을 조정할 수 있습니다. 위로 드래그할수록 진폭이 커지고 아래로 드래그할수록 작아집니다.

파라미터 에디터 내에서 마우스 오른쪽 버튼을 클릭하면 컨텍스트 메뉴가 열리며, 선택한 파라미터 라인에 대해 `초기화`, `센트 단위로 조바꿈`, `도 단위로 조바꿈`, `값 설정`, `평균화`, `스무딩`, `비브라토 추가`, `퀀타이즈`, `평균 퀀타이즈` 등의 작업을 수행할 수 있습니다.

`Alt` 키를 누르면 선택 범위에 대해 4점 편집 모드가 됩니다. VocalShifter의 동일 유형 기능과 유사하게 4개 점을 드래그하여 현재 파라미터 라인을 휘게 할 수 있습니다.

`Alt` 키를 누른 상태에서 선택 영역 가장자리를 드래그하면 선택 영역 내의 파라미터 라인을 스트레치할 수 있습니다.

### 3. 그리기 도구

그리기 도구를 사용하면 파라미터 라인을 그릴 수 있습니다.

왼쪽 드래그로 `드래그 방향` 설정에 따라 자유롭게 또는 수평으로 파라미터 라인을 그릴 수 있습니다. 왼쪽 드래그 중에 오른쪽 버튼을 누르면 드래그 방향을 빠르게 전환할 수 있습니다.

오른쪽 드래그로 현재 라인을 재설정할 수 있습니다.

### 4. 직선/비브라토 도구

그리기 도구 버튼을 마우스 오른쪽 버튼으로 클릭하면 직선/비브라토 도구로 전환됩니다. 이 도구를 사용하면 직선 또는 비브라토를 그릴 수 있습니다.

왼쪽 드래그로 `드래그 방향` 설정에 따라 자유롭게 또는 수평으로 직선을 그릴 수 있습니다. 왼쪽 드래그 중에 오른쪽 버튼을 누르면 드래그 방향을 빠르게 전환할 수 있습니다.

왼쪽 드래그 중에 마우스 휠을 굴리면 직선에 수평 사인파가 중첩되며, 휠로 진폭을 조정할 수 있습니다. `Alt` 키를 누른 상태에서 휠을 굴리면 주파수를 조정할 수 있습니다. `파라미터 미세 조정` 수정 키(기본값 `Ctrl`)를 누른 상태에서 휠을 굴리면 미세 조정할 수 있습니다.

오른쪽 드래그로 현재 라인을 재설정할 수 있습니다.

`Tab` 키를 눌러 파라미터 에디터의 편집 도구(선택 도구/그리기 계열 도구)를 전환할 수 있습니다.

### 5. 피치 스냅

다양한 편집 도구로 피치 파라미터를 편집할 때 피치 스냅을 사용하면 반음 또는 음계에 스냅할 수 있습니다. `Shift` 키를 누르면 임시로 스냅을 전환할 수 있습니다.

피치 스냅 버튼을 마우스 오른쪽 버튼으로 클릭하면 피치 스냅 설정 메뉴가 열리며, 양자화 단위와 허용 오차를 조정할 수 있습니다.

- `양자화 단위`: `반음`과 `음계` 두 가지 유형이 있습니다. 음계를 선택하면 기준 음계는 프로젝트의 음계 설정입니다.
- `허용 오차`: 스냅의 허용 범위를 조정합니다. 허용 오차 내의 피치 편집은 스냅되지 않고, 범위를 벗어난 편집은 가장 가까운 허용 오차 경계에 스냅됩니다.

예를 들어, 보컬 하모니 효과를 만들려면:

1. 프로젝트 음계를 확인하고 설정합니다.
2. 피치 스냅을 활성화하고 양자화 단위를 `음계`로 설정합니다.
3. 음계 하이라이트 기능을 활성화하여 이동 도수를 쉽게 관찰할 수 있도록 합니다.
4. 선택 도구로 수직 드래그합니다.

또는 하위 트랙의 `센트 차` 및 `도수 차` 파라미터를 사용할 수도 있습니다:

1. 프로젝트 음계를 확인하고 설정합니다.
2. 하모니 트랙의 헤더를 메인 보컬 트랙으로 드래그하여 트랙 그룹을 생성합니다(메인 보컬 = 루트, 하모니 = 하위).
3. 파라미터 에디터를 하모니 트랙의 `도수 차` 파라미터로 전환하고 필요한 도수선을 그립니다. `센트 차` 및 `도수 차` 편집도 피치 스냅을 지원하여 각각 정수 반음 및 정수 도수에 스냅할 수 있습니다.

이렇게 하면 도수 이동에 의한 하모니 효과를 빠르게 만들 수 있습니다. 마찬가지로 하위 트랙의 `포먼트 차`로 전환하여 프레임별 포먼트 시프트 곡선을 그리면 `포먼트 시프트`를 지원하는 알고리즘(NSF-HiFiGAN / vslib)에서 음색 차이가 있는 하모니를 만들 수 있습니다.

### 6. 음높이 참조 클립

트랙의 음높이 참조 클립은 타임라인에 피치 곡선을 저장할 수 있는 특수한 클립입니다.

음높이 참조 클립은 다음 경로를 통해 생성할 수 있습니다:

- `파일` 메뉴 또는 파일 드래그를 통해 MIDI를 가져옵니다. MIDI 가져오기 대화상자가 나타납니다.
    - MIDI 파일: 가져올 MIDI 파일을 선택할 수 있습니다. 다른 DAW에서 시스템 클립보드로 출력한 MIDI 데이터 파싱도 지원합니다. 현재 시스템 클립보드를 통한 MIDI 데이터 전송이 확인된 DAW는 Reaper와 FL Studio입니다.
        - Reaper: Reaper의 MIDI 에디터에서 노트를 선택하고 복사하면 선택한 노트 데이터가 시스템 클립보드로 출력되어 HiFiShifter에서 읽을 수 있습니다. Reaper의 클립보드 노트 데이터에는 BPM 정보가 포함되어 있지 않으므로, 가져올 때 현재 프로젝트 BPM을 사용하거나 수동으로 지정할 수 있습니다.
        - FL Studio: FL Studio의 피아노 롤 화면에서 왼쪽 상단의 작은 삼각형을 클릭하여 메뉴를 펼치고 `파일` -> `MIDI 클립보드로 복사`를 선택하면 현재 채널의 모든 노트가 시스템 클립보드로 출력되어 HiFiShifter에서 읽을 수 있습니다.
    - 트랙 선택: 가져올 MIDI 트랙을 선택할 수 있습니다.
    - MIDI BPM을 프로젝트 BPM으로 가져오기: 활성화하면 MIDI의 초기 BPM을 프로젝트 BPM으로 가져옵니다.
    - 노트 BPM: 가져올 노트의 BPM 매핑 방식을 설정할 수 있습니다.
        - MIDI 자체 BPM: BPM 매핑을 하지 않고 MIDI 자체 BPM으로 직접 가져옵니다.
        - 현재 프로젝트 BPM: 노트 BPM을 현재 프로젝트 BPM으로 매핑한 후 가져옵니다.
        - 지정 BPM: 노트 BPM을 수동으로 지정한 BPM으로 매핑한 후 가져옵니다.
    - 멀티트랙 병합: 활성화하면 선택한 모든 트랙과 모든 노트를 자동으로 병합하고, 가장 높은 피치의 노트를 피치 곡선 파라미터로 사용하여 최종적으로 1개의 음높이 참조 클립만 가져옵니다. 비활성화하면 모든 노트가 피치 곡선 파라미터로 가져와질 수 있도록 트랙과 노트를 분할하려고 시도하며, 최종적으로 여러 개의 음높이 참조 클립이 세로로 배치될 수 있습니다.
    - 노트 사이 간격 채우기: 활성화하면 인접한 두 노트 사이의 간격을 자동으로 채웁니다.
- Reaper 프로젝트 또는 Reaper 클립보드를 통해 트랙의 MIDI 아이템을 가져옵니다.
- VocalShifter 프로젝트 또는 VocalShifter 클립보드를 통해 트랙의 MIDI 클립을 가져옵니다.
- 일반 클립을 마우스 오른쪽 버튼으로 클릭하고 컨텍스트 메뉴에서 `음높이 참조 클립으로 변환`을 선택합니다. 이렇게 하면 해당 일반 클립의 원본 피치 곡선이 새로운 음높이 참조 클립의 피치 곡선으로 변환됩니다.
- 파라미터 에디터에서 피치 파라미터를 편집할 때, 선택 도구로 영역을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 컨텍스트 메뉴에서 `음높이 참조 클립으로 저장`을 선택하면 선택 범위 내의 피치 곡선을 새로운 음높이 참조 클립으로 저장할 수 있습니다.

음높이 참조 클립의 일반적인 용도는 다음과 같습니다:

- 트랙에 배치하여 일반 클립이 있는 다른 트랙이 피치를 참조할 수 있도록 합니다. 다른 트랙에서는 파라미터 에디터의 `참조 트랙 그룹` 기능을 사용하여 이 트랙을 보고 피치 곡선을 표시할 수 있습니다.
- 음높이 참조 클립이 트랙 그룹의 루트 트랙에 배치되면, 현재 트랙 그룹의 피치 처리 로직을 변경하여 해당 구간의 원본 피치 곡선을 음높이 참조 클립의 피치 곡선으로 덮어씁니다. 이는 다음 시나리오에 영향을 줍니다:
    - 트랙 그룹 내에서 편집된 적이 없는 피치 곡선 구간이 있으면, 해당 피치 파라미터가 음높이 참조 클립의 피치 곡선으로 직접 덮어쓰기되고 오디오 피치의 재렌더링이 트리거됩니다.
    - `초기화` 관련 기능을 사용할 때--예를 들어 파라미터 에디터에서 그리기 도구로 오른쪽 드래그 작업을 할 때--초기화된 피치 곡선은 트랙 그룹 하위 트랙 내 클립의 원본 피치가 아닌 음높이 참조 클립의 피치 곡선 데이터를 사용합니다.
    - 음높이 참조 클립이 음소거된 경우, 트랙 그룹은 피치를 처리할 때 해당 음높이 참조 클립을 참조하지 않습니다.

음높이 참조 클립을 선택한 뒤 컨텍스트 메뉴에서 `피치 업데이트`를 실행하면 해당 범위의 기존 피치 파라미터가 음높이 참조 클립에 업데이트됩니다.

### 7. 기타 기능

파라미터 에디터의 기타 편리한 기능:

- `클립보드 미리보기`: `보기` 메뉴에 있습니다. 선택 도구로 파라미터 커브 데이터를 복사하면 선택 영역에 클립보드 커브 데이터가 실시간 표시되어 붙여넣기 위치를 정하는 데 편리합니다.
- `파라미터 값 팝업`: `보기` 메뉴에 있습니다. 마우스가 커브 근처에 있거나 그리기 편집을 실행 중일 때 파라미터 값을 표시합니다.
- `파라미터 라인 잠금`: 트랙에서 오디오 클립을 드래그할 때 해당 클립에 대응하는 모든 파라미터 라인도 함께 이동할지 여부를 결정합니다. HiFiShifter의 모든 파라미터 편집 기능은 트랙 기반입니다. 잠기지 않으면 편집된 파라미터 라인이 클립을 따라 이동하지 않습니다.
- `스무딩`: 파라미터 편집 시 자동으로 스무딩을 적용할지 여부와 그 강도.
- `참조 트랙 그룹`: 파라미터가 `피치`일 때 다른 트랙을 선택하여, 다른 트랙 그룹의 피치 곡선을 참조로 피치 편집 창에 표시할 수 있습니다.
- `MIDI 가져오기`: MIDI 파일을 선택하고 단일 또는 다중 트랙의 노트를 피치 라인으로 가져올 수 있습니다.

## 6. 오디오 내보내기

모든 편집을 완료한 후 `파일` 메뉴의 `오디오 내보내기` 기능을 통해 HiFiShifter 프로젝트를 wav 오디오로 내보낼 수 있습니다.

파라미터:

- `내보내기 유형`: `프로젝트` / `분리 트랙`.
- `내보내기 범위`: `전체` / `사용자 지정`. 사용자 지정에서는 시작 및 종료 시간(초)을 설정할 수 있습니다.
- `샘플레이트`: 출력 WAV 오디오의 샘플레이트를 설정합니다.
- `비트 심도`: 출력 WAV 오디오의 비트 심도를 설정합니다.
- `출력 폴더`: 파일 출력 폴더를 설정합니다. 사용 가능한 자리 표시자:
    - `<ProjectFolder>`: 현재 프로젝트가 저장된 폴더. 저장되지 않은 경우 `내 문서` 폴더를 가리킵니다.
    - `<ProjectName>`: 현재 프로젝트의 파일 이름(확장자 제외).
    - 프로젝트 내보내기의 경우 출력 폴더 기본값은 `<ProjectFolder>`입니다. 분리 트랙 내보내기의 경우 기본값은 `<ProjectFolder>/<ProjectName>`입니다.
- `출력 파일 이름`: 파일 출력 이름을 설정합니다. 사용 가능한 자리 표시자:
    - `<ProjectName>`: 현재 프로젝트의 파일 이름(확장자 제외).
    - 기본값은 `<ProjectName>.wav`입니다.
- `분리 트랙 이름 패턴`: 분리 트랙 출력 시 이름 형식을 설정합니다. 사용 가능한 자리 표시자:
    - `<ProjectName>`: 현재 프로젝트의 파일 이름(확장자 제외).
    - `<ExportIndex>`: 내보내기 시 트랙의 순서 번호(0부터 시작).
    - `<TrackIndex>`: 프로젝트 내 트랙 번호(0부터 시작).
    - `<TrackName>`: 프로젝트 내 트랙 이름.
    - `<TrackType>`: 트랙 유형(`Root` / `Sub`).
    - `<TrackId>`: 트랙의 내부 ID(일반 사용자는 사용하지 않는 것이 좋음).
    - 기본 패턴은 `<ExportIndex>_<TrackName>.wav`입니다.
- `분리 트랙 출력 대상` 패널: 내보낼 트랙을 선택할 수 있습니다. 기본적으로 음소거되지 않은 일반 트랙과 루트 트랙만 선택됩니다.
    - 원래 음소거된 트랙을 체크하면 음소거 상태에 관계없이 정상적으로 내보내집니다.
    - 트랙 그룹의 루트 트랙을 체크하면 해당 루트 트랙이 포함된 트랙 그룹이 단일 오디오 파일로 내보내지며, 음소거된 하위 트랙의 오디오 데이터는 제외됩니다.
    - 하위 트랙을 체크하면 해당 하위 트랙이나 해당 루트 트랙의 음소거 상태에 관계없이 정상적으로 내보내집니다.

파일 경로를 입력하는 동안 `자리 표시자` 버튼을 클릭하면 해당 텍스트를 빠르게 입력할 수 있습니다.

위의 모든 파일 경로 관련 문자열은 `%Y-%m-%d-%H-%M-%S`와 같은 시간 형식 문자열을 지원합니다. 출력 경로에 리터럴 `%` 문자를 포함하려면 `%%`를 사용하여 이스케이프 처리하세요.

## 7. 녹음

HiFiShifter는 타임라인에서 직접 녹음할 수 있습니다. 녹음 중에는 재생 커서 위치에서 타임라인 재생이 함께 시작되며(반주나 배경음을 들으며 녹음 가능), 녹음이 끝나면 재생이 자동으로 멈추고 녹음 파일이 타임라인으로 가져와집니다.

### 녹음 버튼과 단축키

- 재생 제어 영역의 빨간 원형 버튼으로 녹음 시작/중지를 전환합니다.
- 기본 단축키는 `Ctrl + R`이며 `옵션 -> 키보드 단축키...`에서 변경할 수 있습니다.
- 녹음 버튼을 마우스 오른쪽 버튼으로 클릭하면 녹음 설정을 빠르게 열 수 있습니다.

### 녹음 설정

`파일 -> 녹음...`에서 설정할 수 있습니다:

- `녹음 소스`: 녹음 소스를 세 가지 모드 중에서 선택합니다.
- `녹음 장치`: 기본값은 `시스템 기본값`이며, 이 PC의 모든 입력 장치(마이크 등)를 나열하여 선택할 수 있습니다.
- `루프백 장치`: 녹음 소스가 `시스템 사운드(루프백)`일 때 캡처할 출력 장치를 선택합니다. 기본은 `시스템 기본 출력`입니다.
- `애플리케이션`: 녹음 소스가 `애플리케이션 오디오`일 때 특정 프로그램의 소리만 캡처할 수 있습니다. `새로고침`을 누르면 현재 오디오를 출력하는 프로그램을 다시 나열합니다. 프로그램이 다시 시작되면 프로세스 이름으로 자동으로 다시 매칭됩니다. Windows 10 21H2(build 20348) 이상에서는 시스템 프로세스 루프백 API를 우선 사용하고, 이전 빌드에서는 다른 세션을 음소거하는 호환 방식으로 자동 전환합니다. Linux에서는 PipeWire(`pw-dump` / `pw-cat`)로 캡처하며, macOS에서는 아직 이 모드를 지원하지 않습니다.
- `샘플 레이트` / `비트 심도` / `채널`: 출력 WAV의 샘플 레이트, 비트 심도, 채널 수.
- `입력 게인`: 녹음 전 게인 보정.
- `카운트다운`: 초 단위로 시간을 입력합니다. 녹음 버튼을 클릭하면 먼저 카운트다운 후 녹음이 시작됩니다.
- `녹음 중 입력 모니터링`: 녹음 중 입력 신호를 출력 장치로 되돌려 보냅니다.
- `가져온 후 자동 정규화`: 중지 후 가져올 때 새 클립의 피크를 자동으로 0 dB로 정규화합니다.
- `선택 클립 끝에서 자동 정지`: 재생이 선택 클립의 끝에 도달하면 자동으로 중지하고 가져옵니다.
- `출력 경로 템플릿`: `<ProjectFolder>`, `<ProjectName>`, 시간 형식 문자열을 지원합니다. 기본값은 `<ProjectFolder>/HiFiShifter Record/%Y-%m-%d-%H-%M-%S.wav`입니다.

### 녹음 과정과 가져오기 규칙

1. 재생 커서를 녹음 시작 위치로 옮기고 대상 트랙을 선택합니다.
2. 녹음 버튼을 누르면 재생 커서에서 타임라인 재생이 시작되고 동시에 캡처가 시작됩니다.
3. 녹음 버튼을 다시 누르면 중지되고 타임라인 재생도 멈춥니다.
4. 선택 트랙이 녹음 범위 안에서 완전히 비어 있으면 해당 트랙으로 직접 가져옵니다. 그렇지 않으면 선택 트랙 바로 아래에 새 `녹음` 트랙을 만들고 가져온 뒤, 새 트랙과 새 클립을 자동으로 선택합니다.

## 8. 로그 및 문제 해결

HiFiShifter는 실행 로그를 OS 표준 로그 디렉터리에 자동으로 기록합니다. 명령줄 인수가 필요하지 않습니다. 문제가 발생하면 로그 파일을 첨부해 보고하면 원인 파악에 큰 도움이 됩니다:

| OS      | 로그 디렉터리                                  |
| ------- | ---------------------------------------------- |
| Windows | `%LOCALAPPDATA%\com.arounder.hifishifter\logs` |
| macOS   | `~/Library/Logs/com.arounder.hifishifter`      |
| Linux   | `~/.local/share/com.arounder.hifishifter/logs` |

- `도움말 → 로그 폴더 열기` 메뉴로 로그 파일 위치를 바로 열 수 있습니다.
- `도움말 → 진단 정보 내보내기…` 메뉴로 진단 패키지 zip(시스템 정보 + 전체 로그 + 추론 장치 벤치마크 결과)을 한 번에 생성할 수 있습니다. 이슈 등록 시 첨부해 주세요.
- 로그는 크기 기준으로 자동 순환됩니다: 파일당 최대 8 MiB, 최대 3개의 이전 파일 보관 (`hifishifter.1.log` … `hifishifter.3.log`).
    - 반복되는 오류 / 경고는 자동으로 스로틀링됩니다: 동일한 위치의 로그는 10초 창당 최대 1건만 출력되며, 억제된 건수는 다음 출력 전에 `[throttled]` 행으로 보완 기록됩니다.
- 프런트엔드와 백엔드 오류가 모두 동일한 로그 파일에 기록되어 하나의 파일로 시간순 추적이 가능합니다.

고급 옵션(일반적인 사용에는 불필요):

- 실행 인수 `--log-file=<path>`: 로그를 지정한 경로에 기록합니다. `--log-file=-` 은 파일 로그를 명시적으로 비활성화합니다.
- 환경 변수 `HIFISHIFTER_LOG=debug` (또는 `trace` / `info` / `warn` / `error`): 로그 상세 수준을 조정합니다. release 빌드의 기본값은 `info`입니다.
- 환경 변수 `HIFISHIFTER_LOG_DIR`: 기본 로그 디렉터리를 대체합니다.
- 터미널에서 `HiFiShifter --benchmark` 실행: 추론 장치 벤치마크를 실행하고 결과를 JSON으로 출력합니다.
