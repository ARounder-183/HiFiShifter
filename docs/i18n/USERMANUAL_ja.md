# HiFiShifter ユーザーマニュアル

[简体中文](USERMANUAL.md) | [繁體中文](USERMANUAL_zh-TW.md) | [English](USERMANUAL_en.md) | [日本語](USERMANUAL_ja.md) | [한국어](USERMANUAL_ko.md)

HiFiShifterは、グラフィカルなボーカル編集・合成ツールです。マルチトラックのオーディオクリップ処理をサポートし、トラックグループ単位で複数のボコーダーを使用してボーカルのピッチ補正やパラメータ調整を行い、人力VOCALOID制作における編集と調声を一体化します。

## 一、インストール

お使いのOSとアーキテクチャに対応したHiFiShifterインストーラーをダウンロードしてください。OS別に`Windows`、`macOS`、`Linux`の3種類、アーキテクチャ別に`x86_64`と`arm64`の2種類があります。

- Windows版はNSISインストーラー版（`installer`）とポータブル版（`portable`）の2種類を提供しています。一般ユーザーはインストーラー版を選んでインストールしてください。  
  Windowsユーザーで`x86_64`と`arm64`の違いがわからない場合は`x86_64`版を選んでください。`arm64`をよく理解しており、Windows ARMデバイスをお持ちの場合のみ`arm64`版をダウンロードしてください。

- macOS版は署名されていないdmgインストーラーを提供しています。署名がないため、インストールには少し複雑な手順が必要です。  
  MチップのmacOSユーザーは`arm64`版をインストールしてください。古いIntelユーザーのみ`x86_64`版が必要です。  
  dmgをダブルクリックした後に「ファイルが壊れています」と表示された場合は、以下の手順で操作してください：
    1. ターミナルで `xattr -cr /Applications/HiFiShifter.app` を実行します；
    2. `システム設定` -> `プライバシーとセキュリティ` -> `このまま開く` をクリックして、アプリの実行を許可します。

- Linux版はAppImageパッケージを提供しています。ファイルの`プロパティ -> パーミッション`で`ファイルをプログラムとして実行するを許可`にチェックを入れると直接実行できます。

**GPUアクセラレーションについて**：HiFiShifterは各プラットフォーム向けに複数のGPUアクセラレーションオプションを提供しています：

- **Windows（x86_64 / ARM64）**：DirectML（DirectX 12） — 成熟した安定パス、NVIDIA / AMD / Intel Arc GPUに対応
- **macOS（Apple Silicon）**：CoreML + WebGPU（Dawn/Metal） — CoreMLはApple Neural Engineを活用、WebGPUは補助バックエンドとして利用可能
- **macOS（Intel）**：CPU推論のみ（ort-tract代替バックエンドを使用、GPUアクセラレーションなし）
- **Linux（x86_64）**：WebGPU（Dawn/Vulkan） — DawnがVulkan APIを通じてGPUにアクセス、GPUがない場合はCPUにフォールバック
- **Linux（ARM64）**：CPU推論のみ（このターゲット向けのWebGPU ONNX Runtimeプリビルドバイナリなし）

メニュー `オプション → 推論デバイス` で `Auto`（自動）、`CPU`、`GPU` を選択できます。ベンチマークを実行して各デバイスの推論遅延を比較し、最速のデバイスを選択できます。

**WebViewについて**：HiFiShifterはRust + Tauriフレームワークで構築されており、インターフェースを表示するためにWebViewコンポーネントが必要です。

- **Windows**：Edge WebView2が必要です。Windows 10（バージョン1803以降）およびWindows 11にはプリインストールされているため、追加の操作は不要です。古いバージョンのWindowsを使用している場合や未インストールの場合は、インストーラーが自動的にダウンロードを促します。詳細は[Tauri公式ドキュメント](https://tauri.app/ja/start/prerequisites/#webview2)を参照してください。一般ユーザーはインストーラーを実行するだけで問題ありません。
- **macOS**：システムにWebKitが含まれているため、追加インストールは不要です。
- **Linux**：WebKitGTKが必要です。ほとんどの主要ディストリビューション（Ubuntu、Fedora、Arch Linuxなど）にはデフォルトで含まれています。不足している場合は、パッケージマネージャーで`webkit2gtk`をインストールしてください（例：`sudo apt install webkit2gtk`）。詳細はお使いのディストリビューションのドキュメントを参照してください。

## 二、メニュー

`ファイル`メニューでは、HiFiShifterプロジェクトファイルの開閉・保存、メディアファイル（音声・動画）のインポート、Reaperプロジェクト（`.rpp`）のインポート、VocalShifterプロジェクト（`.vshp`または`.vsp`）のインポート、MIDIファイルのインポート、オーディオのエクスポートなどができます。

HiFiShifterのプロジェクトファイルの拡張子は`.hshp`または`.hsp`です。また、`名前を付けて保存`では、プロジェクトファイルをプレーンテキストの`json`ファイルとして保存したり、現在のプロジェクトと使用しているすべてのメディアファイルをアーカイブzip`.zip`にパッケージ化したりすることもできます。

`ファイル → メディアファイルをインポート` では、一般的なオーディオ形式（`wav`、`mp3`、`flac`、`ogg`、`m4a`、`aac` など）および一般的なビデオコンテナ（`mp4`、`mov`、`mkv`、`webm`、`avi`、`wmv`、`ts`、`mpg` など）をインポートできます。

自動バックアップ機能により、プロジェクトファイルの自動バックアップを設定できます。`保存時バックアップ`と`定期バックアップ`の2つのモードがあります。

- `保存時バックアップ`：プロジェクトファイルを上書き保存するたびに、古いプロジェクトファイルが元のファイル名に `-bak` を付けた名前として自動的にリネームされます。デフォルトで有効です。
- `定期バックアップ`：編集中に指定した間隔とパスに従って自動的にバックアップファイルを作成します。デフォルトでは無効です。

### HiFiShifterプロジェクトのインポート

`ファイル → HiFiShifter プロジェクトをインポート...` を使うと、別の `.hshp` / `.hsp` / `.json` プロジェクトのすべての内容を、現在のプロジェクトを閉じずに現在のプロジェクトへ統合できます。

- `元のタイムライン位置を維持`：インポートしたクリップは元のプロジェクトと同じ時間位置に配置されます。
- `再生ヘッド位置に配置`：インポート内容全体をシフトし、最も早く始まるクリップを現在の再生ヘッドに合わせます。
- `テンポマップをインポート`：現在のプロジェクトにテンポマップがない場合のみ使用できます。インポート後、元プロジェクト初期点の BPM・拍子・スケールが現在のプロジェクトの基準になります。
- すべてのトラック、子トラック、クリップ、パラメータ曲線、グループ関係にはインポート時に新しい ID が割り当てられ、現在のプロジェクトと衝突しません。音声ソースファイルは、まずインポート元プロジェクトファイルのあるフォルダを基準に解決されます。見つからないファイルは、これまでどおり手動で再指定できます。
- インポート元プロジェクトのノートは、現在のプロジェクトのノートを置き換えずに末尾へ追加されます。

### プロセス間のコピー / カット / ペースト

HiFiShifter の構造化コピー＆ペーストはシステムクリップボードに保存されるため、プロセス間でのコピー＆ペーストに対応しています。

- タイムラインでクリップを選択して `Ctrl + C`（または右クリックの `コピー`）を実行し、もう一方のプロセスのプロジェクトで `Ctrl + V`（またはトラック空白部分を右クリックして `ペースト`）を実行すると、クリップとそのパラメータ曲線を貼り付けできます。
- HiFiShifter でクリップをコピーすると、データは Reaper クリップボードにもシリアライズされ、Reaper で `Ctrl + V` を押せばそのまま貼り付けられます。ソースファイルのないクリップはスキップされます。
- `編集 → 新しいトラックとしてペースト`（`Ctrl + Alt + V`）は元の階層どおり新しいルートトラックグループを作成します。

- **Reaperクリップボードデータをペースト**：Reaper でアイテム/トラック/MIDIノートをコピーした後、HiFiShifter で通常の貼り付けを行うと Reaper クリップボードデータを自動的に認識してインポートします。
    - アイテムデータ：HiFiShifterのオーディオクリップとしてインポートされ、Reaperの調声データ（全体調声とピッチエンベロープの両方）も保持されます。
    - トラックデータ：トラックとその中のアイテムをHiFiShifterのトラックとオーディオクリップとしてインポートします。トラックグループも保持されます。
    - MIDIノートデータ：他のDAW（Reaper、FL Studio など）から音符データをシステムクリップボードの MIDI データへ書き出した後、HiFiShifterのパラメータエディターで`選択`ツールを使ってピッチ曲線の区間を選択すれば、クリップボードのMIDIノートデータをその区間にインポートできます。MIDIインポートの詳細は[音高リファレンスクリップ](#6-音高リファレンスクリップ)を参照してください。

- **VocalShifterクリップボードデータをペースト**：VocalShifterまたはVocalShifter LEでパラメータラインのコピー、オーディオクリップのコピー、トラックのコピーを行った後、この機能でVocalShifterクリップボードデータを素早くHiFiShifterにインポートできます。
    - パラメータラインデータ：HiFiShifterのパラメータエディタで`選択`ツールを使ってパラメータラインの区間を選択した後、VocalShifterクリップボードのパラメータラインデータをその区間にインポートできます。
    - オーディオクリップデータ：HiFiShifterのオーディオクリップとしてインポートされ、各種パラメータラインデータも保持されます。
    - トラックデータ：トラックとその中のオーディオクリップをHiFiShifterのトラックとしてインポートします。HiFiShifterは現在、前回コピーした内容がオーディオクリップかトラックかを区別できません。トラックをインポートする場合は、VocalShifterでトラックコピー操作を実行する前に、VocalShifterプロジェクト内でオーディオクリップが選択されていないことを確認してください。そうしないと、選択されたオーディオクリップだけがインポートされます。

`表示`メニューには、インターフェース表示に関するオプションが含まれます：

- `更新`：ランタイム情報を再読み込みします。
- `波形キャッシュをクリア`：キャッシュ済みの波形データをクリアします。次回表示時に再生成されます。
- `クリップボードプレビュー`：パラメータエディターのクリップボードプレビューを切り替えます。
- `パラメータ値ポップアップ`：パラメータ値ポップアップの表示を切り替えます。
- `テンポマップ`：テンポマップ行の表示/非表示を切り替えます（既定でオン。プロジェクトにテンポマップデータが存在しない場合、その行は表示されません）。
- `すべてのテイクを表示（余裕がある場合）`：マルチテイクのクリップの展開表示を切り替えます（詳細は後述の「テイク」を参照）。
- `時間表示`：タイムラインルーラーの主/副時間単位を選択し、`タイムライン表示設定...` を開くことができます。
- `テーマ：ダーク / ライト`：現在のテーマを切り替えます。
- `外観設定...`：外観設定ウィンドウを開きます。

`オプション`メニューでは、HiFiShifterの各種設定を変更できます。

- `プロジェクトストレッチ上書き`：現在のプロジェクトのストレッチアルゴリズムを変更できます。
- `グローバルストレッチ既定`：デフォルトの全体ストレッチアルゴリズムを変更できます。
- `推論デバイス`：レンダリングに使用する推論デバイスを設定できます。現在は`Auto`、`CPU`、`GPU`の3種類があります。このメニューからベンチマークを実行し、各デバイスのパフォーマンスをテストできます（ベンチマークでは GPU (DirectML)、GPU (WebGPU) などの具体的なバックエンドが表示されます）。`GPU`は対応するGPU版のHiFiShifterでのみ有効です。
- `バックグラウンド事前レンダリング`：有効にすると、プロジェクトを開いたりパラメータを編集した後に、編集済みパラメータが自動的にバックグラウンドで事前レンダリングされ、レンダリング中でも既にレンダリングされた部分を再生できます。無効にすると、再生開始時にのみレンダリングが行われ、タイムラインを正常に再生するにはレンダリングの完了を待つ必要があります。デフォルトは有効です。無効にするとレンダリング頻度が下がり、パフォーマンスを節約できます。
- `すべてのテイクに編集を同期`：有効にすると、あるテイクへの編集（ゲイン、トリミング、レート、逆再生、ループなど）がそのクリップの他のすべてのテイクにも同期適用されます（既定でオン）。
- `変更されたメディアファイルを自動で再読み込み`：有効にすると、プロジェクト内のメディアファイルが外部で変更されたときに自動的に再読み込みします（既定でオン）。
- `新しいクリップのループを有効にする`：有効にすると、新しくインポートまたは作成したクリップのループ（Loop ソース）が既定で有効になります（既定でオン）。
- `スナップ/グリッド設定...`：[スナップ / グリッド設定](#スナップ--グリッド設定) ウィンドウを開きます（タイムラインツールバーで `スナップ` ボタンを右クリックして開くこともできます）。
- `キーボードショートカット...`：HiFiShifterのキーバインドを設定できます。複数のプリセットが利用可能です。

## 三、トラックインターフェース

ソフトウェアの操作ロジックやショートカットは、Reaper、VocalShifter、VEGAS ProなどのDAWソフトを参考にしています。`オプション -> キーボードショートカット...`でショートカットをカスタマイズできます。以下はデフォルトのショートカットを前提としています。

トラックインターフェースはHiFiShifterの中核機能の一つで、オーディオクリップのカットや結合などの操作ができます。操作ロジックは基本的にReaperを参考にしています。

インターフェース操作では、マウス中ボタン（ホイールを押し込む）をドラッグすると画面をパンできます。水平/垂直のズームやスクロールは、`Ctrl`、`Alt`、`Shift`などの修飾キーを押しながらマウスホイールを回して調整します。これらの修飾キーはキーボードショートカット設定で変更できます。

よく使うショートカット：

> **macOS ユーザー**：以下の `Ctrl` は `Command (⌘)`、`Alt` は `Option (⌥)` に対応します。

- `スペース`：再生 / 一時停止（再生開始位置に戻らない）
- `Enter`：再生 / 停止（再生開始位置に戻る）
- `S`：分割
- `G`：グループ化
- `U`：グループ解除
- `T`：次のテイクへ切り替え（`Shift + T`：前のテイクへ）
- `Ctrl + C`：コピー（REAPERMedia データも同時に書き込まれ、そのまま REAPER で貼り付けできます）
- `Ctrl + V`：貼り付け
- `Ctrl + Alt + V`：新しいトラックとして貼り付け
- `Ctrl + Z`：元に戻す
- `Ctrl + Y`：やり直す（macOS：`⌘ + ⇧ + Z`）
- `Ctrl + A`：すべて選択

- `Delete`：オーディオクリップを削除
- `-` / `=`：選択したオーディオクリップのパラメータラインを下げる/上げる
- 修飾キー `Alt`：押しながらクリップの先頭/末尾をドラッグするとクリップをストレッチ、クリップの中央をドラッグすると内部オフセット（スリップ編集）
- 修飾キー `Shift`：押しながらスナップを一時的に切り替え
- 修飾キー `Ctrl`：押しながらクリップをドラッグするとコピー

クリップ左上の小さな円は音量調整ノブで、`M`ボタンでそのクリップを個別にミュートでき、`F`ボタンでそのクリップのフォルマント編集メニューを開けます。クリップの左右端でフェードイン/フェードアウトの長さを調整できます。

クリップを右クリックするとコンテキストメニューが開き、`テイク`、`逆再生`、`ループ`、`名前変更`、`コピー` / `切り取り`、`置換`、`クイック書き出し`、`再生ヘッドで分割`、`ノーマライズ`、`音高リファレンスクリップに変換`、`MIDIをエクスポート`、`フェードカーブタイプ`などの機能があります（`クイック書き出し`は選択したクリップを wav ファイルとして個別に書き出します）。同じトラックの複数のクリップを選択すると、コンテキストメニューで`グルー`を選び、単一のオーディオクリップに結合できます。

複数のオーディオクリップを選択し、コンテキストメニューで`グループ化`（または`G`）を選ぶとグループ化できます。ReaperやVEGAS Proと同様に、同じグループのクリップは編集時に連動します。クリップ左上の鎖ボタンをクリックすると、グループの連動編集を一時的に無効/有効にできます。グループ化されたクリップを選択し、`グループ解除`（または`U`）を選ぶとグループから外せます。

### テイク

1 つのクリップには複数のテイク（REAPER のテイクに類似）を含めることができ、同じ位置にある異なる録音・素材を比較・切り替えできます。

- テイクの追加 / 管理：クリップを右クリックして `テイク` サブメニューを開き、`メディアからテイクを追加...`、`現在のテイクを複製`、`テイク名を変更`、`テイクを削除` などの操作ができます。クリップが複数のテイクを含む場合は、サブメニューからクリックしてアクティブテイクを直接切り替えたり、`次のテイクへ切替` / `前のテイクへ切替`（ショートカット `T` / `Shift + T`）で循環切り替えできます。`テイクを個別クリップに展開` は、そのクリップの各テイクをタイムライン上の独立したクリップに分解します。
- トラック横断でテイクに集約：異なるトラック上の複数のクリップを同時に選択すると、右クリックメニューの `クリップをテイクに集約` で、それらを 1 つのクリップ内の複数テイクとしてまとめられます。
- `表示 -> すべてのテイクを表示（余裕がある場合）`：有効にすると、マルチテイクのクリップはトラックの高さに余裕があればすべてのテイクを平置き表示します。オフにすると現在のアクティブテイクのみ表示します。
- `オプション -> すべてのテイクに編集を同期`：有効にすると、任意のテイクへの編集（ゲイン、トリミング、レート、逆再生、ループなど）がそのクリップの他のすべてのテイクにも同期適用されます。

トラックインターフェースの左側はトラックヘッダー領域で、トラックの追加・削除やトラックパラメータの調整などができます。トラックを右クリックすると複製できます。トラックの空白部分を右クリックすると、クリップボード内のクリップをペーストできます。

Reaperと同様に、HiFiShifterのトラックにはトラックグループの概念があります。トラックヘッダー領域で、あるトラックヘッダーを別のトラックヘッダーにドラッグするとトラックグループを作成できます。トラックグループはパラメータパネルを共有します。実際の使用では、「1つのパート＝1つのトラックグループ」として整理することをお勧めします。

トラックインターフェースの機能ボタン：

- `BPM`：プロジェクト全体のテンポBPMを調整します（テンポマップ有効時は再生ヘッド位置の直近の変化点を調整します。後述の「テンポマップ」を参照）。
- `拍子`：プロジェクトの拍子を設定します。
- `グリッド`：プロジェクトのグリッド間隔を設定します。
- `基準音階`：プロジェクト全体の基準音階設定を調整します。カスタム音階も可能です。音階機能は主に後述の`ピッチスナップ`やその他のピッチ調整機能に関連します。
- `停止` ボタンと `再生 / 一時停止` ボタン：再生を制御します。
- `録音`：選択中のトラックで録音できます。右クリックで録音ソースと録音デバイスを設定できるほか、詳細な録音設定を開けます。
- `ファイルブラウザ`：HiFiShifterのファイルブラウザウィンドウを開きます。
- `メモ帳`：HiFiShifterのメモ帳ウィンドウを開き、Markdown形式のテキストを記録・表示します。
- `自動クロスフェード`：Reaper/VEGAS Proの類似機能と同様、有効にすると、クリップを移動したときに重なる部分のクロスフェードを自動調整します。
- `分割トランジション`：Reaper/VEGAS Proの分割フェード機構を参考にした機能で、既定で有効です。分割後に分割位置で前のクリップへのフェードアウトと後のクリップへのフェードインを自動追加するか、クリップを延伸して重ね合わせ、クリップ間の遷移をより滑らかにします。左クリックでオン/オフ、右クリックで詳細設定を開きます。
- `スナップ`：有効にすると、クリップのすべての調整がグリッドや他のオブジェクト、再生ヘッドなどの設定された対象にスナップします。`Shift`を押すと一時的にスナップを切り替えられます。
- `リップル編集`：有効にすると、トラック上のクリップに対する一部の編集操作が自動的に後続へ波及します。
- `再生ヘッドでズーム`：マウスホイールでの水平ズームの中心を設定します。無効時はマウスカーソル位置が中心、有効時は常に再生ヘッド位置が中心になります（Reaper/VEGAS Proのロジックと同様）。
- `自動スクロール`：有効にすると、再生中に再生ヘッドを追跡してインターフェースが水平スクロールします。
- `パラメータエディターで再生ヘッド移動を許可`：無効にすると、パラメータエディターの編集パネルでのクリック操作では再生ヘッドが移動しません。トラックインターフェースやパラメータエディターのタイムコード領域をクリックした場合のみ再生ヘッドが移動します。
- `タイムラインクリックでトラックを切り替える`：既定で有効です。有効時はタイムライン内のクリップや空き領域をクリックすると現在のトラックが切り替わり、パラメータエディターもそのトラックを編集します。無効時は左側のトラックヘッダーをクリックした場合のみ現在のトラックが切り替わります。
- `グループを無視`：有効にすると、グループ化されたオーディオクリップの編集時にグループ連動編集を全体的に無視します。

### スナップ / グリッド設定

タイムラインツールバーの `スナップ` ボタンはスナップのクイックスイッチです。左クリックでスナップのマスタースイッチを切り替え、右クリックで `スナップ / グリッド設定` ウィンドウを直接開きます。同じウィンドウはメニューの `オプション -> スナップ / グリッド設定` からも開けます。すべての設定は自動保存され、次回起動時に復元されます。

設定内容：

- `グリッド`：グリッド線の表示/非表示、グリッド間隔（通常 / 付点 / 三連符、`1/1`〜`1/64`）、最小ピクセル間隔を設定できます。`Swing` を有効にすると、奇数番目のグリッド線がパーセント（0–100%）で示す量だけスウィングし、`スウィング変更時に全クリップを再整列` を有効にすると、既存クリップが新しいスウィンググリッドへ自動的に移動します。
- `スナップマスター`：`スナップを有効化` がマスタースイッチです。`スナップ距離` は対象まで何ピクセル以内でスナップするかを指定し（既定 4px）、`グリッド相対スナップ` は絶対位置ではなく元のグリッドとのオフセットを保ってスナップします。
- `スナップ対象と目標`：`クリップ`、`選択範囲`、`カーソル` について、`選択 / マーカー / カーソルへ` と `グリッドへ` へのスナップを個別に設定できます。例えばクリップはグリッドのみにスナップし、再生カーソルはグリッドとクリップ端の両方にスナップできます。
- `スナップ動作`：`スナップ設定をグリッド表示に追従` はグリッドを非表示にするとグリッドへのスナップを停止します。`任意の距離でグリッドにスナップ` は距離に関係なくグリッドへ強制配置するモードです。`独立したスナップ間隔を使用` を有効にすると、表示グリッドとは別のスナップ間隔と最小ピクセル値を設定できます。
- `クリップと特殊要素の連携`：クリップの先頭/末尾のみをスナップするか `クリップのスナップオフセットにスナップ`（クリップ内容の開始位置）も使うかを選択できます。`他トラックのクリップへスナップ` を有効にすると、何トラック離れたクリップまでスナップ対象にするかを設定できます。`レザー編集をスナップ` は `S` による分割位置にもスナップを適用します。
- `詳細`：`プロジェクトサンプルレートにスナップ` でサンプル精度のスナップ、`クリップ端をソースの先頭/末尾にスナップ` でトリム済みクリップの端を元のソースの先頭/末尾へ戻せます。`選択範囲を倍数に強制` は選択範囲を指定グリッドに丸め、`アレンジとMIDIエディターで同じグリッド分割を使用` はタイムラインとパラメータエディターのグリッド精度を同期します。

### 分割トランジション

`分割トランジション` は分割位置でのクリックノイズを軽減するための機能で、既定で有効です。タイムストレッチアルゴリズムなどの影響で、分割後にクリップ境界でクリックノイズが発生することがあります。この機能は Reaper/VEGAS Pro の仕組みを参考に、分割のたびに境界を自動処理します。

ツールバーの `分割トランジション` ボタンは `自動クロスフェード` の右側にあります。左クリックでオン/オフを切り替え、右クリックで詳細設定を開きます。

- `フェードのみ`：分割後、前のクリップに長さ X のフェードアウト、後のクリップに長さ X のフェードインを自動追加します。2つのクリップは重なりません。
- `拡張して重ねる`（既定）：分割後、前のクリップの末尾を後方へ X だけ、後のクリップの先頭を前方へ X だけ自動延長し、2X 秒の重なりを作ります。延長時はクリップ内の素材のタイムライン上の位置を保ち、再生レートも正しく処理します。延長範囲はクリップの元素材の実際の長さの範囲内に制限されます。`自動クロスフェード` が有効な場合は、この重なりにクロスフェードも自動追加されます。
- `トランジション長 X`：両モードで使用するフェード/オーバーラップ長で、既定は 0.01 秒です。
- `トランジション長の単位`：`秒` または `パーセント` を選択できます。パーセントは既定 1% で、分割で生成された前後2つのクリップの合計の長さを基準に計算されます。たとえば2つのクリップの合計が10秒の場合、1% は0.1秒になります。
- `フェードカーブ`：分割トランジションが境界フェードに書き込むフェードカーブの種類を選択します。既定は `フェードカーブを変更しない` です。
- `オーバーラップのクロスフェード`：`自動クロスフェードに従う` を選ぶと、`自動クロスフェード` が有効なときだけ重なりにクロスフェードを追加します。`常に適用` を選ぶと、重なりには常にクロスフェードが追加されます。

### クリップのフェードとクロスフェード

各クリップは独立したフェードイン / フェードアウト包絡線を持ち、その操作モデルは REAPER とほぼ完全に一致します。編集の対象は「フェード領域全体」ではなく、画面上に実際に表示されている2本の線——フェード包絡線と、フェード領域の端の縦線です。

**フェード長の調整**

- クリップの左 / 右端にあるフェード包絡線またはフェード領域の端の縦線をドラッグすると、フェードイン / フェードアウトの長さを調整できます。クリップの左上 / 右上コーナーから内側へドラッグすると、長さ0からフェードを作成できます。
- フェード用コントロールを（ドラッグせずに）クリックすると、再生カーソルが対応する位置へ移動します：包絡線はフェード領域の内側の端（フェードイン → 領域の右端、フェードアウト → 領域の左端）、交点グリップはクリック位置、クリップ端はその端の正確な位置です。
- 包絡線、端の縦線、交点グリップなどのフェード用コントロールにマウスを重ねると、フェードイン / フェードアウトの種類（カーブアイコン）、長さ（時間表示設定の主 / 副時間単位）、曲率からなるツールチップが表示されます。

**フェード形状と曲率**

HiFiShifter は REAPER と同じ7種類のフェード形状を提供します：`リニア`、`ファストスタート`、`ファストエンド`、`シャープなファストスタート`、`シャープなファストエンド`、`スロースタート／エンド（S カーブ）`、`シャープなスロースタート／エンド`。

- フェード包絡線または端の縦線を右クリックすると、フェード専用のコンテキストメニューが開きます：上部に7つの形状ボタン（現在の形状はハイライト表示）、下部に曲率スライダーとミニカーブプレビューがあります。曲率の範囲は `-1.00 ~ +1.00` で、変更は即時反映されます。スライダーはホイールでのステップ調整に対応し（`パラメータ微調整`修飾キーを押すと細かく調整できます）、ミニカーブは直接ドラッグできます。
- `フェードカーブ`修飾キー（デフォルト `Alt`）を押しながら包絡線をドラッグすると、カーブをポインタ位置へ「引き寄せる」ように曲率を調整できます。
- 包絡線をダブルクリックすると、その側の曲率を現在の形状の既定値にリセットできます。形状を切り替えると、曲率も新しい形状の既定値にリセットされます。
- `フェード形状を切り替え`修飾キー（デフォルト `Ctrl`）を押しながら包絡線をクリックすると、フェード形状を順に切り替えられます。
- クリップのコンテキストメニューにも `フェードイン` / `フェードアウト` の形状選択行があり、フェード形状を直接切り替えられます。

**自動クロスフェード**

ツールバーの `自動クロスフェード` ボタン（既定で有効）は、REAPER / VEGAS Pro の同種機能と同様に、クリップを移動して同一トラック上で重なりが生じると、その重なりの長さに応じて両クリップにクロスフェードを自動設定します。

- 自動クロスフェードの長さは手動フェードの長さとは別に保存されます：重なりが消えると自動フェードは解除され、以前の手動フェードが再び表示されます。逆に、手動でフェード長を変更すると、その側は手動フェードに変換されます。
- 片方のクリップがもう片方を完全に内包している場合、有効なクロスフェード関係とみなされず、自動クロスフェードは発生しません。
- タイムラインとパラメータエディターに表示されるフェード長は常に「実効フェード」です：自動クロスフェードが手動フェードより優先されます。

**オーバーラップ領域の編集**

2つのクリップが重なると、オーバーラップ領域には双方のクリップ用の完全な編集コントロールが表示され、操作方法は通常のクリップと同じです：オーバーラップの左側は後のクリップ（左端のトリム / 延長とフェードイン用コントロール）、右側は前のクリップ（右端のトリム / 延長とフェードアウト用コントロール）に対応します。優先順位はクリップ端が最も高く、次にフェード領域の端の縦線、最後に包絡線です。

2本のフェードカーブの交点にはグリップ（交点ハンドル）があります：

- グリップをそのままドラッグ：交点が前後に移動し、オーバーラップ長は変わりません；
- `クロスフェード反転モード`修飾キー（デフォルト `Ctrl`）を押しながらドラッグ：前後2つのクリップの端が逆方向に移動し、オーバーラップ長が変化するとともにフェード長が比例的に拡縮します；
- `フェードカーブ`修飾キー（デフォルト `Alt`）を押しながらドラッグ：2本のフェードカーブの曲率を同時に調整します；
- グリップを右クリック：前クリップのフェードアウトと後クリップのフェードインの2列からなるフェードメニューを同時に開き、それぞれの形状と曲率を設定できます。ダブルクリックで両側の曲率を同時にリセットできます。

これらの修飾キーは `オプション -> キーボードショートカット...` の `修飾キー · フェードとクロスフェード` グループで変更できます。

### タイムラインの時間表示

タイムライン上部のルーラーは、水平ズームに応じて目盛りを自動的に細分化します。縮小時は小節のみ（`1.1`、`2.1`）、拡大するにつれて2分音符（`1.1`、`1.3`）、4分音符（`1.1`、`1.2`）、8分音符（`1.1`、`1.1.500`）、さらに16分/32分音符へと細分化されます。最も細かい精度は「グリッド」設定によって制限されます。

4種類の時間単位をサポートしています。

- `小節.拍.小単位`（既定の主単位）：`1.2.500` は第1小節の第2拍からさらに0.5拍後（1000小単位 = 1拍）を意味します。
- `小節.分割`：`1.17/32` は、`1/32` グリッドでの第1小節内の17番目の分割を意味します。分割は「グリッド」設定に従います。三連符グリッドでは整数の分割数（例：`1.2/12`）、付点グリッドでは小数になることがあります（例：`1.2/2.6667`）。
- `秒`：絶対秒で、例えば `1234.5678`。
- `時:分:秒.ミリ秒`（既定の副単位）：時が0の場合は時を省略し、ミリ秒は常に3桁です（例：`4:43.750`、`1:4:43.750`）。

ルーラーを右クリックすると、主時間単位と副時間単位をそれぞれ選択できます。副単位は`不使用`も選択できます。`表示 -> 時間表示` メニューや `タイムライン表示設定...` ダイアログからも調整できます。主単位と副単位の両方を表示する場合は上下2行になり、間に淡い横線が入ります。副単位が`不使用`または主単位と同じ場合は、主単位のみを垂直方向の中央に表示します。

トラックビュー左側の「トラック」見出し行の右側には、再生ヘッドの時間が `主単位 / 副単位`（副単位なしの場合は主単位のみ）の形式でリアルタイムに表示され、再生中や時間形式の切り替え時にも自動的に更新されます。再生ヘッドの時間テキストは桁数を固定して整列されます（例：`1.1.000`、`0.000`）。

ルーラー上でマウスを動かすと、ポインター位置の時間が表示されます。右クリックメニューの `再生ヘッド時間をコピー` で、現在の再生ヘッド時間をテキストとしてクリップボードにコピーできます。`タイムライン表示設定...` では、ルーラーのラベル間隔の調整と、トラックヘッダーへの再生ヘッド時間表示のオン/オフも行えます。

### テンポマップ（テンポ / 拍子 / 音階）

HiFiShifter はプロジェクト単位のテンポマップに対応しており、タイムライン上の異なる位置に異なる BPM・拍子・音階を定義できます。空のプロジェクトにはデフォルトでテンポマップデータはありません。プロジェクトにテンポマップデータを追加すると、ルーラーは時間単位の下にテンポマップ行を自動的に追加表示し（時間単位とは淡い横線で区切られます）、各区間のテンポ・拍子・音階は各変化点のラベルに表示されます。ある区間の開始ラベルが画面左にスクロールアウトすると、行の左端にラベルと同じスタイルのフローティングラベルが現れ、その区間のパラメーターを表示します。ラベルは水平スクロールに合わせてスムーズに切り替わり、ラベルと重なることはなく、固定ラベルとまったく同じ操作（ダブルクリックで入力編集、右クリックで編集ウィンドウ）ができます。パラメーターエディターのルーラーにも同じテンポマップ行が表示されます。

- 変化点の追加：時間ルーラーを右クリックし、メニューの `ここにテンポ/拍子/スケール変更を追加…` でクリック位置に変化点を作成して編集ダイアログを開きます。テンポマップ行の空白部分をダブルクリックすると、その位置に変化点が直接作成されます。
- 変化点の編集：テンポマップ行の変化点ラベル（0 位置の初期点を含む）をダブルクリックすると、BPM・拍子・音階を変更できます。ラベルをダブルクリックするとその場でテキスト入力欄になり、`120 4/4 - C / Am` のようなテキストを直接入力できます。ラベルを右クリックすると、`テンポマップ変更点` 編集ウィンドウが直接開きます。
- 前の拍子 / スケールに従う：各変化点の拍子は `前の拍子に従う`、スケールは `前のスケールに従う` を選択できます。
- 初期点はプロジェクト基準：プロジェクト全体の BPM・拍子（分子と分母）・音階は 0 位置の初期点に記録され、テンポマップ行には `120 4/4 - C / Am` のように表示されます。
- グリッドとルーラー：テンポマップが存在する場合、時間ルーラーの目盛り、小節/拍ラベル、背景グリッドは各変化点で再アラインメントされ、各区間のテンポと拍子に従って区間ごとに計算されます。
- 音階の連動：テンポマップの音階変化は、音高スナップ（音階モード）、音階ハイライト、度数移調 / クオンタイズ / 平均クオンタイズなどの「プロジェクト音階」オプション、子トラックの「度数差」レンダリングに反映されます。
- インポート：MIDI を音高リファレンスクリップとしてインポートする際、インポートダイアログで `テンポマップとしてインポート` を有効にし、テンポ・拍子・音階のインポート有無をそれぞれ選択できます。REAPER プロジェクト（.rpp）のインポート時は、プロジェクトレベルのテンポ・拍子の変化が自動的にインポートされます。

## 四、ファイルブラウザ

ファイルブラウザでは、特定のフォルダを開き、その中の音声・動画メディアファイルを条件検索・ソートし、HiFiShifterのトラックインターフェースにドラッグ＆ドロップできます。動画ファイルは紫色、音声ファイルは青色のアイコンで表示されます。検索は正規表現に対応しています。メディアファイルをクリックすると自動的に試聴が再生されます（動画は音声トラックのみ試聴します）。`Ctrl`や`Shift`キーを押しながら複数選択できます。左ドラッグで1つ以上のメディアファイルを時間軸に跨って一括追加できます。右ドラッグで`時間をまたいで追加` / `トラック間に追加`のメニューが表示されます。`トラック間に追加`では、複数のメディア音声クリップを縦方向に複数のトラックに跨って時間軸に追加できます。

トラック領域にフォーカスがある状態で`Ctrl + F`を押すと、クイック検索ウィンドウが開きます。これはファイルブラウザ機能の簡易版で、フォルダ内の音声/動画メディアファイルを条件検索・試聴（動画は音声トラックのみ）し、時間軸に追加できます。

## 五、パラメータエディター

パラメータエディターはHiFiShifterの中核機能の一つで、現在選択中のトラックの各種パラメータを編集できます。

トラックのパラメータ編集を有効にするには、まずそのトラックの合成ボタン`C`を押し、オーディオ分析が完了するのを待つ必要があります。HiFiShifterはオフラインレンダリングを使用しており、パラメータを編集するたびに再レンダリングが完了するのを待ってから試聴できます。

パラメータエディタの見出し左側にある `タイムライン表示に同期` ボタン（リンクアイコン）で、パラメータエディタとトラックビューの水平同期を切り替えられます。有効にすると、両者の水平位置とズームは完全に一致し、双方向に連動します：どちらかのビューでスクロールまたはズームすると、もう一方も同期して追従します。有効にした瞬間はトラックビューを基準にパラメータエディタが揃います。トラックビュー左側にはトラックヘッダー領域があるため、パラメータエディタは左右のオフセットを自動補正し、グリッド線とタイムライン目盛りが両パネルで同じ画面位置に揃います。無効時（既定）は、両者は独立してズーム・スクロールします。

### 1. アルゴリズムとパラメータ

現在のバージョンのHiFiShifterは、以下の3つの音声調整アルゴリズムとパラメータをサポートしています。

- **PC-NSF-HiFiGAN**：OpenVPI のオープンソースの歌声特化型 hifigan ボコーダー。HiFiShifter のデフォルトアルゴリズムです。
    - `ピッチ`：音声のピッチを調整します。
    - `フォルマントシフト`：音声のフォルマントシフトを調整します。
    - `ブレスゲイン`：ブレスを有効にすると、ブレス音量を調整できます（VR-hnsep モデルベース）。
    - `テンション`：音声のテンションを調整します。
    - `ボリューム`：音量を調整します。
    - `パン`：音声のパンを調整します。
- **World**：オープンソースの高品質音声分析・合成アルゴリズム。
    - `ピッチ`：音声のピッチを調整します。
    - `ボリューム`：音量を調整します。
    - `パン`：音声のパンを調整します。
- **VsLib**：VocalShifter 公式の音声解析・合成ライブラリ。VsLib アルゴリズムは Windows x86_64 版のみ利用可能です。
    - `ピッチ`：音声のピッチを調整します。
    - `フォルマントシフト`：音声のフォルマントシフトを調整します。
    - `ブレッシネス`：音声の気声強度を調整します。
    - `ボリューム`：音量を調整します。
    - `パン`：音声のパンを調整します。
    - `合成モード`：音声の合成モードのアルゴリズムを調整します。特定のモードでは一部のパラメータが無効になる場合があります。
        - `モノ`：VocalShifter の M アルゴリズム、単音楽器向け。
        - `モノ（フォルマント）`：VocalShifter の V アルゴリズム、単音ボーカル向け。
        - `コーラス`：VocalShifter の P アルゴリズム、ハーモニー向け。

1つのトラックで使用できるアルゴリズムは1つだけです。複数のアルゴリズムを同時に使用したい場合は、別のトラックに分けてください。

トラックグループはパラメータを共有し、子トラックはルートトラックからパラメータを継承します。特に、トラックグループの子トラックには`セント差`、`度数差`、`フォルマント差`の3つのパラメータが追加されており、現在の子トラックのルートトラックに対するピッチと音色の変化を簡単に調整できます。このうち`度数差`は、プロジェクトの音階設定を基準とします。パラメータエディターのツールバーでは、子トラックの`セント差` / `度数差`は`ピッチ`ボタンのドロップダウンに、`フォルマント差`は`フォルマントシフト`ボタンのドロップダウンにまとめられています。

`選択`ツールで`ピッチ`の区間をコピーした後、`セント差`や`度数差`に貼り付けると、適切なオフセット値が自動計算されて適用されます。

### 2. 選択ツール

選択ツールでは、パラメータラインの区間を選択し、ドラッグ操作や右クリックのコンテキストメニューでパラメータ調整ができます。

よく使うショートカット：

- `Ctrl + C`：コピー
- `Ctrl + V`：貼り付け
- `Ctrl + Z`：元に戻す
- `Ctrl + Y`：やり直す（macOS：`⌘ + ⇧ + Z`）
- `Ctrl + A`：すべて選択

- `BackSpace`：初期化
- `[` / `]`：選択範囲内のパラメータラインを下げる/上げる

選択したパラメータラインを左ドラッグすると、`ドラッグ方向`の設定に応じて垂直、水平、または自由に移動できます。左ドラッグ中に右ボタンを押すと、ドラッグ方向を素早く切り替えられます。

選択したパラメータラインを右ドラッグすると、振幅を調整できます。上にドラッグすると振幅が大きくなり、下にドラッグすると小さくなります。

パラメータエディター内で右クリックするとコンテキストメニューが開き、`初期化`、`セント指定で移調`、`度数指定で移調`、`設定`、`平均化`、`スムージング`、`ビブラートを追加`、`クオンタイズ`、`平均クオンタイズ`などの操作が選択範囲に対して実行できます。

`Alt`を押すと、選択範囲で四点編集モードになります。VocalShifterの同機能と同様に、4つのポイントをドラッグしてカーブを曲げられます。

`Alt`を押しながら選択範囲の端をドラッグすると、選択範囲内のパラメータラインをストレッチできます。

### 3. 描画ツール

描画ツールでは、パラメータラインを描画できます。

左ドラッグで、`ドラッグ方向`の設定に応じて自由または水平にパラメータラインを描画できます。左ドラッグ中に右ボタンを押すと、ドラッグ方向を素早く切り替えられます。

右ドラッグで現在のラインをリセットできます。

### 4. 直線/ビブラートツール

描画ツールボタンを右クリックすると、直線/ビブラートツールに切り替わります。このツールでは直線またはビブラートを描画できます。

左ドラッグで、`ドラッグ方向`の設定に応じて自由または水平に直線を描画できます。左ドラッグ中に右ボタンを押すとドラッグ方向を切り替えられます。

左ドラッグ中にマウスホイールを回すと、直線に水平方向のサイン波が重畳され、ホイールで振幅を調整できます。`Alt`を押しながらホイールを回すと周波数を調整できます。`パラメータ微調整`修飾キー（デフォルトは`Ctrl`）を押しながらホイールを回すと微調整できます。

右ドラッグで現在のラインをリセットできます。

`Tab`キーを押すと、パラメータエディターの編集ツール（選択ツール/描画系ツール）を切り替えられます。

### 5. ピッチスナップ

各種編集ツールでピッチパラメータを編集する際、ピッチスナップを使用すると半音または音階にスナップできます。`Shift`キーを押すと一時的にスナップを切り替えられます。

ピッチスナップボタンを右クリックするとピッチスナップ設定メニューが開き、量子化単位と許容差を調整できます。

- `量子化単位`：`半音`と`音階`の2種類があります。音階を選択した場合、スナップの基準はプロジェクトの音階設定です。
- `許容差`：スナップの許容範囲を設定します。許容範囲内のピッチ編集はスナップされず、範囲外の編集は最も近い許容範囲の端にスナップされます。

例えば、ボーカルハーモニーを作成する場合：

1. プロジェクトの音階を確認・設定します。
2. ピッチスナップを有効にし、量子化単位を`音階`に設定します。
3. 音階ハイライト機能を有効にして移調度数を観察しやすくします。
4. 選択ツールで垂直ドラッグします。

または、子トラックの`セント差`と`度数差`パラメータを使用する方法もあります：

1. プロジェクトの音階を確認・設定します。
2. ハーモニートラックのヘッダーをメインボーカルトラックにドラッグしてトラックグループを作成します（メインボーカル＝ルート、ハーモニー＝子）。
3. パラメータエディターをハーモニートラックの`度数差`パラメータに切り替え、必要な度数線を描画します。`セント差`と`度数差`の編集もピッチスナップに対応しており、それぞれ整数半音および整数度数にスナップできます。

これにより、度数移調によるハーモニー効果を素早く作成できます。同様に、子トラックの`フォルマント差`へ切り替えてフレーム単位のフォルマントシフト曲線を描画すると、`フォルマントシフト`対応アルゴリズム（NSF-HiFiGAN / vslib）で音色差のあるハーモニーを作成できます。

### 6. 音高リファレンスクリップ

トラック上の音高リファレンスクリップは、タイムライン上にピッチ曲線を格納できる特殊なクリップです。

音高リファレンスクリップは以下の方法で作成できます：

- `ファイル`メニューまたはファイルのドラッグで MIDI をインポートします。MIDI インポートダイアログが表示されます。
    - MIDI ファイル：インポートする MIDI ファイルを選択できます。他の DAW がシステムクリップボードに出力した MIDI データの解析にも対応しています。現在、システムクリップボードによる MIDI データ転送が動作確認済みの DAW は Reaper と FL Studio です。
        - Reaper：Reaper の MIDI エディターで音符を選択してコピーすると、選択した音符データがシステムクリップボードに出力され、HiFiShifter で読み取れます。Reaper のクリップボード音符データには BPM 情報が含まれていないため、インポート時は現在のプロジェクト BPM を使用するか、手動で指定してください。
        - FL Studio：FL Studio のピアノロール画面で、左上の小さな三角をクリックしてメニューを展開し、`ファイル` -> `MIDI クリップボードにコピー` を選択すると、現在のチャンネルのすべての音符がシステムクリップボードに出力され、HiFiShifter で読み取れます。
    - トラック選択：インポートする MIDI トラックを選択できます。
    - MIDI BPM をプロジェクト BPM としてインポート：有効にすると、MIDI の初期 BPM がプロジェクト BPM としてインポートされます。HiFiShifter は現在も可変 BPM に対応していません。
    - ノート BPM：インポートする音符の BPM マッピング方法を設定します。
        - MIDI 自身の BPM：BPM マッピングを行わず、MIDI 自身の BPM で直接インポートします。
        - 現在のプロジェクト BPM：音符 BPM を現在のプロジェクト BPM にマッピングしてからインポートします。
        - 指定 BPM：音符 BPM を手動で指定した BPM にマッピングしてからインポートします。
    - マルチトラック結合：有効にすると、選択したすべてのトラックと音符を自動的に結合し、最も高いピッチの音符をピッチ曲線パラメータとして使用し、最終的に 1 つの音高リファレンスクリップのみをインポートします。無効にすると、すべての音符がピッチ曲線パラメータとしてインポートされるようにトラックと音符の分割を試み、最終的に複数の音高リファレンスクリップが縦に並んでインポートされる場合があります。
    - 音符間の隙間を埋める：有効にすると、隣接する音符間の隙間を自動的に埋めます。
- Reaper プロジェクトまたは Reaper クリップボードからトラック上の MIDI アイテムをインポートします。
- VocalShifter プロジェクトまたは VocalShifter クリップボードからトラック上の MIDI クリップをインポートします。
- 通常のクリップを右クリックし、コンテキストメニューから `音高リファレンスクリップに変換` を選択します。これにより、そのクリップの元のピッチ曲線が新しい音高リファレンスクリップのピッチ曲線に変換されます。
- パラメータエディターでピッチパラメータを編集中に、選択ツールで領域を選択して右クリックし、コンテキストメニューから `音高リファレンスクリップとして保存` を選択すると、選択範囲内のピッチ曲線を新しい音高リファレンスクリップとして保存できます。

音高リファレンスクリップには以下のような一般的な用途があります：

- トラック上に配置し、通常のクリップがある他のトラックがピッチを参照するための一般的なクリップとして機能します。他のトラックでは、パラメータエディターの `参照トラックグループ` 機能を使用してこのトラックを表示し、そのピッチ曲線を確認できます。
- 音高リファレンスクリップをトラックグループのルートトラックに配置すると、そのトラックグループのピッチ処理ロジックが変わり、該当区間の元のピッチ曲線が音高リファレンスクリップのピッチ曲線で上書きされます。これは以下のシナリオに影響します：
    - トラックグループ内の編集されたことがないピッチ曲線区間は、そのピッチパラメータが音高リファレンスクリップのピッチ曲線で直接上書きされ、オーディオピッチの再レンダリングがトリガーされます。
    - `初期化` 関連機能を使用する場合--例えば、パラメータエディターで描画ツールを使って右ドラッグ操作を行う場合--初期化後のピッチ曲線は、トラックグループの子トラック内のクリップの元のピッチではなく、音高リファレンスクリップのピッチ曲線データを使用します。
    - 音高リファレンスクリップがミュートされている場合、トラックグループはピッチ処理時にその音高リファレンスクリップを参照しません。

音高リファレンスクリップを選択し、コンテキストメニューの`ピッチを更新`を実行すると、その範囲内の既存のピッチパラメータを音高リファレンスクリップに更新できます。

### 7. その他の機能

パラメータエディターのその他の便利な機能：

- `クリップボードプレビュー`：`表示`メニューにあります。選択ツールでパラメータカーブデータをコピーすると、選択領域内にクリップボードのカーブデータがリアルタイム表示され、貼り付け位置の確認に便利です。
- `パラメータ値ポップアップ`：`表示`メニューにあります。マウスがカーブの近くにあるとき、または描画編集を実行しているときにパラメータ値を表示します。
- `パラメータ線をロック`：トラック上のオーディオクリップをドラッグしたとき、対応するすべてのパラメータラインも一緒に移動するかどうか。HiFiShifterのパラメータ編集機能はすべてトラックベースです。ロックしないと、編集済みのパラメータラインはクリップに追従しません。
- `平滑度`：パラメータ編集時に自動的にスムージングを行うかどうか、およびその強度。
- `参照トラックグループ`：パラメータが `ピッチ` のとき、他のトラックを選んで、他のトラックグループのピッチ曲線を参照としてピッチ編集ウィンドウに表示できます。
- `MIDIをインポート`：MIDIファイルを選択し、その中の単一または複数トラックのノートをピッチラインとしてインポートできます。

## 六、オーディオのエクスポート

すべての編集が終わったら、`ファイル`メニューの`オーディオをエクスポート`機能でHiFiShifterプロジェクトをwavオーディオとして書き出せます。

パラメータ：

- `エクスポート種別`：`プロジェクト` / `分離トラック`。
- `エクスポート範囲`：`全体` / `カスタム`。カスタムでは開始と終了の秒数を設定できます。
- `サンプリングレート`：出力WAVのサンプリングレートを設定します。
- `ビット深度`：出力WAVのビット深度を設定します。
- `出力フォルダ`：出力フォルダを設定します。使用可能なプレースホルダ：
    - `<ProjectFolder>`：現在のプロジェクトが保存されているフォルダ。未保存の場合は`ドキュメント`フォルダを指します。
    - `<ProjectName>`：現在のプロジェクトのファイル名（拡張子なし）。
    - プロジェクト書き出しの場合、出力フォルダのデフォルトは`<ProjectFolder>`です。分離トラック書き出しの場合、デフォルトは`<ProjectFolder>/<ProjectName>`です。
- `出力ファイル名`：出力ファイル名を設定します。使用可能なプレースホルダ：
    - `<ProjectName>`：現在のプロジェクトのファイル名（拡張子なし）。
    - デフォルトは`<ProjectName>.wav`です。
- `分離トラック命名パターン`：分離トラック出力時の命名形式を設定します。使用可能なプレースホルダ：
    - `<ProjectName>`：現在のプロジェクトのファイル名（拡張子なし）。
    - `<ExportIndex>`：エクスポート時のトラックの連番（0から開始）。
    - `<TrackIndex>`：プロジェクト内のトラック番号（0から開始）。
    - `<TrackName>`：プロジェクト内のトラック名。
    - `<TrackType>`：トラック種別（`Root` / `Sub`）。
    - `<TrackId>`：トラックの内部ID（一般ユーザーは使用しないことを推奨）。
    - デフォルトのパターンは`<ExportIndex>_<TrackName>.wav`です。
- `分離トラックの出力対象`パネル：書き出すトラックを選択できます。デフォルトでは、ミュートされていない通常トラックとルートトラックのみが選択されます。
    - 元々ミュートされているトラックにチェックを入れると、ミュート状態に関係なく書き出されます。
    - トラックグループのルートトラックにチェックを入れると、そのグループ全体が単一のオーディオファイルとして書き出され、ミュートされた子トラックのデータは含まれません。
    - 子トラックにチェックを入れると、その子トラックやルートトラックのミュート状態に関係なく書き出されます。

ファイルパスを入力中に、`プレースホルダ`のボタンをクリックすると対応するテキストを素早く入力できます。

上記のファイルパスに関する文字列はすべて、`%Y-%m-%d-%H-%M-%S`のような時刻フォーマット文字列をサポートしています。出力パスにリテラルとして`%`を含めたい場合は、`%%`でエスケープしてください。

## 七、録音

HiFiShifter はタイムライン上で直接録音できます。録音中は再生ヘッドの位置からタイムラインの再生も同時に始まり（伴奏・背景音を聞きながら録音できます）、録音終了後は自動的に再生を停止して、テイクをタイムラインへ取り込みます。

### 録音ボタンとショートカット

- トランスポート領域にある赤い丸ボタンで録音の開始/停止を切り替えます。
- デフォルトのショートカットは `Ctrl + R` で、`オプション -> キーボードショートカット...` から変更できます。
- 録音ボタンを右クリックすると、録音設定をすばやく開けます。

### 録音設定

`ファイル -> 録音...` から設定できます：

- `録音ソース`：録音元を3つのモードから選びます。
- `録音デバイス`：既定は `システムデフォルト` で、この PC の任意の入力デバイス（マイクなど）を列挙して選択できます。
- `ループバックデバイス`：録音ソースが `システムサウンド（ループバック）` の場合、キャプチャする出力デバイスを選択できます。既定は `システムの既定の出力` です。
- `アプリケーション`：録音ソースが `アプリケーション音声` の場合、特定のアプリケーションの音声だけをキャプチャできます。`更新` を押すと、現在音声を出力しているアプリケーションを再列挙します。アプリケーションが再起動して PID が変わった場合も、プロセス名で自動的に再マッチします。Windows 10 21H2（build 20348）以降では OS のプロセスループバック API を使用し、古いビルドでは他のセッションをミュートする互換方式に自動的に切り替わります。Linux では PipeWire（`pw-dump` / `pw-cat`）でキャプチャします。macOS は現在このモードに対応していません。
- `サンプルレート` / `ビット深度` / `チャンネル`：出力 WAV のサンプルレート、ビット深度、チャンネル数。
- `入力ゲイン`：録音前のゲイン補正。
- `カウントダウン`：待機する秒数を数値で入力します。録音クリック後、カウントダウンが終わってから開始します。
- `録音中に入力をモニター`：録音中に入力信号を出力デバイスへ戻します。
- `取り込み後に自動ノーマライズ`：停止・取り込み後、新しくインポートされたクリップのピークを自動的に 0 dB へ正規化します。
- `選択クリップの末尾で自動停止`：再生が選択クリップの末尾に達したら自動停止して取り込みます。
- `出力パステンプレート`：`<ProjectFolder>`、`<ProjectName>`、strftime 書式に対応。既定値は `<ProjectFolder>/HiFiShifter Record/%Y-%m-%d-%H-%M-%S.wav` です。

### 録音の流れと取り込みルール

1. 再生ヘッドを録音開始位置へ移動し、対象トラックを選択します。
2. 録音ボタンを押すと、再生ヘッドから再生が始まり、同時にキャプチャが開始されます。
3. 再度録音ボタンを押すと停止し、タイムライン再生も止まります。
4. 選択トラックの録音範囲内にクリップがない場合は、そのトラックへ直接取り込みます。クリップがある場合は、選択トラックの直下に新しい `録音` トラックを作成して取り込み、新トラックと新クリップを自動選択します。
