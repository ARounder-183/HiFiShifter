# HiFiShifter 用户手册

[简体中文](USERMANUAL.md) | [繁體中文](USERMANUAL_zh-TW.md) | [English](USERMANUAL_en.md) | [日本語](USERMANUAL_ja.md) | [한국어](USERMANUAL_ko.md)

HiFiShifter 是一款图形化人声编辑与合成工具。它支持多轨道音频切片处理，并以轨道组为单位，使用多种声码器完成人声修音、人力调参功能，实现人力VOCALOID制作的拼调一体化。

## 一、安装

下载你的操作系统和架构所对应的 HiFiShifter 安装包。按操作系统分类，分为 `Windows`、`macOS` 和 `Linux` 这三类。按架构分类，分为 `x86_64` 架构和 `arm64` 架构这两类。

- Windows 版本提供的是 NSIS 安装包版（`installer`）和便携版压缩包（`portable`）这两版。对于一般用户，直接选择安装包版并安装即可。  
  如果你是 Windows 用户，且不知道 `x86_64` 与 `arm64` 有什么区别，请选择 `x86_64` 版本。只有你清楚地了解 `arm64` 是什么，并且你确实拥有一台 Windows ARM 设备，则可以下载使用 `arm64` 版。

- macOS 版本提供的是未经过签名的 dmg 安装包。因为暂未签名，安装时需要经过一个比较复杂的步骤来允许安装。  
  M 芯片的 macOS 用户请安装 `arm64` 版本。只有较老的 Intel 用户需要安装 `x86_64` 版本。  
  如果双击 dmg 安装后提示文件已损坏，按以下步骤操作：
    1. 终端输入 `xattr -cr /Applications/HiFiShifter.app`；
    2. 通过系统设置允许运行 `系统设置` -> `隐私与安全性` -> 点击 `仍要打开`。

- Linux 版本提供的是 AppImage 程序包。AppImage 程序包需要在文件的 `属性 -> 权限` 中，勾选 `允许将文件作为程序运行`，之后便可以直接运行。

**关于 GPU 加速**：HiFiShifter 为各平台提供了多种 GPU 加速方案：

- **Windows（x86_64 / ARM64）**：DirectML（DirectX 12），成熟稳定，支持 NVIDIA / AMD / Intel Arc GPU
- **macOS（Apple Silicon）**：CoreML + WebGPU（Dawn/Metal），CoreML 利用 Apple Neural Engine，WebGPU 作为补充后端
- **macOS（Intel）**：仅 CPU 推理（使用 ort-tract 替代后端，无 GPU 加速）
- **Linux（x86_64）**：WebGPU（Dawn/Vulkan），Dawn 通过 Vulkan API 使用 GPU；无 GPU 时自动回退到 CPU
- **Linux（ARM64）**：仅 CPU 推理（暂无预编译的 WebGPU ONNX Runtime 二进制文件）

> **注意**：WSL2 不向 Linux 子环境暴露硬件 Vulkan，WebGPU/Dawn 只能使用 Lavapipe（CPU 软件渲染），性能极差。如需 GPU 加速，请使用 Windows 原生版本（DirectML）。

在菜单 `选项 → 推理设备` 中可选择 `Auto`（自动）、`CPU`、`GPU`。运行基准测试可比较各设备的推理延迟，帮助你选择最快的设备。

**关于 WebView 的说明**：HiFiShifter 基于 Rust + Tauri 框架开发，需要系统提供 WebView 组件来显示界面。

- **Windows**：需要 Edge WebView2。Windows 10（1803 版本及以上）和 Windows 11 已经预装，无需额外操作。如果你使用的是更早的 Windows 版本或者系统未预装，安装程序会自动提示你下载安装。你也可以参考 [Tauri 官方说明](https://tauri.app/zh-cn/start/prerequisites/#webview2) 了解详情。一般用户无需担心，直接运行安装包即可。
- **macOS**：系统自带 WebKit，无需任何额外安装。
- **Linux**：需要 WebKitGTK。大多数主流发行版（如 Ubuntu、Fedora、Arch Linux）默认已包含。如果提示缺少组件，请使用你的包管理器安装 `webkit2gtk`（例如 `sudo apt install webkit2gtk`）。具体可参考你的发行版文档。

## 二、菜单

`文件` 菜单允许你打开和保存 HiFiShifter 工程文件，也允许你进行导入音频文件、导入 Reaper 工程（`.rpp`）、导入 VocalShifter 工程（`.vshp` 或 `.vsp`）、导入 MIDI 文件、导出音频等操作。

HiFiShifter 的工程文件后缀名为 `.hshp` 或 `.hsp`。除此以外，`另存为` 功能还支持将工程文件保存为明文的 `json` 文件，或者将当前工程连同使用到的所有媒体文件，一起打包为归档压缩包 `.zip`。目前，HiFiShifter 只支持导入常规的音频文件，不支持视频文件。

自动备份功能允许你为工程文件设置自动备份，有 `保存时备份` 和 `定时备份` 两种模式。

- `保存时备份`：每次覆盖保存工程文件时，会自动将旧的工程文件重命名为追加了 `-bak` 后缀的备份文件（例如 `.hshp-bak` 或 `.hsp-bak`）。默认启用。
- `定时备份`：按照你设定的时间间隔和路径，在你编辑工程时，自动创建备份的工程文件。默认禁用。

### 导入 HiFiShifter 工程

`文件 → 导入 HiFiShifter 工程...` 允许你把另一个 `.hshp` / `.hsp` / `.json` 工程中的全部内容合并进当前工程，而不必关闭当前工程。

- `保持原时间轴位置`：导入的音频块保留其在来源工程中的时间位置。
- `放置到播放头`：把导入内容整体平移，使其最早开始的音频块对齐到当前播放头。
- `导入速度映射`：仅当当前工程没有速度映射时可用。导入后，来源工程初始点处的 BPM、拍号和音阶会成为当前工程的基准。
- 所有轨道、子轨道、音频块、参数曲线、编组关系都会在导入时自动分配新 ID，避免与当前工程冲突。音频源文件会优先按照来源工程文件所在目录解析；缺失文件仍会提示你手动定位。
- 来源工程的记事本内容会追加到当前工程记事本末尾，不会覆盖已有内容。

### 跨进程复制 / 剪切 / 粘贴

HiFiShifter 的结构化复制粘贴现在由程序后端直接写入系统剪贴板。二进制数据优先存放在平台私有剪贴板格式中；普通文本位置只写入类似 `HiFiShifter: 3 clip(s) copied...` 的简短可读提示，因此把剪贴板粘贴到其他输入框时不会再出现 base64 乱码。读取端仍兼容旧版本写入的文本信封。以下操作可以在两个同时运行的 HiFiShifter 进程之间工作：

- 在时间轴中选择音频块后按 `Ctrl + C`（或右键 `复制`），在另一个进程的工程中按 `Ctrl + V`（或右键轨道空白处 `粘贴`），即可粘贴音频块及其参数曲线。
- 在轨道头上右键选择 `复制轨道` / `剪切轨道`，在另一个进程中按 `Ctrl + V` 或右键轨道空白处粘贴，可以复制完整轨道组（含子轨道、音频块和整条参数曲线）。
- 参数编辑器中的参数曲线复制 / 粘贴同样使用该后端剪贴板，可在两个进程之间传递。
- 在时间轴中选中一个或多个 Clip 后，使用 `编辑 → 将选中 Clip 复制到 REAPER 剪贴板`，可把这些 Clip（含音频源、起止位置、播放速率、倒放、淡入淡出、静音与 MIDI 音符）写为 REAPERMedia 数据；随后在 REAPER 中按 `Ctrl + V` 即可粘贴。没有可用源文件的 Clip 会被跳过。


`编辑` 菜单允许你进行各种编辑操作。除了比较常规的轨道编辑和参数编辑操作以外，还有 `粘贴 Reaper 剪贴板数据` 和 `粘贴 VocalShifter 剪贴板数据` 这两项。

- `粘贴 Reaper 剪贴板数据`：当你在 Reaper 中进行物件（Item）复制、轨道复制、MIDI 音符复制操作后，通过该功能，可以将 Reaper 剪贴板数据快速导入进 HiFiShifter 中。
    - 物件数据：导入为 HiFiShifter 中的音符块，同时允许保留 Reaper 中的调音数据（整体调音和音高包络均可）。
    - 轨道数据：连同轨道中的物件，导入为 HiFiShifter 中的轨道和音频块。可保留轨道组。
    - MIDI 音符数据：从其他 DAW （Reaper、FL Studio 等）将音符数据导出至剪贴板 MIDI 音符数据以后，在 HiFiShifter 中使用参数编辑器的 `选择` 工具选择一段音高线，可将剪贴板 MIDI 音符数据导入至该段音高线数据。导入 MIDI 功能的详细介绍可见 [音高参考块](#音高参考块) 章节。

- `粘贴 VocalShifter 剪贴板数据`：当你在 VocalShifter 或者 VocalShifter LE 中进行参数线复制、音频块复制、轨道复制操作后，通过该功能，可以将 VocalShifter 剪贴板数据快速导入进 HiFiShifter 中。
    - 参数线数据：在 HiFiShifter 中使用参数编辑器的 `选择` 工具选择一段参数线后，可将 VocalShifter 剪贴板参数线数据导入至该段参数线数据。
    - 音频块数据：导入为 HiFiShifter 中的音符块，同时允许保留各种参数线数据。
    - 轨道数据：连同轨道中的音频块，导入为 HiFiShifter 中的轨道。注意，HiFiShifter 目前无法区分你上一次复制的内容是音频块还是轨道。如果你打算导入轨道，在 VocalShifter 执行复制轨道操作前，请先保证 VocalShifter 工程中，没有音频块处于选中状态，这样才能正常导入轨道；否则，只有被选中的音频块会被导入。

`视图` 菜单包含界面显示相关的选项。

- `剪贴板预览`：切换参数编辑器剪贴板预览。
- `弹出展示参数`：切换参数值浮窗显示。
- `时间显示`：允许选择时间轴的主/副时间单位，并打开 `时间轴显示设置...`。
- `主题：深色 / 浅色`：切换当前主题。
- `外观设置`：打开外观设置窗口。

`选项` 菜单允许你修改 HiFiShifter 的各个选项。

- `工程拉伸覆盖`：允许你修改当前工程的拉伸算法。
- `全局拉伸默认`：允许你修改全局默认的拉伸算法。
- `推理设备`：允许你设置渲染所使用的推理设备。目前分为 `Auto`、`CPU`、`GPU` 三种。可以通过该菜单运行基准测试，以检测各推理设备的性能（基准测试中会显示具体后端，如 GPU (DirectML)、GPU (WebGPU) 等）。GPU 选项仅在对应的 GPU 版本 HiFiShifter 中有效。
- `后台预渲染`：当被启用时，每次打开工程或者编辑完参数以后，均会自动在后台对已编辑的参数进行预渲染，且即使仍然在渲染状态中，也可以播放已渲染的部分；否则，只有在进行播放操作时，才会进入渲染流程，且需要等待渲染完毕，才可以正常播放时间轴。默认为启用。禁用后可以降低渲染频率，节省性能。
- `快捷键设置`：允许你设置 HiFiShifter 的快捷键映射。有多种预设可以选择。

## 三、轨道界面

软件的大致操作逻辑和快捷键可以参考 Reaper、VocalShifter、VEGAS Pro 等 DAW 软件。可以通过 `选项 -> 快捷键设置` 来调整自己的快捷键偏好。以下介绍均以默认快捷键为基础。

轨道界面是 HiFiShifter 最核心的功能之一，允许你对音频块进行裁切、拼接等操作。其操作逻辑，基本可以参考 Reaper。

对于界面操作，拖动鼠标中键（即按住鼠标滚轮）可以进行界面的平移拖动。水平/竖直的缩放或滚动，可以按住 `Ctrl`、`Alt`、`Shift` 等修饰键，并滚动鼠标滚轮来调整。这些修饰键均可在快捷键设置中调整。

常用快捷键一览：

- `空格`：播放/暂停（不返回播放起始点）
- `回车`：播放/停止（返回播放起始点）
- `S`：切割
- `G`：编组
- `U`：解组
- `Ctrl + C`：复制
- `Ctrl + V`：粘贴
- `Ctrl + Z`：撤销
- `Ctrl + Y`：重做
- `Ctrl + A`：全选
- `Ctrl + R`：取消选择
- `Delete`：删除音频块
- `-` / `=`：对选中的音频块的参数线进行下移/上移
- 修饰键 `Alt`：按住后，拖动音频块开头/结尾可以拉伸音频块，拖动音频块中间可以调整音频块的内部偏移量
- 修饰键 `Shift`：按住后，可以切换是否吸附到网格
- 修饰键 `Ctrl`：按住后，拖动音频块可以将其复制

音频块左上角的小圆圈是音量调整旋钮，`M` 按钮可以单独静音该音频块，`F` 按钮可以打开该音频块的共振峰编辑菜单。音频块左右端分别能够调整淡入/淡出包络长度。

对着音频块右键可以打开上下文菜单，里边有 `倒放`、`规格化`、`转换为音高参考块`、`导出 MIDI`、`淡入/淡出包络类型` 等功能。如果选择同一轨道的多个音频块，在右键的上下文菜单中，可以对它们进行 `胶合`，合成一个单一的音频块。

选中多个音频块，在右键的上下文菜单中选择 `编组`（或者按下快捷键 `G`），可以将选中的多个音频块进行编组。类似于 Reaper 或者 VEGAS Pro 的同类型功能，所有同组的音频块，在执行一些编辑操作时，会被联动编辑。此时点击音频块左上角的锁链按钮，可以临时禁用或者启用该编组的联动编辑效果。选中已编组的音频块后，在右键的上下文菜单中选择 `解组`（或者按下快捷键 `U`），可以将其从编组中移出。

轨道界面的左侧是轨道头区域，允许你添加或删除轨道、调整轨道参数等。右键轨道可以对轨道进行克隆、复制或剪切；在轨道空白处右键可以粘贴剪贴板中的音频块或完整轨道组。

类似于 Reaper，HiFiShifter 的轨道也是有轨道组的概念的。在轨道头区域中，将一个轨道头拖拽至另一个轨道头，即可创建轨道组。轨道组共享一套参数面板。实际使用中，建议按“一个声部一个轨道组”去整理。

轨道界面的一些功能按钮：

- `BPM`：用于调整工程整体的曲速 BPM（存在速度映射时调整播放头最近变化点的 BPM，见下文“速度映射”）。
- `拍号`：由分子输入框与分母下拉框组成（分母支持鼠标滚轮选择），用于设置工程的拍号（每小节拍数）。
- `网格`：用于设置工程的网格间距。
- `基准音阶`：用于调整工程整体的基准音阶设置。允许自定义音阶。音阶功能主要和后边会介绍到的 `音高吸附` 以及其他音高调整相关功能有关。
- `停止` 按钮和 `播放 / 暂停`按钮：用来控制是否播放。
- `文件浏览器`：用于打开 HiFiShifter 的文件浏览器窗口。
- `记事本`：用于打开 HiFiShifter 的记事本窗口，记录并展示 MarkDown 格式的文本内容。
- `自动交叉淡化`：同 Reaper / VEGAS Pro 的类似功能，启用后，当移动音频块时，如果有音频块重叠，自动调整重叠位置的淡入淡出包络。
- `分割过渡`：参考 Reaper / VEGAS Pro 的分割淡入淡出机制，默认启用。分割后自动在分割处为前一个音频块添加淡出、为后一个音频块添加淡入，或通过延伸重叠减少 click 声。左键单击开关，右键打开详细设置。
- `网格吸附`：启用后，对音频块的所有调整都会尝试吸附在网格位置。按住 `Shift` 可以进行临时的吸附切换。
- `基于播放光标的缩放`：滚动鼠标滚轮可以对界面进行水平缩放。未启用该设置时，缩放中心为当前鼠标光标位置；启用后，水平缩放的逻辑类似于 Reaper / VEGAS Pro 的逻辑，总是基于播放头位置进行缩放。
- `自动滚屏`：启用后，在播放时，自动对界面进行水平滚动操作，以跟随播放头位置。
- `允许参数编辑器调整播放头`：禁用后，参数编辑器的编辑面板的一些点击操作不会进行播放头的调整，只有点击轨道界面，或者点击参数编辑器的时间码区域，才能调整播放头位置。
- `允许时间轴点击切换轨道`：默认启用。启用后，点击时间轴中的音频块或空白区域会自动切换当前轨道，参数编辑器随之编辑对应轨道；禁用后，只有点击左侧轨道头才会切换当前轨道。
- `忽略编组`：启用后，在编辑所有已编组的音频块时，均会全局忽略编组联动编辑。

### 吸附 / 网格设置

时间轴工具栏中的 `网格吸附` 按钮用于快速开关吸附。左键单击按钮可切换吸附总开关；右键单击按钮会直接打开 `吸附 / 网格设置` 窗口。该窗口也可以通过菜单栏 `选项 -> 吸附 / 网格设置` 打开。所有设置都会自动保存，并在下次启动时恢复。

设置内容：

- `网格`：可以开关网格线显示，选择网格间距（普通 / 附点 / 三连音，从 `1/1` 到 `1/64`），并设置网格线的最小像素间距，防止网格过密。开启 `Swing` 后，奇数网格线会按百分比（0–100%）产生摇摆偏移；勾选 `调整 Swing 时自动重新对齐所有项目` 后，改变 Swing 强度时，时间轴上已有的音频块会自动移动到新的 Swing 网格位置。
- `吸附总开关`：`启用吸附` 为总开关；`吸附距离` 指定鼠标距离吸附目标多少像素以内才会触发吸附（默认 4 像素）；`相对网格吸附` 会保留音频块原来相对网格的偏移量，而不是强制吸附到绝对网格位置。
- `吸附对象与目标`：可以分别设置 `媒体项目`（音频块）、`选区`、`光标` 是否吸附到 `选择 / 光标` 或 `网格`。例如可以让音频块只吸附网格，而播放光标同时吸附网格与音频块边缘。
- `网格吸附联动`：`网格吸附跟随网格显示` 会在关闭网格线显示后停止吸附到网格；`任意距离吸附到网格` 是激进模式，拖拽时无论离网格多远都会强制定位到网格；开启 `使用独立网格吸附间距` 后，可以为吸附单独指定不同于显示网格的间距，并设置其最小像素值。
- `项目与特殊交互`：可选择仅让音频块起点参与吸附，或同时吸附 `snap offset`（音频块内容起点）；开启 `允许跨轨道吸附媒体项目` 后，可以设置允许跨多少条轨道寻找吸附目标；`剃刀编辑吸附` 会让 `S` 分割操作的分割位置也参与吸附。
- `高级`：`吸附到工程采样率` 可进行采样级精确吸附；`媒体项目边缘吸附到源素材头尾` 可把被裁剪过的音频块边缘吸回原始素材的起点/终点；`强制选区为网格倍数` 会让框选范围按指定网格取整；`编排视图与 MIDI 编辑器使用相同网格划分` 保证时间轴与参数编辑器使用同一网格精度。

HiFiShifter 当前的数据模型没有 REAPER 的 take markers、固定轨道 Comp 区域和独立自动化项目对象，因此设置窗口中不包含这些概念；其余吸附行为均已按 HiFiShifter 的 Clip 模型实现。

### 分割过渡

`分割过渡` 是专门用于消除分割处 click 声的功能，默认启用。由于拉伸算法等原因，音频块在分割后可能会在分割边界产生 click 声；该功能参考 Reaper / VEGAS Pro 的机制，在每次分割后自动处理边界。

工具栏中的 `分割过渡` 按钮位于 `自动交叉淡化` 的右侧。左键单击可开关该功能；右键单击可打开详细设置。

- `仅淡入淡出`：分割后，自动为前一个音频块添加长度 X 的淡出，为后一个音频块添加长度 X 的淡入，两个音频块之间没有重叠。
- `延伸重叠`（默认）：分割后，自动将前一个音频块的末尾向后延长 X，将后一个音频块的起始位置向前延长 X，形成 2X 秒的重叠区域。延长时会保持音频块内素材在时间轴上的位置不变，并正确处理播放速率；延伸范围会被钳制在 Clip 原素材的实际长度范围内；如果同时开启了 `自动交叉淡化`，还会自动为这段重叠区域创建交叉淡化。
- `过渡长度 X`：以上两种模式使用的淡入淡出/重叠长度，默认为 0.01 秒。
- `过渡长度单位`：可选择 `秒` 或 `百分比`。百分比默认为 1%，按分割后前后两个 Clip 的全长合计折算；例如两个 Clip 全长 10 秒、1% 即为 0.1 秒。
- `淡化曲线`：选择分割过渡使用的淡化曲线。
- `重叠交叉淡化`：选择 `跟随自动交叉淡化` 时，仅在 `自动交叉淡化` 开启时才对延伸重叠区域添加交叉淡化；选择 `始终应用` 时，延伸重叠区域始终会添加交叉淡化。

### 时间轴时间显示

时间轴顶部的标尺会随水平缩放自动细化刻度：缩小时只显示小节（`1.1`、`2.1`），逐渐放大后依次细化到二分音符（`1.1`、`1.3`）、四分音符（`1.1`、`1.2`）、八分音符（`1.1`、`1.1.500`）以及更细的十六分/三十二分音符；最大精度受“网格”设置限制。

支持四种时间单位：

- `小节.节拍.小单位`（默认主单位）：`1.2.500` 表示第 1 小节第 2 拍再往后 0.5 拍（1000 小单位 = 1 拍）。不精确时会追加 `..`（如 `1.1.333..`）。
- `小节.切分`：`1.17/32` 表示第 1 小节内以 `1/32` 网格计的第 17 个切分。切分由“网格”设置决定；三连音网格会得到整数切分数（如 `1.2/12`），附点网格的切分数可能是小数（如 `1.2/2.6667`）。
- `秒`：绝对秒值，例如 `1234.5678`；不精确时追加 `..`。
- `时:分:秒.毫秒`（默认副单位）：小时为 0 时省略小时，毫秒固定 3 位（如 `4:43.750`、`1:4:43.750`）。

在时间轴标尺上右键，可以分别选择主时间单位和副时间单位；副单位也可以选择“不使用”。还可以通过 `视图 -> 时间显示` 菜单或 `时间轴显示设置...` 对话框进行调整。主副单位同时显示时分为上下两行，中间用淡横线分隔；副单位为“不使用”或与主单位相同时，只显示主单位并垂直居中。

轨道视图左侧的“轨道”标题行右侧会实时显示播放光标时间，格式为 `主单位 / 副单位`（副单位未使用时仅显示主单位），并随播放与时间格式切换自动刷新。光标时间文本会按固定位数对齐（如 `1.1.000`、`0.000`），方便阅读。

在标尺上移动鼠标会显示指针位置的时间提示；右键菜单中的 `复制播放光标时间` 可以把当前光标时间以文本形式复制到剪贴板。`时间轴显示设置...` 还允许调整标尺标签间距，以及开关轨道头的播放光标时间显示。

### 速度映射（变速 / 拍号 / 音阶）

HiFiShifter 支持工程内的速度映射，允许在时间轴的不同位置定义不同的 BPM、拍号和音阶。空白工程默认没有速度映射数据；当你向工程中添加速度映射参数后，时间标尺会自动在时间单位下方多显示一行速度映射行（用一条淡横线与时间单位分隔），每段的速度、拍号与音阶以各变化点处的标签展示。当某段的起始标签滚出画面左侧后，行最左侧会出现一个与标签同款的悬浮标签，展示该段的参数；悬浮标签随水平滚动平滑切换，并与标签互不遮挡，且与固定标签提供完全相同的交互（双击进入输入编辑状态、右键弹出编辑窗口）。参数编辑器的标尺同样会显示速度映射行。

- 添加变化点：右键时间标尺，通过菜单中的 `在此添加速度/拍号/音阶变化…` 在点击位置创建变化点并打开编辑对话框（对话框内 BPM、拍号与音阶均支持鼠标滚轮调节；按住「参数微调」修饰键滚动时 BPM 以 0.1 步进）。在速度映射行空白处双击，则会在该位置直接创建变化点——新点继承该位置生效的 BPM，拍号与音阶均“跟随之前的拍号 / 音阶”——并立即进入该标签的输入编辑状态（可直接输入 `120 4/4 - C / Am` 这类文本，`Enter` 确认、`Esc` 取消）。双击新增与随后的内联编辑合并为一次编辑：只需按一次撤销即可完全撤销本次新增；按 `Esc` 取消编辑时会一并放弃本次新增（与编辑对话框的取消语义一致）。
- 编辑变化点：双击速度映射行中的变化点旗帜（包括 0 位置的初始点），可修改 BPM（10-960）、拍号分子（1-32）/分母（1/2/4/8/16/32）和音阶。旗帜双击后原地变为文本输入框，可直接输入 `120 4/4 - C / Am` 这类文本；按 `Enter` 或点击别处确认，`Esc` 取消，输入无法识别时静默放弃。右键标签（含最左侧的悬浮标签）会直接弹出“速度映射变化点”编辑窗口，不再显示时间标尺的右键菜单（右键输入框打开的窗口参数继承自输入框中的内容，确认后按一次撤销即可同时撤销输入编辑与窗口编辑）。输入状态下无需先退出编辑：按住左键把指针拖出输入框边界（含少量容差）会被判定为“确认编辑并拖动标签”——编辑立即确认，标签随指针移动（与普通拖拽一致，指针抬起时一并提交，只产生一个撤销步）；输入框内部的拖动（无论多长）始终保持选中文字的行为。初始点（0 位置）不可拖动。
- 跟随之前的拍号 / 音阶：每个变化点的拍号可以选择 `跟随之前的拍号`（勾选“跟随之前的拍号”复选框），音阶可以选择 `跟随之前的音阶`；两个选项后都会附上实际生效的内容。新添加的变化点默认都处于跟随状态。旗帜文本严格按此显示：拍号与音阶都跟随时只显示 BPM（如 `120`）；仅拍号显式时显示 BPM 与拍号（如 `120 4/4`）；仅音阶显式时显示 BPM 与音阶（如 `120 - C / Am`）；都显式时全部显示（如 `120 4/4 - C / Am`）。输入文本同样按此规则解析。
- 初始点即工程基准：工程的全局 BPM、拍号（分子与分母）与音阶都记录在 0 位置的初始点处，并在速度映射行中显示为类似 `120 4/4 - C / Am` 的文本。修改工程音阶会同步更新初始点的音阶设置；编辑初始点的音阶设置也会同步更新工程音阶。初始点不能“跟随之前的拍号”。
- 移动 / 删除变化点：非首点可通过左右拖拽移动（网格吸附开启时自动吸附）；右键菜单或编辑对话框中的 `删除此变化点` 可删除；`清除速度映射` 会移除全部数据，工程恢复使用全局 BPM / 拍号 / 音阶。
- 旗帜悬浮提示：把鼠标悬停在速度映射行中的旗帜（或视口左侧的悬浮标签）上，会显示项目统一风格的自定义提示，按用户设置的主/副时间单位显示位置，并展示实际的 BPM、拍号与音阶（跟随设置的项显示其实际生效值），例如：

  ```text
  位置：2.1.000 / 0:2.000
  BPM：120
  拍号：4/4
  音阶：C / Am
  ```

- 显示开关与角落按钮：`视图 -> 速度映射` 菜单（默认开启）控制速度映射行是否显示。工程不存在速度映射数据时不显示该行。轨道视图左上角（“轨道”标题区）与参数编辑器左上角的矩形区域右下角各有一个小按钮：无速度映射或速度映射被隐藏时，点击按钮会自动显示速度映射，并在工程没有速度映射时为其创建一个速度映射（只包含 0 位置的初始点，即工程基准记录，不添加其他变化点）；速度映射存在且正在显示时，按钮变为红色提醒，点击后弹出确认对话框，可以选择 `清空`（删除全部速度映射数据）或 `仅隐藏`（效果与 `视图 -> 速度映射` 相同，数据保留）。切换 `视图 -> 速度映射` 会自动更新按钮的图标与模式。
- 网格与标尺：存在速度映射时，时间标尺刻度、小节/节拍标签与背景网格都会在每个变化点处重新对齐、按各段速度与拍号分段计算（不等距网格）；网格吸附同样遵循速度映射。
- 工具栏 BPM / 拍号 / 基准音阶：工具栏左上角的“拍号”由分子输入框与分母下拉框组成（分母支持鼠标滚轮选择）。存在速度映射时，工具栏显示播放头位置的生效值；修改 BPM、拍号分子/分母或基准音阶时，会更新从播放头位置开始、往前寻找的最近一个变化点（不自动新建变化点）。此时基准音阶代表该最近变化点的音阶设置，而不再是工程整体音阶。
- 音阶联动：速度映射中的音阶变化会作用于音高吸附（音阶模式）、音阶高亮、按度数移调 / 量化 / 均值量化等操作的“工程音阶”选项，以及子轨道的“度数差”渲染。当参数编辑器选区范围内存在音阶变化时，“工程音阶”选项文本会提示“选区受速度映射音阶影响”；修改工程音阶或速度映射音阶后会自动失效相关渲染缓存，并在“后台预渲染”开启时自动重新渲染。
- 导入：将 MIDI 导入为音高参考块时，可在导入对话框中启用 `导入为速度映射`，并分别选择是否导入速度（默认开）、拍号（默认开）与音阶（默认关，因为大多数 MIDI 文件只包含默认的 C 大调调号，容易产生误导）；导入 REAPER 工程（.rpp）时会自动导入工程级的速度与拍号变化（REAPER 内部 MIDI item 的变速不参与）。

## 四、文件浏览器

文件浏览器允许你打开特定的文件夹，按条件搜索和排序其中的音频文件，并拖拽导入到 HiFiShifter 的轨道界面。搜索支持正则表达式。当点击音频文件时，会自动播放试听。可以按住 `Ctrl` 和 `Shift` 键进行文件的多选。左键拖拽文件可以将一个或多个音频文件批量地跨时间添加到时间轴中。右键拖拽文件可以弹出 `跨时间添加` / `跨轨道添加` 的选单。`跨轨道添加` 允许你将多个音频块竖直地跨多个轨道添加到时间轴中。

当焦点为轨道区域时，按下快捷键 `Ctrl + F` 可以打开快速搜索窗口。这个是文件浏览器功能的简易版，允许你快速按条件搜索并试听文件夹内的音频文件，最终添加到时间轴上。

## 五、参数编辑器

参数编辑器是 HiFiShifter 最核心的功能之一，允许你编辑当前选中轨道的各种参数。

要启用对轨道的参数编辑功能，必须先按下对应轨道的合成按钮 `C`，并等待音频分析工作完成后，即可开始进行参数编辑。HiFiShifter 采用离线渲染，每次编辑完参数后，需等待参数重新渲染完毕，才能够进行试听。

参数编辑器标题左侧的 `同步时间轴视图` 按钮（链接图标）可以启用或禁用参数编辑器与轨道视图的水平同步。启用后，两者的水平位置与缩放完全一致并双向联动：在任一视图中滚动或缩放，另一个视图都会同步跟随；启用瞬间以轨道视图为基准对齐参数编辑器。由于轨道视图左侧有轨道头区域，参数编辑器会自动补偿左右偏移，使网格线与时间轴刻度在两个面板中按同一屏幕位置对齐。禁用时（默认），两者保持独立缩放与滚动。

### 1. 算法和参数

目前版本的 HiFiShifter，兼容以下 3 种音声修音算法和参数：

- `PC-NSF-HiFiGAN`：OpenVPI 开源的歌声特化的 hifigan 声码器，也是 HiFiShifter 默认的算法。
    - `音高`：允许调整音声的音高。
    - `气声音量`：开启气声后，允许调整音声的气声音量，该参数基于 VR-hnsep 模型。
    - `张力`：允许调整音声的张力。
    - `共振峰偏移`：允许调整音声的共振峰偏移。
    - `音量`：允许调整音声的音量。
- `World`：开源的高质量语音分析与合成算法。
    - `音高`：允许调整音声的音高。
- `VsLib`：VocalShifter 官方发布的音声解析与合成库。VsLib 算法仅在 Windows x86_64 版本中可用。
    - `音高`：允许调整音声的音高。
    - `音量`：允许调整音声的音量。
    - `声像`：允许调整音声的声像。
    - `共振峰偏移`：允许调整音声的共振峰偏移。
    - `气声`：允许调整音声的气声。
    - `合成模式`：允许调整音声的合成模式算法，上述某些参数可能会在特定算法无效。
        - `单音`：VocalShifter 的 M 算法，单音乐器算法。
        - `单音+共振峰补正`：VocalShifter 的 V 算法，单音人声算法。
        - `和音`：VocalShifter 的 P 算法，和声算法。

一条轨道只能使用一种算法，如果想同时使用多种算法，请分轨。

轨道组共用一套参数，子轨道的各种参数继承于根轨道。特别地，对于轨道组中的子轨道来说，额外有 `音分差` 与 `度数差` 这两个参数，可以便捷地调整当前子轨道相对于根轨道的音高变化。其中，`度数差` 参数参考的音阶标准是当前工程的音阶设置。

使用选择工具选择一段 `音高` 参数并复制后，也可以粘贴到 `音分差` 或者 `度数差` 参数，这样会自动计算合适的 `音分差` 或者 `度数差` 参数并应用。

### 2. 选择工具

选择工具允许你选择一段参数线，进行拖拽操作，或者右键打开上下文菜单，以进行参数的调整。

常用快捷键一览：

- `Ctrl + C`：复制
- `Ctrl + V`：粘贴
- `Ctrl + Z`：撤销
- `Ctrl + Y`：重做
- `Ctrl + A`：全选
- `Ctrl + R`：取消选择
- `BackSpace`：初始化
- `[` / `]`：对选中范围内的参数线进行下移/上移

左键拖拽选中的参数线，可以对其进行竖直、水平或自由的拖拽移动操作。拖拽方向取决于当前的 `拖动方向` 设置。左键拖拽时，按下右键，可以快速切换拖拽方向。

右键拖拽选中的参数线，可以对其进行幅度的调整，越向上拖拽，幅度越大；越向下拖拽，幅度越小。

右键参数编辑器界面内，可以打开上下文菜单，允许对选中的参数线执行各种处理操作，包括 `初始化`、`按指定音分移调`、`按指定度数移调`、`设置到`、`平均化`、`平滑化`、`添加颤音`、`量化`、`均值量化` 等。

按住 `Alt`，可以为选定的参数线进入四点编辑模式。类似于 VocalShifter 中的同类型功能，拖拽 4 个点可以对当前参数线进行弯曲。

按住 `Alt`，拖拽选择区域边缘，可以对选择区域内的参数线进行拉伸。

### 3. 绘制工具

绘制工具允许你绘制参数线。

左键拖拽可以进行自由或者水平的参数线绘制操作。拖拽方向取决于当前的 `拖动方向` 设置。左键拖拽时，按下右键，可以快速切换拖拽方向。

右键拖拽可以重置当前参数线。

### 4. 直线/颤音工具

在绘制工具按钮处右键，可以切换至直线/颤音工具。直线/颤音工具允许你绘制直线或者颤音。

左键拖拽可以进行自由或者水平的直线绘制操作。拖拽方向取决于当前的 `拖动方向` 设置。左键拖拽时，按下右键，可以快速切换拖拽方向。

左键拖拽时，滚动鼠标滚轮，相当于为直线叠加了水平的正弦波，滚动鼠标滚轮可以调整正弦波的振幅。按住修饰键 `Alt` 并滚动鼠标滚轮，可以调整正弦波的频率。按住修饰键 `参数微调`（默认为 `Ctrl`）可以允许你在滚动鼠标滚轮时进行微调。

右键拖拽可以重置当前参数线。

按 `Tab` 键，可以切换参数编辑器的编辑工具（选择工具/绘制类型的工具）。

### 5. 音高吸附

当使用各种编辑工具编辑音高参数时，音高吸附允许你将音高编辑吸附至半音或者音阶。按住 `Shift` 键可以临时切换是否吸附。

对音高吸附按钮按下右键可以进入音高吸附设置选单，允许你调整量化单位和容差。

- `量化单位`：分为半音和音阶这两种类型。其中，当量化单位为音阶时，参考的吸附音阶为当前工程的音阶设置。
- `容差`：允许你调整吸附的容差范围，容差范围内的音高编辑，不进行吸附处理；容差范围外的音高编辑，会被吸附到离它最近的容差边缘。

比如，如果你想要制作人声和声效果，你可以按照以下步骤进行操作：

1. 确认并设置好工程音阶；
2. 启用音高吸附，并将量化单位设置成音阶；
3. 启用音阶高亮功能，以便于观察移调度数；
4. 用选择工具进行竖直拖拽。

或者，也可以使用轨道组的子轨道功能的 `音分差` 和 `度数差` 参数，按照以下步骤进行操作：

1. 确认并设置好工程音阶；
2. 将和声轨道的轨道头拖拽到主唱人声轨道上，组成轨道组，主唱人声轨道为根轨道，和声轨道为子轨道；
3. 将参数编辑器切换到和声轨道的 `度数差` 功能，并按需求绘制度数线。`音分差` 与 `度数差` 参数的编辑也支持音高吸附功能，能分别吸附到整数半音以及整数度数，可以加以利用。

即可快速制作出按度数移调的和声效果。

### 6. 音高参考块

轨道上的音高参考块是一种特殊的音频块，可以在时间轴上存储一段音高线。

音高参考块可以通过以下途径创建：

- 通过 `文件` 菜单或者拖拽文件导入 MIDI。这会弹出一个 MIDI 导入弹窗。
    - MIDI 文件：允许你选择导入的 MIDI 文件。也支持解析其他 DAW 输出到系统剪贴板中的 MIDI 数据。目前已经经过测试，能够使用系统剪贴板进行 MIDI 数据传输的 DAW 有 Reaper 和 FL Studio。
        - Reaper：在 Reaper 的 MIDI 编辑器中，选中音符，并复制，即可将选中的音符数据导出至系统剪贴板中，供 HiFiShifter 读取。注意，由于 Reaper 的剪贴板音符数据并不包含 BPM 信息，导入时，可以使用当前工程 BPM，或者自行指定。
        - FL Studio：在 FL Studio 的钢琴窗界面中，点击钢琴窗左上角的小三角展开菜单，选择 `文件` -> `复制到 MIDI 剪贴板`，即可将当前通道的所有音符导出至系统剪贴板中，供 HiFiShifter 读取。
    - 轨道选择区：允许你选择即将导入的 MIDI 轨道。
    - 将 MIDI BPM 导入为工程 BPM：启用后，将 MIDI 的初始 BPM 导入为工程 BPM。HiFiShifter 目前仍然不支持变速 BPM。
    - 音符 BPM：允许设置将要导入的音符的 BPM 映射方式。
        - MIDI 自身 BPM：不进行 BPM 映射，直接以 MIDI 自身 BPM 导入。
        - 当前工程 BPM：将音符 BPM 映射到当前工程 BPM 后再导入。
        - 指定 BPM：将音符 BPM 映射到指定 BPM 后再导入。
    - 多轨合并：若启用，则自动将选择的所有轨道和所有音符进行合并，取音高更高的音符作为音高线参数，最终只导入 1 个音高参考块。若禁用，将尝试拆分各种轨道和音符，确保所有音符都能够导入为音高线参数，最终可能会纵向导入多个音高参考块。
    - 填补音符间的空隙：启用后，自动填补两个相邻音符之间的空隙。
- 通过 Reaper 工程或者 Reaper 剪贴板导入轨道上的 MIDI 物件。
- 通过 VocalShifter 工程或者 VocalShifter 剪贴板导入轨道上的 MIDI 音频块。
- 右键常规的音频块，在弹出的上下文菜单中选择 `转换为音高参考块`。这会将该常规音频块的原始音高线转换为新的音高参考块的音高线。
- 在参数编辑器中，编辑音高参数时，使用选择工具，选择一段区域并右键，在弹出的上下文菜单中选择 `保存为音高参考块`，可以将选择范围内的音高线保存为新的音高参考块。

音高参考块有以下常见的用法：

- 放置在轨道上，作为一般的音频块，供其他有常规音频块的轨道进行音高的参考。在其他轨道上，可以使用参数编辑器的 `参考轨道组` 功能查看这条轨道，以展示其音高线。
- 当音高参考块被放置在轨道组的根轨道时，可以改变当前轨道组的音高处理逻辑，使音高参考块的音高线覆盖掉这一段的原始音高线。这会影响以下几个场景：
    - 若轨道组中有某段音高线未被进行过编辑，则其音高参数会直接被音高参考块的音高线覆盖，并触发音频音高的重新渲染。
    - 当使用 `初始化` 相关功能，比如在参数编辑器中使用绘制工具进行右键拖拽操作时，初始化后的音高线使用的是音高参考块的音高线数据，而非轨道组子轨道内的音频块的原始音高。
    - 如果音高参考块被静音，则轨道组处理音高时，不会参考该音高参考块。

选中音高参考块，在右键的上下文菜单中执行 `更新音高`，可以将音高参考块范围内的现有音高参数，更新到音高参考块中。

### 7. 其他功能

参数编辑器的其他一些便捷功能：

- `剪贴板预览`：使用选择工具复制参数线数据后，可以在选择区域内实时展示剪贴板参数线数据，便于粘贴定位。该选项位于顶部 `视图` 菜单中，不再显示在参数编辑器工具栏。
- `弹出展示参数`：当鼠标靠近参数线，或者正在执行绘制编辑操作时，展示参数值。该选项位于顶部 `视图` 菜单中，不再显示在参数编辑器工具栏。
- `锁定参数线`：在拖动轨道上的音频块时，是否同步挪动其音频块在轨道上对应的所有参数线。HiFiShifter 的所有参数线编辑功能基于轨道的，如果不锁定参数线，则已编辑的参数线不会跟随音频块进行移动。
- `平滑度`：编辑参数时，是否自动进行平滑处理，以及自动平滑处理的强度。
- `参考轨道组`：当参数为 `音高` 时，允许你选择其他轨道，将其他轨道组的音高线，作为参考，展示在音高参数编辑窗口内。
- `导入 MIDI`：允许你选择 MIDI 文件，并将其中单轨或多轨的音符导入为音高线。

## 六、导出音频

做完所有编辑后，通过 `文件` 菜单的 `导出音频` 功能，可以将 HiFiShifter 工程导出为 wav 音频。

有以下参数：

- `导出类型`：`工程` / `分轨`。
- `导出范围`：`全部` / `自定义`。`自定义` 允许你设置导出的起始和结束的秒数。
- `采样率`：允许你设置输出的 WAV 音频的采样率。
- `位深`：允许你设置输出的 WAV 音频的位深度。
- `输出文件夹`：允许你设置文件输出的文件夹。允许使用的占位符如下：
    - `<ProjectFolder>`：表示当前工程所在文件夹。如果当前工程未被保存过，则指向 `我的文档` 文件夹。
    - `<ProjectName>`：表示当前工程的文件名称，不含后缀名。
    - 对于导出工程来说，`输出文件夹` 的默认值为 `<ProjectFolder>`；对于导出分轨来说，`输出文件夹` 的默认值为 `<ProjectFolder>/<ProjectName>`。
- `输出文件名称`：允许你设置文件的输出名称。允许使用的占位符如下：
    - `<ProjectName>`：表示当前工程的文件名称，不含后缀名。
    - `输出文件名称` 的默认值为 `<ProjectName>.wav`。
- `分轨命名格式`：允许你设置分轨输出时的命名格式。允许使用的占位符如下：
    - `<ProjectName>`：表示当前工程的文件名称，不含后缀名。
    - `<ExportIndex>`：表示当前分轨在导出时的顺序编号。编号从 `0` 开始。
    - `<TrackIndex>`：表示当前分轨在工程内的编号。编号从 `0` 开始。
    - `<TrackName>`：表示当前分轨在工程内的轨道名称。
    - `<TrackType>`：表示当前分轨在工程内的轨道类型，根轨道 `Root` / 子轨道 `Sub`。
    - `<TrackId>`：表示当前分轨在工程内的内部 ID。一般用户不建议使用这个。
    - `分轨命名格式` 的默认值为 `<ExportIndex>_<TrackName>.wav`。
- `分轨选择面板`：可以选择你打算导出的分轨。默认情况下，只会选择工程内不静音的普通轨道和根轨道。
    - 如果你勾选了原本处于静音的轨道，则可以正常导出该轨道，而忽略该轨道是否处于静音状态。
    - 如果你勾选了轨道组的根轨道，则表示将该根轨道所包含的轨道组导出为单个音频文件分轨，且导出的根轨道的音频数据中，不包含目前被静音的子轨道的音频数据。
    - 如果你勾选了轨道组的子轨道，则可以正常导出该轨道，而忽略该子轨道或者其根轨道是否处于静音状态。

当你正在输入文件路径时，点击 `占位符` 那一排按钮，可以快速将对应文本填入文本框中。

上述所有和文件路径有关的字符串，均支持时间格式化字符串，比如 `%Y-%m-%d-%H-%M-%S`。如果你打算在输出路径中包含实际的 `%` 字符，请使用 `%%` 进行转义。
