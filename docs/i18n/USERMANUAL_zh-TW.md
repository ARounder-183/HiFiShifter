# HiFiShifter 使用手冊

[简体中文](USERMANUAL.md) | [繁體中文](USERMANUAL_zh-TW.md) | [English](USERMANUAL_en.md) | [日本語](USERMANUAL_ja.md) | [한국어](USERMANUAL_ko.md)

HiFiShifter 是一款圖形化人聲編輯與合成工具。它支援多軌道音訊片段處理，並以軌道組為單位，使用多種聲碼器完成人聲修音、人力調參功能，實現人力 VOCALOID 製作的拼調一體化。

## 一、安裝

下載你的作業系統和架構所對應的 HiFiShifter 安裝包。依作業系統分類，分為 `Windows`、`macOS` 和 `Linux` 這三類。依架構分類，分為 `x86_64` 架構和 `arm64` 架構這兩類。

- Windows 版本提供的是 NSIS 安裝包版（`installer`）和可攜版壓縮包（`portable`）這兩版。對於一般使用者，直接選擇安裝包版並安裝即可。  
  如果你是 Windows 使用者，且不知道 `x86_64` 與 `arm64` 有什麼區別，請選擇 `x86_64` 版本。只有你清楚地了解 `arm64` 是什麼，並且你確實擁有一台 Windows ARM 裝置，則可以下載使用 `arm64` 版。

- macOS 版本提供的是未經過簽名的 dmg 安裝包。因為暫未簽名，安裝時需要經過一個比較複雜的步驟來允許安裝。  
  M 晶片的 macOS 使用者請安裝 `arm64` 版本。只有較老的 Intel 使用者需要安裝 `x86_64` 版本。  
  如果按兩下 dmg 安裝後提示檔案已損毀，按以下步驟操作：
    1. 終端機輸入 `xattr -cr /Applications/HiFiShifter.app`；
    2. 透過系統設定允許執行 `系統設定` -> `隱私權與安全性` -> 點選 `仍要打開`。

- Linux 版本提供的是 AppImage 程式包。AppImage 程式包需要在檔案的 `屬性 -> 權限` 中，勾選 `允許將檔案作為程式執行`，之後便可以直接執行。

**關於 GPU 加速**：HiFiShifter 為各平台提供了多種 GPU 加速方案：

- **Windows（x86_64 / ARM64）**：DirectML（DirectX 12）—— 成熟穩定，支援 NVIDIA / AMD / Intel Arc GPU
- **macOS（Apple Silicon）**：CoreML + WebGPU（Dawn/Metal）—— CoreML 利用 Apple Neural Engine，WebGPU 作為補充後端
- **macOS（Intel）**：僅 CPU 推理（使用 ort-tract 替代後端，無 GPU 加速）
- **Linux（x86_64）**：WebGPU（Dawn/Vulkan）—— Dawn 透過 Vulkan API 使用 GPU，無 GPU 時自動回退至 CPU
- **Linux（ARM64）**：僅 CPU 推理（尚無預編譯的 WebGPU ONNX Runtime 二進位檔案）

> **注意**：WSL2 不向 Linux 子環境暴露硬體 Vulkan，WebGPU/Dawn 只能使用 Lavapipe（CPU 軟體渲染），效能極差。如需 GPU 加速，請使用 Windows 原生版本（DirectML）。

在選單 `選項 → 推理裝置` 中可選擇 `Auto`（自動）、`CPU`、`GPU`。執行基準測試可比較各裝置的推理延遲，幫助你選擇最快的裝置。

**關於 WebView 的說明**：HiFiShifter 基於 Rust + Tauri 框架開發，需要系統提供 WebView 元件來顯示介面。

- **Windows**：需要 Edge WebView2。Windows 10（1803 版本及以上）和 Windows 11 已經預裝，無需額外操作。如果你使用的是更早的 Windows 版本或者系統未預裝，安裝程式會自動提示你下載安裝。你也可以參考 [Tauri 官方說明](https://tauri.app/zh-cn/start/prerequisites/#webview2) 了解詳情。一般使用者無需擔心，直接執行安裝包即可。
- **macOS**：系統自帶 WebKit，無需任何額外安裝。
- **Linux**：需要 WebKitGTK。大多數主流發行版（如 Ubuntu、Fedora、Arch Linux）預設已包含。如果提示缺少元件，請使用你的套件管理器安裝 `webkit2gtk`（例如 `sudo apt install webkit2gtk`）。具體可參考你的發行版文件。

## 二、選單

`檔案` 選單允許你開啟和儲存 HiFiShifter 專案檔，也允許你進行匯入音訊檔案、匯入 Reaper 專案（`.rpp`）、匯入 VocalShifter 專案（`.vshp` 或 `.vsp`）、匯入 MIDI 檔案、匯出音訊等操作。

HiFiShifter 的專案檔副檔名為 `.hshp` 或 `.hsp`。除此以外，`另存新檔` 功能還支援將專案檔儲存為明文的 `json` 檔案，或者將當前專案連同使用到的所有媒體檔案，一起打包為歸檔壓縮包 `.zip`。目前，HiFiShifter 只支援匯入常規的音訊檔案，不支援視訊檔案。

自動備份功能允許你為專案檔設定自動備份，有 `儲存時備份` 和 `定時備份` 兩種模式。

- `儲存時備份`：每次覆蓋儲存專案檔時，會自動將舊的專案檔重新命名為原檔名後附加 `-bak` 的備份檔（例如 `.hshp-bak` 或 `.hsp-bak`）。預設為啟用。
- `定時備份`：在你編輯專案時，依照你設定的時間間隔與路徑，自動建立備份專案檔。預設為停用。

### 匯入 HiFiShifter 專案

`檔案 → 匯入 HiFiShifter 專案...` 可將另一個 `.hshp` / `.hsp` / `.json` 專案的全部內容合併至目前專案，不需先關閉目前專案。

- `保留原始時間軸位置`：匯入的音訊片段維持來源專案中的時間位置。
- `放到播放頭`：將匯入內容整體平移，使最早開始的片段對齊目前播放頭。
- `匯入速度圖`：僅目前專案沒有速度圖時可用。匯入後，來源專案初始點的 BPM、拍號與音階會成為目前專案的基準。
- 所有軌道、子軌道、音訊片段、參數曲線與群組關係都會在匯入時自動分配新 ID，避免與目前專案衝突。音訊來源檔會優先依來源專案所在資料夾解析；遺失檔案仍會提示手動重新定位。
- 來源專案的記事本內容會附加到目前專案記事本結尾，不會覆蓋既有內容。

### 跨處理程序複製 / 剪下 / 貼上

HiFiShifter 的結構化複製貼上現在由程式後端直接寫入系統剪貼簿。二進位資料優先存放在平台私有剪貼簿格式中；一般文字位置只寫入類似 `HiFiShifter: 3 clip(s) copied...` 的簡短可讀提示，因此貼到其他輸入框時不會再出現 base64 亂碼。讀取端仍相容舊版本寫入的文字信封。以下操作可以在兩個同時執行的 HiFiShifter 處理程序之間使用：

- 在時間軸中選取片段後按 `Ctrl + C`（或右鍵 `複製`），在另一個處理程序的專案中按 `Ctrl + V`（或在軌道空白處右鍵 `貼上`），即可貼上片段及其參數曲線。
- 在軌道標題上按右鍵選擇 `複製軌道` / `剪下軌道`，在另一個處理程序中按 `Ctrl + V` 或於軌道空白處右鍵貼上，可複製完整軌道群組（含子軌道、片段與完整參數曲線）。
- 參數編輯器中的參數曲線複製 / 貼上同樣使用此後端剪貼簿，可在兩個處理程序之間傳遞。
- 在時間軸中選取一個或多個片段後，使用 `編輯 → 複製到 Reaper 剪貼簿`（`Ctrl + Shift + C`），可將這些片段（含音訊來源、位置、長度、播放速率、倒放、淡入淡出、靜音與 MIDI 音符）寫為 REAPERMedia 資料；隨後在 REAPER 中按 `Ctrl + V` 即可貼上。沒有可用來源檔的片段會被略過。
- 貼上規則：`Ctrl + V`（或 `編輯 → 貼上`）現在始終等同於「貼到選取軌道」，會將貼上內容壓平到目前選取的軌道，不會根據複製時是否選取了整個軌道群組而自動建立子軌道。
- 貼上帶有音高編輯曲線的片段時，目標根軌道會自動進入合成模式，並立即失效相關渲染快取、排定音高分析與背景渲染；不需要儲存並重新開啟專案。
- `編輯 → 作為新軌道群組貼上`（`Ctrl + Alt + V`）可強制依來源層級建立新根軌道群組。


`編輯` 選單用於常見的軌道 / 時間軸編輯與剪貼簿匯入操作，不再包含參數曲線批次處理項目。`初始化`、`按指定音分移調`、`按指定度數移調`、`設定到`、`平均化`、`平滑化`、`加入顫音`、`量化`、`均值量化` 等參數處理操作僅位於參數編輯器的右鍵選單中。

- **貼上 Reaper 剪貼簿資料**：當你在 Reaper 中進行物件（Item）複製、軌道複製、MIDI 音符複製操作後，透過該功能，可以將 Reaper 剪貼簿資料快速匯入進 HiFiShifter 中。
    - 物件資料：匯入為 HiFiShifter 中的音符塊，同時允許保留 Reaper 中的調音資料（整體調音和音高包絡均可）。
    - 軌道資料：連同軌道中的物件，匯入為 HiFiShifter 中的軌道和音訊塊。可保留軌道組。
    - MIDI 音符資料：從其他 DAW（Reaper、FL Studio 等）將音符資料匯出為剪貼簿 MIDI 音符資料後，在 HiFiShifter 中使用參數編輯器的 `選擇` 工具選擇一段音高線，即可將剪貼簿 MIDI 音符資料匯入至該段音高線資料。匯入 MIDI 的詳細介紹可見 [音高參考塊](#音高參考塊) 章節。

- **貼上 VocalShifter 剪貼簿資料**：當你在 VocalShifter 或者 VocalShifter LE 中進行參數線複製、音訊塊複製、軌道複製操作後，透過該功能，可以將 VocalShifter 剪貼簿資料快速匯入進 HiFiShifter 中。
    - 參數線資料：在 HiFiShifter 中使用參數編輯器的 `選擇` 工具選擇一段參數線後，可將 VocalShifter 剪貼簿參數線資料匯入至該段參數線資料。
    - 音訊塊資料：匯入為 HiFiShifter 中的音符塊，同時允許保留各種參數線資料。
    - 軌道資料：連同軌道中的音訊塊，匯入為 HiFiShifter 中的軌道。注意，HiFiShifter 目前無法區分你上一次複製的內容是音訊塊還是軌道。如果你打算匯入軌道，在 VocalShifter 執行複製軌道操作前，請先保證 VocalShifter 專案中，沒有音訊塊處於選中狀態，這樣才能正常匯入軌道；否則，只有被選中的音訊塊會被匯入。

`檢視` 選單包含與介面顯示相關的選項。

- `剪貼簿預覽`：切換參數編輯器剪貼簿預覽。
- `彈出展示參數`：切換參數值浮窗顯示。
- `時間顯示`：允許選擇時間軸的主/副時間單位，並開啟 `時間軸顯示設定...`。
- `主題：深色 / 淺色`：切換目前主題。
- `外觀設定`：開啟外觀設定視窗。

`選項` 選單允許你修改 HiFiShifter 的各個選項。

- `工程拉伸覆寫`：允許你修改目前專案的拉伸演算法。
- `全域拉伸預設`：允許你修改全域預設的拉伸演算法。
- `推理裝置`：允許你設定渲染所使用的推理裝置。目前分為 `Auto`、`CPU`、`GPU` 三種。可以透過該選單執行基準測試，以檢測各推理裝置的效能（基準測試中會顯示具體後端，如 GPU (DirectML)、GPU (WebGPU) 等）。GPU 選項僅在對應的 GPU 版本 HiFiShifter 中有效。
- `背景預渲染`：當被啟用時，每次開啟專案或者編輯完參數以後，均會自動在背景對已編輯的參數進行預渲染，且即使仍然在渲染狀態中，也可以播放已渲染的部分；否則，只有在進行播放操作時，才會進入渲染流程，且需要等待渲染完畢，才可以正常播放時間軸。預設為啟用。禁用後可以降低渲染頻率，節省效能。
- `快捷鍵設定`：允許你設定 HiFiShifter 的快捷鍵對應。有多種預設可以選擇。

## 三、軌道介面

軟體的大致操作邏輯和快捷鍵可以參考 Reaper、VocalShifter、VEGAS Pro 等 DAW 軟體。可以透過 `選項 -> 快捷鍵設定` 來調整自己的快捷鍵偏好。以下介紹均以預設快捷鍵為基礎。

軌道介面是 HiFiShifter 最核心的功能之一，允許你對音訊塊進行裁切、拼接等操作。其操作邏輯，基本可以參考 Reaper。

對於介面操作，拖動滑鼠中鍵（即按住滑鼠滾輪）可以進行介面的平移拖動。水平/垂直的縮放或捲動，可以按住 `Ctrl`、`Alt`、`Shift` 等修飾鍵，並捲動滑鼠滾輪來調整。這些修飾鍵均可在快捷鍵設定中調整。

常用快捷鍵一覽：
> **macOS 使用者**：下文中的 `Ctrl` 皆對應 `Command (⌘)`，`Alt` 對應 `Option (⌥)`。逐項多選請使用 `⌘ + 點擊`，範圍多選使用 `⇧ + 點擊`；複製拖動預設為 `⌘ + 拖動`，重做預設為 `⌘ + ⇧ + Z`。


- `空格鍵`：播放/暫停（不返回播放起始點）
- `Enter`：播放/停止（返回播放起始點）
- `S`：切割
- `G`：編組
- `U`：解組
- `Ctrl + C`：複製
- `Ctrl + V`：貼上
- `Ctrl + Alt + V`：作為新軌道群組貼上
- `Ctrl + Shift + C`：複製到 Reaper 剪貼簿
- `Ctrl + Z`：復原
- `Ctrl + Y`：重做（macOS：`⌘ + ⇧ + Z`）
- `Ctrl + A`：全選
- `Ctrl + R`：取消選擇
- `Delete`：刪除音訊塊
- `-` / `=`：對選中的音訊塊的參數線進行下移/上移
- 修飾鍵 `Alt`：按住後，拖動音訊塊開頭/結尾可以拉伸音訊塊，拖動音訊塊中間可以調整音訊塊的內部偏移量
- 修飾鍵 `Shift`：按住後，可以切換是否吸附到格線
- 修飾鍵 `Ctrl`（macOS：`⌘`）：按住後，拖動音訊塊可以將其複製

音訊塊左上角的小圓圈是音量調整旋鈕，`M` 按鈕可以單獨靜音該音訊塊，`F` 按鈕可以開啟該音訊塊的共振峰編輯選單。音訊塊左右端分別能夠調整淡入/淡出包絡長度。

對著音訊塊右鍵可以開啟上下文選單，裡邊有 `倒放`、`正規化`、`轉換為音高參考塊`、`匯出 MIDI`、`淡入/淡出包絡類型` 等功能。如果選擇同一軌道的多個音訊塊，在右鍵的上下文選單中，可以對它們進行 `膠合`，合成一個單一的音訊塊。

選中多個音訊塊，在右鍵的上下文選單中選擇 `編組`（或者按下快捷鍵 `G`），可以將選中的多個音訊塊進行編組。類似於 Reaper 或者 VEGAS Pro 的同類型功能，所有同組的音訊塊，在執行一些編輯操作時，會被聯動編輯。此時點擊音訊塊左上角的鎖鏈按鈕，可以臨時停用或者啟用該編組的聯動編輯效果。選中已編組的音訊塊後，在右鍵的上下文選單中選擇 `解組`（或者按下快捷鍵 `U`），可以將其從編組中移出。

軌道介面的左側是軌道頭區域，允許你新增或刪除軌道、調整軌道參數等。右鍵軌道可以複製、複製或剪下軌道；在軌道空白處右鍵可以貼上剪貼簿中的音訊片段或完整軌道群組。

類似於 Reaper，HiFiShifter 的軌道也是有軌道組的概念的。在軌道頭區域中，將一個軌道頭拖曳至另一個軌道頭，即可建立軌道組。軌道組共享一套參數面板。實際使用中，建議按「一個聲部一個軌道組」去整理。

軌道介面的一些功能按鈕：

- `BPM`：用於調整專案整體的曲速 BPM（存在速度映射時調整播放游標最近變化點的 BPM，見下文「速度映射」）。
- `拍號`：由分子輸入框與分母下拉框組成（分母支援滑鼠滾輪選擇），用於設定專案的拍號（每小節拍數）。
- `格線`：用於設定專案的格線間距。
- `基準音階`：用於調整專案整體的基準音階設定。允許自訂音階。音階功能主要和後邊會介紹到的 `音高吸附` 以及其他音高調整相關功能有關。
- `停止` 按鈕和 `播放 / 暫停`按鈕：用來控制是否播放。
- `檔案瀏覽器`：用於開啟 HiFiShifter 的檔案瀏覽器視窗。
- `記事本`：用於開啟 HiFiShifter 的記事本視窗，記錄並展示 MarkDown 格式的文字內容。
- `自動交叉淡化`：同 Reaper / VEGAS Pro 的類似功能，啟用後，當移動音訊塊時，如果有音訊塊重疊，自動調整重疊位置的淡入淡出包絡。
- `分割過渡`：參考 Reaper / VEGAS Pro 的分割淡入淡出機制，預設啟用。分割後自動在分割處為前一個音訊塊加入淡出、為後一個音訊塊加入淡入，或透過延伸重疊減少 click 聲。左鍵按一下開關，右鍵開啟詳細設定。
- `格線吸附`：啟用後，對音訊塊的所有調整都會嘗試吸附在格線位置。按住 `Shift` 可以進行臨時的吸附切換。
- `基於播放游標的縮放`：捲動滑鼠滾輪可以對介面進行水平縮放。未啟用該設定時，縮放中心為當前滑鼠游標位置；啟用後，水平縮放的邏輯類似於 Reaper / VEGAS Pro 的邏輯，總是基於播放頭位置進行縮放。
- `自動捲動`：啟用後，在播放時，自動對介面進行水平捲動操作，以跟隨播放頭位置。
- `允許參數編輯器調整播放頭`：停用後，參數編輯器的編輯面板的一些點擊操作不會進行播放頭的調整，只有點擊軌道介面，或者點擊參數編輯器的時間碼區域，才能調整播放頭位置。
- `允許時間軸點擊切換軌道`：預設啟用。啟用後，點擊時間軸中的音訊塊或空白區域會自動切換目前軌道，參數編輯器隨之編輯對應軌道；停用後，只有點擊左側軌道標題列才會切換目前軌道。
- `忽略編組`：啟用後，在編輯所有已編組的音訊塊時，均會全域忽略編組聯動編輯。

### 吸附 / 網格設定

時間軸工具列中的 `吸附` 按鈕用於快速開關吸附。左鍵按一下按鈕可切換吸附總開關；右鍵按一下按鈕會直接開啟 `吸附 / 網格設定` 視窗。該視窗也可以透過選單列 `選項 -> 吸附 / 網格設定` 開啟。所有設定都會自動儲存，並在下次啟動時還原。

設定內容：

- `網格`：可以開關網格線顯示，選擇網格間距（普通 / 附點 / 三連音，從 `1/1` 到 `1/64`），並設定網格線的最小像素間距，防止網格過密。開啟 `Swing` 後，奇數網格線會按百分比（0–100%）產生搖擺偏移；勾選 `調整 Swing 時自動重新對齊所有項目` 後，改變 Swing 強度時，時間軸上既有的音訊塊會自動移動到新的 Swing 網格位置。
- `吸附總開關`：`啟用吸附` 為總開關；`吸附距離` 指定滑鼠距離吸附目標多少像素以內才會觸發吸附（預設 4 像素）；`相對網格吸附` 會保留音訊塊原來相對網格的偏移量，而不是強制吸附到絕對網格位置。
- `吸附物件與目標`：可以分別設定 `媒體項目`（音訊塊）、`選區`、`游標` 是否吸附到 `選擇 / 游標` 或 `網格`。例如可以讓音訊塊只吸附網格，而播放游標同時吸附網格與音訊塊邊緣。
- `吸附行為`：`吸附跟隨網格顯示` 會在關閉網格線顯示後停止吸附到網格；`任意距離吸附到網格` 是激進模式，拖曳時無論離網格多遠都會強制定位到網格；開啟 `使用獨立吸附間距` 後，可以為吸附單獨指定不同於顯示網格的間距，並設定其最小像素值。
- `項目與特殊互動`：可選擇僅讓音訊塊起點參與吸附，或同時吸附 `snap offset`（音訊塊內容起點）；開啟 `允許跨軌吸附媒體項目` 後，可以設定允許跨多少條軌道尋找吸附目標；`剃刀編輯吸附` 會讓 `S` 分割操作的分割位置也參與吸附。
- `進階`：`吸附到工程取樣率` 可進行取樣級精確吸附；`媒體項目邊緣吸附到來源素材頭尾` 可把被裁剪過的音訊塊邊緣吸回原始素材的起點/終點；`強制選區為網格倍數` 會讓框選範圍按指定網格取整；`編排視圖與 MIDI 編輯器使用相同網格劃分` 保證時間軸與參數編輯器使用同一網格精度。

HiFiShifter 目前的資料模型沒有 REAPER 的 take markers、固定軌道 Comp 區域和獨立自動化項目物件，因此設定視窗中不包含這些概念；其餘吸附行為均已按 HiFiShifter 的 Clip 模型實作。

### 分割過渡

`分割過渡` 是專門用於消除分割處 click 聲的功能，預設啟用。由於拉伸演算法等原因，音訊塊在分割後可能會在分割邊界產生 click 聲；該功能參考 Reaper / VEGAS Pro 的機制，在每次分割後自動處理邊界。

工具列中的 `分割過渡` 按鈕位於 `自動交叉淡化` 的右側。左鍵按一下可開關該功能；右鍵按一下可開啟詳細設定。

- `僅淡入淡出`：分割後，自動為前一個音訊塊加入長度 X 的淡出，為後一個音訊塊加入長度 X 的淡入，兩個音訊塊之間沒有重疊。
- `延伸重疊`（預設）：分割後，自動將前一個音訊塊的結尾向後延長 X，將後一個音訊塊的起始位置向前延長 X，形成 2X 秒的重疊區域。延長時會保持音訊塊內素材在時間軸上的位置不變，並正確處理播放速率；延伸範圍會被鉗制在 Clip 原素材的實際長度範圍內；如果同時開啟了 `自動交叉淡化`，還會自動為這段重疊區域建立交叉淡化。
- `過渡長度 X`：以上兩種模式使用的淡入淡出/重疊長度，預設為 0.01 秒。
- `過渡長度單位`：可選擇 `秒` 或 `百分比`。百分比預設為 1%，按分割後前後兩個 Clip 的全長合計折算；例如兩個 Clip 全長 10 秒、1% 即為 0.1 秒。
- `淡化曲線`：選擇分割過渡使用的淡化曲線。
- `重疊交叉淡化`：選擇 `跟隨自動交叉淡化` 時，僅在 `自動交叉淡化` 開啟時才對延伸重疊區域加入交叉淡化；選擇 `始終套用` 時，延伸重疊區域始終會加入交叉淡化。

### 時間軸時間顯示

時間軸頂部的標尺會隨水平縮放自動細化刻度：縮小時只顯示小節（`1.1`、`2.1`），逐漸放大後依次細化到二分音符（`1.1`、`1.3`）、四分音符（`1.1`、`1.2`）、八分音符（`1.1`、`1.1.500`）以及更細的十六分/三十二分音符；最大精度受「格線」設定限制。

支援四種時間單位：

- `小節.拍.小單位`（預設主單位）：`1.2.500` 表示第 1 小節第 2 拍再往後 0.5 拍（1000 小單位 = 1 拍）。不精確時會追加 `..`（如 `1.1.333..`）。
- `小節.分割`：`1.17/32` 表示第 1 小節內以 `1/32` 格線計的第 17 個分割。分割由「格線」設定決定；三連音格線會得到整數分割數（如 `1.2/12`），附點格線的分割數可能是小數（如 `1.2/2.6667`）。
- `秒`：絕對秒值，例如 `1234.5678`；不精確時追加 `..`。
- `時:分:秒.毫秒`（預設副單位）：小時為 0 時省略小時，毫秒固定 3 位（如 `4:43.750`、`1:4:43.750`）。

在時間軸標尺上按右鍵，可以分別選擇主時間單位和副時間單位；副單位也可以選擇「不使用」。還可以透過 `檢視 -> 時間顯示` 選單或 `時間軸顯示設定...` 對話框進行調整。主副單位同時顯示時分為上下兩行，中間用淡橫線分隔；副單位為「不使用」或與主單位相同時，只顯示主單位並垂直置中。

軌道介面左側的「軌道」標題列右側會即時顯示播放游標時間，格式為 `主單位 / 副單位`（副單位未使用時僅顯示主單位），並隨播放與時間格式切換自動重新整理。游標時間文字會按固定位數對齊（如 `1.1.000`、`0.000`），方便閱讀。

在標尺上移動滑鼠會顯示指標位置的時間提示；右鍵選單中的 `複製播放游標時間` 可以把目前游標時間以文字形式複製到剪貼簿。`時間軸顯示設定...` 還允許調整標尺標籤間距，以及開關軌道頭的播放游標時間顯示。

### 速度映射（變速 / 拍號 / 音階）

HiFiShifter 支援專案內的速度映射，允許在時間軸的不同位置定義不同的 BPM、拍號和音階。空白專案預設沒有速度映射資料；當你向專案中加入速度映射參數後，時間標尺會自動在時間單位下方多顯示一行速度映射行（用一條淡橫線與時間單位分隔），每段的速度、拍號與音階以各變化點處的標籤展示。當某段的起始標籤滾出畫面左側後，行最左側會出現一個與標籤同款的懸浮標籤，展示該段的參數；懸浮標籤隨水平捲動平滑切換，並與標籤互不遮擋，且與固定標籤提供完全相同的互動（雙擊進入輸入編輯狀態、右鍵彈出編輯視窗）。參數編輯器的標尺同樣會顯示速度映射行。

- 新增變化點：在時間標尺上按右鍵，透過選單中的 `在此新增速度/拍號/音階變化…` 在點擊位置建立變化點並開啟編輯對話框（對話框內 BPM、拍號與音階均支援滑鼠滾輪調節；按住「參數微調」修飾鍵滾動時 BPM 以 0.1 步進）。在速度映射行空白處雙擊，則會在該位置直接建立變化點——新點繼承該位置生效的 BPM，拍號與音階均「跟隨之前的拍號 / 音階」——並立即進入該標籤的輸入編輯狀態（可直接輸入 `120 4/4 - C / Am` 這類文字，`Enter` 確認、`Esc` 取消）。雙擊新增與隨後的內聯編輯合併為一次編輯：只需按一次復原即可完全復原本次新增；按 `Esc` 取消編輯時會一併放棄本次新增（與編輯對話框的取消語義一致）。
- 編輯變化點：雙擊速度映射行中的變化點標籤（包括 0 位置的初始點），可修改 BPM（10-960）、拍號分子（1-32）/分母（1/2/4/8/16/32）和音階。標籤雙擊後原地變為文字輸入框，可直接輸入 `120 4/4 - C / Am` 這類文字；按 `Enter` 或點擊別處確認，`Esc` 取消，輸入無法識別時靜默放棄。右鍵標籤（含最左側的懸浮標籤）會直接彈出「速度映射變化點」編輯視窗，不再顯示時間標尺的右鍵選單（右鍵輸入框開啟的視窗參數繼承自輸入框中的內容，確認後按一次復原即可同時復原輸入編輯與視窗編輯）。輸入狀態下無需先退出編輯：按住左鍵把指標拖出輸入框邊界（含少量容差）會被判定為「確認編輯並拖動標籤」——編輯立即確認，標籤隨指標移動（與普通拖曳一致，指標放開時一併提交，只產生一個復原步）；輸入框內部的拖動（無論多長）始終保持選取文字的行為。初始點（0 位置）不可拖動。
- 跟隨之前的拍號 / 音階：每個變化點的拍號可以選擇 `跟隨之前的拍號`（勾選「跟隨之前的拍號」核取方塊），音階可以選擇 `跟隨之前的音階`；兩個選項後都會附上實際生效的內容。新加入的變化點預設都處於跟隨狀態。旗幟文字嚴格按此顯示：拍號與音階都跟隨時只顯示 BPM（如 `120`）；僅拍號顯式時顯示 BPM 與拍號（如 `120 4/4`）；僅音階顯式時顯示 BPM 與音階（如 `120 - C / Am`）；都顯式時全部顯示（如 `120 4/4 - C / Am`）。輸入文字同樣按此規則解析。
- 初始點即專案基準：專案的全域 BPM、拍號（分子與分母）與音階都記錄在 0 位置的初始點處，並在速度映射行中顯示為類似 `120 4/4 - C / Am` 的文字。修改專案音階會同步更新初始點的音階設定；編輯初始點的音階設定也會同步更新專案音階。初始點不能「跟隨之前的拍號」。
- 移動 / 刪除變化點：非首點可透過左右拖曳移動（格線吸附開啟時自動吸附）；右鍵選單或編輯對話框中的 `刪除此變化點` 可刪除；`清除速度映射` 會移除全部資料，專案恢復使用全域 BPM / 拍號 / 音階。
- 旗幟懸浮提示：把滑鼠懸停在速度映射行中的旗幟（或視口左側的懸浮標籤）上，會顯示專案統一風格的自訂提示，按使用者設定的主/副時間單位顯示位置，並展示實際的 BPM、拍號與音階（跟隨設定的項顯示其實際生效值），例如：

  ```text
  位置：2.1.000 / 0:2.000
  BPM：120
  拍號：4/4
  音階：C / Am
  ```

- 顯示開關與角落按鈕：`檢視 -> 速度映射` 選單（預設開啟）控制速度映射行是否顯示。專案不存在速度映射資料時不顯示該行。軌道檢視左上角（「軌道」標題區）與參數編輯器左上角的矩形區域右下角各有一個小按鈕：無速度映射或速度映射被隱藏時，點擊按鈕會自動顯示速度映射，並在專案沒有速度映射時為其建立一個速度映射（只包含 0 位置的初始點，即專案基準記錄，不新增其他變化點）；速度映射存在且正在顯示時，按鈕變為紅色提醒，點擊後彈出確認對話框，可以選擇 `清空`（刪除全部速度映射資料）或 `僅隱藏`（效果與 `檢視 -> 速度映射` 相同，資料保留）。切換 `檢視 -> 速度映射` 會自動更新按鈕的圖示與模式。
- 格線與標尺：存在速度映射時，時間標尺刻度、小節/節拍標籤與背景格線都會在每個變化點處重新對齊、按各段速度與拍號分段計算（不等距格線）；格線吸附同樣遵循速度映射。
- 工具列 BPM / 拍號 / 基準音階：工具列左上角的「拍號」由分子輸入框與分母下拉框組成（分母支援滑鼠滾輪選擇）。存在速度映射時，工具列顯示播放游標位置的生效值；修改 BPM、拍號分子/分母或基準音階時，會更新從播放游標位置開始、往前尋找的最近一個變化點（不自動新增變化點）。此時基準音階代表該最近變化點的音階設定，而不再是專案整體音階。
- 音階聯動：速度映射中的音階變化會作用於音高吸附（音階模式）、音階醒目提示、按度數移調 / 量化 / 均值量化等操作的「專案音階」選項，以及子軌道的「度數差」渲染。當參數編輯器選區範圍內存在音階變化時，「專案音階」選項文字會提示「選區受速度映射音階影響」；修改專案音階或速度映射音階後會自動失效相關渲染快取，並在「背景預先渲染」開啟時自動重新渲染。
- 匯入：將 MIDI 匯入為音高參考塊時，可在匯入對話框中啟用 `匯入為速度映射`，並分別選擇是否匯入速度（預設開）、拍號（預設開）與音階（預設關，因為大多數 MIDI 檔案只包含預設的 C 大調調號，容易產生誤導）；匯入 REAPER 專案（.rpp）時會自動匯入專案級的速度與拍號變化（REAPER 內部 MIDI item 的變速不參與）。

## 四、檔案瀏覽器

檔案瀏覽器允許你開啟特定的資料夾，按條件搜尋和排序其中的音訊檔案，並拖曳匯入到 HiFiShifter 的軌道介面。搜尋支援正規表示式。當點擊音訊檔案時，會自動播放試聽。可以按住 `Ctrl` 和 `Shift` 鍵進行檔案的多選。左鍵拖曳檔案可以將一個或多個音訊檔案批次地跨時間加入到時間軸中。右鍵拖曳檔案可以彈出 `跨時間加入` / `跨軌道加入` 的選單。`跨軌道加入` 允許你將多個音訊塊垂直地跨多個軌道加入到時間軸中。

當焦點為軌道區域時，按下快捷鍵 `Ctrl + F` 可以開啟快速搜尋視窗。這個是檔案瀏覽器功能的簡易版，允許你快速按條件搜尋並試聽資料夾內的音訊檔案，最終加入到時間軸上。

## 五、參數編輯器

參數編輯器是 HiFiShifter 最核心的功能之一，允許你編輯當前選中軌道的各種參數。

要啟用對軌道的參數編輯功能，必須先按下對應軌道的合成按鈕 `C`，並等待音訊分析工作完成後，即可開始進行參數編輯。HiFiShifter 採用離線渲染，每次編輯完參數後，需等待參數重新渲染完畢，才能夠進行試聽。

參數編輯器標題左側的 `同步時間軸檢視` 按鈕（連結圖示）可以啟用或停用參數編輯器與軌道檢視的水平同步。啟用後，兩者的水平位置與縮放完全一致並雙向連動：在任一檢視中捲動或縮放，另一個檢視都會同步跟隨；啟用瞬間以軌道檢視為基準對齊參數編輯器。由於軌道檢視左側有軌道頭區域，參數編輯器會自動補償左右偏移，使格線與時間軸刻度在兩個面板中按同一螢幕位置對齊。停用時（預設），兩者保持獨立縮放與捲動。

### 1. 演算法和參數

目前版本的 HiFiShifter，相容以下 3 種音聲修音演算法和參數：

- **PC-NSF-HiFiGAN**：OpenVPI 開源的歌聲特化的 hifigan 聲碼器，也是 HiFiShifter 預設的演算法。
    - `音高`：允許調整音聲的音高。
    - `氣聲音量`：開啟氣聲後，允許調整音聲的氣聲音量，該參數基於 VR-hnsep 模型。
    - `張力`：允許調整音聲的張力。
    - `共振峰偏移`：允許調整音聲的共振峰偏移。
    - `音量`：允許調整音聲的音量。
- **World**：開放原始碼的高品質語音分析與合成演算法。
    - `音高`：允許調整音聲的音高。
- **VsLib**：VocalShifter 官方發佈的音聲解析與合成庫。VsLib 演算法僅在 Windows x86_64 版本中可用。
    - `音高`：允許調整音聲的音高。
    - `音量`：允許調整音聲的音量。
    - `聲像`：允許調整音聲的聲像。
    - `共振峰偏移`：允許調整音聲的共振峰偏移。
    - `氣聲`：允許調整音聲的氣聲。
    - `合成模式`：允許調整音聲的合成模式演算法，上述某些參數可能會在特定演算法無效。
        - `單音`：VocalShifter 的 M 演算法，單音樂器演算法。
        - `單音+共振峰補正`：VocalShifter 的 V 演算法，單音人聲演算法。
        - `和音`：VocalShifter 的 P 演算法，和聲演算法。

一條軌道只能使用一種演算法，如果想同時使用多種演算法，請分軌。

軌道組共用一套參數，子軌道的各種參數繼承於根軌道。特別地，對於軌道組中的子軌道來說，額外有 `音分差`、`度數差` 與 `共振峰差` 三個參數，可以便捷地調整當前子軌道相對於根軌道的音高與音色變化。其中，`度數差` 參數參考的音階標準是當前專案的音階設定。`共振峰差` 以音分為單位逐幀繪製，並沿「根軌道 → 父軌道 → 目前子軌道」的層級累加；該參數僅在目前軌道組演算法支援 `共振峰偏移` 時顯示（NSF-HiFiGAN 與 VocalShifter / vslib），編輯時按 50 音分吸附。在參數編輯器工具列中，子軌道的 `音分差` / `度數差` 收納在 `音高` 按鈕的下拉選單中，`共振峰差` 收納在 `共振峰偏移` 按鈕的下拉選單中。

使用選擇工具選擇一段 `音高` 參數並複製後，也可以貼到 `音分差` 或者 `度數差` 參數，這樣會自動計算合適的 `音分差` 或者 `度數差` 參數並應用。

### 2. 選擇工具

選擇工具允許你選擇一段參數線，進行拖曳操作，或者右鍵開啟上下文選單，以進行參數的調整。

常用快捷鍵一覽：

- `Ctrl + C`：複製
- `Ctrl + V`：貼上
- `Ctrl + Z`：復原
- `Ctrl + Y`：重做（macOS：`⌘ + ⇧ + Z`）
- `Ctrl + A`：全選
- `Ctrl + R`：取消選擇
- `BackSpace`：初始化
- `[` / `]`：對選中範圍內的參數線進行下移/上移

左鍵拖曳選中的參數線，可以對其進行垂直、水平或自由的拖曳移動操作。拖曳方向取決於當前的 `拖曳方向` 設定。左鍵拖曳時，按下右鍵，可以快速切換拖曳方向。

右鍵拖曳選中的參數線，可以對其進行幅度的調整，越向上拖曳，幅度越大；越向下拖曳，幅度越小。

右鍵參數編輯器介面內，可以開啟上下文選單，允許對選中的參數線執行各種處理操作，包括 `初始化`、`按指定音分移調`、`按指定度數移調`、`設定到`、`平均化`、`平滑化`、`加入顫音`、`量化`、`均值量化` 等。

按住 `Alt`，可以為選定的參數線進入四點編輯模式。類似於 VocalShifter 中的同類型功能，拖曳 4 個點可以對當前參數線進行彎曲。

按住 `Alt`，拖曳選擇區域邊緣，可以對選擇區域內的參數線進行拉伸。

### 3. 繪製工具

繪製工具允許你繪製參數線。

左鍵拖曳可以進行自由或者水平的參數線繪製操作。拖曳方向取決於當前的 `拖曳方向` 設定。左鍵拖曳時，按下右鍵，可以快速切換拖曳方向。

右鍵拖曳可以重置當前參數線。

### 4. 直線/顫音工具

在繪製工具按鈕處右鍵，可以切換至直線/顫音工具。直線/顫音工具允許你繪製直線或者顫音。

左鍵拖曳可以進行自由或者水平的直線繪製操作。拖曳方向取決於當前的 `拖曳方向` 設定。左鍵拖曳時，按下右鍵，可以快速切換拖曳方向。

左鍵拖曳時，捲動滑鼠滾輪，相當於為直線疊加了水平的正弦波，捲動滑鼠滾輪可以調整正弦波的振幅。按住修飾鍵 `Alt` 並捲動滑鼠滾輪，可以調整正弦波的頻率。按住修飾鍵 `參數微調`（預設為`Ctrl`）可以允許你在捲動滑鼠滾輪時進行微調。

右鍵拖曳可以重置當前參數線。

按 `Tab` 鍵，可以切換參數編輯器的編輯工具（選擇工具/繪製類型的工具）。

### 5. 音高吸附

當使用各種編輯工具編輯音高參數時，音高吸附允許你將音高編輯吸附至半音或者音階。按住 `Shift` 鍵可以臨時切換是否吸附。

對音高吸附按鈕按下右鍵可以進入音高吸附設定選單，允許你調整量化單位和容差。

- `量化單位`：分為半音和音階這兩種類型。其中，當量化單位為音階時，參考的吸附音階為當前專案的音階設定。
- `容差`：允許你調整吸附的容差範圍，容差範圍內的音高編輯，不進行吸附處理；容差範圍外的音高編輯，會被吸附到離它最近的容差邊緣。

比如，如果你想要製作人聲和聲效果，你可以按照以下步驟進行操作：

1. 確認並設定好專案音階；
2. 啟用音高吸附，並將量化單位設定成音階；
3. 啟用音階高亮功能，以便於觀察移調度數；
4. 用選擇工具進行垂直拖曳。

或者，也可以使用軌道組的子軌道功能的 `音分差` 和 `度數差` 參數，按照以下步驟進行操作：

1. 確認並設定好專案音階；
2. 將和聲軌道的軌道頭拖曳到主唱人聲軌道上，組成軌道組，主唱人聲軌道為根軌道，和聲軌道為子軌道；
3. 將參數編輯器切換到和聲軌道的 `度數差` 功能，並按需求繪制度數線。`音分差` 與 `度數差` 參數的編輯也支援音高吸附功能，能分別吸附到整數半音以及整數度數，可以加以利用。

即可快速製作出按度數移調的和聲效果。類似地，將參數編輯器切換到子軌道的 `共振峰差`，即可繪製逐幀共振峰偏移曲線，在支援 `共振峰偏移` 的演算法（NSF-HiFiGAN / vslib）下製作出帶音色差異的和聲。

### 6. 音高參考塊

軌道上的音高參考塊是一種特殊的音訊片段，可以在時間軸上儲存一段音高線。

音高參考塊可以透過以下途徑創建：

- 透過 `檔案` 選單或者拖曳檔案匯入 MIDI。這會彈出一個 MIDI 匯入彈窗。
    - MIDI 檔案：允許你選擇匯入的 MIDI 檔案。也支援解析其他 DAW 輸出到系統剪貼簿中的 MIDI 資料。目前已經過測試，能夠使用系統剪貼簿進行 MIDI 資料傳輸的 DAW 有 Reaper 和 FL Studio。
        - Reaper：在 Reaper 的 MIDI 編輯器中，選中音符，並複製，即可將選中的音符資料匯出至系統剪貼簿中，供 HiFiShifter 讀取。注意，由於 Reaper 的剪貼簿音符資料並不包含 BPM 資訊，匯入時，可以使用目前專案 BPM，或者自行指定。
        - FL Studio：在 FL Studio 的鋼琴窗介面中，點擊鋼琴窗左上角的小三角展開選單，選擇 `檔案` -> `複製到 MIDI 剪貼簿`，即可將目前通道的所有音符匯出至系統剪貼簿中，供 HiFiShifter 讀取。
    - 軌道選擇區：允許你選擇即將匯入的 MIDI 軌道。
    - 將 MIDI BPM 匯入為專案 BPM：啟用後，將 MIDI 的初始 BPM 匯入為專案 BPM。HiFiShifter 目前仍然不支援變速 BPM。
    - 音符 BPM：允許設定將要匯入的音符的 BPM 映射方式。
        - MIDI 自身 BPM：不進行 BPM 映射，直接以 MIDI 自身 BPM 匯入。
        - 目前專案 BPM：將音符 BPM 映射到目前專案 BPM 後再匯入。
        - 指定 BPM：將音符 BPM 映射到指定 BPM 後再匯入。
    - 多軌合併：若啟用，則自動將選擇的所有軌道和所有音符進行合併，取音高較高的音符作為音高線參數，最終只匯入 1 個音高參考塊。若停用，將嘗試拆分各種軌道和音符，確保所有音符都能夠匯入為音高線參數，最終可能會縱向匯入多個音高參考塊。
    - 填補音符間的空隙：啟用後，自動填補兩個相鄰音符之間的空隙。
- 透過 Reaper 專案或者 Reaper 剪貼簿匯入軌道上的 MIDI 物件。
- 透過 VocalShifter 專案或者 VocalShifter 剪貼簿匯入軌道上的 MIDI 音訊片段。
- 右鍵常規的音訊片段，在彈出的上下文選單中選擇 `轉換為音高參考塊`。這會將該常規音訊片段的原始音高線轉換為新的音高參考塊的音高線。
- 在參數編輯器中，編輯音高參數時，使用選取工具，選取一段區域並右鍵，在彈出的上下文選單中選擇 `儲存為音高參考塊`，可以將選取範圍內的音高線儲存為新的音高參考塊。

音高參考塊有以下常見的用法：

- 放置在軌道上，作為一般的音訊片段，供其他有常規音訊片段的軌道進行音高的參考。在其他軌道上，可以使用參數編輯器的 `參考軌道群組` 功能檢視這條軌道，以展示其音高線。
- 當音高參考塊被放置在軌道群組的根軌道時，可以改變目前軌道群組的音高處理邏輯，將音高參考塊的音高線覆蓋掉這一段的原始音高線。這會影響以下幾個場景：
    - 若軌道群組中有某段音高線未被進行過編輯，則其音高參數會直接被音高參考塊的音高線覆蓋，並觸發音訊音高的重新算繪。
    - 當使用 `初始化` 相關功能，比如在參數編輯器中使用繪製工具進行右鍵拖曳操作時，初始化後的音高線使用的是音高參考塊的音高線資料，而非軌道群組子軌道內的音訊片段的原始音高。
    - 如果音高參考塊被靜音，則軌道群組處理音高時，不會參考該音高參考塊。

選中音高參考塊，在右鍵的上下文選單中執行 `更新音高`，可以將音高參考塊範圍內的現有音高參數更新到音高參考塊中。

### 7. 其他功能

參數編輯器的其他一些便捷功能：

- `剪貼簿預覽`：使用選擇工具複製參數線資料後，可以在選擇區域內即時展示剪貼簿參數線資料，便於貼上定位。該選項位於頂部 `檢視` 選單中，不再顯示在參數編輯器工具列。
- `彈出展示參數`：當滑鼠靠近參數線，或者正在執行繪製編輯操作時，展示參數值。該選項位於頂部 `檢視` 選單中，不再顯示在參數編輯器工具列。
- `鎖定參數線`：在拖動軌道上的音訊塊時，是否同步挪動其音訊塊在軌道上對應的所有參數線。HiFiShifter 的所有參數線編輯功能基於軌道的，如果不鎖定參數線，則已編輯的參數線不會跟隨音訊塊進行移動。
- `平滑度`：編輯參數時，是否自動進行平滑處理，以及自動平滑處理的強度。
- `參考軌道組`：當參數為 `音高` 時，允許你選擇其他軌道，將其他軌道組的音高線，作為參考，展示在音高參數編輯視窗內。
- `匯入 MIDI`：允許你選擇 MIDI 檔案，並將其中單軌或多軌的音符匯入為音高線。

## 六、匯出音訊

做完所有編輯後，透過 `檔案` 選單的 `匯出音訊` 功能，可以將 HiFiShifter 專案匯出為 wav 音訊。

有以下參數：

- `匯出類型`：`專案` / `分軌`。
- `匯出範圍`：`全部` / `自訂`。`自訂` 允許你設定匯出的起始和結束的秒數。
- `取樣率`：允許你設定輸出的 WAV 音訊的取樣率。
- `位元深度`：允許你設定輸出的 WAV 音訊的位元深度。
- `輸出資料夾`：允許你設定檔案輸出的資料夾。允許使用的佔位符如下：
    - `<ProjectFolder>`：表示當前專案所在資料夾。如果當前專案未被儲存過，則指向 `我的文件` 資料夾。
    - `<ProjectName>`：表示當前專案的檔案名稱，不含副檔名。
    - 對於匯出專案來說，`輸出資料夾` 的預設值為 `<ProjectFolder>`；對於匯出分軌來說，`輸出資料夾` 的預設值為 `<ProjectFolder>/<ProjectName>`。
- `輸出檔案名稱`：允許你設定檔案的輸出名稱。允許使用的佔位符如下：
    - `<ProjectName>`：表示當前專案的檔案名稱，不含副檔名。
    - `輸出檔案名稱` 的預設值為 `<ProjectName>.wav`。
- `分軌命名格式`：允許你設定分軌輸出時的命名格式。允許使用的佔位符如下：
    - `<ProjectName>`：表示當前專案的檔案名稱，不含副檔名。
    - `<ExportIndex>`：表示當前分軌在匯出時的順序編號。編號從 `0` 開始。
    - `<TrackIndex>`：表示當前分軌在專案內的編號。編號從 `0` 開始。
    - `<TrackName>`：表示當前分軌在專案內的軌道名稱。
    - `<TrackType>`：表示當前分軌在專案內的軌道類型，根軌道 `Root` / 子軌道 `Sub`。
    - `<TrackId>`：表示當前分軌在專案內的內部 ID。一般使用者不建議使用這個。
    - `分軌命名格式` 的預設值為 `<ExportIndex>_<TrackName>.wav`。
- `分軌選擇面板`：可以選擇你打算匯出的分軌。預設情況下，只會選擇專案內不靜音的普通軌道和根軌道。
    - 如果你勾選了原本處於靜音的軌道，則可以正常匯出該軌道，而忽略該軌道是否處於靜音狀態。
    - 如果你勾選了軌道組的根軌道，則表示將該根軌道所包含的軌道組匯出為單個音訊檔案分軌，且匯出的根軌道的音訊資料中，不包含目前被靜音的子軌道的音訊資料。
    - 如果你勾選了軌道組的子軌道，則可以正常匯出該軌道，而忽略該子軌道或者其根軌道是否處於靜音狀態。

當你正在輸入檔案路徑時，點擊 `佔位符` 那一排按鈕，可以快速將對應文字填入文字框中。

上述所有和檔案路徑有關的字串，均支援時間格式化字串，比如 `%Y-%m-%d-%H-%M-%S`。如果你打算在輸出路徑中包含實際的 `%` 字元，請使用 `%%` 進行跳脫。
