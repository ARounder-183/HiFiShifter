# HiFiShifter 使用手冊

[简体中文](USERMANUAL.md) | [繁體中文](USERMANUAL_zh-TW.md) | [English](USERMANUAL_en.md) | [日本語](USERMANUAL_ja.md) | [한국어](USERMANUAL_ko.md)

HiFiShifter 是一款圖形化人聲編輯與合成工具。它支援多軌道音訊塊處理，並以軌道組為單位，使用多種聲碼器完成人聲修音、人力調參功能，實現人力 VOCALOID 製作的拼調一體化。

## 一、安裝

下載你的作業系統和架構所對應的 HiFiShifter 安裝包。依作業系統分類，分為 `Windows`、`macOS` 和 `Linux` 這三類。依架構分類，分為 `x86_64` 架構和 `arm64` 架構這兩類。

- Windows 版本提供的是 NSIS 安裝包版（`installer`）和可攜版壓縮包（`portable`）這兩版。對於一般使用者，直接選擇安裝包版並安裝即可。  
  如果你是 Windows 使用者，且不知道 `x86_64` 與 `arm64` 有什麼區別，請選擇 `x86_64` 版本。只有你清楚地了解 `arm64` 是什麼，並且你確實擁有一台 Windows ARM 裝置，則可以下載使用 `arm64` 版。

- macOS 版本提供的是未經過簽名的 dmg 安裝包。因為暫未簽名，安裝時需要經過一個比較複雜的步驟來允許安裝。  
  M 晶片的 macOS 使用者請安裝 `arm64` 版本。只有較老的 Intel 使用者需要安裝 `x86_64` 版本。  
  如果按兩下 dmg 安裝後提示檔案已損毀，按以下步驟操作：
    1. 終端機輸入 `xattr -cr /Applications/HiFiShifter.app`；
    2. 透過系統設定允許執行 `系統設定` -> `隱私權與安全性` -> 點選 `仍要打開`。

- Linux 版本提供的是 AppImage 程式包。AppImage 程式包需要在檔案的 `屬性 -> 權限` 中，勾選 `允許將檔案作為程式執行`，之後便可以直接執行。

**關於 GPU 加速**：HiFiShifter 為各平台提供了多種 GPU 加速方案：

- **Windows（x86_64 / ARM64）**：DirectML（DirectX 12）—— 成熟穩定，支援 NVIDIA / AMD / Intel Arc GPU
- **macOS（Apple Silicon）**：CoreML + WebGPU（Dawn/Metal）—— CoreML 利用 Apple Neural Engine，WebGPU 作為補充後端
- **macOS（Intel）**：僅 CPU 推理（使用 ort-tract 替代後端，無 GPU 加速）
- **Linux（x86_64）**：WebGPU（Dawn/Vulkan）—— Dawn 透過 Vulkan API 使用 GPU，無 GPU 時自動回退至 CPU
- **Linux（ARM64）**：僅 CPU 推理（尚無預編譯的 WebGPU ONNX Runtime 二進位檔案）

在選單 `選項 → 推理裝置` 中可選擇 `自動`（Auto）、`CPU`、`GPU`。執行基準測試可比較各裝置的推理延遲，幫助你選擇最快的裝置。

**關於 WebView 的說明**：HiFiShifter 基於 Rust + Tauri 框架開發，需要系統提供 WebView 元件來顯示介面。

- **Windows**：需要 Edge WebView2。Windows 10（1803 版本及以上）和 Windows 11 已經預裝，無需額外操作。如果你使用的是更早的 Windows 版本或者系統未預裝，安裝程式會自動提示你下載安裝。你也可以參考 [Tauri 官方說明](https://tauri.app/zh-cn/start/prerequisites/#webview2) 了解詳情。一般使用者無需擔心，直接執行安裝包即可。
- **macOS**：系統自帶 WebKit，無需任何額外安裝。
- **Linux**：需要 WebKitGTK。大多數主流發行版（如 Ubuntu、Fedora、Arch Linux）預設已包含。如果提示缺少元件，請使用你的套件管理器安裝 `webkit2gtk`（例如 `sudo apt install webkit2gtk`）。具體可參考你的發行版文件。

在 Windows 上，HiFiShifter 已停用 WebView2 自帶的瀏覽器快捷鍵（如 `Ctrl + F`、`Ctrl + P`、`F5` 以及 `Ctrl` 搭配 `+` / `-` 的頁面縮放），因此這些按鍵會正常交給 HiFiShifter 處理，不會打斷你的編輯操作。

**關於 VST3 / ARA 外掛**：除獨立 App 外，HiFiShifter 還提供 VST3（ARA）外掛形態，可以把同一套編輯介面直接開在 REAPER 的專案裡。目前外掛為 Windows x64 版本，且只針對 REAPER 驗證過；安裝與使用見 [VST3 / ARA 外掛](#八vst3--ara-外掛reaper)章節。

## 二、選單

選單列從左到右依次為 `檔案`、`編輯`、`軌道`、`檢視`、`選項`、`說明` 六個選單，選單列最右側還有 `語言` 按鈕，可以在 English / 简体中文 / 繁體中文 / 日本語 / 한국어 之間切換介面語言。

`檔案` 選單允許你新建、開啟和儲存 HiFiShifter 專案檔（`新建專案`、`開啟專案...`、`最近開啟`、`儲存`、`另存新檔...`），也允許你進行匯入媒體檔案（音訊或視訊檔案）、匯入 MIDI 檔案、匯入外部工程、匯出音訊、自動備份、錄音等操作。匯出音訊支援 `wav`、`mp3` 和 `flac` 三種格式，詳見[匯出音訊](#六匯出音訊)章節。

HiFiShifter 的專案檔副檔名為 `.hshp` 或 `.hsp`。除此以外，`另存新檔` 功能還支援將專案檔儲存為明文的 `json` 檔案，或者將當前專案連同使用到的所有媒體檔案，一起打包為歸檔壓縮包 `.zip`。

`檔案 → 匯入媒體檔案` 可以匯入常見音訊格式（`wav`、`mp3`、`flac`、`ogg`、`m4a`、`aac` 等）以及常見視訊容器（`mp4`、`mov`、`mkv`、`webm`、`avi`、`wmv`、`ts`、`mpg` 等）。一次選擇多個媒體檔案時，會彈出匯入方式選擇，可以選擇 `跨時間新增`（沿時間軸依次排列）、`跨軌道新增`（垂直跨多個軌道）或 `作為 Take 新增`（合併為一個音訊塊的多個 Take）。如果媒體檔案包含多條音軌（如多語言音軌的視訊），匯入時還可以選擇要匯入的音軌。

`檔案 → 重新擷取缺失媒體...` 用於在專案內的媒體檔案被移動或遺失後，重新定位這些檔案。

自動備份功能允許你為專案檔設定自動備份，有 `儲存時備份` 和 `定時備份` 兩種模式。

- `儲存時備份`：每次覆蓋儲存專案檔時，會自動將舊的專案檔重新命名為原檔名後附加 `-bak` 的備份檔（例如 `.hshp-bak` 或 `.hsp-bak`）。預設為啟用。
- `定時備份`：在你編輯專案時，依照你設定的時間間隔與路徑，自動建立備份專案檔。預設為停用。

### 匯入 HiFiShifter 專案

`檔案 → 匯入外部工程 → 匯入 HiFiShifter 專案...` 允許你把另一個 `.hshp` / `.hsp` / `.json` 專案中的全部內容合併進目前專案，而不必關閉目前專案。同一子選單下還有 `匯入 Reaper 專案...`（`.rpp`）和 `匯入 VocalShifter 專案...`（`.vshp` 或 `.vsp`）。

- `保留原始時間軸位置`：匯入的音訊塊維持來源專案中的時間位置。
- `放到播放頭`：將匯入內容整體平移，使最早開始的音訊塊對齊目前播放頭。
- `匯入速度映射`：僅目前專案沒有速度映射時可用。匯入後，來源專案初始點的 BPM、拍號與音階會成為目前專案的基準。
- 所有軌道、子軌道、音訊塊、參數曲線與群組關係都會在匯入時自動分配新 ID，避免與目前專案衝突。音訊來源檔會優先依來源專案所在資料夾解析；遺失檔案仍會提示手動重新定位。
- 來源專案的記事本內容會附加到目前專案記事本結尾，不會覆蓋既有內容。

### 跨處理程序複製 / 剪下 / 貼上

HiFiShifter 的結構化複製貼上是保存在系統剪貼簿中的，因此支援跨處理程序複製貼上。

複製、剪下與貼上會依據你目前操作的位置自動判斷對象，不需要手動切換模式：

- 焦點在軌道介面、且已選取音訊塊時，`Ctrl + C` / `Ctrl + X` / `Ctrl + V` 作用於音訊塊。
- 焦點在參數編輯器、且已選取一段參數線時，同樣這三個快捷鍵作用於參數線。此時 `Ctrl + X` 為 `剪下參數幀`，會把選取的參數線複製進剪貼簿並清空，方便你搬到別處；而 `BackSpace`（初始化）只把選區恢復預設值，不會寫入剪貼簿。
- 貼上時還會參考剪貼簿中的實際內容來決定貼成什麼，因此即使中途切換了軌道，也能正確把參數線貼到新軌道上。

- 在時間軸中選取音訊塊後按 `Ctrl + C`（或右鍵 `複製`），在另一個處理程序的專案中按 `Ctrl + V`（或在軌道空白處右鍵 `貼上`），即可貼上音訊塊及其參數曲線。
- 在 HiFiShifter 中複製音訊塊時，同時還會將資料序列化為 Reaper 剪貼簿資料，隨後在 Reaper 中按 `Ctrl + V` 即可貼上。沒有可用來源檔的音訊塊會被略過。
- `編輯 → 作為新軌道群組貼上`（`Ctrl + Alt + V`）可強制依來源層級建立新根軌道群組。

- `貼上 Reaper 剪貼簿資料`：當你在 Reaper 中進行物件（Item）複製、軌道複製、MIDI 音符複製操作後，在 HiFiShifter 中執行普通貼上即可自動辨識並匯入 Reaper 剪貼簿資料。
    - 物件資料：匯入為 HiFiShifter 中的音訊塊，同時允許保留 Reaper 中的調音資料（整體調音和音高包絡均可）。
    - 軌道資料：連同軌道中的物件，匯入為 HiFiShifter 中的軌道和音訊塊。可保留軌道組。
    - MIDI 音符資料：從其他 DAW（Reaper、FL Studio 等）將音符資料匯出至系統剪貼簿 MIDI 資料後，在 HiFiShifter 中使用參數編輯器的 `選擇` 工具選擇一段音高線，即可將剪貼簿 MIDI 音符資料匯入至該段音高線資料。匯入 MIDI 的詳細介紹可見 [音高參考塊](#8-音高參考塊) 章節。

- `Reaper 包絡`：無論是匯入 Reaper 專案（`.rpp`）、貼上 Reaper 剪貼簿資料，或是把 HiFiShifter 的內容複製回 Reaper，都會一併處理 Reaper 的 Take 包絡與軌道包絡（音量、聲像、靜音），它們會與 HiFiShifter 的參數曲線互相轉換。需要注意的是，音高包絡只有在對應軌道組的根軌道開啟了合成（`C`）時才會匯出，這樣可以保證匯出的資料與你實際聽到的聲音一致。

- `貼上 VocalShifter 剪貼簿資料`：當你在 VocalShifter 或者 VocalShifter LE 中進行參數線複製、音訊塊複製、軌道複製操作後，透過該功能，可以將 VocalShifter 剪貼簿資料快速匯入進 HiFiShifter 中。
    - 參數線資料：在 HiFiShifter 中使用參數編輯器的 `選擇` 工具選擇一段參數線後，可將 VocalShifter 剪貼簿參數線資料匯入至該段參數線資料。
    - 音訊塊資料：匯入為 HiFiShifter 中的音訊塊，同時允許保留各種參數線資料。
    - 軌道資料：連同軌道中的音訊塊，匯入為 HiFiShifter 中的軌道。注意，HiFiShifter 目前無法區分你上一次複製的內容是音訊塊還是軌道。如果你打算匯入軌道，在 VocalShifter 執行複製軌道操作前，請先保證 VocalShifter 專案中，沒有音訊塊處於選中狀態，這樣才能正常匯入軌道；否則，只有被選中的音訊塊會被匯入。

`編輯` 選單匯集了與剪貼簿和選取相關的常用操作：`復原` / `重做`、`剪下` / `複製` / `貼上`、`作為新軌道群組貼上`，以及 `貼上 VocalShifter 剪貼簿`（僅 Windows 版本提供）。選取類操作有 `全選`、`取消選取`，以及 `音訊塊範圍加入參數選取區` / `音訊塊範圍移出參數選取區`（詳見[軌道介面](#三軌道介面)章節）。

`軌道` 選單提供 `新增軌道`（在目前選取軌道下方插入）、`複製選取軌道` 與 `刪除選取軌道`。

`檢視` 選單包含介面顯示相關的選項：

- `視窗` / `佈局`：管理各個停靠面板的顯示與佈局預設、匯入匯出、重置等。
- `速度映射`：顯示或隱藏速度映射行（預設開啟；專案不存在速度映射資料時，該行不顯示）。
- `顯示所有 Take (如果空間足夠)`：切換多 Take 音訊塊的展開顯示。
- `剪貼簿預覽`：切換參數編輯器剪貼簿預覽。
- `彈出顯示參數`：切換參數值浮窗顯示。
- `時間顯示`：允許選擇時間軸的主/副時間單位，並開啟 `時間軸顯示設定...`。
- `主題：自動 / 深色 / 淺色`：切換目前主題。選擇 `自動` 時，HiFiShifter 會跟隨系統的深色 / 淺色外觀自動切換（也是預設值）。
- `外觀設定...`：開啟外觀設定面板。
- `ARA 宿主連線...`：連線正在執行的 ARA 宿主（REAPER）實例，用於在獨立 App 中編輯宿主的音訊。僅在獨立 App 中顯示；開啟後是一個浮出的工作階段面板，可提交、重新整理或中斷連線，詳見 [VST3 / ARA 外掛](#八vst3--ara-外掛reaper)章節。
- `重新整理`：重新載入執行階段資訊。
- `清除波形快取`：清除已快取的波形資料，下次顯示時會重新產生。

`選項` 選單允許你修改 HiFiShifter 的各個選項：

- `工程拉伸覆寫`：允許你修改目前專案的拉伸演算法與 HiFiGAN Mel 拉伸開關。
- `全域拉伸預設`：允許你修改全域預設的拉伸演算法與 HiFiGAN Mel 拉伸開關。
- `推理裝置`：允許你設定渲染所使用的推理裝置。目前分為 `自動`、`CPU`、`GPU` 三種，選擇 `GPU` 時還可以從 `GPU 裝置` 清單中指定顯示卡。可以透過該選單執行基準測試，以檢測各推理裝置的效能（基準測試中會顯示具體後端，如 GPU (DirectML)、GPU (WebGPU) 等）。GPU 選項僅在對應的 GPU 版本 HiFiShifter 中有效。
- `背景預渲染`：當被啟用時，每次開啟專案或者編輯完參數以後，均會自動在背景對已編輯的參數進行預渲染，且即使仍然在渲染狀態中，也可以播放已渲染的部分；否則，只有在進行播放操作時，才會進入渲染流程，且需要等待渲染完畢，才可以正常播放時間軸。預設為啟用。禁用後可以降低渲染頻率，節省效能。
- `同步編輯所有 Take`：開啟後，對某個 Take 的編輯（增益、裁剪、速率、倒放、循環等）會同步套用到該音訊塊的所有其他 Take（預設開啟）。
- `自動重新載入已修改的媒體檔案`：開啟後，當專案內的媒體檔案在外部被修改時，會自動重新載入（預設開啟）。
- `為新的音訊塊啟用循環`：開啟後，新匯入或建立的音訊塊預設啟用循環（Loop 源）（預設開啟）。
- `吸附/網格設定...`：開啟 [吸附 / 網格設定](#吸附--網格設定) 視窗（也可以透過時間軸工具列 `吸附` 按鈕的右鍵選單開啟）。
- `搜尋與匹配...`：設定檔案瀏覽器與快速搜尋共用的搜尋匹配規則（如大小寫、正規表示式等）。
- `渲染快取管理...`：檢視並清理渲染快取。
- `顫音預設管理...`：開啟[顫音預設](#6-顫音預設)管理器。
- `匯入聲道處理...`：設定匯入媒體檔案時對聲道數量的處理策略（例如假立體聲轉單聲道）。
- `指標與觸控筆輸入...`：設定觸控板、數位板、觸控筆、觸控螢幕等指標裝置的輸入偏好。
- `鍵盤快捷鍵...`：允許你設定 HiFiShifter 的快捷鍵對應。有多種預設可以選擇。

`說明` 選單包含與診斷和支援相關的入口：

- `開啟日誌資料夾`：直接在系統檔案管理員中開啟執行日誌所在的資料夾，詳見[日誌與故障排除](#九日誌與故障排除)章節。
- `匯出診斷資訊...`：選擇儲存位置後，一鍵產生診斷套件（包含系統資訊、全部日誌與推理裝置基準測試結果），提交 issue 時附上即可。
- `關於 HiFiShifter`：開啟關於對話框，查看專案簡介、目前版本號與 GitHub 儲存庫連結。

## 三、軌道介面

軟體的大致操作邏輯和快捷鍵可以參考 Reaper、VocalShifter、VEGAS Pro 等 DAW 軟體。可以透過 `選項 -> 鍵盤快捷鍵...` 來調整自己的快捷鍵偏好。以下介紹均以預設快捷鍵為基礎。

軌道介面是 HiFiShifter 最核心的功能之一，允許你對音訊塊進行裁切、拼接等操作。其操作邏輯，基本可以參考 Reaper。

對於介面操作，拖動滑鼠中鍵（即按住滑鼠滾輪）可以進行介面的平移拖動。水平/垂直的縮放或捲動，可以按住 `Ctrl`、`Alt`、`Shift` 等修飾鍵，並捲動滑鼠滾輪來調整。這些修飾鍵均可在鍵盤快捷鍵中調整。

把滑鼠指標移到介面邊緣的捲軸上再捲動滾輪，只會捲動該捲軸對應的方向（垂直捲軸為上下捲動，水平捲軸為左右捲動），不會被當成縮放。此時如果再按住縮放修飾鍵（預設 `Alt`），滾輪就會變成對該方向的縮放：在垂直捲軸上是縮放軌道高度，在水平捲軸上是縮放時間軸，並且會以指標所在位置為中心。

常用快捷鍵一覽：

> **macOS 使用者**：下文中的 `Ctrl` 皆對應 `Command (⌘)`，`Alt` 對應 `Option (⌥)`。

- `空格鍵`：播放/暫停（不返回播放起始點）
- `Enter`：播放/停止（返回播放起始點）
- `K`：開關節拍器
- `S`：切割
- `G`：編組
- `U`：解組
- `T`：循環切換到下一個 Take（`Shift + T`：上一個）
- `Ctrl + C`：複製（同時寫入 REAPERMedia 資料，可直接在 REAPER 中貼上）
- `Ctrl + X`：剪下
- `Ctrl + V`：貼上
- `Ctrl + Alt + V`：作為新軌道群組貼上
- `Ctrl + Z`：復原
- `Ctrl + Shift + Z` / `Ctrl + Y`：重做（macOS：`⌘ + ⇧ + Z` / `⌘ + Y`）
- `Ctrl + A`：全選
- `Delete`：刪除音訊塊
- `-` / `=`：對選取音訊塊的參數線進行下移/上移（按住 `Shift` 為大幅、按住 `Ctrl` 為微調）
- 修飾鍵 `Alt`：按住後，拖動音訊塊開頭/結尾可以拉伸音訊塊，拖動音訊塊中間可以調整音訊塊的內部偏移量
- 修飾鍵 `Shift`：按住後，可以切換是否吸附到格線
- 修飾鍵 `Ctrl`：按住後，拖動音訊塊可以將其複製
- 修飾鍵 `Alt + Shift`：按住後在音訊塊上垂直拖動，可以整體調整該音訊塊的音高，參數編輯器中的音高線會即時跟著變化，方便邊拖邊看

在時間軸中雙擊音訊塊，會自動選取該音訊塊範圍內的全部參數幀，並把複製 / 剪下的焦點切換到參數編輯器，便於快速整段處理。

按住 `Alt`（可在 `選項 -> 鍵盤快捷鍵...` 中改為其它鍵）並雙擊音訊塊，則把該音訊塊的範圍**併入**參數編輯器選取區（與既有選取區重疊或相接時自動合併），再次以相同操作點擊同一個音訊塊會**取消**該塊的範圍 —— 如此可快速把數個音訊塊的時間範圍拼成一個多段選取區，一次處理。若音訊塊較多，也可在音訊塊的右鍵選單中選擇 `範圍加入參數選取區` / `範圍移出參數選取區` 批次處理，或直接按快捷鍵 `Ctrl + Shift + A`（macOS 上 `Alt` 為 `Option`、快捷鍵為 `⌘ + ⇧ + A`）把目前選取的音訊塊範圍全部加入。這類操作只作用於**目前參數編輯器所屬根軌道群組**內的音訊塊：參數編輯器一次只顯示一條根軌道的參數，其它軌道的音訊塊會被忽略。

音訊塊左上角的小圓圈是音量調整旋鈕，`M` 按鈕可以單獨靜音該音訊塊，`F` 按鈕可以開啟該音訊塊的共振峰編輯選單。共振峰編輯選單以元音圖（F1/F2 平面）方式設定目標共振峰：圖中會顯示素材目前偵測到的源共振峰位置（空心點與軌跡散點），源點與目標點之間的箭頭直觀展示共振峰的遷移方向；點擊元音字母可以一鍵把該元音設為目標；`旁通試聽` 按鈕可在按住期間臨時對比處理前後的聲音。若素材中未偵測到穩定的元音，視窗會給出提示。音訊塊左右端分別能夠調整淡入/淡出包絡長度。雙擊音訊塊的名稱區域可以重新命名（作用於目前活躍的 Take）。

對著音訊塊右鍵可以開啟上下文選單，其中包含 `刪除`、`靜音` / `取消靜音`、`Take`（子選單，含 `取代`）、`聲道模式`（子選單，可交換左右聲道、轉為單聲道等，並有 `掃描假立體聲並轉換`）、`倒放`、`循環`、`複製` / `剪下`、`在播放頭處分割`、`正規化`、`範圍加入參數選取區`、`編輯播放速率...`、`靜音偵測...`、`轉換為音高參考塊`（音高參考塊則顯示 `更新音高`）、`快速匯出`、`匯出為 MIDI`、`編組`（子選單，含 `編組` / `解組` / `膠合`）以及選單底部的 `淡入` / `淡出` 形狀按鈕列等功能。如果選擇同一軌道的多個音訊塊，在右鍵的上下文選單中選擇 `膠合`，可以把它們合成一個單一的音訊塊。

選中多個音訊塊，在右鍵的上下文選單中選擇 `編組`（或者按下快捷鍵 `G`），可以將選中的多個音訊塊進行編組。類似於 Reaper 或者 VEGAS Pro 的同類型功能，所有同組的音訊塊，在執行一些編輯操作時，會被聯動編輯。此時點擊音訊塊左上角的鎖鏈按鈕，可以臨時停用或者啟用該編組的聯動編輯效果。選中已編組的音訊塊後，在右鍵的上下文選單中選擇 `解組`（或者按下快捷鍵 `U`），可以將其從編組中移出。

### Take

一個音訊塊可以包含多個 Take（類似於 Reaper 的 Take），用於在同一段位置上比較或切換不同的錄音 / 素材。

- 新增 / 管理 Take：右鍵音訊塊，在 `Take` 子選單中可以進行 `從媒體檔案新增 Take...`、`複製目前 Take`、`重新命名 Take`、`刪除 Take` 等操作；當音訊塊包含多個 Take 時，還可以在子選單中直接點擊切換活躍 Take，或使用 `切換到下一個 Take` / `切換到上一個 Take`（快捷鍵 `T` / `Shift + T`，會循環切換）。`將 Take 展開為獨立音訊塊` 會把該音訊塊的每個 Take 拆成時間軸上獨立的音訊塊。`取代` 也位於該子選單中，可以用新的媒體檔案取代目前 Take 的音訊源。每個 Take 列的右側還有獨立的 `倒放` 與 `聲道模式` 小按鈕，可分別作用於單個 Take。
- 跨軌道聚合為 Take：同時選取不同軌道上的多個音訊塊後，右鍵選單中的 `跨軌道聚合為 Take` 會把它們合併為同一個音訊塊下的多個 Take。
- `檢視 -> 顯示所有 Take (如果空間足夠)`：啟用後，多 Take 音訊塊在軌道高度足夠的情況下會平鋪顯示所有 Take。關閉後只顯示目前活躍的 Take。
- `選項 -> 同步編輯所有 Take`：啟用後，對任意 Take 的編輯（增益、裁剪、速率、倒放、循環等）會同步套用到該音訊塊的所有其他 Take。

軌道介面的左側是軌道頭區域，允許你新增或刪除軌道、調整軌道參數等。右鍵軌道可以對軌道進行克隆；在軌道空白處右鍵可以貼上剪貼簿中的音訊塊。

類似於 Reaper，HiFiShifter 的軌道也是有軌道組的概念的。在軌道頭區域中，將一個軌道頭拖曳至另一個軌道頭，即可建立軌道組。軌道組共享一套參數面板。實際使用中，建議按「一個聲部一個軌道組」去整理。

軌道介面的一些功能按鈕（自左向右）：

- `節拍器`：播放時提供打點參考。左鍵按一下開關，右鍵開啟音量、細分、音色等設定，詳見[節拍器](#節拍器)章節。
- `BPM`：用於調整專案整體的曲速 BPM（存在速度映射時調整播放游標最近變化點的 BPM，見下文「速度映射」）。
- `拍號`：用於設定專案的拍號。
- `格線`：用於設定專案的格線間距。
- `基準音階`：用於調整專案整體的基準音階設定。允許自訂音階。音階功能主要和後邊會介紹到的 `音高吸附` 以及其他音高調整相關功能有關。
- `停止` 按鈕和 `播放 / 暫停` 按鈕：用來控制是否播放。
- `錄音`：可在目前選取的軌道進行錄音。右鍵可設定錄音來源和錄音裝置，或者進入詳細的錄音設定。
- `復原` / `重做`：與編輯選單中的同名功能一致；右鍵按鈕可以開啟 `操作記錄` 面板，檢視最近的操作歷史並跳轉到任意一步。
- `檔案瀏覽器`：用於開啟 HiFiShifter 的檔案瀏覽器視窗。
- `記事本`：用於開啟 HiFiShifter 的記事本視窗，記錄並展示 MarkDown 格式的文字內容。
- `自動交叉淡化`：同 Reaper / VEGAS Pro 的類似功能，啟用後，當移動音訊塊時，如果有音訊塊重疊，自動調整重疊位置的淡入淡出包絡。
- `分割過渡`：參考 Reaper / VEGAS Pro 的分割淡入淡出機制，預設啟用。分割後自動在分割處為前一個音訊塊加入淡出、為後一個音訊塊加入淡入，或延伸重疊，使音訊塊間的過渡更平滑。左鍵按一下開關，右鍵開啟詳細設定。
- `吸附`：啟用後，對音訊塊的所有調整都會嘗試吸附到格線、其他物件邊緣、播放游標等目標。按住 `Shift` 可以進行臨時的吸附切換。
- `波紋編輯（自動跟進）`：啟用後，會自動對軌道上音訊塊的一些編輯操作執行自動跟進。左鍵按一下可在 `關閉`、`按軌道`、`全部軌道` 三檔之間循環切換，右鍵可直接選擇模式。
- `基於播放游標縮放`：捲動滑鼠滾輪可以對介面進行水平縮放。未啟用該設定時，縮放中心為當前滑鼠游標位置；啟用後，水平縮放的邏輯類似於 Reaper / VEGAS Pro 的邏輯，總是基於播放頭位置進行縮放。
- `自動捲動`：啟用後，在播放時，自動對介面進行水平捲動操作，以跟隨播放頭位置。
- `允許參數編輯器調整播放頭`：停用後，參數編輯器的編輯面板的一些點擊操作不會進行播放頭的調整，只有點擊軌道介面，或者點擊參數編輯器的時間碼區域，才能調整播放頭位置。
- `允許時間軸點擊切換軌道`：預設啟用。啟用後，點擊時間軸中的音訊塊或空白區域會自動切換目前軌道，參數編輯器隨之編輯對應軌道；停用後，只有點擊左側軌道標題列才會切換目前軌道。
- `忽略編組`：啟用後，在編輯所有已編組的音訊塊時，均會全域忽略編組聯動編輯。

### 吸附 / 網格設定

時間軸工具列中的 `吸附` 按鈕用於快速開關吸附。左鍵按一下按鈕可切換吸附總開關；右鍵按一下按鈕會直接開啟 `吸附 / 網格設定` 視窗。該視窗也可以透過選單列 `選項 -> 吸附 / 網格設定` 開啟。所有設定都會自動儲存，並在下次啟動時還原。

設定內容：

- `網格`：可以開關網格線顯示，選擇網格間距（普通 / 附點 / 三連音，從 `1/1` 到 `1/64`），並設定網格線的最小像素間距，防止網格過密。開啟 `Swing` 後，奇數網格線會按百分比（0–100%）產生搖擺偏移；勾選 `調整 Swing 時自動重新對齊所有音訊塊` 後，改變 Swing 強度時，時間軸上既有的音訊塊會自動移動到新的 Swing 網格位置。
- `吸附總開關`：`啟用吸附` 為總開關；`拖拽時顯示吸附豎線高亮`（預設開啟）在拖拽命中吸附目標時顯示輔助豎線；`吸附距離` 指定滑鼠距離吸附目標多少像素以內才會觸發吸附（預設 4 像素）；`相對網格吸附` 會保留音訊塊原來相對網格的偏移量，而不是強制吸附到絕對網格位置。
- `吸附物件與目標`：可以分別設定 `音訊塊`、`選區`、`游標` 是否吸附到 `選擇 / 標記 / 游標` 或 `網格`。例如可以讓音訊塊只吸附網格，而播放游標同時吸附網格與音訊塊邊緣。
- `吸附行為`：`吸附跟隨網格顯示` 會在關閉網格線顯示後停止吸附到網格；`任意距離吸附到網格` 是激進模式，拖曳時無論離網格多遠都會強制定位到網格；開啟 `使用獨立吸附間距` 後，可以為吸附單獨指定不同於顯示網格的間距，並設定其最小像素值。
- `音訊塊與特殊互動`：可選擇僅讓音訊塊起點/終點參與吸附，或同時吸附 `snap offset`（音訊塊內容起點）；開啟 `允許跨軌吸附音訊塊` 後，可以設定允許跨多少條軌道尋找吸附目標；`剃刀編輯吸附` 會讓 `S` 分割操作的分割位置也參與吸附。
- `進階`：`吸附到工程取樣率` 可進行取樣級精確吸附；`音訊塊邊緣吸附到來源素材首尾` 可把被裁剪過的音訊塊邊緣吸回原始素材的起點/終點；`強制選區為網格倍數` 會讓框選範圍按指定網格取整（可用 `選區倍數` 指定按幾倍網格取整）；`編排視圖與 MIDI 編輯器使用相同網格劃分` 保證時間軸與參數編輯器使用同一網格精度。

### 分割過渡

`分割過渡` 是專門用於消除分割處 click 聲的功能，預設啟用。由於拉伸演算法等原因，音訊塊在分割後可能會在分割邊界產生 click 聲；該功能參考 Reaper / VEGAS Pro 的機制，在每次分割後自動處理邊界。

工具列中的 `分割過渡` 按鈕位於 `自動交叉淡化` 的右側。左鍵按一下可開關該功能；右鍵按一下可開啟詳細設定。

- `僅淡入淡出`：分割後，自動為前一個音訊塊加入長度 X 的淡出，為後一個音訊塊加入長度 X 的淡入，兩個音訊塊之間沒有重疊。
- `延伸重疊`（預設）：分割後，自動將前一個音訊塊的結尾向後延長 X，將後一個音訊塊的起始位置向前延長 X，形成 2X 秒的重疊區域。延長時會保持音訊塊內素材在時間軸上的位置不變，並正確處理播放速率；延伸範圍會被鉗制在音訊塊原素材的實際長度範圍內；如果同時開啟了 `自動交叉淡化`，還會自動為這段重疊區域建立交叉淡化。
- `過渡長度 X`：以上兩種模式使用的淡入淡出/重疊長度，預設為 0.01 秒。
- `過渡長度單位`：可選擇 `秒`（預設）或 `百分比`。百分比預設為 1，按分割後前後兩個音訊塊的全長合計折算；例如兩個音訊塊全長 10 秒、1% 即為 0.1 秒。
- `淡化曲線`：選擇分割過渡寫入邊界淡變時使用的曲線類型。預設是 `不修改淡化曲線`。
- `重疊交叉淡化`：選擇 `跟隨自動交叉淡化` 時，僅在 `自動交叉淡化` 開啟時才對延伸重疊區域加入交叉淡化；選擇 `始終套用` 時，延伸重疊區域始終會加入交叉淡化。

### 音訊塊淡入淡出與交叉淡化

每個音訊塊都帶有獨立的淡入 / 淡出包絡，互動模型與 REAPER 幾乎完全一致：可編輯的物件不是「整片淡化區域」，而是畫面上真正可見的淡化包絡線，以及淡化區域的邊緣豎線。

**調整淡化長度**

- 拖曳音訊塊左 / 右端的淡化包絡線或淡化區域邊緣豎線，可以調整淡入 / 淡出的長度；從音訊塊名稱列**下方**（波形區頂角）的小三角按住拖曳，可以從零開始建立淡化 —— 該側尚未有淡化時才會顯示這個小三角，建立之後改由包絡線本身充當把手。名稱列上的旋鈕與徽標屬於音訊塊控件，不接受淡化手勢。
- 按一下淡化控件（未發生拖曳時）會將播放頭定位到對應位置：包絡線定位到淡化區內側邊緣（淡入 → 淡化區右緣，淡出 → 淡化區左緣），交叉點抓手定位到點擊位置，音訊塊邊緣定位到該邊緣的準確位置。
- 滑鼠懸停在包絡線、邊緣豎線、交叉點抓手等淡化控件上時，會顯示浮動提示，內容為淡入 / 淡出類型（曲線圖示）、長度（按時間軸顯示設定的主 / 副時間單位）與曲率。

**淡化形狀與曲率**

HiFiShifter 提供 7 種與 REAPER 相同的淡化形狀：`線性`、`快起`、`快收`、`陡峭快起`、`陡峭快收`、`慢起慢收（S 曲線）`、`陡峭慢起慢收（銳利 S 曲線）`。

- 對淡化包絡線或淡化區域邊緣豎線按右鍵，會開啟淡化專屬上下文選單：上方為 7 個形狀按鈕（目前形狀高亮），下方為曲率滑桿與迷你曲線預覽。曲率取值範圍為 `-1.00 ~ +1.00`，調整即時生效；滑桿支援滾輪步進（按住 `精細調整` 修飾鍵可細調），也可以直接在迷你曲線上拖曳。
- 按住 `淡化曲率` 修飾鍵（預設 `Alt`）拖曳包絡線，可以直接把曲線「拉」過指標位置來調整曲率。
- 連按兩下包絡線，可將該側曲率重設為目前形狀的預設值；切換形狀時，曲率也會重設為新形狀的預設值。
- 按住 `循環切換淡化形狀` 修飾鍵（預設 `Ctrl`）按一下包絡線，可以循環切換淡化形狀。
- 音訊塊右鍵選單中也包含 `淡入` / `淡出` 形狀選擇列，可直接切換淡化形狀。

**自動交叉淡化**

工具列中的 `自動交叉淡化` 按鈕（預設啟用）與 REAPER / VEGAS Pro 的同類功能一致：當移動音訊塊產生同軌重疊時，自動按重疊長度為兩個音訊塊設定交叉淡化。

- 自動交叉淡化長度與手動淡化長度分開儲存：重疊消失後，自動淡化會被清除，先前的手動淡化自動恢復顯示；反之，手動調整淡化長度後，該側會轉換為手動淡化。
- 一個音訊塊完全包含另一個音訊塊時，不視為有效的交叉淡化關係，不會觸發自動交叉淡化。
- 時間軸與參數編輯器中顯示的淡化長度均為「有效淡化」：自動交叉淡化優先於手動淡化。

**交叉區域編輯**

兩個音訊塊重疊時，重疊區域會為雙方音訊塊提供完整的編輯控件，互動方式與一般音訊塊一致：重疊區左側屬於後一個音訊塊（左邊緣裁短 / 拉伸與淡入控件），右側屬於前一個音訊塊（右邊緣裁短 / 拉伸與淡出控件）。其中音訊塊邊緣的優先順序最高，其次是淡化區域邊緣豎線，最後是包絡線。

兩條淡化曲線的交叉點處有一個抓手（交叉點手柄）：

- 直接拖曳抓手：交叉點整體前後移動，重疊長度保持不變；
- 按住 `交叉淡化反向模式` 修飾鍵（預設 `Ctrl`）拖曳：前後兩個音訊塊的邊緣向相反方向移動，重疊長度隨之變化，淡化長度按比例縮放；
- 按住 `淡化曲率` 修飾鍵（預設 `Alt`）拖曳：同時調整兩條淡化曲線的曲率；
- 對抓手按右鍵：同時開啟前塊淡出與後塊淡入兩列淡化選單，分別設定形狀與曲率；連按兩下抓手可以同時重設兩側曲率。

以上修飾鍵均可在 `選項 -> 鍵盤快捷鍵...` 的 `修飾鍵 · 淡化與交叉淡化` 分組中調整。

### 時間軸時間顯示

時間軸頂部的標尺會隨水平縮放自動細化刻度：縮小時只顯示小節（`1.1`、`2.1`），逐漸放大後依次細化到二分音符（`1.1`、`1.3`）、四分音符（`1.1`、`1.2`）、八分音符（`1.1`、`1.1.500`）以及更細的十六分/三十二分音符；最大精度受「格線」設定限制。

支援四種時間單位：

- `小節.拍.小單位`（預設主單位）：`1.2.500` 表示第 1 小節第 2 拍再往後 0.5 拍（1000 小單位 = 1 拍）。
- `小節.分割`：`1.17/32` 表示第 1 小節內以 `1/32` 格線計的第 17 個分割。分割由「格線」設定決定；三連音格線會得到整數分割數（如 `1.2/12`），附點格線的分割數可能是小數（如 `1.2/2.6667`）。
- `秒`：絕對秒值，例如 `1234.5678`。
- `時:分:秒.毫秒`（預設副單位）：小時為 0 時省略小時，毫秒固定 3 位（如 `4:43.750`、`1:4:43.750`）。

在時間軸標尺上按右鍵，可以分別選擇主時間單位和副時間單位；副單位也可以選擇「不使用」。還可以透過 `檢視 -> 時間顯示` 選單或 `時間軸顯示設定...` 對話框進行調整。主副單位同時顯示時分為上下兩行，中間用淡橫線分隔；副單位為 `不使用` 或與主單位相同時，只顯示主單位並垂直置中。

軌道介面左側的「軌道」標題列右側會即時顯示播放游標時間，格式為 `主單位 / 副單位`（副單位未使用時僅顯示主單位），並隨播放與時間格式切換自動重新整理。游標時間文字會按固定位數對齊（如 `1.1.000`、`0.000`），方便閱讀。

在標尺上移動滑鼠會顯示指標位置的時間提示；右鍵選單中的 `複製播放游標時間` 可以把目前游標時間以文字形式複製到剪貼簿。`時間軸顯示設定...` 還允許調整標尺標籤間距，以及開關軌道頭的播放游標時間顯示。

### 速度映射（變速 / 拍號 / 音階）

HiFiShifter 支援專案內的速度映射，允許在時間軸的不同位置定義不同的 BPM、拍號和音階。空白專案預設沒有速度映射資料；當你向專案中加入速度映射參數後，時間標尺會自動在時間單位下方多顯示一行速度映射行（用一條淡橫線與時間單位分隔），每段的速度、拍號與音階以各變化點處的標籤展示。當某段的起始標籤滾出畫面左側後，行最左側會出現一個與標籤同款的懸浮標籤，展示該段的參數；懸浮標籤隨水平捲動平滑切換，並與標籤互不遮擋，且與固定標籤提供完全相同的互動（雙擊進入輸入編輯狀態、右鍵彈出編輯視窗）。參數編輯器的標尺同樣會顯示速度映射行。

- 新增變化點：在時間標尺上按右鍵，透過選單中的 `在此新增速度/拍號/音階變化...` 在點擊位置建立變化點並開啟編輯對話框。在速度映射行空白處雙擊，則會在該位置直接建立變化點。
- 編輯變化點：雙擊速度映射行中的變化點標籤，可修改 BPM、拍號和音階。標籤雙擊後原地變為文字輸入框，可直接輸入 `120 4/4 - C / Am` 這類文字。右鍵標籤會直接彈出 `速度映射變化點` 編輯視窗。變化點標籤也可以直接拖動調整位置；標尺右鍵選單中的 `編輯此變化點...` / `刪除此變化點` 作用於游標所在的變化點，`清除速度映射` 可以清空（或僅隱藏）整個速度映射。
- 跟隨之前的拍號 / 音階：每個變化點的拍號可以選擇 `跟隨之前的拍號`，音階可以選擇 `跟隨之前的音階`。
- 初始點即專案基準：專案的全域 BPM、拍號（分子與分母）與音階都記錄在 0 位置的初始點處，並在速度映射行中顯示為類似 `120 4/4 - C / Am` 的文字。
- 格線與標尺：存在速度映射時，時間標尺刻度、小節/節拍標籤與背景格線都會在每個變化點處重新對齊、按各段速度與拍號分段計算。此外，每個速度映射變化點處都會顯示該點的時間數值，方便你直接讀出變化發生在哪個位置。
- 音階聯動：速度映射中的音階變化會作用於音高吸附（音階模式）、音階醒目提示、按度數移調 / 量化 / 均值量化等操作的 `專案音階` 選項，以及子軌道的 `度數差` 渲染。
- 匯入：將 MIDI 匯入為音高參考塊時，可在匯入對話框中啟用 `匯入為速度映射`，並分別選擇是否匯入速度、拍號與音階；匯入 REAPER 專案（.rpp）時，匯入對話框中的 `匯入速度映射（僅目前專案無速度映射時）` 選項預設勾選，會一併匯入專案級的速度與拍號變化。

### 音訊塊的速率與增益徽章

每個音訊塊標題列的右側會直接顯示兩個徽章：`速率`（形如 `x1.5`）和 `增益`（形如 `+3.0dB`）。最常用的這兩項調整因此不必開啟任何視窗。

- 雙擊徽章即可在原位置輸入數值，`Enter` 確認、`Esc` 取消，點擊音訊塊以外的區域也會自動儲存。
- 音訊塊左上角的音量旋鈕依然可以直接上下拖動，雙擊恢復為 0 dB。
- 音訊塊太窄時徽章會自動隱藏；把軌道拉高或水平放大後即可重新看到。

在速率徽章上按右鍵（或在音訊塊右鍵選單中選擇 `編輯播放速率...`），會開啟一個輕量浮層，適合需要按 BPM 換算或批次調整的場合：

- `拉伸倍率`、`原 BPM`、`新 BPM` 三個欄位互相關聯，始終滿足「倍率 = 新 BPM ÷ 原 BPM」。例如素材原本是 120 BPM、想改成 140 BPM，只需把 `新 BPM` 填成 140，倍率就會自動變成約 1.167；反過來修改倍率或原 BPM，其餘欄位也會自動換算。在欄位上捲動滑鼠滾輪可以按固定步長微調（倍率 0.1、BPM 1），按住 `精細調整` 修飾鍵（預設 `Ctrl`，macOS 為 `Command`）可進一步細調（倍率 0.01、BPM 0.1）。
- `時長` 欄位可以直接填寫目標時長，軟體會由時長反推出倍率。它的輸入很寬鬆，不必嚴格照著顯示格式輸入，例如 `1.2`（秒）、`0:01.5`（時:分:秒）、`1.2.500`（小節.拍.小單位）、`1.2/16`（帶格線）都能辨識，逗號也可以當作小數點使用。
- `自動調整音訊塊長度以適應新倍率`（預設開啟）：音訊塊時長隨倍率一起變化，也就是常說的「變速同時變調」。取消勾選則維持目前時長不變，只改變播放速率與音高。
- 選取多個音訊塊時，浮層底部會提示將同時套用到幾個音訊塊，一次即可批次調整。

### 靜音偵測

`靜音偵測` 用於自動找出音訊塊中「沒有聲音」的片段並批次切除，省去手動逐段切開再刪除的麻煩。選取一個或多個音訊塊後按右鍵，選擇 `靜音偵測...` 即可開啟。

對話框開啟後會自動預覽分析結果：被判定為靜音的區間會以紅色覆蓋顯示在音訊塊上，底部給出一共偵測到多少段、合計多長。修改參數會立即重新分析，確認無誤後點擊 `套用` 才會真正改動時間軸，並且可以復原。

- `偵測方式`：`RMS（能量）`（預設）按平均響度判斷，最常用；`峰值` 只看瞬時最大音量，適合處理夾雜爆音的間隙。
- `閾值 (dBFS)`：低於該音量才算靜音，預設 `-50`。數值調得越高，越容易被判定為靜音。
- `自適應閾值（估計噪底 + 6 dB）`：勾選後由軟體自動估算底噪並決定閾值，不必手動反覆嘗試。
- `最短靜音 (ms)`：短於該長度的安靜片段不會被切掉，預設 `120`。想切得更細就把它調小。
- `最短發聲 (ms，0 = 關)`：被靜音夾在中間、又短於該長度的聲音，會連同靜音一起刪除。預設關閉。
- `保留餘量 (ms)`：切口向靜音內側各多留一點，避免切掉字頭字尾，預設 `10`。
- `切口淡化 (ms)`：在切口兩端加一小段淡入淡出，防止爆音，預設 `5`。
- `處理方式`：
    - `切除並閉合間隙`（預設）：刪掉靜音，並把後面的內容整體前移補位，時間軸更緊湊。
    - `僅切除（保留間隙）`：刪掉靜音，但保留原本的時間空隙，方便之後再手動擺放。
    - `僅切分`：只在靜音的邊界切開，不刪除任何內容，適合想自己逐段處理的情況。
- `刪除全靜音音訊塊`：整段都是靜音的音訊塊直接刪除（預設開啟）。
- `偵測所有 Take（取聯集）`：把同一音訊塊下所有 Take 的靜音區間合併後一起處理，避免切換 Take 之後又冒出靜音。

在對話框中雙擊某個參數所在的列，可以把該參數重設為預設值。

### 關閉間隙

在軌道的空白區域按右鍵，選擇 `關閉間隙`，可以把點擊位置之後、同一軌道上的音訊塊整體向前挪動，消除它們之間的空隙，使其首尾相接。點擊位置之前的內容維持不動。如果點擊位置之後該軌道已經沒有音訊塊，該選單項目會變為不可用。

### 節拍器

節拍器在播放時提供穩定的打點參考，方便對節奏、跟唱或者核對變速。

- 開關：主工具列中位於 BPM 左側的節拍器按鈕，左鍵按一下即可開關，預設快捷鍵為 `K`。
- 在節拍器按鈕上按右鍵可以開啟設定：
    - `音量`：節拍器音量，除了拖動之外也支援滾輪調整，按住 `精細調整` 修飾鍵（預設 `Ctrl`，macOS 為 `Command`）可細調。
    - `細分`：決定打點密度。`跟隨格線`（預設）按目前格線細分發聲，例如格線為 `1/8` 時每半拍一聲，附點與三連音格線同樣跟隨；`僅每拍` 只按 BPM 每拍一聲；`僅小節首` 只在每小節的第一拍發聲，最為稀疏。
    - `音色`：可選 `嗒聲`（預設）、`木魚`、`蜂鳴`。
    - `強調重拍`：開啟後小節首拍的聲音更重，便於聽清強弱規律。
- 專案中存在速度映射（變速）時，節拍器會自動跟隨每一個 BPM 變化點，不會出現打點與音樂錯位的情況。

## 四、檔案瀏覽器

檔案瀏覽器允許你開啟特定的資料夾，按條件搜尋和排序其中的音訊與視訊媒體檔案，並拖曳匯入到 HiFiShifter 的軌道介面。視訊檔以紫色圖示顯示，音訊檔以藍色圖示顯示。搜尋支援正規表示式。當點擊媒體檔案時，會自動播放試聽（視訊只試聽其音訊軌）。可以按住 `Ctrl` 和 `Shift` 鍵進行檔案的多選。左鍵拖曳檔案可以將一個或多個媒體檔案批次地跨時間加入到時間軸中。右鍵拖曳檔案可以彈出 `依序排列於同一軌道` / `分配到多條軌道` 的選單。`分配到多條軌道` 允許你將多個媒體音訊塊垂直地跨多個軌道加入到時間軸中。

當焦點為軌道區域時，按下快捷鍵 `Ctrl + F` 可以開啟快速搜尋視窗。這個是檔案瀏覽器功能的簡易版，允許你快速按條件搜尋並試聽資料夾內的音訊/視訊媒體檔案（視訊只試聽其音訊軌），最終加入到時間軸上。

## 五、參數編輯器

參數編輯器是 HiFiShifter 最核心的功能之一，允許你編輯當前選中軌道的各種參數。

要啟用對軌道的參數編輯功能，必須先按下對應軌道的合成按鈕 `C`，並等待音訊分析工作完成後，即可開始進行參數編輯。HiFiShifter 採用離線渲染，每次編輯完參數後，需等待參數重新渲染完畢，才能夠進行試聽。

參數編輯器標題左側的 `同步時間軸檢視` 按鈕（連結圖示）可以啟用或停用參數編輯器與軌道檢視的水平同步。啟用後（預設），兩者的水平位置與縮放完全一致並雙向連動：在任一檢視中捲動或縮放，另一個檢視都會同步跟隨；啟用瞬間以軌道檢視為基準對齊參數編輯器。由於軌道檢視左側有軌道頭區域，參數編輯器會自動補償左右偏移，使格線與時間軸刻度在兩個面板中按同一螢幕位置對齊。停用時，兩者保持獨立縮放與捲動。

### 1. 演算法和參數

目前版本的 HiFiShifter，相容以下 3 種音聲修音演算法和參數：

- `PC-NSF-HiFiGAN`（介面演算法清單中顯示為 `nsf-hifigan`）：OpenVPI 開源的歌聲特化的 hifigan 聲碼器，也是 HiFiShifter 預設的演算法。
    - `音高`：允許調整音聲的音高。
    - `共振峰偏移`：允許調整音聲的共振峰偏移。
    - `氣聲音量`：允許調整音聲的氣聲音量，該參數基於 VR-hnsep 模型。
    - `張力`：允許調整音聲的張力。
    - `音量`：允許調整音聲的音量。
    - `動態`：允許調整音聲的響度。
    - `聲相`：允許調整音聲的聲相。
    注意：`氣聲音量` 與 `張力` 都需要先開啟工具列上的 `氣聲分離` 開關。開啟會增加額外的渲染成本（首次每個音訊塊都要做一次分離，可能較慢）；關閉時完全不進行分離，這兩個參數會被置灰、其曲線保持可見但不可編輯，也不參與合成。此外，`共振峰偏移`、`氣聲音量`、`張力` 這三個參數還要求所在軌道群組的合成開關（`C`）處於開啟狀態，否則同樣會被置灰。
- `World`：開放原始碼的高品質語音分析與合成演算法。
    - `音高`：允許調整音聲的音高。
    - `音量`：允許調整音聲的音量。
    - `動態`：允許調整音聲的響度。
    - `聲相`：允許調整音聲的聲相。
- `VsLib`（介面演算法清單中顯示為 `vslib`）：VocalShifter 官方發佈的音聲解析與合成庫。VsLib 演算法僅在 Windows x86_64 版本中可用。
    - `音高`：允許調整音聲的音高。
    - `共振峰偏移`：允許調整音聲的共振峰偏移。
    - `氣聲強度`：允許調整音聲的氣聲強度。
    - `音量`：允許調整音聲的音量。
    - `動態`：允許調整音聲的響度。
    - `聲相`：允許調整音聲的聲相。
    - `合成模式`：允許調整音聲的合成模式演算法，上述某些參數可能會在特定演算法無效。
        - `單聲道`：VocalShifter 的 M 演算法，單音樂器演算法。
        - `單聲道（共振峰）`：VocalShifter 的 V 演算法，單音人聲演算法。
        - `合唱`：VocalShifter 的 P 演算法，和聲演算法。

一條軌道只能使用一種演算法，如果想同時使用多種演算法，請分軌。

軌道組共用一套參數，子軌道的各種參數繼承於根軌道。特別地，對於軌道組中的子軌道來說，額外有 `音分差`、`度數差` 與 `共振峰差` 這 3 個參數，可以便捷地調整當前子軌道相對於根軌道的音高與音色變化。其中，`度數差` 參數參考的音階標準是當前專案的音階設定。在參數編輯器工具列中，子軌道的 `音分差` / `度數差` 收納在 `音高` 按鈕的下拉選單中，`共振峰差` 收納在 `共振峰偏移` 按鈕的下拉選單中，`動態` 收納在 `音量` 按鈕的下拉選單中。

使用選擇工具選擇一段 `音高` 參數並複製後，也可以貼到 `音分差` 或者 `度數差` 參數，這樣會自動計算合適的 `音分差` 或者 `度數差` 參數並應用。

### 2. 選擇工具

選擇工具允許你選擇一段參數線，進行拖曳操作，或者右鍵開啟上下文選單，以進行參數的調整。

常用快捷鍵一覽：

- `Ctrl + C`：複製
- `Ctrl + X`：剪下參數幀（把選取的參數線複製進剪貼簿並清空，可再貼到別處）
- `Ctrl + V`：貼上
- `Ctrl + Z`：復原
- `Ctrl + Shift + Z` / `Ctrl + Y`：重做（macOS：`⌘ + ⇧ + Z` / `⌘ + Y`）
- `Ctrl + A`：全選

- `BackSpace`：初始化（把選區恢復為預設狀態，不會寫入剪貼簿）
- `-` / `=`：對目前音訊塊範圍內的整條參數線進行下移/上移
- `[` / `]`：對選中範圍內的參數線進行下移/上移

在上面這兩組移位快捷鍵中，`-` / `=` 移動的是整個音訊塊範圍內的參數線，`[` / `]` 只移動目前選取的那一小段。兩者都支援三種幅度，方便從「粗調」到「細修」一次到位：

| 幅度               | 音訊塊範圍                | 選取範圍                  | 音高參數的步長       |
| ------------------ | ------------------------- | ------------------------- | -------------------- |
| 預設               | `-` / `=`                 | `[` / `]`                 | ±1 半音              |
| 大幅（加 `Shift`） | `Shift + -` / `Shift + =` | `Shift + [` / `Shift + ]` | ±12 半音（一個八度） |
| 微調（加 `Ctrl`）  | `Ctrl + -` / `Ctrl + =`   | `Ctrl + [` / `Ctrl + ]`   | ±1 音分              |

按住不放時會先執行一次，短暫停頓後自動連續重複，便於連續微調。除音高外的其他參數也有對應的三段步長（預設約為量程的 2.5%，大幅約 12.5%，微調約 0.25%）。以上快捷鍵均可在 `選項 -> 鍵盤快捷鍵...` 的 `參數編輯器` 分組中修改（macOS 上 `Ctrl` 對應 `Command`）。

左鍵拖曳選中的參數線，可以對其進行垂直、水平或自由的拖曳移動操作。拖曳方向取決於當前的 `拖動方向` 設定。左鍵拖曳時，按下右鍵（或按快捷鍵 `D`），可以快速切換拖曳方向。

拖曳到檢視左右邊緣附近時，參數編輯器會自動橫向捲動（選擇工具只在指標移動時逐次推進，指標停在邊緣不動不會持續捲動），詳見[繪製工具](#3-繪製工具)章節。

右鍵拖曳選中的參數線，可以調整它的幅度：越向上拖曳幅度越大，越向下拖曳幅度越小，拖到最低相當於完全抹平。對音高參數來說，幅度調整只會增強或減弱顫音一類的細節，音符的整體輪廓與音程保持不變，因此不會出現「整條音高被抬高」的情況。拖曳過程中會即時預覽結果。

右鍵參數編輯器介面內，可以開啟上下文選單，允許對選中的參數線執行各種處理操作，包括 `初始化`、`按指定音分移調...`、`按指定度數移調...`（僅音高參數顯示）、`設定到...`、`平均化...`、`平滑化...`、`新增顫音...`、`量化...`、`均值量化...` 等；當參數為音量或動態時，還會出現 `轉換為動態` / `轉換為音量`（兩者為響度等效換算，不是簡單複製）；當參數為音高時，還有 `儲存為音高參考塊` 與 `匯出為 MIDI`。

這些處理操作都有預設快捷鍵：`按指定音分移調` 為 `Ctrl + F`、`按指定度數移調` 為 `Ctrl + I`、`設定到` 為 `Ctrl + 0`、`平均化` 為 `Ctrl + E`、`平滑化` 為 `Ctrl + M`、`新增顫音` 為 `Ctrl + B`、`量化` 為 `Ctrl + P`、`均值量化` 為 `Ctrl + Q`，均可在 `選項 -> 鍵盤快捷鍵...` 中修改。

`新增顫音` 會開啟一個**套用彈窗**：左列選擇預設（每列都帶該預設的波形縮圖），右側把**選區裡的真實曲線**套上該預設畫出來 —— 虛線是原曲線，實線是套用後的結果，一眼能看出顫音疊在哪條音高運動之上。預覽右上角可以選擇 `擺放方式`（決定顫音圍繞什麼擺動，預設 `起點 → 終點`；選擇 `保持現有曲線` 可在既有曲線上疊加顫音而不改動原有的音高運動）。彈窗裡還有深度 / 速率兩個快捷旋鈕，改的是本次套用的本地副本 —— `套用` 只把這份參數交給編輯管線，**不寫庫**（想留存就按 `儲存`）。沒有選區時會先隱式全選整條參數線。頁腳左側的 `從選區提取顫音預設` 作用於目前選區，把其中既有的顫音反推成一個預設。

按住 `Alt`，可以為選定的參數線進入四點編輯模式。類似於 VocalShifter 中的同類型功能，拖曳 4 個點可以對當前參數線進行彎曲。

按住 `Alt`，拖曳選擇區域邊緣，可以對選擇區域內的參數線進行拉伸。

按住多選區修飾鍵（預設為 `Ctrl`，macOS 上為 `Command`，可在 `選項 -> 鍵盤快捷鍵...` 的 `參數編輯器修飾鍵` 分組中修改），可以在選擇工具下建立**多個選取區**：按住拖曳會**追加**一段選取區（與既有選取區重疊或相接時自動合併為一段），按住點擊既有選取段則**取消該段**。多段選取區在時間上彼此獨立 —— 複製、剪下、貼上、移調、設定到、平均化、平滑化、量化、均值量化、幅度調整、形變、拖曳與邊緣拉伸等所有操作都**逐段獨立**執行，段與段之間未被選取的部分始終保持原樣，不會被填充、壓縮或合併。例如複製 `0~1s` 與 `2~3s` 兩段後選取 `0~3s` 再貼上，只有 `0~1s` 與 `2~3s` 被寫入，`1~2s` 保持原值；反過來，複製 `0~3s` 後選取 `0~1s` 與 `2~3s` 再貼上，第一段得到剪貼簿開頭的 1 秒、第二段得到剪貼簿末尾的 1 秒，`1~2s` 既不寫入也不顯示剪貼簿預覽。

### 3. 繪製工具

繪製工具允許你自由手繪參數線。預設快捷鍵 `F8`。

左鍵拖曳可以進行自由或者水平的參數線繪製操作。拖曳方向取決於當前的 `拖動方向` 設定。左鍵拖曳時，按下右鍵（或按快捷鍵 `D`），可以快速切換拖曳方向。

拖曳到檢視左右邊緣附近時，檢視會自動橫向捲動，越靠邊捲得越快，方便一筆畫到看不見的地方。繪製、直線與顫音工具在按住拖曳期間連續捲動；選擇工具只在指標移動時逐次推進，指標停在邊緣不動不會持續捲動。垂直方向不會自動捲動。該行為無需設定，也不能關閉。

右鍵拖曳可以重置當前參數線。

在參數編輯器工具列的繪製類型工具按鈕上**右鍵**，可以在這三種繪製工具之間切換：繪製工具、直線工具、顫音工具（選單裡同時標出各自的快捷鍵）。工具列上那個按鈕顯示的就是目前選中的那一個，左鍵點擊可以直接啟用它。

參數編輯器共四種工具手勢：選擇工具（`F7`）、繪製工具（`F8`）、直線工具（`F9`）、顫音工具（`F10`）。按 `Tab` 可以在選擇工具與上一次用過的繪製類型工具之間來回切換。**目前使用的工具會被記住**，下次啟動程式照舊。

### 4. 直線工具

直線工具畫一條從起點到終點的直線。預設快捷鍵 `F9`。

它就是「顫音工具 + 直線預設」—— 所以下一節裡講的所有手勢（滾輪調深度與速率、`,` `.` 與滑鼠側鍵換預設、雙鍵重置、讀數氣泡）在直線工具上**同樣可用**；唯一的區別是起手時用哪個預設：直線工具固定從「直線」起手，顫音工具從你選中的那個預設起手。

左鍵拖曳可以進行自由或者水平的直線繪製操作。拖曳方向取決於當前的 `拖動方向` 設定。左鍵拖曳時，按下右鍵（或按快捷鍵 `D`），可以快速切換拖曳方向。

拖拽中把深度調起來時，畫出來的就不再是直線了 —— 這是刻意的：直線工具是「從零顫音起手」，這一筆要多少顫音由你自己決定；反過來，用顫音工具時按雙鍵重置（或輪轉切到「直線」預設）會直接切到直線工具。

右鍵拖曳可以重置當前參數線。

### 5. 顫音工具

顫音工具在起點與終點之間疊一層顫音。預設快捷鍵 `F10`。

左鍵拖曳可以進行自由或者水平的顫音繪製操作。拖曳方向取決於當前的 `拖動方向` 設定。左鍵拖曳時，按下右鍵（或按快捷鍵 `D`），可以快速切換拖曳方向。

左鍵拖曳時，捲動滑鼠滾輪可以調整顫音的**深度**，按住修飾鍵 `Alt` 並捲動滑鼠滾輪可以調整**速率**。按住修飾鍵 `精細調整`（預設為 `Ctrl`）可以在捲動滑鼠滾輪時進行微調。拖拽過程中，指標旁會浮出一個讀數氣泡：**第一列是參數值**（這一筆落在什麼值上），**其下是顫音狀態**（目前預設、深度與速率）。兩者合成一個氣泡而不是各彈一個 —— 否則後彈出的那個會擋住前一個。整個氣泡由 `選項 → 彈出顯示參數` 開關控制，關掉後不顯示。深度可以調到**負值**：負深度等於把波形整體反相（起點先往下擺），繼續往負方向調不會在 0 處卡住。

**深度的單位、一格走多少、最大能到多少，都按目前參數類型決定**，因為同一個深度值落在不同參數上是完全不同的量：

- **音高類**（音高、子軌音分差 / 度數差、共振峰偏移）：深度以**音分**計，一格 24 音分。上限取工具的深度上限（±1200 音分）；若參數自己的量程更窄，則以量程為準 —— 再大只會被寫入口鉗平，波形頂部會變成一條直線，並不「更顫」。
- **增益類**（動態、音量、氣聲音量）：深度以**百分比**計，一格 2%。100% 即把增益擺到滿幅。
- **其他值域類**（聲相、張力、氣聲強度）：深度同樣以**百分比**計 —— 說的是「占該參數滿擺幅的幾成」，一格 2%，100% 即鋪滿整個值域。於是聲相上的 `30%` 與氣聲強度上的 `30%` 是同一量級的深淺，不必再換算回各自的裸數字。

每格的步長都是該參數**滿擺幅的 1/50**，所以「從零調到滿幅」在任何參數上都大約是 50 格。參數若沒被描述符覆蓋，程式會按內建量程兜底，不會退化成「捲不動」或「一格跳到底」。

拖拽期間可以隨時切換顫音預設：

- **滑鼠側鍵**：前進鍵（前側鍵）切到下一個預設，後退鍵切到上一個預設；
- **鍵盤**：`,` 切到上一個預設，`.` 切到下一個預設（可在 `選項 → 鍵盤快捷鍵...` 中改綁）。

預設決定波形（正弦 / 三角 / 上升鋸齒 / 下降鋸齒 / 方波 / 梯形 / 顫指台階 / 手繪）、包絡（漸入、漸強、漸出）與速率漸變；深度與速率是本次拖拽自己的調整。拖拽期間的深度 / 速率微調**不會**改寫預設，也不會留到下一次起手 —— 預設只能在預設管理器裡修改。但**切換預設是持久的**：拖拽中按側鍵或 `,` `.` 換預設，等於換了目前使用的預設（會記進設定，重開也是它）。

輪轉時若落在 `直線` 預設上，會直接**切到直線工具**（直線工具就是「顫音工具 + 直線預設」）；從直線工具輪轉出去，則切回顫音工具並換到相鄰的預設。切換工具**不會**改動你記住的顫音預設 —— 畫完直線切回來，還是你原來挑的那個音色。

切換時深度與速率的歸屬**分別**判斷：調過振幅就沿用振幅，調過速率就沿用速率；沒調過的那個取新預設自帶的值 —— 換的是音色，你沒碰過的那一項自然該聽新預設的。

拖拽中還有幾組「雙鍵」手勢，用來一鍵回到已知狀態：

- **同時按下兩個預設切換鍵**（預設 `,` `.`），或**同時按下滑鼠的兩個側鍵**：切到直線工具（於是直接畫出一條直線），並清空本次手勢記錄的振幅與頻率調整。
- **同時按下振幅的增大 / 減小鍵**（預設 `↑` `↓`），或在滾輪處於振幅調整狀態（未按住頻率修飾鍵 `Alt`）時**按下滑鼠中鍵**：把振幅退回預設自帶值，並清空振幅調整記錄。
- **同時按下頻率的增大 / 減小鍵**（預設 `←` `→`），或在滾輪處於頻率調整狀態（按住 `Alt`）時**按下滑鼠中鍵**：把頻率退回預設自帶值，並清空頻率調整記錄。

「清空記錄」的效果是：之後切換預設時，被清掉的那一項不再沿用你的調整，而是取新預設自帶的值。

縮放劇烈變化的參數時，拖拽的速率始終以 Hz 計，因此同一個預設不論拖多長，聽感上的快慢都一樣。

右鍵拖曳可以重置當前參數線。

### 6. 顫音預設

顫音預設是一組可重複使用的顫音參數，從 `選項 → 顫音預設管理...`、參數編輯器工具列的繪製類型工具按鈕**右鍵 → 顫音預設**（二級選單，列出全部可用預設，底部是「管理預設...」），或 `新增顫音` 套用彈窗頁腳的 `從選區提取顫音預設` 開啟。**預設使用的預設是 `自然`** —— 切到顫音工具時想要的是聽得出來的顫音，而「零顫音」那條線現在由直線工具負責。出廠預設裡 `直線` 仍排在清單首位，但它是**直線工具在預設序列裡的位置**：在清單裡選中它，等於切到直線工具。

預設入口那一列顯示的是**顫音工具**目前使用的預設 —— 即使你現在用的是直線工具，它也照舊顯示那個值，因為那正是你切回顫音工具時會用到的音色。清單裡打鉤的也是它。

預設管理器最上方是**波形預覽**（整行寬度，且不參與捲動 —— 調下面的參數時它始終看得見，不會捲出視野），參數一改立刻重畫；其下左側是預設清單、右側是參數編輯器。縱向刻度是一條**固定的**標尺：開啟對話框或切換預設時，按該預設的幅度一次性擬合到一個檔位（波形通常占畫布六成上下），此後編輯期間不再變動。這樣波形的高度就等於深度，配合軸上的 `+N / −N` 刻度標籤可以直接讀出幅度大小；調深度時看到的是波形實打實地長高變矮，而不是整幅被重新縮放（那樣只會「抖一下」，讀不出大小）。把波形拖到超出量程時，點預覽卡片上的 `適應` 重新擬合即可。預覽卡片的播放按鈕可以用**合成音色試聽**目前預設 —— 與鋼琴卷簾琴鍵同一套音色，不需要跑聲碼器，點一下立即出聲，再點一次停止；聽到的就是畫的那條曲線（含漸入、漸強與不規則度）。系統預設也可以試聽。

預覽畫布不只是看的：拖動**左緣 / 右緣的小方塊手柄**可以改漸入 / 漸出時長（游標變成左右縮放），在波形主體上按住拖動可以改起始相位（左右）與深度（上下）。兩個手柄都能一直拖到顫音線的另一端 —— 漸入拉滿就是整條線由弱到強；兩邊都拉滿時，兩段增益相乘，中間會平滑地凹下去。深度是**與畫布 1:1** 的 —— 標尺固定（見上），所以「把波峰拖到中線」就是「把深度拖到 0」，深度小的時候每像素走過的音分也少，不會一拖就飛。按住「精細調整」修飾鍵（預設 `Ctrl`，macOS 上為 `Command`）時位移縮到 1/5，適合一像素一像素地捏；修飾鍵可以在拖拽途中隨時按下或鬆開，當前的拖拽不會被中斷（數值不會跳回去），只是此後的每一格走得更細或更粗。所有手勢改的都是目前草稿，點 `儲存` 才寫回預設；系統預設的畫布與表單一樣唯讀。

`儲存` **不會關閉視窗** —— 你可以先存一版、接著繼續調，或再切到別的預設。編輯到一半切到另一個預設時，目前改動會**自動寫回庫**（與按 `儲存` 同一條路徑），不會因為換了個預設就丟掉。庫裡多出一條自訂預設只有兩個時機：你按了 `複製為自訂`，或者你對系統預設動了手（見上）。頁腳的 `關閉` 按鈕（或 `Esc`）退出視窗。

頁腳的 `匯出` 把目前選中的預設存成 JSON 檔案，`匯入` 從檔案讀入：重複的預設自動跳過（同一檔案匯入兩次不會翻倍），匯入完成後會選中新預設並顯示一條回饋；拿錯的檔案（例如外觀主題的 JSON）會被拒收並說明原因。匯入的預設永遠是新的自訂預設，即使檔案裡帶著系統預設的名字。

可調的參數分四組：

- **波形**：形狀（正弦 / 三角 / 上升鋸齒 / 下降鋸齒 / 方波 / 梯形 / 顫指台階）與偏斜。偏斜的含義隨形狀變化：三角波是上升段占比，方波類是占空比。這是讓人聲顫音聽起來自然的最重要的一個參數 —— 真人顫音的上升與下降並不對稱。形狀右側的 `手繪...` 按鈕展開**單週期編輯畫布**：按住拖動即可逐格畫出這一個週期的波形（初值取自目前形狀，改形比從零畫順手），`平滑` 點一下修順一次、**按住則連續修順**（與鍵盤的自動重複同一套手感）。復位有兩個按鈕：`重設為舊形狀` 回到進入手繪前的波形（可能是一段提取或手繪出來的表），`重設為{形狀}` 把表格重新取樣成形狀下拉框裡目前選中的那個形狀 —— 手繪畫歪了想從頭來、或把提取出來的波形換成規整的正弦，都靠它。手繪過程中改變形狀不會退出編輯器，改完即時套用。表格首尾相接，接縫處不會出現折角。
- **深度**：幅度（按目前參數的類型顯示：音高與音分類參數是音分，動態等增益參數與其餘值域參數都是**占滿擺幅的百分比**）、漸強（起點 / 終點的深度倍率）、基線偏移、不規則度。不規則度用確定性的噪聲抖動相位與深度，做出「搖曳」而不是機器味；旁邊的骰子按鈕可以**換一種抖動圖案**（種子是預設欄位，同一預設每次渲染 / 試聽 / 提交都完全一致）。不規則度為 0 時沒有任何圖案可換（噪聲被整個乘掉了），骰子按鈕會停用並說明原因。
- **速率**：按頻率（Hz）或按整段週期數計量、末端速率（漸變到句尾快或慢）、收尾對齊整數週期（讓音符乾淨地落回基準線）。
- **包絡**：漸入 / 漸出的時長與曲線形狀（時長以整條顫音線為上限，拉到滿即全程漸入 / 漸出）、起始相位。

預設參數不含 `擺放方式`：它是**套用時**的設定，在 `新增顫音` 彈窗預覽的右上角選擇（見前文），決定顫音圍繞什麼擺動 —— `起點 → 終點`、`起點水平`、`終點水平`、`全程均值`，或**保持現有曲線**（在既有曲線上疊加，保留原本的音高運動）。

系統預設本身是唯讀的（出廠定義永遠可復原），但它的參數可以隨便調：**你一動手，程式就立刻把「出廠定義 + 你的這次改動」另存為一份自訂預設**，並把編輯焦點切到那一份上（清單裡當場多出一列，名字預填成 `自然 2` 這樣的編號，清單也會自動捲到它那裡）。於是「編輯系統預設會產生一個自訂預設」是你當場看得見的事，而不是等你切走時才在背後多出一條。原先那條系統預設始終原樣保留。**把一條預設設為目前使用**有兩個看得見的入口：點清單列最左邊的圓點（實心 = 目前使用中，空心 = 可切換；滑鼠懸停會寫明），或點編輯器頂部那個寫著 `設為目前使用` 的按鈕 —— 後者作用於你正在編輯的那一條，已經是目前使用時會變成 `目前使用中` 並停用。雙擊清單列是同一件事的快捷方式。

點擊清單項只是選中它進行編輯，**不會**把它設為目前使用 —— 調一個還沒定稿的預設不應該順帶改掉你現在要畫的音色。

每列右側有一個**啟用 / 停用**按鈕（眼睛圖示）：停用後的預設不出現在參數編輯器工具列的預設清單裡，拖拽中按快捷鍵或滑鼠側鍵循環切換時也會**跳過**它。系統預設與自訂預設都可以停用 —— 比如你只用得上其中兩三條，把其餘停掉，工具列清單與循環切換就乾淨了。停用只影響「怎麼挑預設」：預設本身仍可編輯，也仍然可以作為目前使用的預設（停用目前正在用的那一條是允許的）。

**右鍵點擊**清單列會開啟該預設的上下文選單：`啟用 / 停用`、`設為目前使用`、`重新命名`、`上移 / 下移`、`複製為自訂`、`刪除`（系統預設的刪除與重新命名不可用，只能刪副本）。`重新命名` 會在該列原地展開一個輸入框（覆蓋在名字上），按 Enter 或點擊別處提交、`Esc` 取消。懸停列上會顯示該項目自訂的氣泡，內容是該預設的說明與摘要 —— 摘要裡的第一項是波形形狀（取樣表會報出最接近的形狀名，都不像時寫 `手繪`）。

`新增`、`複製為自訂`、`從選區提取`、`匯入` 之後，清單都會自動捲到新出現的那一條上 —— 新預設附加在清單末尾，清單一長就落在視野之外。

預設清單可以**拖拽排序**：按住某一列上下拖，越過相鄰列的中線即換位，鬆手落盤；拖動時被拖的列會壓暗，落點處有一條高亮指示線；拖到清單上下邊緣時清單會**自動捲動**（越靠邊越快），因此預設很多時也能一次拖到位。系統預設與自訂預設各自成組、各排各的（不會互相穿插）。鍵盤使用者可以用右鍵選單裡的 `上移 / 下移` 完成同樣的調整。

**從選區提取顫音預設**：已經畫好一段滿意的顫音後，選中它，在 `新增顫音` 套用彈窗頁腳點擊 `從選區提取顫音預設`。程式會去掉音高本身的走勢，用自相關測出週期，把殘差折疊成一個平均週期作為波形，並測出深度、漸入漸出與不規則度，直接產生一個可繼續微調的預設。折疊出的波形會經過一次低通（只保留最低的幾個諧波），因此結果是一條**光滑**的曲線，而不會把錄音裡的觀測噪聲一起存進去、看起來坑坑窪窪。它適用於任何參數。

### 7. 音高吸附

當使用各種編輯工具編輯音高參數時，音高吸附允許你將音高編輯吸附至半音或者音階。按住 `Shift` 鍵可以臨時切換是否吸附。

音高吸附功能預設關閉。對音高吸附按鈕按下右鍵可以進入音高吸附設定選單，允許你調整量化單位和容差。

- `量化單位`：分為半音和音階這兩種類型（預設半音）。其中，當量化單位為音階時，參考的吸附音階為當前專案的音階設定。
- `容差`：允許你調整吸附的容差範圍（預設 0 音分），容差範圍內的音高編輯，不進行吸附處理；容差範圍外的音高編輯，會被吸附到離它最近的容差邊緣。

比如，如果你想要製作人聲和聲效果，你可以按照以下步驟進行操作：

1. 確認並設定好專案音階；
2. 啟用音高吸附，並將量化單位設定成音階；
3. 啟用音階醒目提示功能，以便於觀察移調度數；
4. 用選擇工具進行垂直拖曳。

或者，也可以使用軌道組的子軌道功能的 `音分差` 和 `度數差` 參數，按照以下步驟進行操作：

1. 確認並設定好專案音階；
2. 將和聲軌道的軌道頭拖曳到主唱人聲軌道上，組成軌道組，主唱人聲軌道為根軌道，和聲軌道為子軌道；
3. 將參數編輯器切換到和聲軌道的 `度數差` 功能，並按需求繪制度數線。`音分差` 與 `度數差` 參數的編輯也支援音高吸附功能，能分別吸附到整數半音以及整數度數，可以加以利用。

即可快速製作出按度數移調的和聲效果。類似地，將參數編輯器切換到子軌道的 `共振峰差`，即可繪製逐幀共振峰偏移曲線，在支援 `共振峰偏移` 的演算法（NSF-HiFiGAN / vslib）下製作出帶音色差異的和聲。

### 8. 音高參考塊

軌道上的音高參考塊是一種特殊的音訊塊，可以在時間軸上儲存一段音高線。

音高參考塊可以透過以下途徑創建：

- 透過 `檔案` 選單、拖曳 MIDI 檔案到軌道介面，或在參數編輯器的音高參數下直接拖放 MIDI 檔案來匯入。這會彈出一個 MIDI 匯入彈窗。
    - MIDI 檔案：允許你選擇匯入的 MIDI 檔案。也支援解析其他 DAW 輸出到系統剪貼簿中的 MIDI 資料。目前已經過測試，能夠使用系統剪貼簿進行 MIDI 資料傳輸的 DAW 有 Reaper 和 FL Studio。
        - Reaper：在 Reaper 的 MIDI 編輯器中，選中音符，並複製，即可將選中的音符資料匯出至系統剪貼簿中，供 HiFiShifter 讀取。注意，由於 Reaper 的剪貼簿音符資料並不包含 BPM 資訊，匯入時，可以使用目前專案 BPM，或者自行指定。
        - FL Studio：在 FL Studio 的鋼琴窗介面中，點擊鋼琴窗左上角的小三角展開選單，選擇 `檔案` -> `複製到 MIDI 剪貼簿`，即可將目前通道的所有音符匯出至系統剪貼簿中，供 HiFiShifter 讀取。
    - 軌道選擇區：允許你選擇即將匯入的 MIDI 軌道。
    - 匯入目標：可以選擇匯入為 `音高參考塊` 或 `音高參數`（直接寫入目前選取軌道的音高線）。
    - 匯入位置：可以選擇 `工程開頭`、`播放頭位置` 或 `選擇區域範圍`。
    - 將 MIDI BPM 匯入為專案 BPM：啟用後，將 MIDI 的初始 BPM 匯入為專案 BPM。
    - 音符 BPM：允許設定將要匯入的音符的 BPM 映射方式。
        - MIDI 自身 BPM：不進行 BPM 映射，直接以 MIDI 自身 BPM 匯入。
        - 目前專案 BPM：將音符 BPM 映射到目前專案 BPM 後再匯入。
        - 指定 BPM：將音符 BPM 映射到指定 BPM 後再匯入。
    - 多軌合併：若啟用，則自動將選擇的所有軌道和所有音符進行合併，取音高較高的音符作為音高線參數，最終只匯入 1 個音高參考塊。若停用，將嘗試拆分各種軌道和音符，確保所有音符都能夠匯入為音高線參數，最終可能會縱向匯入多個音高參考塊。
    - 填補音符之間的空隙：啟用後，自動填補兩個相鄰音符之間的空隙。另有 `關閉開頭空隙` 選項，用於去掉匯入內容開頭、第一個音符之前的空隙。
    - 匯入為速度映射：啟用後，可以分別選擇是否把 MIDI 中的速度（Tempo）、拍號與音階匯入為專案的速度映射變化點。
- 透過 Reaper 專案或者 Reaper 剪貼簿匯入軌道上的 MIDI 物件。
- 透過 VocalShifter 專案或者 VocalShifter 剪貼簿匯入軌道上的 MIDI 音訊塊。
- 右鍵常規的音訊塊，在彈出的上下文選單中選擇 `轉換為音高參考塊`。這會將該常規音訊塊的原始音高線轉換為新的音高參考塊的音高線。
- 在參數編輯器中，編輯音高參數時，使用選取工具，選取一段區域並右鍵，在彈出的上下文選單中選擇 `儲存為音高參考塊`，可以將選取範圍內的音高線儲存為新的音高參考塊。

音高參考塊有以下常見的用法：

- 放置在軌道上，作為一般的音訊塊，供其他有常規音訊塊的軌道進行音高的參考。在其他軌道上，可以使用參數編輯器的 `參考軌道群組` 功能檢視這條軌道，以展示其音高線。
- 當音高參考塊被放置在軌道群組的根軌道時，可以改變目前軌道群組的音高處理邏輯，將音高參考塊的音高線覆蓋掉這一段的原始音高線。這會影響以下幾個場景：
    - 若軌道群組中有某段音高線未被進行過編輯，則其音高參數會直接被音高參考塊的音高線覆蓋，並觸發音訊音高的重新算繪。
    - 當使用 `初始化` 相關功能，比如在參數編輯器中使用繪製工具進行右鍵拖曳操作時，初始化後的音高線使用的是音高參考塊的音高線資料，而非軌道群組子軌道內的音訊塊的原始音高。
    - 如果音高參考塊被靜音，則軌道群組處理音高時，不會參考該音高參考塊。

選中音高參考塊，在右鍵的上下文選單中執行 `更新音高`，可以將音高參考塊範圍內的現有音高參數更新到音高參考塊中。

### 9. 其他功能

參數編輯器的其他一些便捷功能：

- `音階醒目提示`：位於工具列中。按當前專案的基準音階，在鋼琴卷簾背景中醒目提示屬於音階的琴鍵列，便於觀察音高與調式的關係。
- `拖動方向`：位於工具列中。控制左鍵拖曳參數線時的移動方向（`自由` / `僅 X` / `僅 Y`），與拖拽中按 `D` 鍵切換等效。
- `剪貼簿預覽`：位於 `檢視` 選單中。當使用選擇工具複製參數線資料後，可以在選擇區域內即時展示剪貼簿參數線資料，便於貼上定位。
- `彈出顯示參數`：位於 `檢視` 選單中。當滑鼠靠近參數線，或者正在執行繪製編輯操作時，展示參數值。
- `鎖定參數線`：位於工具列中。在拖動軌道上的音訊塊時，是否同步挪動該音訊塊在軌道上對應的所有參數線。HiFiShifter 的所有參數線編輯功能基於軌道的，如果不鎖定參數線，則已編輯的參數線不會跟隨音訊塊進行移動。
- `平滑度`：位於工具列中。編輯參數時，是否自動進行平滑處理，以及自動平滑處理的強度。
- `參考軌道群組`：位於工具列中。當參數為 `音高` 時，允許你選擇其他軌道，將其他軌道群組的音高線，作為參考，展示在音高參數編輯視窗內。
- `匯入 MIDI`：位於工具列中。當參數為 `音高` 時，允許你選擇 MIDI 檔案，並將其中單軌或多軌的音符匯入為音高線；也可以直接把 MIDI 檔案拖放到參數編輯器中。
- `副參數疊加`：每個參數按鈕右側都有一個眼睛圖示，開啟後可以在編輯目前參數的同時，以副曲線形式疊加顯示該參數關聯的另一個參數（如編輯 `音高` 時疊加 `音分差`），方便對照。
- `音量 / 動態縱軸單位切換`：參數為 `音量` 或 `動態` 時，點擊縱軸刻度區域可以在 dB 與倍率兩種顯示單位之間切換。

### 10. 平滑處理

用選擇工具框選一段區域後，按右鍵選擇 `平滑化...`（預設快捷鍵 `Ctrl + M`），可以把過於抖動的參數線變得平順。

- `平滑度`：0 ~ 100% 的連續滑桿，數值越大越平滑。對話框的初始值跟隨工具列 `平滑度` 設定的值（該設定預設為 0%，即預設不平滑）。
- 平滑會參考選取區兩側的曲線做銜接，因此選取區邊緣不會出現突兀的台階；邊緣過渡的寬度固定按時間計算，不會因為選取區越長而越寬，反覆編輯也不會在選取區之外累積變形。
- `量化` 與 `均值量化` 對話框中也提供了同樣的 `平滑度` 滑桿，可以在量化音高的同時順便平滑。

如果只是想快速抹平一段，也可以用選擇工具在選取區內按住右鍵向下拖曳，拖得越低越平滑，且支援即時預覽。

## 六、匯出音訊

做完所有編輯後，透過 `檔案` 選單的 `匯出音訊` 功能，可以將 HiFiShifter 專案匯出為音訊檔。

有以下參數：

- `輸出格式`：`WAV` / `MP3` / `FLAC`。
    - `WAV`：不壓縮的無損格式，相容性最好、體積最大。還要拿到別的軟體裡繼續編輯時選它。
    - `FLAC`：無損壓縮，音質與 WAV 完全相同，但體積明顯更小。想長期無損保存時選它。
    - `MP3`：有損壓縮，體積最小，幾乎所有裝置和播放器都支援。分享、上傳或做試聽小樣時選它。
    - 切換格式後，輸出檔名與分軌命名樣板的副檔名會自動跟著改變。
- `匯出類型`：`專案` / `分軌`。
- `匯出範圍`：`全部` / `自訂`。`自訂` 允許你設定匯出的起始和結束的秒數。
- `取樣率`：允許你設定輸出音訊的取樣率。三種格式都能設定，但 MP3 只支援 8 kHz ~ 48 kHz 之間的固定級距（例如 44100、48000 Hz）；如果你選了 MP3 不支援的取樣率，軟體會自動改用最接近的可支援級距，並給出提示。
- `位元深度`：允許你設定輸出音訊的位元深度。WAV 支援 16 / 24 / 32 位元浮點，FLAC 支援 16 / 24 位元。MP3 沒有位元深度選項——它內部始終以等效 16 位元的精度編碼，所以不必為 MP3 糾結位元深度。
- `編碼參數`：選擇 MP3 或 FLAC 時才會出現，用來在音質與體積之間取平衡。
    - MP3：
        - `編碼模式`：`VBR（品質優先）` 會依內容複雜程度動態分配位元率，在聽感相近的前提下檔案更小，一般選它即可；`CBR（固定位元率）` 全程位元率恆定，檔案大小更容易預估。
        - `位元率`：選擇 `CBR` 時可用，範圍 8 ~ 320 kbps，數值越高音質越好、檔案越大。
        - `VBR 品質檔`：選擇 `VBR` 時可用，從 q0（約 245 kbps）到 q9（約 65 kbps），預設 q2 已經足夠好。
        - `中繼資料（ID3 標籤）`：可填寫 `標題`、`演出者`、`專輯`、`備註`，會寫入 MP3 檔案中；留空則不寫入。
    - FLAC：
        - `壓縮層級`：0 ~ 8。`0` 壓縮最快但檔案略大，`8` 檔案最小但壓縮最慢，預設 `5`。壓縮層級只影響檔案大小與壓縮耗時，不影響音質，一般維持預設即可。
    - 通用：
        - `抖動`：在降低位元深度時加入極輕微的雜訊以改善聽感，可選 `關閉` 或 `TPDF`。僅對整數位元深度（16 / 24 位元）有效，一般維持 `關閉` 即可。
        - `聲道`：`立體聲` 保持原有的左右聲道；`單聲道下混` 把左右聲道混合成單聲道。
- `輸出資料夾`：允許你設定檔案輸出的資料夾。允許使用的佔位符如下：
    - `<ProjectFolder>`：表示當前專案所在資料夾。如果當前專案未被儲存過，則指向 `我的文件` 資料夾。
    - `<ProjectName>`：表示當前專案的檔案名稱，不含副檔名。
    - 對於匯出專案來說，`輸出資料夾` 的預設值為 `<ProjectFolder>`；對於匯出分軌來說，`輸出資料夾` 的預設值為 `<ProjectFolder>/<ProjectName>`。
- `輸出檔案名稱`：允許你設定檔案的輸出名稱。允許使用的佔位符如下：
    - `<ProjectName>`：表示當前專案的檔案名稱，不含副檔名。
    - `輸出檔案名稱` 的預設值為 `<ProjectName>.wav`。
- `分軌命名格式`：允許你設定分軌輸出時的命名格式。允許使用的佔位符如下：
    - `<ProjectName>`：表示當前專案的檔案名稱，不含副檔名。
    - `<ExportIndex>`：表示當前分軌在匯出時的順序編號。編號從 `0` 開始。
    - `<TrackIndex>`：表示當前分軌在專案內的編號。編號從 `0` 開始。
    - `<TrackName>`：表示當前分軌在專案內的軌道名稱。
    - `<TrackType>`：表示當前分軌在專案內的軌道類型，根軌道 `Root` / 子軌道 `Sub`。
    - `<TrackId>`：表示當前分軌在專案內的內部 ID。一般使用者不建議使用這個。
    - `分軌命名格式` 的預設值為 `<ExportIndex>_<TrackName>.wav`。
- `分軌匯出目標`：可以選擇你打算匯出的分軌。預設情況下，只會選擇專案內不靜音的普通軌道和根軌道。面板上方有 `全選`、`全不選`、`子軌全選` 與 `排除靜音` 快捷按鈕。
    - 如果你勾選了原本處於靜音的軌道，則可以正常匯出該軌道，而忽略該軌道是否處於靜音狀態。
    - 如果你勾選了軌道組的根軌道，則表示將該根軌道所包含的軌道組匯出為單個音訊檔案分軌，且匯出的根軌道的音訊資料中，不包含目前被靜音的子軌道的音訊資料。
    - 如果你勾選了軌道組的子軌道，則可以正常匯出該軌道，而忽略該子軌道或者其根軌道是否處於靜音狀態。
    - `排除靜音` 按鈕只對你目前已勾選的目標生效：它會把其中處於靜音狀態的項目取消勾選，而沒有勾選的項目維持不變。因此可以先手動挑選，再點它做一次剔除。

當你正在輸入檔案路徑時，點擊 `佔位符` 那一排按鈕，可以快速將對應文字填入文字框中。

上述所有和檔案路徑有關的字串，均支援時間格式化字串，比如 `%Y-%m-%d-%H-%M-%S`。如果你打算在輸出路徑中包含實際的 `%` 字元，請使用 `%%` 進行跳脫。

選取音訊塊後按右鍵選擇 `快速匯出`，可以在小視窗中直接匯出這幾個音訊塊。這裡同樣可以選擇 `WAV` / `MP3` / `FLAC` 格式，但不會再要求設定編碼參數——它會沿用你在 `匯出音訊` 對話框中所儲存的設定。

## 七、錄音

HiFiShifter 支援直接在時間軸上錄音。錄音時可以從目前播放游標處同時開始播放時間軸（用於跟伴奏或背景音樂），錄音結束後會自動停止播放並把錄音匯入時間軸。

### 錄音按鈕與快捷鍵

- 播放控制區中的紅色圓形按鈕用於開始/停止錄音。
- 預設快捷鍵為 `Ctrl + R`，可以在 `選項 -> 鍵盤快捷鍵...` 中修改。
- 在錄音按鈕上按一下滑鼠右鍵可快速開啟錄音設定。

### 錄音設定

透過 `檔案 -> 錄音...` 開啟錄音設定：

- `錄音來源`：選擇錄音來源，共三種模式。
- `錄音裝置`：預設 `系統預設`，可列舉並選擇目前電腦上的任意輸入裝置（麥克風等）。
- `迴圈裝置`：當錄音來源為 `系統聲音（迴圈）` 時，可選擇要擷取的輸出裝置，預設 `系統預設輸出`。
- `應用程式`：當錄音來源為 `應用程式音訊` 時，可選擇只擷取某個程式的聲音；按一下 `重新整理` 可重新列舉目前正在輸出音訊的程式。程式重啟後（PID 改變）會自動依程序名稱重新比對。Windows 10 21H2（build 20348）以上優先使用系統進程迴圈 API，舊版本自動改用「靜音其他會話」的相容方案；Linux 下透過 PipeWire（`pw-dump` / `pw-cat`）擷取；macOS 目前不支援此模式。
- `取樣率` / `位元深度` / `聲道`：輸出 WAV 的取樣率、位元深度與聲道數。
- `輸入增益`：錄音前的增益補償。
- `倒數計時`：輸入秒數，點擊錄音後先倒數再開始。
- `錄音時監聽輸入`：錄音的同時把輸入訊號送回輸出裝置，`監聽增益` 可調節回送音量。
- `匯入後自動正規化`：停止錄音並匯入後，自動把新音訊塊峰值正規化到 0 dB。
- `播放到選取音訊塊末尾自動停止`：錄音播放到所選音訊塊的末尾時自動停止並匯入。
- `輸出路徑範本`：支援 `<ProjectFolder>`、`<ProjectName>` 與時間格式字串，預設 `<ProjectFolder>/HiFiShifter Record/%Y-%m-%d-%H-%M-%S.wav`。

### 錄音流程與匯入規則

1. 把播放游標移到想開始錄音的位置，並選取目標軌道。
2. 點擊錄音按鈕，時間軸從播放游標處開始播放，同時開始擷取。
3. 再次點擊錄音按鈕停止錄音；時間軸播放隨之停止。
4. 如果目前選取軌道在錄音範圍內沒有任何音訊塊，錄音會直接匯入該軌道；否則會在目前選取軌道正下方新建一條 `錄音` 軌道並匯入，同時自動選取新軌道和新音訊塊。

## 八、VST3 / ARA 外掛（REAPER）

除獨立 App 之外，HiFiShifter 還提供一個 VST3（ARA）外掛形態：把它載入進 REAPER，就能在 REAPER 的專案裡直接開啟同一套 HiFiShifter 編輯介面。外掛與獨立 App 共用同一套編輯與渲染邏輯，但**不需要先啟動獨立 App**，編輯結果隨 REAPER 專案一起儲存。

目前外掛為 Windows x64 版本，且只針對 REAPER 驗證過；Linux / macOS 暫無外掛交付。

### 安裝與接入

外掛有兩種裝法，任選其一：

- **安裝程式（建議）**：執行 `HiFiShifter_v<版本>_windows-x86_64-vst3-setup.exe`。精靈跟隨系統介面語言，可以自選 VST3 目錄；模型會裝進全機共享庫（見[模型檔案與共享](#模型檔案與共享)），並在 Windows 的「程式和功能 / 已安裝的應用程式」裡註冊解除安裝項目。安裝程式會先確認 REAPER 及其外掛宿主行程已經結束。
- **手動複製**：關閉 REAPER，把**整個** `HiFiShifter.vst3` 資料夾放入一個 VST3 目錄（例如 `C:\Program Files\Common Files\VST3`），或把它的父目錄加入 REAPER 的 VST 掃描路徑。不要只複製資料夾裡的單一檔案 —— 介面、模型與執行依賴都在這個資料夾裡。這種裝法不寫登錄檔，解除安裝時手動刪除該資料夾即可。

兩種裝法都需要已安裝 WebView2 執行階段與 VC++ x64 執行階段函式庫。

接入步驟（兩種裝法相同）：

1. 重啟 REAPER 並讓它掃描外掛，然後在有人聲音訊片段的軌道上新增 VST3 外掛 HiFiShifter，依宿主的 ARA 方式接入（而不是把音訊匯入獨立 App）。建議先用專案副本試用。
2. 需要處理多條軌道時，在每條軌道上分別新增外掛實例。開啟其中任意一個 HiFiShifter 視窗，都可以編輯同一專案裡已接入的全部軌道；這些視窗是同一個工作區的不同檢視，不是各自獨立的編輯副本。不同專案之間不共享編輯。
3. 使用快捷鍵前先點擊一次外掛視窗，讓鍵盤焦點進入介面（外掛會轉發 `Ctrl + C` / `Ctrl + X` / `Ctrl + V` / `Ctrl + Z` / `Ctrl + Y`，其餘快捷鍵由介面自身處理）。

### 軌道組（folder）裡為什麼看不到音訊

REAPER 按**軌道**管理 ARA 外掛：它只會把外掛所在**那一條軌道**上的音訊交給外掛。因此把 HiFiShifter 加在軌道組（folder）的父軌上時，組內子軌的片段雖然能在介面裡看到、也能拖曳，但**不會**取得音訊內容 —— 沒有波形，也不能做參數分析。

- 正確做法是**為每條需要處理的音訊軌道各新增一個 HiFiShifter 實例**，而不是只加在組父軌上。
- 不需要先選取片段，也不需要手動「啟用 ARA」：REAPER 的 ARA 支援預設開啟、分析會自動開始；唯一前提是該軌道上確實有音訊片段。
- 外掛能辨識這種情形：此時時間軸上方會給出提示，組內片段也以「等待 REAPER 提供音訊」的樣式顯示，而不是一個看起來能用的空白片段。

> 這是 REAPER 按軌道管理 ARA 外掛的結果，不是外掛的缺陷。

### 模型檔案與共享

外掛需要 FCPE、HNSEP 與 HiFiGAN 三個模型（合計約 150 MB）。安裝程式把模型裝進**全機共享庫**（`%ProgramData%\HiFiShifter\models\<模型版本>`），獨立 App 讀的是同一份 —— 同時使用外掛與獨立 App 不會重複佔用這 150 MB。手動複製的版本自帶一份模型，不依賴共享庫。

- 模型版本由模型內容派生：升級後新版本落在新目錄，同版本的重複安裝會被跳過。
- 解除安裝外掛**不會**刪除共享模型庫（獨立 App 也在用）。確實需要清理時，手動刪除 `%ProgramData%\HiFiShifter\models`。
- 用環境變數 `HIFISHIFTER_MODELS_DIR` 可以指定模型目錄，優先於共享庫。

### 外掛模式下的分工

外掛模式下，**宿主負責**音訊匯入、片段的位置 / 裁切 / 線性拉伸、BPM 與漸變聲音；**HiFiShifter 負責**音高、氣聲、張力、共振峰等參數曲線的編輯。

- `檔案` 選單只保留 `匯入媒體檔案...` 與一條不可用的 `儲存 · REAPER`；儲存專案、匯出與錄音都在 REAPER 中完成。
- `檔案 → 匯入 MIDI...` 在外掛裡可用，但匯入目標是**音高曲線**（對話框裡的 `匯入到音高參數`）：音符直接寫進外掛自己的曲線，與獨立 App 走同一條實作。`建立音高參考區塊` 與片段右鍵的 `取代 MIDI` 在外掛裡**不會出現** —— 片段屬於 REAPER，外掛建不出宿主看不見的本機片段。
- `軌道` 選單、`錄音` 按鈕、`選項 → 推理裝置` 等由宿主接管的入口在外掛裡**直接不出現**（而不是灰著佔位）：宿主給的 VST 視窗通常很窄，用不上的控制項只該讓路。
- 當宿主開放控制能力時，`停止` 與 `播放 / 暫停` 按鈕用於控制 REAPER 的播放；播放頭以 REAPER 專案的位置為準，BPM 也由 REAPER 決定。宿主不提供播放控制時整組按鈕不出現。
- 工具列上的 `BPM` / 拍號輸入框、節拍器按鈕與錄音按鈕在外掛裡不出現 —— 它們是宿主的權威讀數或宿主的命令，REAPER 自己的介面就在顯示與操作它們。
- 片段上的漸變聲音由 REAPER 處理；介面裡顯示的是 HiFiShifter 自己的示意包絡。懸停提示與獨立 App 一樣只給三個量（形狀 / 長度 / 曲率），不顯示宿主的 `c=` / `S=` 讀數 —— 那對使用者沒有可採取行動的資訊。曲線不要求與 REAPER 逐點一致。
- 速度映射在外掛裡**可用，但只編輯音階那一軸**：速度映射就是「隨時間變化的音階」的儲存，而音階是 HiFiShifter 自有的（REAPER 沒有工程調號概念）。變化點裡的 `BPM` 與拍號是宿主的權威讀數，在對話框裡顯示為唯讀；外掛也不會自動匹配宿主的速度映射（REAPER 不向 ARA 外掛提供速度 / 拍號內容，本機實測見 `probe/ara/README.md` 的 F-2）。音階變化點存在外掛自己的設定裡。
- 循環源（REAPER 的「循環源」開關）會被如實讀入並寫回：外掛按 REAPER 的循環語意渲染，右鍵選單裡的 `循環` / `取消循環` 可用。
- 倒放**不參與**外掛處理：ARA 不提供反向音訊，外掛渲染不出正確內容。這類片段照常顯示（帶倒放標記），右鍵選單的倒放項停用並說明原因，請在 REAPER 裡操作。
- 片段沒有音訊時，提示會說明**原因**：`正在等待 REAPER 完成音訊分配`（剛分割 / 裁切 / 貼上後的正常在途）、`等待 REAPER 提供音訊`（該片段拿不到音訊，例如 FX 掛在軌道組父軌上）、`由 REAPER 倒放；HiFiShifter 不處理這一條`。分割出來的片段會立刻繼承父段的音訊，不會長時間停在佔位。
- 片段浮標只顯示名稱，不顯示檔案路徑。
- 片段右鍵選單與獨立 App 是**同一份**：Take 子選單、聲道模式、循環、淡變形狀列都會出現；外掛裡做不到的項顯示為停用並說明原因（例如膠合、靜音偵測），而不是整項消失。

### 編輯與自動套用

參數編輯方式與獨立 App 完全一致（見[參數編輯器](#五參數編輯器)章節）。每次編輯後，外掛會在背景自動渲染並套用回宿主，狀態列右側顯示目前進度：

- `等待宿主音訊`：宿主尚未把音訊交給外掛。
- `正在自動套用...`：有編輯正在渲染；模型較重時，首次處理可能較慢。
- `已套用`：沒有待處理的編輯。懸停可以看到修訂數（`編輯 {edits} / 音訊 {audio}`）。
- 只有渲染完成的音訊才會取代目前輸出，尚未完成的渲染不會被當成成功。
- 失敗時顯示 `尚未套用：{原因}`。此時先按提示排查，不要反覆強制重新載入。
- 就緒後會出現 `重新載入宿主` 按鈕：用於在模型 / 權限衝突時重新讀取宿主狀態。**仍有未套用編輯時它會先要求確認**，因為重新載入會用宿主狀態取代本機曲線；通常不必把它當作日常的「提交」按鈕。

### 儲存與限制

- 在 REAPER 中儲存專案即可，外掛參數隨專案儲存；關閉外掛視窗不會遺失編輯，也不需要讓獨立 App 常駐。
- **介面設定會持久保存**：介面語言、快捷鍵、外觀與自訂主題、時間軸與參數編輯器的縮放、檔案瀏覽器上次所在目錄，結束 REAPER 後仍然保留。
- 這些設定與獨立 App **共用同一份設定**：在獨立 App 裡調好的外觀與快捷鍵，外掛裡直接生效，反之亦然。
- 重新開啟專案後，外掛需要重新從宿主取得音訊並完成背景準備，狀態列會先回到 `等待宿主音訊`。
- 升級外掛前請先儲存專案並完全結束 REAPER，不要在宿主執行時覆寫已載入的外掛資料夾。
- 只支援正向、**線性**拉伸：倒放與非線性拉伸不在支援範圍內，介面會明確標註 `不支援倒放`。
- 氣聲分離（HNSEP）按整段處理，很長的素材在開啟 `氣聲分離` 後可能佔用大量記憶體；HiFiGAN 推理則是分塊進行的。

### 常見問題

- 在 REAPER 裡找不到外掛：確認複製的是**整個** `HiFiShifter.vst3` 資料夾（而不是裡面的單一檔案），確認它的上層目錄在 REAPER 的 VST 掃描路徑中，並確認已安裝 WebView2 執行階段與 VC++ x64 執行階段。
- 一直顯示 `等待宿主音訊` 或無法分析：檢查該軌道上是否有有效音訊、外掛是否以 ARA 方式接入，以及狀態列右側的自動套用狀態。
- 把外掛加在軌道組（folder）父軌上，介面裡有片段卻完全沒有波形：REAPER 按軌道管理 ARA 外掛，只會把外掛所在軌道的音訊交給它。請為每條需要處理的音訊軌道各新增一個 HiFiShifter 實例（見[軌道組（folder）裡為什麼看不到音訊](#軌道組folder裡為什麼看不到音訊)）。
- 參數沒有生效，或重新開啟專案後不一致：保留專案副本和狀態列上的錯誤訊息，先不要覆寫專案，也不要反覆強制重新載入。
- 出現記憶體不足的提示：表示這次沒有執行氣聲分離，`氣聲分離` 相關的效果不會被靜默忽略；可以改用更短的素材，或先關閉 `氣聲分離`。
- 需要提交日誌或排查問題：外掛日誌與獨立 App 的日誌**放在同一個目錄**（外掛是 `plugin.log`，獨立 App 是 `hifishifter.log`，檔名不同，互不覆蓋、各自輪轉）。選單 `說明 → 開啟日誌資料夾` 會替你開啟這個資料夾；若宿主環境不允許，則顯示路徑供你複製。`說明 → 匯出診斷資訊...` 與 `選項 → 推理裝置基準測試` 屬於獨立 App，外掛裡不可用。
- 解除安裝：裝的是安裝程式版本時，在 Windows 的「程式和功能 / 已安裝的應用程式」裡解除安裝 HiFiShifter VST3；手動複製的版本刪除 `HiFiShifter.vst3` 資料夾即可。兩種情況下設定與共享模型庫都會保留（見[模型檔案與共享](#模型檔案與共享)）。

### 從獨立 App 連線宿主

如果習慣在獨立 App 裡編輯，也可以讓它連線正在執行的 REAPER：先按上面的方式在 REAPER 中接入外掛，再開啟獨立 App，選擇 `檢視 → ARA 宿主連線...`，在浮出的工作階段面板（標題為 `ARA / REAPER`）裡 `重新整理實例` → 選擇實例 → `連線`，之後可以 `提交到 REAPER`、`重新整理宿主` 或 `中斷連線`。狀態會顯示 `未連線` / `已連線` / `已重新整理` / `已提交` / `已中斷連線`，懸停可以看到修訂號。目前專案有未儲存修改時，連線或重新整理前會先詢問是否用宿主快照取代。

## 九、日誌與故障排除

HiFiShifter 會自動把執行日誌寫入系統標準日誌目錄，無需任何命令列參數。遇到問題時，把日誌檔案提交給開發者即可幫助定位：

| 系統    | 日誌目錄                                       |
| ------- | ---------------------------------------------- |
| Windows | `%LOCALAPPDATA%\com.arounder.hifishifter\logs` |
| macOS   | `~/Library/Logs/com.arounder.hifishifter`      |
| Linux   | `~/.local/share/com.arounder.hifishifter/logs` |

- 透過 `說明 → 開啟日誌資料夾` 可以直接定位日誌檔案。
- 外掛（ARA）的日誌與獨立 App **同目錄、同格式、同樣輪轉**，檔名是 `plugin.log`；兩份日誌都會帶上版本號、日期與時間戳，便於一起打包提交。
- 透過 `說明 → 匯出診斷資訊...` 可以一鍵產生診斷套件 zip（系統資訊 + 全部日誌 + 推理裝置基準測試結果），提交 issue 時附上即可。
- 日誌依大小自動輪替：單一檔案上限 8 MiB，預設保留 3 份歷史（`hifishifter.1.log` ~ `hifishifter.3.log`）。
    - 高頻重複的錯誤 / 警告會自動限流：同一位置的日誌預設每 10 秒最多輸出一條，被抑制的條數會在下一條輸出前以 `[throttled]` 彙總行補記。
- 前端與後端的錯誤都會統一記錄在同一份日誌檔案裡，方便按時間軸對照排查。

進階選項（一般使用者無需使用）：

- 啟動參數 `--log-file=<path>`：把日誌寫入指定路徑；`--log-file=-` 明確關閉檔案日誌。
- 環境變數 `HIFISHIFTER_LOG=debug`（或 `trace` / `info` / `warn` / `error`）：調整日誌詳細程度，release 版預設為 `info`。
- 環境變數 `HIFISHIFTER_LOG_DIR`：覆蓋預設日誌目錄。
- 在終端機執行 `HiFiShifter --benchmark`：直接執行推理裝置基準測試並以 JSON 格式輸出結果。
