# ARA 编辑器操作恢复与四项编辑问题

中文设计。最新用户目标在四项排查之外新增：恢复 clip 绝大部分操作，包括复制粘贴。
本文覆盖旧分割批次“不添加删除/胶合”和插件仅分割菜单的范围限制。
只在 `.worktrees/ara-plugin` 工作，独立 App 保持同源且行为不变，不自动 push。

## 范围与完成标准

1. 撤销排查：区分本地分组历史、宿主录入、组件保存/恢复、GUI 回流，不能将
   owner 往返测试当真实 REAPER Undo；宿主几何与私有参数必须有明确的归属。
2. 右键：参数面板正常，不修改；用户允许轨道头禁用。空白区菜单必须保留，
   clip 菜单恢复正常操作，已实现操作可用，尚未接通的动作解释原因而不是静默消失。
3. 参数显示：排查结果必须解释提交后清窗与同步 DSP 队列的关系，适用于所有参数。
4. 参数数据：确认整轨空白处和 clip 边界数据丢失；后续 clip 操作不能继续扩大
   这个问题。源域曲线负责跟随素材，整轨用户编辑（含空白）也要持久保存。
5. 操作恢复不是仅改菜单：真实 REAPER item 修改、ARA 回流、源域曲线继承、混合
   Undo/Redo、多轨、保存重开均需要一致。最终统一 Release 安装 `D:\VST`。

## 操作清单

| 操作族 | 要求 |
| --- | --- |
| 复制、剪切、粘贴、重复 | 单选/多选，保留相对位置、轨道关系、源区间、倍率、属性和曲线；剪切删除原 item 后仍可粘贴；支持已有目标轨道和粘贴到新轨道 |
| 删除、静音、解除静音、改名 | 写真实 item/take，不把 UI 私有删除或属性修改当宿主成功 |
| 分割、移动、跨轨、裁切、线性拉伸 | 沿用原界面；回执按真实 GUID 和目标几何验证，避免 A/B 闪回 |
| clip 音量、归一化、声道模式 | 宿主负责 item/take 属性，归一化基于真实素材，不重复烘焙增益 |
| 渐变、吸附偏移 | 保持已约定的 REAPER 音频责任；长度双向同步，不用自有包络双重淡化 |
| 编组、解组、关闭间隙 | 写真实宿主属性/几何，批量预检，单个宿主 Undo 块 |
| 替换素材、Take 操作 | 保留原 GUI 入口，宿主创建/选择真实 take，更新源授权；不能仅更换缓存路径 |
| 胶合、静音检测切割、导出、音高参考 | 复用原计算能力，涉及媒体/几何变化时使用宿主写口，保留曲线与真实身份 |
| 选择、多选、重叠选择、并入参数选区 | UI 操作恢复，不需要伪造宿主几何 |

倒放与非线性拉伸继续按用户先前要求不做；不能据此排除线性拉伸。每个操作完成
后登记实际能力，不把 `clipEditing` 一项等同全部 clip 操作均已实现。

## 原生复制粘贴

- 已核对锁定官方 SDK 的 `GetItemStateChunk`、`SetItemStateChunk`、`genGuid`、
  `guidToString` 签名；item/take GUID 格式另与用户 RPP 只读样本核对。
- 复制时捕获真实 item 状态和 HFS 区域参数 seed，不仅保存指向活动 item 的引用。
  因此剪切、删除原 item 后、跨轨粘贴仍可以恢复。源文件仍由 REAPER 管理。
- 粘贴前有界解析单个 `<ITEM>`，为 item、take 和 take FX 实例生成全新宿主 GUID；
  不修改源状态或插件不透明 payload 内部字节。不能先加载重复 GUID 后再改身份。
- item 状态为宿主权威；创建通过已验证目标轨道，不调用全局粘贴 action，不改变
  活动工程或借用户选择来定位目标。主线程执行，不持 document/timeline 锁重入。
- 参数继承凭确切新 GUID 与复制时冻结的 seed，支持跨根轨道，不靠同源路径或
  附近位置推断父片段。完成门同时检查真实 item 存在和 GUI 回流。
- 剪贴板不包含 HWND、宿主指针、认证 token；结构、总字节、clip 数量和采样预算
  有界。外部剪贴板当数据解析，不执行其中的指令。
- 多选操作先全部预检。中途失败明确报告宿主已发生的修改并保留 Undo，不伪造
  原子回滚；回流重试不重复创建 item 或 setter。

## 曲线与撤销基础

整轨用户曲线与 clip 源域曲线需要各自明确的时间坐标、覆盖范围和持久身份。
不得靠连线隐藏数据丢失；clip 外向网格点不能用默认零覆盖有效编辑。
复制/分割不重新采样原始源 basis；相同源、重叠、跨轨与冷恢复必须使用确切谱系。

分组检查点提前 return 的缺陷已有真实 actor 对照。组件 state 在 DSP 暂缓时已经
包含轨道参数，恢复前后 state 能回流 actor；真正 REAPER 录入点尚未实测闭合。
保留 IComponentHandler 并正确通知宿主私有状态改变是待实现接口，不据此虚报 Undo。
UI 参数读取与音频 DSP 分离，不能因渲染队列阻塞而假报提交失败或清掉可见曲线。

## 验证约束

只在批次末跑相关定向检查，最终统一 GUI/声音/Undo/保存验收，不反复全套 review。
运行中的用户 REAPER 不热换 DLL、不用 `-nonewinst` 注入脚本、不改安全设置绕过
Computer Use。隔离工程只在明确安全的独立配置流程中创建；用户当前工程不作隐藏试验。
源码测试不等同真实宿主验收，旧 `nativeAcceptance=false` 不凭推断改为 true。
