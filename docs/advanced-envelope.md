# 原生音频与 OTO 高级包络（0.25 / 内部更新 177）

## 标点多选快捷操作

- 按住 **Ctrl** 逐个点击标点加入选区；再点已选标点取消选择。音高、响度和线性 FLAG 可跨可见音符／CVVC 音素选择当前参数的标点。
- 拖动任一已选标点，整组同步上下左右平移；碰到值域或相邻未选点时整组停止。高级包络混合模式支持同样的节点多选，首尾节点的时间仍固定。
- **Ctrl+R** 或多选右键菜单“初始化选中标点”：保留各点时间，重置为默认值。音高回所属音符音高，响度 100%，FLAG 为参数默认值；DiffSinger 实参回原始预测值。
- **Del／Backspace** 批量删除。保留音高、响度、CVVC 和高级包络的两端，以及普通 FLAG 最后一个点。
- 普通点击未选点重新单选；点击空白、切换编辑上下文或失焦清除选择。一次平移、初始化或删除可整体撤销。
- 高级包络仍先修改当前预览的草稿；点“应用”写入目标音符／音素。贝塞尔方形控制柄沿用逐个拖动，双击恢复默认。

## 非 U 原生响度包络通道

点击“音量”旁的 **响度包络**，或在音频片段上右键选择 **响度包络**，在钢琴卷帘下方打开百分比曲线通道，再次点击按钮可关闭。

- 双击曲线添加点，拖动点调整时间与响度，右键内部点删除；保留两个端点。
- 可直接编辑同轨道其他可见片段；多选后按各片段长度比例应用形状。
- 新素材默认平直的 100%，打开通道不改变音频；背景显示拉伸后的原始波形近似与响度变化。
- 修改支持撤销重做、工程保存和实际播放／导出。开启了高级包络时，虚线表示叠加后的结果。

## 非 U 原生高级包络弹窗

选中原生音频片段，右键 **音量** 打开高级包络。勾选“启用音频包络”后编辑；新素材默认关闭，前后均为 100% 响度，不自动添加淡入或淡出。点击“恢复默认”得到平直的 100% 草稿，应用后生效。

包络范围以当前音频片段全长为基准，起止响度允许 0–200%，支持淡入、淡出，以及混合分段。混合模式下双击加点、拖动节点调整时间与响度、右键删点；每段可选择直线或贝塞尔曲线，并拖动两个控制柄。应用并试听可直接听到结果；多选会将相同的比例设置应用到每个所选片段。

原生模式将此曲线乘在基础响度包络上，图中灰线为基础、绿色为结果、黄色为选中分段。原生预设与 OTO 预设分开保存。修改支持撤销、工程保存和重开，播放与 WAV 导出使用同一设置；拉伸跟随片段长度，分离或裁剪保留对应曲线部分。以下音头／音尾专用规则仅用于 OTO 模式。

## OTO 模式入口

选中要处理的音符，点击包络预设旁的 **高级包络**，或右键 **响度包络**，打开 **OTO 音头与音尾包络** 设置窗口。窗口先编辑草稿；**应用** 保存但保留窗口，**应用并试听** 保存后从选区起点试听。关闭窗口丢弃尚未应用的修改，已经应用的修改可在主窗口撤销。

## 混合分段包络

右上角选择“音头 · 第一区”或“音尾 · 最后一区”，启用该侧后，在“曲线形状”选择 **混合**。

- 双击预览中所选包络范围内的位置添加分段点（最多 64 个内部点）。
- 拖动节点调整时间和响度；按住 Shift 精细拖动。首尾节点只调整响度，顶部两个圆点调整整体范围。
- 单击线段，或用图下的“分段”列表选择一段，再选择 **直线** 或 **贝塞尔曲线**。暖黄色表示当前选中段；选中曲线段后显示两个方形控制柄，以及控制点 1／2 的时间和过渡百分比。拖动控制柄或输入数值可单独调整这一段，双击控制柄重置；Shift 支持精细拖动。控制点参数以当前分段为范围，与其他段独立。
- 右键内部节点可删除；右键也可设置所选段的形状。各段连续连接，内部点不能越过相邻点。
- 混合模式可在 0–200% 间上升、下降或保持，音头／音尾独立编辑。保存预设同时保存两侧；点击“应用”或“应用并试听”后才修改音符。

分段时间相对于当前 OTO 包络范围，跟随音符拉伸和 OTO 分区变化。工程保存、撤销重做和预设载入保留全部分段；旧版直线、S 曲线与贝塞尔预设仍可读取；旧混合分段 S 曲线使用等效默认贝塞尔控制柄，保持原形状。切到直线会保留该段的控制柄，切回曲线可继续编辑。下面有关单段淡出方向和曲线强度的限制适用于线性／曲线模式，混合模式由各段节点定义。

## 细节设置

- **启用尾段淡出**：关闭后恢复原包络效果，保留这些细节以便重新启用。
- **曲线形状**：线性按振幅降低；平滑 S 曲线在两端更柔和。
- **淡出起点 / 终点 · 尾段 %**：在 OTO 最后一段内部指定范围，默认 0% 至 100%。拖动预览上方的两个圆点也可调整。起点须早于终点，边界跟随音符时长和 OTO 分区。
- **淡出前响度 · %**：相对原包络的振幅倍率，默认 100%。例如 80% 约为 -1.94 dB；它作用于整段淡出前的发声，而不只作用于尾段。
- **结束响度 · %**：到达终点后保留的倍率，默认 0%（静音）；不能大于淡出前响度。这个倍率以淡出起点的原包络响度为基准；原包络后续收尾不再重复叠加。
- **曲线强度**：默认 1；小于 1 先快后慢，大于 1 先慢后快，范围 0.25–4，仅 S 曲线可调整，线性模式始终为直线。
- **恢复默认**：草稿恢复为启用、线性、完整尾段、100% 至 0%、强度 1；点击应用后才写入工程。

预览可切换当前选中的可用音符，实线为原包络，绿色虚线为替换收尾后的实际响度。背景标出 OTO 尾段和淡出范围，下面给出相对音符起点的毫秒位置。多选时应用会统一所有可用音符的参数；窗口显示可用数量及是否原先存在不同设置。没有有效 OTO 尾段的音符跳过。工程在窗口打开期间发生其他修改时，应用会提示重新打开以更新预览，避免覆盖新修改。

## OTO 与原包络

普通 UTAU 使用固定辅音 / 拉伸元音的两段 OTO；界·UTAU / 谋·UTAU 使用实际 2、3、4 段 OTO，取最后一个存在的分区。单音 OTO、辅音速度、预发声、音符长度及手动分界都会影响尾段位置。没有长度的末段不产生额外淡出。DS 没有 OTO 分区，不启用此功能。

淡出起点之前保留原包络形状，并应用“淡出前响度”倍率。从起点开始固定原包络的基准响度，再用所选直线或 S 曲线连续降到结束响度，避免原包络收尾和淡出相乘后出现折弯。若淡出起点本身静音，整个淡出仍为静音。响度包络通道的实线及标点仍编辑原包络；绿色虚线、音符形状和波形显示叠加后的结果。自动采样只用于绘图，不写入密集标点。试听和 WAV 导出共用混音规则，修改效果继续复用原始合成缓存。

模式与细节按音符保存，支持多选一次撤销、重做、复制、HAMOOD 和声和工程重开。旧工程缺失细节时，沿用原来的完整尾段淡出默认值；关闭效果不会删除原包络或 FLAG。

## MCP

`set_note` 的 `tail_fade` 支持 `off`、`linear`、`smooth`；另有五个可选数值字段：`tail_fade_start_percent`、`tail_fade_end_percent`、`tail_fade_start_gain_percent`、`tail_fade_end_gain_percent`、`tail_fade_curve_power`。省略的字段保持当前值，参数范围与 GUI 相同。无效范围先拒绝整次编辑，不会改动同一请求中的其他字段。选区与工程快照返回这些设置；实时编辑须提供 `expected_revision`。批量音符可用 `editor_batch` 合并撤销。


## 自动交叉淡化的直线／曲线选择（更新 173）

右键“自动交叉淡化”，选择“直线”或“曲线”，当前项显示勾选。默认直线，选择会记住；切换选项不会立即修改已有音符。然后选中同轨两个前后重叠的音符，左键按钮应用；仍只处理已有发声重叠部分，不移动音符。没有选中两个音符时可以先右键设定方式，左键会提示选择条件。

直线在幅度域均匀淡入／淡出；曲线采用与 CVVC 自动交叉相同的互补 smoothstep（平滑 S 形），两端变化缓慢，中段较快。为沿用所有后端的包络存储与读取，曲线以 32 个幅度直线段近似，归一化插值误差小于 0.001；既有约 0.001 的静音阈值仍适用。生成的中间点可继续编辑。该选项独立于发音器菜单中的“默认交叉方式”，后者控制 CVVC 自动拼接。

一次应用同时修改两边的响度包络，可撤销／重做、保存工程；重复应用同一方式不累加淡化。改选直线后再次应用，会替换重叠区的曲线中间点。普通音频、UTAU 各模式及 CVVC 音素使用同一提交入口。

验证入口：`--smoke-auto-crossfade <输出目录>`；更新 173 报告位于 `test-output/update173/build/verification.json` 和 `test-output/update173/installed/verification.json`，覆盖增益、各后端请求、切换与重复应用、CVVC 分片、保存及撤销、菜单勾选及偏好恢复。

更新 173 构建版与安装版均通过 33 项专项检查；1001 个重叠位置的最大曲线形状误差约 0.000709，互补增益最大误差约 0.001010（现有静音阈值造成）。验证未改动用户工程。


## 节点选择与 Delete（更新 176）

高级包络的混合模式中，点击节点后松开鼠标仍保持高亮；按 Delete 或 Backspace 删除该节点，也可沿用右键删除。拖动后松开同样适用。点击其他位置或控件后清除选择；连续按 Delete 不会继续删除相邻节点。首尾边界点保留，贝塞尔方形控制柄仍用于调形／双击重置。删除立即反映到面板预览，点击“应用”或“应用并试听”后才写入工程；关闭面板不提交草稿。
