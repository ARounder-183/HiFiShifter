# HAMOOD 自动和声（0.25 / 内部更新 055）

入口：**编辑 → HAMOOD 自动和声…**。选择一条旋律、普通 UTAU 或谋·UTAU / DiffSinger 轨道；有选中音符时默认处理当前轨道选区，无选中音符时界面明确显示“当前整轨”。跨轨选择时，只处理对话框所选源轨道中的音符。原始音频轨需要先转换为旋律轨道。

## 用法

1. 选择源轨道与范围。
2. 选择调性方式：自动分析单一调性、按 2/4/8/16 小节自动分段分析转调，或手动指定主音和大调/自然小调；手动模式可添加多个小节范围。
3. 勾选所需声部：上方/下方三、四、五、六、八度，可同时生成多个声部。
4. 查看下方预览中的分段调性、原音和和声音高。调性有歧义时提示手动指定；预览只显示前 120 个音符，生成处理所选范围内全部音符。
5. 设置是否保留唱法和新轨音量，点击“生成和声轨道”。新轨紧跟源轨放置，名称包含 HAMOOD 和音程。用编辑器原有播放功能试听；Ctrl+Z 一次撤销整次生成，Ctrl+Y 恢复。

例如 C 大调的 C–D–E，上方三度为 E–F–G，不是统一升高 4 个半音。分段边界按工程拍号与曲速计算，跨边界的长音按其起点所属段处理。

## 手动分段（032）

在“手动指定调性”下先选择上方主音和大小调，再填“起始小节”和“小节数量”，点击“添加分段”。例如起始 1、数量 8、C 大调，表示第 1–8 小节使用 C 大调；添加后起始自动变为 9，可更换调性继续添加。列表中点选一行后可修改数值并点击“更新所选”，也可“删除所选”。

小节编号对应工程标尺，结束小节包含在内；0 可用于第一小节前的弱起。修改曲速时仍按音乐小节换算。区间不能重叠，必须覆盖本次目标音符的所有起点；没有目标音符的空隙可以留空。音符跨过分段边界时仍使用起点所在段，不拆分或改变时长。列表为空时使用上方指定的一个调性处理全部目标音符。有效的调性设置、分段表与人工确认状态保存在工程中，关闭 HAMOOD 后仍保留；保存工程后重新打开也可继续。自动调性参考单独保存，可用“采用预测调性”转入手动修改。

## 参数与数据

- 新声部默认比原轨低 6 dB，可调 -36 至 +6 dB；最终轨道增益限制在编辑器支持的范围内。继承音源、合成引擎、语言、声线、歌词、读音、时长和音符时间位置。
- 保留唱法时，绝对 pitch 控制点和 DS 原始参考线一起随音符移调；相对音高轮廓、颤音和 DS pitch 偏移保持。每个音符独立按生成的和声音程移动。
- 关闭保留唱法时，新声部使用平直音高，清除复制来的 pitch 控制点、DS pitch 参考/偏移和颤音，可随后在 DS 中重新生成唱法。
- 保留手工 FLAG 实参和偏移；新轨清除依赖旧乐句的 DS 音素时长上下文、自动参数快照与预测参数参考，让新乐句重新推理。原轨所有数据保持。
- 新轨、片段、音符使用独立 ID，不共享编辑对象。编辑器的 RR 休止符与独立辅音候选不作为旋律和声音符生成；DS 还跳过其 R/SP/AP 休止与呼吸标记。非 DS 的 R/AP/SP 别名正常保留，原时间空隙保留。新片段不复制跨片段连接，新音符不继承旧的相邻连接标记。
- 不修改调性、曲速或原旋律；生成的轨道按普通工程内容保存、重新打开和导出。

## 普通 UTAU / 界·UTAU / 非 DS 谋·UTAU（031）

三个模式都可以作为 HAMOOD 源轨道，新和声沿用同一模式、音源库及当前重采样引擎。是否为 DS 同时根据 UTAU 模式和音源 `dsconfig.yaml` 判断，不会把所有谋·UTAU 音源当成 DS。

以下设置直接保留：

- 轨道全局 FLAG 与单音文本 FLAG，包括未知扩展 FLAG；维持单音优先于全局的原有顺序。
- 四区 FLAG 的四份文本与开关、空区的继承关系。
- 所有线性 FLAG 的名称、控制点时间/数值、插值形状、贝塞尔控制点和开启状态。关闭的曲线保留数据而不意外启用。
- 辅音速度（包括跟随轨道）、预发声/重叠覆盖、STP、单音 OTO、四区边界、谋·UTAU 音素类型及拼接设置。

勾选或关闭“保留原唱法”只控制 pitch 层，不清除 FLAG。非 DS 和声不做 DS 自动参数清理。重采样器仍按其自身支持的 FLAG 方言解释这些值；普通 UTAU 沿用普通采样模式，四区处理在界/谋模式与分区数据具备时使用。

## 算法与边界

HAMOOD 使用独立的本机规则实现：按音符的四分音符拍长统计音级，比较 24 个大小调候选。采用 Krumhansl–Kessler 与 Temperley–Kostka–Payne 轮廓的相关性组合（0.8 / 0.2），替换原来对调外音过度惩罚的评分。相关系数与候选分数差是启发式指标，不是概率或准确率。

自动分析始终使用完整源轨作为上下文，选区仅决定实际生成哪些音符。分段分析结合本段、前后邻近小节与整轨信息，通过动态规划抑制证据不足的调性切换。充分局部证据下，只在距离本段最高分不超过 0.15 的候选间平滑，避免为连续性牺牲明确转调。短句、空段和单一音级会提示证据不足。界面列出前三个候选供复核，候选排序是本段原始分数，最终选择还考虑上下文。

单一调性是整轨音级分布的总体匹配，分段调性是各段的上下文判断，两者不保证相同。出现多个持续调性区域时会提示使用分段或手动确认；不再将单一结果直接当作全曲每一段的调性。

和声按调内音级距离生成。调外音以最近音级为基准保留升降变化，等距时取较低音级；微分音偏差也保留。超出 MIDI 0–127 时拒绝整次生成，不静默截断。

这适合快速创建简单和声草稿。只有主旋律时，关系大小调、和弦借用和转调位置可能无法唯一确定，应以实际伴奏和试听为准，可用手动分段修正。菜单和 MCP 均可使用保存的和弦资料；通过“和弦 / 段落资料…”可读取或分析伴奏、人工修正。音频分析的详细边界见 `hamood-audio.md`。不执行完整复杂对位或声部音域优化。自动转调的时间精度由每段小节数决定，没有引入模型下载或联网推理。

## MCP

- `hamood_preview`：只分析和预览，默认当前焦点轨的真实选区，空选区报错。
- `hamood_generate`：相同参数实际生成；要求 `expected_revision`，一次提交，可撤销。
- `track_id` 可显式指定源轨；`whole_track=true` 才处理整轨。
- `key_mode`: `auto` / `sections` / `manual`；手动时 `tonic=0..11`（C=0）、`minor=false/true`。
- `manual_sections`：仅用于 `manual` 模式。每行必填整数 `start_bar`、`end_bar`、`tonic`，可选布尔 `minor`；前两项是包含结束小节的绝对标尺范围。非空时逐段调性取代顶层调性。与界面共用重叠和覆盖校验；输出含 `start_bar`、`end_bar`、候选分数、分析上下文音符数与多调性提示。
- `section_bars=1..64`（默认 8）；`voices` 是有符号的音级步数：±2 三度、±3 四度、±4 五度、±5 六度、±7 八度。默认 `[2]`。
- `preserve_pitch=true`，`gain_db=-6`。预览后若用户更改选区，应重新预览再生成。

```json
{"name":"hamood_preview","arguments":{"key_mode":"manual","tonic":0,"minor":false,"voices":[2,-2]}}
```

```json
{"name":"hamood_preview","arguments":{"whole_track":true,"key_mode":"manual","manual_sections":[{"start_bar":1,"end_bar":8,"tonic":0},{"start_bar":9,"end_bar":16,"tonic":9,"minor":true}],"voices":[2]}}
```

## 工程资料（055）

“和弦 / 段落资料…”可编辑开始、结束秒数、和弦或段落名称，以及是否人工确认。添加、更新、删除即时写入工程，关闭窗口不清空；请保存工程以保留到下次使用。无效区间会提示并拒绝保存。

和弦支持 C、Am、Bbmaj7、G7/B、Dm7b5 等常见写法。分数是模型的启发式指标，不是准确率；确认后的和弦作为人工资料使用。点击“读取 / 分析伴奏”优先复用有效缓存，缺失时调用本机已配置的模型；不会下载新的模型。分析无法覆盖人工确认的和弦范围。勾选“使用工程中的和弦资料”后，GUI 与 MCP 的和声预览及生成使用这份资料。

资料内部按 quarter-note 拍点定位；调性分段使用工程标尺小节。曲速变化后时间显示会换算。移动伴奏不会自动移动人工确认的音乐标记，需要重新读取并人工核对。段落标签目前用于记录，尚不自动控制编配密度。

MCP 新增 `hamood_get_context`（只读）和 `hamood_set_context`（要求 expected_revision，一次撤销）。资料 schema=1，包含 settings、chords、sections、key_predictions；时间线条目使用 start_quarter / end_quarter。和弦另含 label、pitch_classes、score、confirmed，段落含 label、confirmed。应先读取完整资料，保留无关条目后提交修改。`hamood_preview` / `hamood_generate` 未提供的调性及声部设置继承保存的设置，明确提供的参数优先；整轨范围仍必须显式 whole_track=true。
