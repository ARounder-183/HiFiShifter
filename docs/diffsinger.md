# DiffSinger 兼容（0.25）

DF 参数曲线见内部更新 001；音源预检与反复试听加速见更新 003；谋 UTAU 整合与音素时长编辑见更新 004，辅音发声与显示修正见更新 005；对外版本维持 0.25，更新编号见 [更新记录](updates.md)。

在 **谋•UTAU** 模式选择包含 `dsconfig.yaml` 的 OpenUtau / OpenVPI ONNX 音源目录。
程序自动切换为 DiffSinger 乐句合成，不需要安装 OpenUtau，不调用 WCSNDM。旧工程的 DS 轨道，以及从其他 UTAU 模式载入的 DS 音源，会自动归入谋•UTAU。普通录音音源的谋 C/V 分区功能继续保留；同一轨道根据音源类型显示对应功能。

## 使用

1. 导入 MIDI 或创建音符，每个音符输入一个音节的歌词。
2. 选择谋•UTAU 算法，选择 DiffSinger 音源根目录。后台预检通过后才切换音源；失败时显示缺失/不兼容文件，并保留原轨道音源。可在编辑菜单取消预检。
3. 打开“音源库设置”，选择语言词典和音色。默认 `zh`，汉字结合相邻歌词转换无声调拼音；特殊读音可单独覆盖。
4. 编辑 → **DiffSinger 生成 pitch**。未选音符时生成整轨；选中音符时仅重生成选中范围，现有音高作为锁定上下文。编辑菜单和音符右键均有入口。
5. 可手动编辑生成的曲线，播放或导出 WAV。Ctrl+Z 一次撤销整次生成。语言、音色和曲线随工程保存。

生成过程中可继续编辑；若工程发生修改，生成结果会被丢弃，防止覆盖新修改。
编辑菜单可以取消生成，关闭程序也会终止后台推理。

只有带 `dspitch/dsconfig.yaml` 及其模型的音源能生成 pitch。只有声学模型的音源仍可按现有 MIDI/pitch 合成。
歌词支持音源 YAML 词典条目、库存中的单音素、`[zh/n zh/i]` 等显式音素、`+` / `-` 连续延音、`RR` / `SP` 休止和 `AP` 换气。
无法转换或音源不支持的发音会提示错误；英文生词会使用离线模型预测并在预览中标明。默认语言需与所选音源的词典相符。

## 原始 pitch 虚线参考（更新 012）

成功生成 DS pitch 后，编辑器把该次预测独立保存为**浅蓝色虚线**；实线为当前使用、可以修改的 pitch。拉动控制点、自由绘制、画直线或拉平音高后，仍可对照原始预测。两条线重合时实线会盖住参考线；修改后即可看出差异。

参考线记录最近一次成功生成的结果。局部重生成只更新选中音符，整轨生成更新整轨；Ctrl+Z 同时撤销该次生成的音高和参考。参考随工程保存，并跟随音符移动、移调、拉伸、复制和拆分。它不参与合成，也不提供可拖拽的控制点。

“显示 → 音高线”同时控制当前音高和参考线；编辑音量包络时暂时隐藏。旧工程若已有 pitch、但没有保存独立原始预测，会将文件里的现存音高作为“旧工程载入时音高”参考。它会随工程保存，后续编辑与重开不会覆盖。该参考不能追回文件中从未记录的历史预测；右键音高点可查看参考来源。再次成功生成 DS pitch 后，参考更新为真正的该次预测，支持撤销。

## 生成后的简洁标点（更新 014）

DS 的完整 pitch 采样继续用于显示和合成；标点模式只把首尾及主要转折显示为可拖动的圆点，自动关键点按音符时长控制在 **2～16 个**，不会再每帧显示一个圆点。手动添加或修改过的控制点保留，数量可以超过自动关键点上限。旧工程的密集预测也会自动采用此显示方式，无需重新生成。

拖动一个关键点会调整其相邻关键点之间的局部音高，其余位置保持原样。双击实线可以加点；仅点击而不拖动不会改写音高。完整原始预测虚线仍可用于对照和还原，退出或切换标点工具不会改变声音。

## 点击还原原始音高（更新 013）

右键工具栏的**标点**按钮，选择**还原至初始音高线（DS）**，再单击音高实线上的控制点。该控制点会消失，其前后相邻编辑点之间的局部音高回到虚线预测；相邻点的手动值保留，边缘作短过渡。继续点击相邻点可以还原更大的范围，原始虚线本身不会改变。音高控制点的右键菜单也提供这个模式开关。

一次点击对应一次 Ctrl+Z，支持重做和工程保存；直接使用恢复后的 pitch 合成，无需重新运行模型。还原模式下空白点击或双击不添加控制点。按 **Esc** 或在菜单选择**普通标点编辑**即可继续拉点；已还原的采样点保持隐藏，需重新修改时可双击实线添加控制点。切换工具、轨道、关闭音高线也会退出。

此功能只对具有已保存预测参考的 DS 轨道开放。普通 UTAU 不可开启；旧工程已有的 pitch 可自动建立载入时参考；没有实际 pitch 的音符仍需先生成 DS pitch。通常参考代表最近一次成功生成的结果，旧工程兼容参考会明确标注来源。

## 跨音符连续参数编辑（更新 011）

点击 **FLAG** 打开实参，或在底部选择 **偏移**，偏移默认启用，手动关闭后可为选中音符点击 **启用**。右键任一 FLAG 按钮，选择 **跨音符（连续绘制）**；在通道右上角选择参数，然后按住左键横跨多个音符绘制。选择 **逐音符（控制点）** 即可回到原来的控制点编辑，模式会保存在本机。

连续模式按当前轨道的实际发声范围（含前置辅音）分配曲线：实参侧编辑有对应预测数据的音符；偏移侧只编辑已经启用偏移的音符。仅影响笔划经过的音符，不局限于当前选中音符。可跨空隙、反向或往返重画。其他参数、其他轨道和未划过的曲线保持不变。松手提交，一次 Ctrl+Z 撤销整笔，Esc 取消当前笔。

音源不支持的参数继续禁用；PEXP 仍须重生成 pitch 才体现对预测的影响，其他参数按原有合成流程生效。编辑模式不改变工程格式、歌词或 MIDI。

## GPU 与质量档位（更新 010）

打开 **设置 → DiffSinger**，或者在 DS **音源库设置 → GPU / 质量设置** 中进入；调整后点击“应用”。设置保存在本机首选项，不改工程版本。

- **自动**：优先 DirectML GPU，失败时使用 CPU；**CPU**：始终使用 CPU；**DirectML GPU**：明确要求 GPU，启动或执行失败则报错。GPU 编号使用 DirectML 的 DXGI 适配器编号，默认 GPU 0；多显卡机器可选择其他编号。
- **最近运行**显示实际会话后端。DirectML + CPU 表示已启用 GPU，同时允许少量不支持的算子在 CPU 上执行。完整回退原因可悬停查看。第一次加载/第一次合成包含模型读取和 GPU 编译，不一定比 CPU 快。
- **试听 / pitch 预测质量**控制播放、音符试听和下一次 pitch 重生成。**导出质量**用于 WAV 导出的声学与表现参数合成，沿用现有 pitch，不会自动替换手调曲线。默认标准试听、精细导出；需要两者一致时选择同一档。

| 档位 | 声学步数 | pitch 步数 | 表现参数步数 | 声学深度 |
| --- | ---: | ---: | ---: | --- |
| 快速 | 8 | 8 | 8 | 音源允许的最大值 |
| 标准 | 20 | 20 | 20 | 音源允许的最大值，保留原默认步数 |
| 精细 | 50 | 40 | 40 | 音源允许的最大值 |
| 自定义 | 1–1000 | 1–1000 | 1–1000 | 1–100%，自动限制到音源上限 |

更多步数通常增加计算量，音质收益取决于音源；“精细”不代表每种模型都更好听。自定义深度只作用于有 depth 输入的声学模型；例如挚彬配置上限 0.7，100% 会按 0.7 运行。旧整数 diffusion 接口自动换算为 speedup/depth，实际步数可能因整除而近似。固定步数模型没有相应输入时不会被强制改图。

运行库采用微软 ONNX Runtime DirectML 1.22.0（含 CPU 后端），无需安装 CUDA。Windows 需支持 DirectML 的显卡与驱动。本机 RTX 3070 Laptop 已完成模型算子 GPU 执行记录与实际音频验证。第三方来源：[ONNX Runtime DirectML 文档](https://onnxruntime.ai/docs/execution-providers/DirectML-ExecutionProvider.html)。

## 中英文发音转换（更新 009）

选中音符 → 右键 **DS 发音转换 / 读音覆盖…**，或使用编辑菜单同名入口。单选只显示该音符，多选显示所选，未选则显示整轨。窗口自动预览实际音素；修改后点击“预览发音”，检查通过后“检查并应用”。不会修改音源文件。

- **歌词和读音分开保存**：例如歌词“行”，读音填 `hang`；歌词仍显示“行”。留空使用自动转换，清除覆盖可恢复自动读音；更改歌词会清除旧读音及其时长覆盖。
- **中文**：同一片段内的相邻汉字按词组注音，例如 `银 / 行`、`音 / 乐`；支持 `ni3`、`nǐ`、`lü`、`lv`、`lu:` 等写法。词组判断不是语义理解，多音字仍可手动指定。数字请先写成中文或拼音。
- **英文**：音源词典 → CMU 词典 → 离线生词预测。中文轨道可用 `en/hello` 强制英语读音，英文轨道可在音源库设置选 `en`。`a` 等中英文歧义词应显式指定语言。英文同形异音词默认采用词典读音，需另一个读音时手动覆盖；数字请写成英文单词。
- **音素覆盖**：`[zh/n zh/i]`，默认中文时可写 `[n i]`；也兼容 `ni[zh/n zh/i]`。必须使用音源及其预测模型实际支持的音素，界面会检查并报出缺失项。
- **多音节分配**：第一个音符填 `en/hello`，紧接的第二个音符填 `+2`；更多音节继续 `+3`。音符必须在同一片段内连续，按顺序分配；剩余音节合在最后一个分配音符内。自动分音节可能需要调整，精确控制可直接给各音符填写 `[音素...]`。`+` / `-` 仍表示前一个发音的延音。
- **用户词典**：窗口下部每行 `歌词 = 读音`，如 `行 = hang`、`en/read = [r eh d]`；作用于当前轨道，随工程保存，优先于音源词典。修改轨道词典会清除本轨全部手动音素时长覆盖，避免套用旧边界；逐音符覆盖只清除对应音符。现有 pitch 均保留。一次应用可 Ctrl+Z 撤销。

挚彬和 Umidaji 的 `ang` 本身仍是整体音素。若要试验独立音尾，可在读音填 `[zh/zh zh/a en/ng]`，再到 DS 音素时长窗口调节第三段。此例使用英文鼻音尾，不保证与原生中文韵母一样自然，也不会自动改写所有 `ang`。

## 局部 pitch 重生成（更新 009）

选中一个或多个音符 → **DS 局部重生成 pitch**。模型收到现有实际音高（含手调和颤音）以及选区掩码，未选音符与间隙作为锁定上下文，结果只写入所选音符；相隔的未选乐句不运行 pitch 推理。修改歌词、读音、音素时长或 PEXP 后，可用此入口更新相关音符。

局部生成替换选中音符内部已有修音；边界 20 ms 内衔接原曲线，选区外控制点保留。选中音符的颤音会烘入新曲线，避免重复叠加；未选音符参数和控制点不变。若要重新处理全部音符，使用 **DS 重新生成整轨 pitch**，或取消选择后生成。缺少 retake 输入的音源会明确提示不支持局部生成，仍可整轨生成。

可在编辑菜单取消任务；生成期间工程发生修改，结果不写回。一次写入可 Ctrl+Z 撤销。局部推理的粒度是相关乐句，不保证短选区的耗时按音符数量同比下降。

离线资源：pypinyin 0.55.0（MIT）、CMU Dictionary / cmudict 1.1.1（BSD）、g2p-en 2.1.0（Apache-2.0）。资源和许可证位于 `engines/diffsinger/pronunciation-data`。g2p-en 仅保留 NumPy 预测器，移除 NLTK 导入和运行时下载；不提供自动英语词性消歧。

## DS 音素时长（更新 004）

在谋•UTAU 载入 DS 音源后，右键音符选择 **DS 音素时长…**，或选中音符按 **Ctrl+G**；也可以使用 **编辑 → DS 音素时长…**。选中一个音符时只显示该音符，多选时显示所选音符，未选中音符时显示当前整轨（更新 008）。后台使用当前音源的时长模型预测，未提供时长模型时显示规则分配结果。静音片段不参与预测。

- 预测始终保留完整上下文，显示、应用和“恢复当前预测”按所选范围处理；“应用并试听”也只选中本窗口的音符。单选延音符号时显示延续的元音区间，共享边界需回到原歌词音符编辑。
- 上排显示 MIDI 歌词音符，下排显示音源实际音素；C 为辅音、V 为元音、S 为休止。音素数量可变，不强制拆成四区。`+/-` 延音继续使用前一个歌词的音素。
- 拖动音素左边的圆点/分界线，调整它与前一个音素共享的边界。点击色块后，可在右下角输入起点相对所属 MIDI 音符的毫秒数，按 Enter 应用；负数表示提前发音。
- 默认开启 **保持元音拍点**，锁定当前元音起点（已有手动元音偏移需先恢复预测）；关闭后可移动元音起点。MIDI 音符的起点、长度和音高均保持不变。修改分界线只在相邻分界线之间进行，最短为一个模型帧；Umidaji 的一帧约 11.61 ms。
- 黄色圆点标识手动边界，灰线显示原预测位置。双击或 **恢复选中预测** 清除该边界的覆盖；**恢复全部预测** 清除当前显示音符的时长覆盖。
- 窗口内的撤销/重做用于本次编辑；**应用** 后整体成为一次工程撤销步骤，支持保存重开。**取消** 不改工程；**应用并试听** 会选中本窗口参与编辑的音符并重新试听。
- 新时长用于试听、WAV 导出及后续 pitch/variance/声学预测。已有手画或生成的 pitch 曲线不自动改写；若希望预测音高随新咬字重新生成，请再次执行 **DiffSinger 生成 pitch**。
- 手动起点以相对音符的秒数保存。移动整个音符会随之移动；缩短音符或更改曲速后，过界位置会限制在可用帧范围。换歌词会清除该音符覆盖；音源、语言或音素序列失配时旧覆盖会被忽略，重新打开编辑器会提示。
- 预测结果只在同一工程修订上可应用；预测期间修改了工程会丢弃过期结果。音素窗口不编辑 OTO 或音源本身。

## 主界面的 DS 辅音与包络（更新 005）

选中音符试听、合成完成后，主界面使用模型返回的音素位置显示发声区域：蓝色为辅音，绿色为元音。辅音可以在 MIDI 拍点之前开始，波形、音符包络和 DF 曲线的可编辑范围随实际发声区域对齐。音素位置仍在 **DS 音素时长** 窗口编辑，不使用普通 UTAU 的 OTO 辅音速度拖动。

例如本机 Umidaji 中，`zhang` 对应 `zh/zh`（辅音）和 `zh/ang`（元音）；`zh/` 是音源的语言前缀。更新 006 起，色块直接显示 `zh` / `ang`；`bang` 则显示 `b` / `ang`，避免前缀挤掉真正的辅音名。悬停色块可查看完整标识，音素窗口下方的选中详情也保留完整名称。发声时提前的辅音归该音符所有，前一个音符的尾部包络、静音或 DYN 不会削掉它。音符的包络首尾贴合实际音素范围，保留四点包络的起音/收音渐变长度。

只试听选中的音符时，同片段内未选音符仍参与上下文预测，声音保持静音。旧工程中手动调整的音素边界不会自动清除；需要使用新的预测结果时，打开音素窗口点击 **恢复全部预测 → 应用**，再试听。没有手动覆盖的工程直接使用新预测。

## DF 专属线性 FLAG（更新 001）

1. 在谋•UTAU 模式选择 DiffSinger 音源，选中需要修改的音符。
2. 点击 **FLAG** 打开底部通道，在参数下拉框旁选 **偏移**，偏移默认启用；若曾手动关闭，点 **启用** 恢复所选音符的偏移控制。
3. 用通道右上角的下拉菜单切换参数。单击加点、拖动调值；右键标点可输入数值、重置和选择直线/平滑/贝塞尔形状。
4. 切换到另一参数继续绘制：同一音符的多条曲线独立保存，同时参与合成，不会互相替换。
5. 修改一般参数后重新播放或导出即可。**修改 PEXP 后需再次执行“编辑 → DiffSinger 生成 pitch”**，再播放；它不直接改变已生成的 pitch。

在偏移通道点击“已启用”可关闭所选音符的偏移，暂时恢复默认控制，已经绘制的参数曲线仍保留。右键重置某条曲线不会清除该音符的其他参数。支持工程保存/读取、撤销/重做。曲线位于各音符的相对时间轴上，端点外保持端点值，下一个音符未画该参数时恢复默认值。

| 参数 | 范围 / 默认值 | 作用及音源要求 |
| --- | --- | --- |
| DYN | −240～120 / 0 | 合成后响度，每单位 0.1 dB（−24～+12 dB），所有音源可用；与音符音量、振幅包络叠加 |
| GENC | −100～100 / 0 | 共振峰/性别；正值下移、负值上移；需要 key shift embedding |
| VELC | 0～200 / 100 | 声学模型发音速度控制，倍率 0.5～2；需要 speed embedding，不拉伸 MIDI 音符 |
| ENE | −100～100 / 0 | 对预测能量加减最多 12 dB；需要对应声学输入和 variance 预测模型 |
| BREC | −100～100 / 0 | 对预测气声加减最多 12 dB；同上 |
| TENC | −100～100 / 0 | 对预测张力加减最多 5；同上 |
| VOIC | 0～100 / 100 | 相对预测实声比例降低最多 12 dB；同上 |
| PEXP | 0～100 / 100 | 自动 pitch 的表现强度；需要带 expr 输入的 pitch 模型 |
| SHFC | −1200～1200 / 0 | 音区偏移（音分）；改变声学输入音高，声码器仍使用原 pitch；需要声码器声明 pitch_controllable |
| CLR：音色名称 | 0～100 / 0 | 该音色的混合百分比；需要多个 speaker embedding |

音色权重之和不足 100 时，剩余部分使用“音源库设置”选择的默认音色；超过 100 时按比例归一化。音色曲线作用于声学、pitch 和 variance 模型，音素时长预测仍使用所选默认音色。

参数列表从音源配置读取。不支持的项目会显示灰色和原因；不会为了显示效果而替换成后处理滤镜。若从另一音源带来不支持的非默认曲线，合成会提示错误，可关闭这些音符的曲线，或在参数下拉菜单底部点击“清除”对应的不支持曲线（对当前显示轨道生效，可撤销）。变更音源文件后可打开“音源库设置”重新读取能力。

DF 曲线与 WCSNDM 曲线分别保存（工程中 DF 参数使用 `DS:` 前缀），不会把 DF 参数作为普通 UTAU 字符 FLAG 发给重采样器。这里只兼容对应模型参数，不是 OpenUtau 工程全格式兼容。DYN 最小值是 −24 dB；需要完全静音时请使用音符音量/振幅包络。

## 当前范围

- Windows x64，ONNX Runtime CPU / DirectML GPU 推理；每个编辑器进程复用一个私有后台进程，最多保留一个音源的模型。闲置 120 秒释放模型与缓存；切换音源/语言/默认音色，或检测到音源文件修改时重新加载。取消任务会终止正在推理的后台，下次自动重建；退出编辑器也会终止后台。
- 乐句按间隙或约 15 秒拆分（连续延音除外）。复用时长布局和声码器；未改变的乐句复用合成结果，只修改 DYN 时使用原始声音重新计算响度。修改音素时长、pitch、发音或声学参数会使相应声音缓存失效。
- 声音缓存上限 64 MiB、时长布局缓存上限 8 MiB，分别最多 32 项；另有两组各 16 MiB 的参数预测上下文/历史缓存，最多 16 / 32 项。模型本身的内存另计。首次加载仍需等待，GPU 支持与质量选择见更新 010。
- 读取 `dsconfig.yaml`、TXT/JSON 音素表、语言 ID、说话人 embedding、`dsdur`、可选 `dspitch` / `dsvariance`。
- 兼容 `steps` 或 `speedup` 采样接口、可变 depth、带/不带 melody encoder 的 pitch 输入。旧式整数 depth 会从 YAML 的 0～1 比例转换为 1000 步时间轴，并保证与 speedup 整除；连续 depth 保留小数。
- 检查声码器采样率、hop、mel 规格，按需转换 ln/log10；优先读取音源 `dsvocoder/vocoder.yaml`。独立声码器包放 `models/diffsinger/vocoders/<dsconfig 中的 vocoder 名>/`。
- 没有时长模型时使用规则时长；有时长模型时使用预测，元音起点对齐 MIDI 音符起点。
- 采用编辑器提供的实际秒数，支持已有局部曲速。手动 pitch、音符音量和振幅包络影响合成。
- 不运行 OpenUtau C# phonemizer 插件；中英文有离线发音转换，其他语言使用音源词典或显式音素。并非所有第三方扩展音源都已验证。
- 提供下述 DF 参数曲线和动态混合音色；提供 DS 音素边界编辑；提供 CPU / DirectML GPU 推理与质量档位。传统 UTAU FLAG、OTO、分区设置不作用于 DiffSinger。
- 同一轨道需要单声部；重叠音符请分轨。

## 音源预检与试听缓存（更新 003）

预检会实际打开 ONNX 模型检查输入接口，核对音素表、语言 ID、音色 embedding、已声明预测器和声码器规格。缺少可选的 pitch/时长模型会提示对应限制；已存在但损坏或缺文件的模型会报错。没有词典时仍可使用显式音素；词典中部分条目含音源不支持的音素会提示警告。音源库设置中也可查看警告并重新预检。

缓存按音源配置和文件状态区分，DF 与传统 WCSNDM 不共用此缓存。预检会提前加载模型，因此第一次选择音源可能需要几秒。不要把缓存复用等同于降低合成质量或减少采样步数。

本机 Umidaji 的 2.4 秒短句测得：旧版 DYN 修改后的新请求约 4.02 秒；本更新复用后约 0.045 秒；pitch 修改约 1.82 秒。首次冷请求约 4.34 秒，旧版约 3.88 秒。数值包含请求传递和 WAV 输出，仅代表本次短句 CPU 测试，不是整曲速度保证。DYN 撤销后与原始波形逐样本相同。

## 独立音高偏移线（文档更新 017）

在谋·UTAU 的 DS 轨道，右键“标点”按钮 → **绘制偏移（DS）**。每个音符出现紫色直线，默认与该音符 MIDI 音高等高，表示 0 半音偏移。浅蓝色虚线仍是原始预测，实线是当前实际音高。

- **整体移动**：拖动紫色线段上下移动整条偏移线，原音高起伏不变。右键线段 →“整音偏移数值…”可直接输入 `-2`，表示降低两个半音。
- **斜线或分段调整**：拖动两端圆点；双击线段添加中间点，或右键线段 →“增加偏移标点”，再拖动新点调整。各偏移点线性连接，横向是时间，纵向每个音高格为一个半音。
- **自由绘制**：按住 Ctrl 拖动，在当前音符内重画局部偏移，未画区域保留。
- **恢复**：右键线或点 →“此音偏移归零”；右键点可删除该点。Ctrl+Z 撤销一次编辑，Esc 取消尚未提交的拖动，再按退出偏移模式。

偏移独立保存，不改写原始预测虚线。实际音高 = 当前编辑后的音高 + 偏移；斜着画时仅叠加相应倾斜，原来的颤动和转音仍保留。切回普通标点模式后偏移继续生效，普通标点及“还原至初始音高线”编辑底层曲线。重新生成 DS pitch 会更新底层和虚线，并保留偏移，不会把偏移反复加进预测结果。

偏移用于试听和导出，随工程保存，并支持复制、拆分、时长变更。偏移值相对音符音高：整音移调时偏移数值不变；改变时长时偏移随音符时间变化。合并为无歌词的新音符时沿用编辑器原行为，将曲线及偏移重置。

文档更新 018：修正偏移线双击加点的鼠标事件顺序，并增加右键菜单入口。加点时保持原有偏移曲线不变，移动新点后才改变音高。


## 预测实参 / FLAG 偏移（文档更新 023）

点击 **FLAG**（或打开 **FLAG曲线**）默认显示预测实参。底部参数下拉框旁的 **实参 / 偏移** 可来回切换；两层优先保持相同参数。轨道没有实参时自动启动预测；也可右键 FLAG 选择“局部重算实参”。选中音符时仅更新选中音符，未选择时处理整轨；“重新生成整轨实参”始终处理整轨。生成使用当前有效 pitch，包括已编辑的音高和独立音高偏移。切换通道可选音源实际支持的预测参数。

- **橙色实线：实参基准**，直接送入声学模型的参数值；单击加点、拖点、右键输入数值和调整形状，或切换“跨音符连续绘制”。自动控制点最多 24 个，底层逐帧数据完整保留。局部编辑保留相邻编辑区间以外的逐帧数据。
- **蓝色虚线：原始预测**，编辑实参和 FLAG 偏移不改变它。右键点可恢复该点预测或恢复此音的参数；通道选择按钮右键可恢复整轨当前实参。
- **绿色短虚线：最终值**，等于实参基准叠加已开启的 FLAG 偏移，并按参数范围限幅。实参无需开启偏移。偏移通道的“启用 / 已启用”只控制所选音符的偏移/控制层，开关保留所有曲线。

ENE（能量）、BREC（气声）、VOIC（实声量）使用模型对数域的 dB 值，范围 −96～0；TENC（张力）使用模型单位，范围 −10～10。这些值不是输出 WAV 的响度读数，VOIC 实参也不是百分比。

旧 FLAG 数值保持兼容：ENE/BREC 每 100 单位偏移 +12 dB；TENC 每 20 单位偏移 +1；VOIC 的 100 仍表示无偏移，0 表示 −12 dB。例如 BREC 实参 −40 dB，加 FLAG 50，最终为 −34 dB。DYN、GENC、VELC、PEXP、SHFC 和音色混合没有这四项预测实参的含义，继续作为各自的控制使用。

生成后基准冻结并随工程保存，重开和修改 pitch 不会悄悄覆盖它。需要跟随新音高、歌词或咬字时，重新生成相关音符的实参；这会替换目标实参的手动编辑与原始参考，保留 FLAG 偏移，支持一次撤销。“清除实参，恢复自动预测”则释放选中音符（未选为整轨）的冻结数据，恢复合成时自动预测。普通 FLAG 重置不会清除实参。

ZhiBin CE 本机音源支持 BREC/TENC/VOIC，不支持 ENE；Umidaji 本机音源不提供这四项预测实参，界面会提示限制。对应音源没有的模型能力不会用虚构曲线或后期滤镜代替。

### 气声、力度等局部重算

1. 在谋·UTAU 的 DS 轨道选中需要重算的一个或多个音符。
2. 右键 **FLAG / FLAG曲线** → **局部重算实参（选中音符；未选则整轨）**。
3. 根据当前有效 pitch、音色混合和音素时长重新预测音源支持的气声 BREC、能量 ENE、张力 TENC、实声量 VOIC。目标音符的手动实参被新预测替换；其 FLAG 偏移、pitch、pitch 虚线及未选音符全部保留。可用 Ctrl+Z 撤销。

局部遮罩从所选音符的前置辅音起点开始，到下一个音符的辅音起点结束；未选部分以已有的原始实参为条件锁定，不把 FLAG 偏移带回预测器。新工程还没有历史曲线时，会先初始化缺失的上下文，但仅向选中音符写入预测。重开工程后的已保存实参也可作为上下文，不依赖上一次运行的内存缓存。

已保存的实参不会因为编辑 pitch 自动变化。若使用“清除实参，恢复自动预测”，合成时会保留最近的预测上下文：pitch、音高偏移或音色混合变化后，对变化帧重算；单纯改气声等 FLAG 偏移或 DYN 不重算预测。首次使用、音素/时长/质量改变、切换音源或工作进程释放后，重新建立所需上下文。音频合成仍可能执行整句，不能据局部长度推算耗时。

旧 variance 模型若缺少 retake/参数上下文输入，局部命令会明确报错，可改用“重新生成整轨实参”；自动模式会回退整句并在推理报告中提示。只提供音源真正支持的参数：当前 ZhiBin CE 可重算气声、张力、实声量，未训练 ENE，因此不提供能量预测。

### 偏移默认启用（更新 022）

新建 DS 音符、转入 DS 的音符默认启用 FLAG 偏移；旧 DS 工程第一次在本更新中打开也会按新默认开启。没有绘制的偏移为中性值。需要关闭时选中音符，在偏移通道点击“已启用”，关闭状态会随新格式工程保存，重新打开不会自动恢复开启。普通 UTAU 的线性 FLAG 默认行为不变。

### 实参和偏移互显（更新 023）

实参侧显示紫色偏移虚线，并继续保留蓝色原始预测；偏移侧显示蓝色当前实参虚线。最右侧第二列刻度对应另一层，按其自身全范围显示，当前编辑曲线仍使用第一列刻度和原有缩放。另一层的虚线不参与点选或拖动。

两侧绿色短虚线都是最终叠加结果，拖动控制点和连续绘制时实时更新，无需先松手或重新合成。关闭偏移时实参侧的偏移参考会淡化，绿色结果按未叠加偏移的值显示；偏移侧仍显示实参。尚未生成实参时不会伪造实参曲线，DYN 等无对应预测的控制也不显示互参线。

### 自动预测的保存（内部更新 024）

试听完成后，自动生成的能量、气声、张力、实声值会作为预测快照随工程保存，重开可直接查看。自动快照继续允许修改音高后的自动重算；手动编辑实参和显式生成的实参仍保持原来的冻结规则。请在预测完成后保存工程。旧文件没有写入过的值需重新试听或生成一次，再保存。

### 工程同目录缓存（内部更新 025）

保存为 `diff.hjpx` 后，工程旁会出现 `diff.hjpx.ds-cache`。其中 `entries` 存放渲染音频和生成信息，`cache-info.json` 标识缓存格式。相同请求在重开后复用音频和音素、预测参数；模型、歌词、pitch、FLAG、时长和推理档位变化后，相关请求会重新生成。

未命名工程的缓存会在首次保存时迁入；另存为会复制已有缓存。迁移工程时可一并携带同名缓存文件夹。显式“重新生成”不读取旧预测；模型与程序依赖变化后缓存可能失效。缓存不是工程源码或模型备份，可以在关闭软件后删除，之后需要重新渲染。旧版未保留的渲染无法恢复，先在本版试听一次即可建立缓存。

### 音符右键重生成 FLAG（内部更新 027）

右键 DS 音符，选择“DS 局部重新生成 FLAG（预测实参）”。右键选区内音符时重算本轨选区，右键其他音符时只重算该音符；其余预测、pitch 和已有 FLAG 偏移保留，Ctrl+Z 可撤销。
