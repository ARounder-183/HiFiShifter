# WAV 音频导出（0.25，文档更新 034）

从“文件 → 导出 WAV”菜单选择全部轨道或单个轨道后，立即弹出“WAV 导出设置”，选择声道、位深和采样率。点击“下一步：保存位置…”后选择文件位置，确认保存才开始渲染和导出。菜单中不再提供单独的格式设置项。

每次导出都会弹出格式设置，即使使用上次相同的参数。“导出上次渲染音频”也使用相同顺序。全部轨道仍是每条可听轨道一个文件，同一批使用相同设置；上次渲染仍只输出上次框选的范围。

| 设置 | 选项 |
| --- | --- |
| 声道 | 单声道；双声道（立体声） |
| 位深 | 16 bit PCM；24 bit PCM；32 bit 浮点 |
| 采样率 | 跟随播放设备；8000、16000、22050、24000、32000、44100、48000、88200、96000、176400、192000 Hz |

首次默认双声道、24 bit、跟随播放设备。程序记住上次确认的选择，但不会跳过确认窗口。取消格式窗口不会打开保存窗口、开始渲染或改变已确认参数；取消保存窗口也不会写入音频。导出时不会修改工程的 MIDI、pitch、音素或包络。

单声道将最终左、右声道按 `(L + R) / 2` 混合，不会丢掉只在右声道的声音；双声道保留声像。采样率改变会实际转换输出采样，不改变歌曲时长和音高。提高采样率或位深不会恢复原素材已经丢失的细节。32 bit 是 IEEE 浮点 WAV，保留编辑器当前的混音与限幅行为。

DiffSinger 的“试听 / 导出质量”继续在“设置 → DiffSinger”中选择；WAV 格式决定文件的声道、采样率与位深，并不替代模型推理质量。普通 UTAU、DiffSinger 和音频轨道均使用同一导出格式设置。


## 高级：导出人声分量

在 WAV 导出设置里点击“高级”展开，提供“仅导出气声”和“仅导出非气声”。两项互斥；均不选时输出完整声音。折叠后仍显示所选分量，本次选择不会成为下次默认值。声道、采样率和位深继续记忆。

气声指合成引擎的非周期 / 噪声分量，可能包含清辅音和呼吸；非气声指对应的谐波 / 周期分量。这不是按高低频切分，也不是歌词中某几个音符的筛选。

| 当前合成路径 | 分量导出 |
| --- | --- |
| 原生 LLSM | 支持，读取同一次合成的噪声分量与谐波分量 |
| 原生 WORLD | 支持，从原有周期 / 非周期合成中分别输出；未经变调的素材也会为分量导出执行分析合成 |
| WCSNDM 0.0803，纯 K2（兼容 L2） | 支持，临时发送 Mx2 / Mx1，保留音符、分区与线性 FLAG；原工程 FLAG 不变 |
| WCSNDM K1、默认 V2、V1、M1、HF，或带 u / Mm 的路径 | 禁用，现有接口无法可靠给出完整的独立分量；不会替换内核 |
| DiffSinger、NSF-HiFiGAN、其他未提供分量的引擎、原始音频直接播放 | 禁用；调节气声参数不等于支持分量输出 |

可用性根据本次实际导出范围、音符的有效内核 FLAG、静音与独奏状态判断。单轨导出不受其他轨道限制；全部轨道中包含不支持的可听轨道时，两项禁用并显示原因。上次渲染范围沿用原选区规则。

分量使用独立渲染缓存，导出结束后恢复完整试听。合成失败、引擎不支持或缺少分量时终止导出，保留已有目标文件，不以原始素材或完整混音代替。

原生路径的音量、力度、气声后处理与响度校正使用完整信号的增益基准；WCSNDM 分量遵循引擎自身 Mx 与归一化设置。轨道声像、包络和最终限幅照常执行。不同次合成的随机噪声及每次导出的限幅可能不同，因此不保证分别导出的文件逐采样相加与一次完整导出完全一致。
