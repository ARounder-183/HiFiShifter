# HiFisampler（PC-NSF-HiFiGAN）

轨道或区域右键 → **选择输出引擎 → HiFisampler（PC-NSF-HiFiGAN）**。也可以在设置中将其设为 UTAU 默认输出引擎。调音模式继续选择 UTAU、界•UTAU、谋•UTAU，读取对应 OTO；界／谋的两、三、四段、C/V/S 分类、手动分段及高级音头／音尾包络继续生效。

实现来源：[openhachimi/hifisampler](https://github.com/openhachimi/hifisampler)，固定源码提交 `8c34d86110edc3a72bac9378ea482c4ed69da9bf`。移植其实际实现的 10 项 FLAG，保留 Apache-2.0 许可和来源说明。解析器中出现但上游没有实现处理的旧 FLAG 不视为支持。

| FLAG | 范围 | 默认 / 作用 |
| --- | --- | --- |
| g | -600～600 | 0；按上游可变 FFT 窗口提取 Mel，调整共振峰 |
| Hb | 0～500 | 100；气声／噪声比例 |
| Hv | 0～150 | 100；谐波／实声比例 |
| Ht | -100～100 | 0；对分离出的谐波施加频谱张力处理 |
| HG | 0～100 | 0；80 Hz 方波调制高频声带，产生嘶吼／沙哑效果 |
| P | 0～100 | 写 P 或 P100 时完整归一化至 -16 LUFS；P0 关闭 |
| t | -1200～1200 | 0；音分偏移，叠加到目标 F0 |
| A | -100～100 | 0；根据目标音高变化率调制振幅 |
| G | 无数值 | 本次合成忽略声学特征与谐波分离缓存，重新生成 |
| He | 无数值 | 手动启用 Mel 反射循环延长；不输入时按 OTO 拉伸 |

数值 FLAG 使用整数，上下限会截断。可以连续输入，例如 `g120Hb60Hv110Ht20HG10P80t-30A20`。同名 FLAG 第一次出现优先：音符覆盖全局，分区覆盖音符。开启参数曲线后，有曲线的参数覆盖同名文本 FLAG。

与上游实际代码一致，未写 `P` 不启动响度归一化；裸 `P` 表示强度 100。绘制 P 曲线也启动该处理。上游 `loudness_norm` 附加的尾部淡出没有叠加到这里，响度测量可截去静音，但音头／音尾仍由编辑器 OTO 包络控制。峰值限制在效果处理后执行。Hb 与 Hv 都为 0 时，该段保持静音。

**参数曲线：**选中音符 → 开启线性flag → 打开 flag 包络 → 选择 g、Hb、Hv、Ht、HG、P、t、A。界面根据实际输出引擎切换范围。HiFisampler 曲线以 `HIFI:` 前缀独立保存，保留原有 WCSNDM 曲线；旧的同名曲线也可读取，显式 HIFI 曲线优先。G、He 是开关，在 FLAG 文本中输入。 在 HiFisampler 通道清空／重置旧曲线后会恢复文本和分区 FLAG，清空状态随工程保存；旧 WCSNDM 同名曲线保留，切回传统引擎仍可使用。

**分区：**分区时长与 OTO 分类沿用编辑器的映射。默认将每一区完整的源片段线性拉伸或压缩至该区目标时长，读取一次，不循环；固定 C／S 段仍按辅音速度处理。普通 OTO 的元音段、界／谋的两、三、四段及手动分区使用同一规则。只有显式输入 He 才在需要延长的可伸缩段中反射循环，不循环固定 C／S 段，也不跨越其他分区。该时间映射是面向界／谋 OTO 的编辑器扩展，不声称整句输出与上游独立 resampler 逐样本一致。

**模型与缓存：**原 PC-NSF-HiFiGAN 模型继续使用。Hb≠Hv 或 Ht≠0 时加载新增 `models/nsf_hifigan/hnsep/model.onnx`。其权重取自官方 v0.0.6 models.7z，使用上游封装导出为 float32 ONNX，大小 59,053,378 字节（约 56.3 MiB）。默认 Hb=Hv=100、Ht=0 时不加载该分离模型。无需 Python 渲染服务，也不在音源目录中写入缓存。缓存限制内存并计入相关参数和模型信息。

更新 178：上述内存缓存之外，分离波形与 HN1 共用磁盘缓存；严格校验实际 PCM、模型、配置内容和算法版本。默认用户缓存目录预算 512 MiB，G 同时跳过两级缓存，细节见 [HN 模式说明](wcsndm-hn.md)。

`models/nsf_hifigan/hifisampler.json` 可设置：

```json
{"loop_mode": false, "wave_norm": true, "trim_silence": true}
```

编辑器音源渲染始终默认拉伸；旧配置的 loop_mode（包括 true）不再覆盖 OTO 时间映射，保留该字段仅为兼容旧模型包。He 可针对音符或分区手动开启循环。wave_norm 控制 P 是否生效，trim_silence 只影响响度测量。

**MCP：**`output_engine` 的兼容键仍为 `pc-nsf-hifigan`；实际后端名称为 `hifisampler-native-voicebank`。`utau_flags` 与 `region_flags` 使用上述文本 FLAG。`flag_curve.flag` 使用 `HIFI:g`、`HIFI:Hb`、`HIFI:Hv`、`HIFI:Ht`、`HIFI:HG`、`HIFI:P`、`HIFI:t`、`HIFI:A`。旧工程与全局默认设置继续兼容。WCSNDM 特有的 HF、V、Mt 等参数不会误识别成这些 FLAG，使用时会提示。

**音符拉长后的响度包络：**HiFisampler 与传统 UTAU 共用包络时长适配。起音跟随实际先行时间，收尾跟随当前音符及相邻音符的交接位置；保留原起音／收尾斜坡的长度，不改写工程中的控制点。避免旧包络在拉长音符的中途结束并持续静音。高级音头／音尾效果仍在适配后的包络上生效。

**引擎标识：**上方区域标题及左侧轨道标题显示实际输出引擎名称。区域标题以引擎标识开头，悬停可查看完整标题；重采样器显示所选 EXE 文件名，跟随设置时显示当前默认引擎。伴奏区域不显示合成引擎。

**首段发音排查：**第一段输出时长由实际先行时间决定，其源长度由 OTO 分段决定，两者不一致会压缩或拉长声母。He 只循环可伸缩区，C／S 类分区不循环。默认仍按各区源片段读取一次；当前没有额外修改首段音素或强制改变其有声／无声属性。

**真实上下文与帧位置：**完整录音用于 Mel／HN-SEP 分析，OTO 区域仍按现有多段规则拉伸。模型边缘取 OTO 截取点前后的真实录音特征；不足时保持录音边界帧，不把音符内部反向复制为上下文。目标 Mel 使用半 hop 中心，音高及 FLAG 网格、音符位置和输出时长不变。

**缓存刷新：**修改或替换音源 WAV 后，在下一次工程同步／渲染请求中检查文件修改时间与大小，并更新实际录音时长。输入 G 后，重新选择音符或请求导出会生成新片段，并重新计算声学特征及所需的 HN-SEP 分离；一次请求期间的界面刷新不会重复渲染。仅原位修改但刻意保留文件大小与修改时间时，请使用 G 强制重算。
