# 按播放位置优先渲染

更新 059，对外版本仍为 0.25。自动启用，无需额外设置。

- 优先处理覆盖播放位置的区域，其次是播放位置之后由近到远的区域，最后处理已经经过的区域。同位置的任务保持提交顺序。
- 停止时移动红线、播放中跳转，以及正常播放向前推进，都会更新待处理任务的优先级。选区试听先确定起点，再提交该次渲染。
- 普通 UTAU 在区域内部也按此规则选择下一个待合成音符；音符原始顺序、相邻音符关系、OTO、FLAG、包络和混音顺序不变。
- DiffSinger 保留整份区域请求及未选音符的上下文，按区域调整先后。不会为了排序切开音节、延音或预测上下文。一个大区域仍需要等这份请求完成才能播放，尚未增加区域内部的 DS 流式输出。
- 播放前只等待播放位置附近 0.75 秒内涉及的区域。远处尚未完成的区域继续在后台处理；播放到未完成的区域时，整条时间轴暂停推进，人声和伴奏一起等待，完成后自动继续。导出仍要求全部请求完成。
- 跳转不强行中断正在执行的合成。新的优先级在工作线程领取下一项任务、普通 UTAU 领取下一个音符时生效。已完成的声音缓存继续复用。
- 工程或选区更新时清理不再需要的排队任务。DiffSinger、外部 UTAU 引擎、LLSM 和神经合成分别串行执行各自的区域请求，避免同类任务占满工作线程等待引擎锁；其他可并行任务最多同时运行四项。
- 原音试听使用独立的位置，不会把歌曲渲染的优先位置移到采样的开头。伴奏依然直接播放，不进入调音渲染队列。

验证入口：`--smoke-playback-priority <测试输出目录> <priority-resampler-probe.exe>`。测试覆盖动态排序、同位置稳定顺序、串行引擎隔离、过期任务清理、取消与复用、实际 UTAU 引擎调用顺序、音频一致性、缓存复用、边播放边渲染、等待时的时间轴同步、导出完整性和原音试听位置恢复。
