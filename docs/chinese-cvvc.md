更新 162：修复旧 CVVC 工程保存的整音符默认分贝包络继续叠乘，造成句首弯曲起音和收尾弯曲淡出。ProjectModel::fromValueTree 仅对缺少 cvvcEnvelopeVersion、无高级包络及 UST 原始段的中文 CVVC 音符，识别四点 0 dB 平台、5/15 ms 起音、35 ms 收尾的历史默认形状，恢复为各音素独立标准梯形。新工程保存 cvvcEnvelopeVersion=1；现代显式曲线、非标准时长／音量、线性手绘和非 CVVC 曲线保持。音频与拼字混音缓存版本同步更新。真实“CVVC测试”工程专项覆盖修复前失败、保存重开、首尾像素位置、两种交叉方式逐采样增益及 HiFiSampler／WCSNDM 合成。

适用版本：0.25，内部更新 165（2026-10-14；基础实现为更新 112）。这是根据 OpenUtau 中文 CVVC 规则适配的原生 C++ 发音器；不是加载 OpenUtau 插件 DLL。

## 使用

1. 轨道选择标准 **UTAU**，选择带有 `oto.ini` 和 `presamp.ini` 的中文 CVVC 音源。
2. 点击 **拉伸算法下方的“发音器：手动别名” → 中文 CVVC**。也可右键轨道或区域 → **发音器 → 中文 CVVC**。两处是同一设置，按钮显示当前选择；仅标准 UTAU 显示。旧工程与新轨道仍默认 **手动别名**；可随时切回，切换支持撤销。
3. 每个音符填写一个拼音音节，也支持现有拼音表中的单个汉字。选择需要试听的音符后渲染。
4. 输出引擎可以是外部重采样器，也可以是 HiFisampler（PC-NSF-HiFiGAN）。两者使用同一份发音编排。

设置按轨道保存在工程中。当前只在标准 UTAU 生效；切换到界、谋或 DiffSinger 时停用，保存的发音器选择不会丢失。

## 音源要求

音源根目录的 `presamp.ini` 至少提供 `[VOWEL]` 和 `[CONSONANT]`；支持 `[REPLACE]` 的精确替换。示例（必须与实际 OTO 别名相符）：

```ini
[VOWEL]
a=A=a,ba,pa=100
i=I=i,bi,pi=100
[CONSONANT]
b=ba,bi=1
p=pa,pi=1
[REPLACE]
bah=ba
```

支持 UTF-8 及音源的传统文本编码设置；在没有显式编码设置、默认解码失败时，对中文 presamp 增加 GBK 重试。配置文件不会被改写。配置缺失或无法构成有效规则时，渲染保留手动别名并报告原因。

不需要 `oto4.ini` 或 `otomou.ini`。普通 `oto.ini` 的先行发声、重叠和 `prefix.map` 是发音安排的基础。

## 实际行为

- 先尝试配置的完整连接别名，再尝试 VC + CV；未配置时为“前元音 + 空格 + 当前音节”，句首为 `-`。`[PRIORITY]` 中逐个列出的音节优先 VC + CV，不匹配其整段 VCV。
- 例如相邻歌词 `a → ba`、音源存在对应条目时，内部安排为 `a → a b → ba`。VC 属于后一个歌词音符，位置可以在其名义起点之前。
- VC 时长参考当前 CV 的先行发声、零／负重叠、辅音速度、局部 BPM，并限制在前一个音符的可用时长内。
- 句末存在配置指定的收尾音时自动安排收尾，默认 `元音 R`；显式 `R` 或 `-` 使用同一格式查询前元音的收尾音。`RR` 保持本编辑器的休止符含义。
- 缺少 VC 时使用 CV；缺少 CV 时报告缺失并保持该段静音，不把任意单素材错误当成 CV。原手动模式的单素材回退仍保留。
- 多音高音源先按 `prefix.map` 查找。VC 使用前音符音高选择录音，CV 使用当前音符音高；已经解析的别名不会再次套用前后缀。
- 空隙和休止符切断相邻发音上下文。含空格的完整别名或 `[别名]` 可以直接指定素材、绕过自动拆分。
- 原歌词、音符 ID、位置和音符数量不改变。生成片段共享父音符音高；未编辑的 FLAG／响度继承父曲线，编辑后各片段分别读取自己的曲线。波形在渲染后归并回原音符，片段分界可见，悬停显示别名。
- 框选试听保留同一区域内未选音符的上下文和 OTO 衔接参数，但不合成、不播放这些未选音符。发音方式、音符上下文、presamp 和 prefix.map 变更会影响缓存。

## 当前边界

### 发音片段响度与 FLAG（更新 153）

先渲染生成片段后，响度包络与线性 FLAG 包络中分别显示 VC、CV／VCV 和收尾的名称、范围及控制点。单击选片段，双击曲线加点，拖动调整时间与数值，右键删除内部点；Shift 可精细调整数值，Esc 放弃当前拖动。端点标记该片段的编辑范围，可上下调整。FLAG 仍需开启原来的“线性 flag”；连续绘制时只改起笔的片段。

先行发声可能与相邻片段重叠，选中的片段更亮，并绘制在其他片段上层；可点击顶部不同高度的片段名称选择。新增数据保存在工程中，不修改音源 OTO。原歌词音符仍是移动、音高、歌词和时长编辑的整体，各片段的曲线随重新规划的范围变化。缺失或暂时不生成的角色保留数据，但不参与合成；切回手动发音模式时不应用这些数据。

没有单独编辑过的片段：存在明确保存的父响度曲线时沿用原曲线，否则使用更新 155 的独立标准梯形；FLAG 继续继承原曲线。修改一个片段不会写入其他片段。整音符应用响度预设会覆盖其分片响度设置；FLAG 重置仅清除指定参数，两个输出引擎的数据保持区分。改变包络后旧波形暂不显示，重新渲染后显示实际分片混合结果。

### 初始包络（更新 155）

未编辑的 CV、VC、CV／VCV 与收尾片段，各自生成独立的标准四点包络：5 ms 直线淡入、100% 平台、35 ms 直线淡出。这里的“直线”是线性音量百分比，不是 dB 插值，因此不会生成指数式的弯曲尾部。极短片段使用起点、1/3、2/3、终点，防止控制点倒序。

已有明确保存的父音符包络（含导入曲线）与分片手动覆盖保持原样，不通过形状猜测并重置用户数据。旧工程中没有保存包络的片段也使用新默认值；看图、渲染不会往工程中写入默认控制点，第一次编辑才保存。基准音量只乘一次。

自动交叉淡化仍按真实混音叠加在默认包络上，因等功率交叉或去爆音处理，实线局部可以不同于手动虚线的直线梯形。

### 交叉淡化显示（更新 154）

响度包络会显示渲染器实际计算的自动淡化，不需要额外开启：

- 橙色 CV／VCV、青色 VC、紫色收尾，交叉区域带有淡色背景；单击片段名称或曲线选中后提高亮度。
- **实线**是手动响度包络乘上自动淡入／淡出；能同时看到前片段下降、后片段上升。**虚线与圆点**保留手动包络，拖动圆点仍编辑原始响度，自动淡化不会再次写入控制点。
- 线性／等功率曲线和实际起止时刻取自所选输出引擎：传统 UTAU 遵循拼接设置，HiFisampler 使用等功率交叉。不从音符矩形的接缝猜测 OTO 重叠长度，也不在绘制时扫描音源。
- 首次尚未渲染，或邻音时序／输出引擎改变后，先显示手动包络并提示等待；新渲染完成后显示交叉。编辑响度时，实线立即跟随手动曲线更新，支持原来的保存、撤销和 FLAG 编辑。

该曲线表示每个片段的手动响度与自动混音增益，不是叠加后音频的瞬时响度、全曲峰值归一化或单独高级音头／音尾包络的读数。自动增益只作为渲染元数据，不写进工程；本更新保持合成策略不变。HiFisampler 的 CVVC 波形预览也纳入相同交叉增益。

已观察到的原有混音边界：HiFisampler 对前片段的衰减只作用于后片段的 overlap 窗口；若前片段 PCM 超出该窗口仍未结束，后续仍会参与叠加。显示会如实画出恢复的部分，不将其伪画为永久淡出。传统 UTAU 的序列淡出则保持为零。本次没有改变这项声音行为。

### presamp 配置与拼写（更新 152）

实际解析 `[VOWEL]`、`[CONSONANT]`、`[REPLACE]`。VOWEL 第一个字段是输出元音符号，不能把不同方案的 `v`、`v0`、`e0` 等分组强行合并。CONSONANT 的分组名也由音源定义，例如东方栀子使用 `ny/ly/jw/shw`，其他方案可能使用 `n/l/j/sh`。

对普通中文音节支持四组等价拼写：`nve/nue/nüe/nu:e`、`lve/lue/lüe/lu:e`、`nv/nü/nu:`、`lv/lü/lu:`。先用原始 CV 或连接别名；均不存在且没有显式 REPLACE 时，才按当前音高寻找音源规则与 OTO 同时支持的等价拼写。元／辅音表中缺失的拼写只能继承同组一致的定义；已有定义不覆盖，冲突不猜测。拼写选择同步用于后续 VC 和句尾元音。`[别名]`、带空格的显式别名和显式 REPLACE 不被此规则改写。工程歌词与音源文件均不修改。

更新 152 增加以下配置驱动的拼写，不需要为 Risku、Hr.J 等名称分别选择发音器：

| 设置 | 实际作用 |
| --- | --- |
| `[ALIAS]` 的 `CV`、`VC`、`VCV`、`BEGINING_CV`、`ENDING1` | 各类别名模板；逗号分隔候选，按顺序选择真实 OTO 中存在的项 |
| `%v%`、`%V%`、`%c%`、`%CV%` | 前元音（收尾为当前元音）、当前音节的代表元音、辅音组、当前音节；大小写有意义 |
| `VCPAD`、`VCVPAD` 与对应占位符 | VC／VCV 分隔符，可为空格、多个空格、下划线、加号或空字符串；占位符接受大小写写法 |
| `[VCPAD]`、`[ENDTYPE]`、`[ENDTYPE1]` | 旧格式配置；独立段优先于 ALIAS，ENDTYPE1 优先于 ENDTYPE，与文件先后顺序无关 |
| `[PRIORITY]` | 精确音节列表，跳过其 VCV，使用 VC + CV；不将辅音组名自动扩展为全部音节 |

例如 `VC=%v%%VCPAD%%c%` 配合 `VCPAD=+` 会查询 `a+b`；`CV=%CV%,%c%%V%` 可依次查询 `ba` 与该音源定义的 `bA`；`ENDING1=%v%_tail` 查询 `a_tail`。格式明确指定后，不暗中换回原来的空格拼法。未知占位符不会生成伪别名。未提供模板时保留原 ZH CVVC 行为，不强行增加日语 Presamp 的默认候选。手写别名绕过模板；所有配置只读。

自动发音的 OTO 查询与后续已解析片段合成优先区分大小写，避免 `ba`／`bA`、`a r`／`a R` 混用。精确项不存在时保留原大小写兼容查询；手动模式仍沿用旧查询规则。新增索引在既有后台音源索引中一次构建，不在工具栏打开时扫描音源。中文 CVVC 的工程音频缓存增加规则修订标识，避免沿用更新前的整段渲染。

这不是完整 Presamp 插件移植：仍不执行 `[SU]`、`[PITCH]`、`[ENDFLAG]`、`[MUSTVC]`、ALIAS_PRIORITY 以及 CROSS_CV／LONG_V／ENDING2，也不使用 VOWEL 音量或 CONSONANT flag。自动收尾时机仍沿用 ZH CVVC，音阶映射来自 `prefix.map`。2026-10-14 核对的 OpenUtau ZH CVVC 主要使用三张音节表；本次额外参考其 Presamp 配置格式，不能把 JA Presamp 的完整行为当作中文发音器的实现。

本机东方栀子 Era 的 VOWEL 写 `nue/lue`，CONSONANT 和 OTO 写 `nve/lve`；新逻辑在内存中衔接两者，无需修改这份音源。没有 presamp 或有效元辅音表时仍报告配置不足，不套用其他音源的整套字典。

### 其他边界

本版针对**一音符一音节、同一区域内的中文 CVVC**。汉字使用编辑器现有的常用单字读音，不具备 OpenUtau 的完整上下文多音字转换；建议多音字直接填写拼音。未实现多字歌词自动分配、`+` 连音组展开、跨区域自动发音衔接，以及 OpenUtau voice color/subbank 元数据。

发音片段支持独立响度和 FLAG 编辑；尚无独立的逐音素时长编辑器，时长仍通过原音符参数、歌词别名与单音 OTO 覆盖调整。本功能不等于日语 CVVC、韩语 CVC 或其他语言发音器。

### 音头拖动（更新 158）

修复 CVVC 音头拖动时预览与松手后位置不一致：按 VC 提前量及实际 OTO 先行声共同反推辅音速度，负值和超过 200 的值遵循合成器时序，保留源音频与相邻音符的时长限制。拖动只改变辅音速度；音符节拍位置不变。整数速度可表达的最接近位置即为最终预览，达到源音频或前音时长边界后不再继续延伸。

## 音素标签与单独包络编辑（更新 160）

音符上方的小标签可直接选择 VC、CV 或尾音，与“显示→拼字信息”的常驻文字选项独立。标签高亮后，响度预设、下方响度控制点和线性 FLAG 编辑只作用于该音素；其他音素的实际曲线淡显。点击音符主体恢复整音符选择。音素属于原来的乐谱音符，时长与歌词仍由主体管理；没有复制或拆成新的乐谱音符。高级 OTO 音头／尾部设置属于整音符，音素选区下点击高级包络会聚焦独立响度面板。

实线仍表示手动包络与自动交叉淡化相乘的实际结果，虚线和圆点表示可编辑的手动值；选中音素后只保留该音素的这些编辑辅助线。不会为让显示变直而更改真实自动混音曲线。

## 默认包络和交叉方式（更新 161）

在发音器菜单选择“默认交叉方式→直线／曲线”。按轨道保存，初始为直线，两种输出引擎共用。曲线为首尾平滑的互补曲线。新音素独立使用 5 ms 起音／35 ms 释放的标准直线梯形，短音采用三等分。遇到交叉时，对应边缘由交叉窗接管，不再次叠加标准淡化；孤立头尾继续保持标准梯形。已有非标准手绘包络保留，仍作为用户的幅度控制参与合成。

选中整个 CVVC 音符点击“标准”，会为每个音素分别应用同一套梯形规则，支持一次撤销。若只选小标签，则只重置该音素。派生混音缓存随规则与菜单选择失效；无须修改源音源库。

### 拖动音素分界（更新 164）

音符内部的竖线带有小握柄，鼠标靠近时显示左右拖动光标。在默认编辑、响度或 FLAG 模式均可拖动；向左拖动尾音开始线可延长尾音，向右可缩短尾音，前一音素反向调整。音符整体起止不动，OTO 的交叉重叠仍由合成器计算。仅支持同一音符内部已有的相邻音素；整音符间的边界保持原编辑方式。拖动中按 Esc 取消，松开后一次撤销可恢复。手动分界随工程保存，拉伸音符时按比例变化；改词后不存在的角色覆盖不参与规划。
