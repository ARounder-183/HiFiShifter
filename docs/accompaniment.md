# 伴奏轨道

适用版本：0.25，文档更新 145。

## 创建与导入

1. 选择“轨道 → 新建伴奏轨道”，或在轨道区域空白处右键选择“新建伴奏轨道”。
2. 选中新轨道，使用“文件 → 导入音频”，也可把音频文件直接拖到该轨道。
3. 同时导入多个文件时按顺序接在该轨道上；片段可在时间线上移动、裁剪。

轨道名称旁显示“伴奏轨道”，变调算法显示“原音播放”，拉伸算法显示“不启用”。音符调音编辑被禁用，切回人声轨道即可恢复。

## 播放与导出

- 直接播放源音频，不启动音高分析或任何合成、变调、时间拉伸引擎，也不把源文件旁的调音标记转换为音符。
- 保留源音频的音高与速度。缩短片段会裁掉播放范围；延长到源文件以外的部分不会自动拉伸或循环音频。
- 保留片段 / 轨道音量、声像、静音、独奏与淡入淡出等混音控制，随工程播放，不要求保持选中。
- 单轨及全部轨道 WAV 导出都包含可听的伴奏轨道，声道、采样率与位深仍按本次导出设置处理。音频文件需保留在原位置，或重新链接。
- 伴奏不能导出引擎的气声 / 非气声合成分量，包含伴奏的导出范围会禁用这两个高级选项。
- 轨道类型随工程保存；创建可撤销 / 重做。旧工程没有伴奏标记时保持原行为。

## 识别曲速

在伴奏轨道的音频片段上右键，选择“识别曲速”。后台调用已有的 Beat This! small0，结果窗口显示估计 BPM。只分析这个片段当前可见的音频范围，支持裁剪和合并片段；模型不足以判断时明确显示失败，不返回默认工程 BPM。

该功能仅查看，不修改工程曲速、拍号、音频位置、长度、音符或撤销记录。曲速可能存在半速／倍速歧义；明显变速素材显示整体估计与变化提示。可以取消，关闭结果窗口或退出程序会回收该分析进程。一个窗口中重复点击会置前已有的分析窗口，关闭后可分析另一片段。

沿用 `engines/hamood/runtime.json` 的 Python 和已有 `models/beat-this-small0.ckpt`，不下载或训练新模型，也不运行和弦模型。运行环境缺失时在窗口内说明原因。

## MCP

`add_track` 增加可选参数 `accompaniment: true`，会覆盖 `compose` 为 false。查询工程可读到 `accompaniment: true`，`pitch_algorithm` 和 `stretch_algorithm` 为 `none`。`set_track` 可调节音量 / 声像 / 静音 / 独奏等，但不能启用调音引擎。
